# Second conditional

## Uso

Para situações **hipotéticas ou improváveis** no presente ou no futuro.

## Estrutura

**If + Simple Past, would + verbo base**

- If I **won** the lottery, I **would travel** the world.
- If she **had** more time, she **would learn** Spanish.
- What would you do if you **found** a million dollars?

Atenção: o passado depois de *if* não se refere ao tempo passado, mas ao grau de irrealidade.

## O verbo to be

Usa-se **were** para todas as pessoas: *If I were a bird, I would fly.* *If I were you, I would study more.*

## Comparação entre condicionais

- **Zero:** fato geral. If you heat ice, it melts.
- **First:** possibilidade real. If it rains, I will stay home.
- **Second:** hipótese. If I had wings, I would fly to school.

## Ordem das orações

*I would help everyone if I were rich.* A vírgula só é usada quando *if* vem primeiro.
