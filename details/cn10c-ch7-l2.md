# 氮及其化合物

## 氮的氧化物

- N₂ 化学性质稳定；N₂ + O₂ =(放电)= 2NO；
- NO（无色）遇空气变成 NO₂（红棕色）：2NO + O₂ = 2NO₂；
- 3NO₂ + H₂O = 2HNO₃ + NO。

## 氨

- 无色、有刺激性气味的气体，**极易溶于水**（喷泉实验），易液化；
- NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻，水溶液显碱性，能使湿润的红色石蕊试纸变蓝；
- **实验室制取：** 2NH₄Cl + Ca(OH)₂ =(△)= CaCl₂ + 2NH₃↑ + 2H₂O，向下排空气法收集，用碱石灰干燥。

## 铵盐

受热易分解，与碱共热放出氨气：NH₄⁺ + OH⁻ =(△)= NH₃↑ + H₂O（用来检验 NH₄⁺）。

## 硝酸

有强氧化性：

- Cu + 4HNO₃（浓）= Cu(NO₃)₂ + 2NO₂↑ + 2H₂O；
- 3Cu + 8HNO₃（稀）= 3Cu(NO₃)₂ + 2NO↑ + 4H₂O。
