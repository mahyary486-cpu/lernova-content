# Mathematical Induction and the Binomial Theorem

## Mathematical induction
Induction proves that a statement P(n) is true for every positive integer n. It works like a line of dominoes.
1. **Base case:** show P(1) is true.
2. **Inductive step:** assume P(k) is true for some integer k (the inductive hypothesis), then show P(k + 1) must also be true.
If both parts hold, P(n) is true for all positive integers n.

## Binomial theorem
**(a + b)^n = sum of C(n, k) a^(n-k) b^k, for k = 0 to n**
- C(n, k) = n! / (k!(n - k)!) counts the ways to choose k items from n.
- The expansion has **n + 1 terms**.
- The coefficients are row n of **Pascal's triangle**: 1, 1; 1, 2, 1; 1, 3, 3, 1; 1, 4, 6, 4, 1; and so on.
- The general term (the term with b^k) is C(n, k) a^(n-k) b^k.
- The coefficients are symmetric: C(n, k) = C(n, n - k). Their sum is 2^n.

## Worked examples
1. Prove that 1 + 2 + ... + n = n(n + 1) / 2.
   1. Base case: n = 1 gives 1 and 1 x 2 / 2 = 1, so it is true.
   2. Assume 1 + ... + k = k(k + 1) / 2.
   3. Add k + 1 to both sides: k(k + 1) / 2 + (k + 1) = (k + 1)(k + 2) / 2.
   4. This is the formula for n = k + 1, so the proof is complete.
2. Expand (x + 2)^4.
   1. The coefficients are 1, 4, 6, 4, 1.
   2. Terms: x^4 + 4(x^3)(2) + 6(x^2)(4) + 4(x)(8) + 16.
   3. Result: x^4 + 8x^3 + 24x^2 + 32x + 16.
3. Find the coefficient of x^3 in (2x + 1)^5.
   1. The term with x^3 is C(5, 3)(2x)^3(1)^2.
   2. C(5, 3) = 10 and (2x)^3 = 8x^3.
   3. The coefficient is 10 x 8 = 80.
4. Evaluate C(7, 2) = 7! / (2! x 5!) = 7 x 6 / 2 = 21.

## Common mistakes
- Skipping the base case, or checking many cases and calling it a proof. Examples never prove a statement for all n.
- In the inductive step, assuming P(k + 1) instead of proving it.
- Forgetting to raise the coefficient of the first term to a power: (2x)^3 is 8x^3, not 2x^3.
- Sign errors in (a - b)^n: the signs alternate, + - + - ...
- Miscounting terms: (a + b)^n has n + 1 terms.
