# Limits Introduced Graphically and Numerically

## The idea of a limit
The limit of f(x) as x approaches a is the value that f(x) gets close to when x gets close to a, from both sides. We write **lim (x to a) f(x) = L**. The limit describes what happens near a, not necessarily at a. The function does not even need to be defined at a.

## Finding limits numerically
Make a table of x values closer and closer to a on each side and watch f(x).

For f(x) = (x^2 - 1) / (x - 1), f(1) is undefined. But:
- f(0.9) = 1.9, f(0.99) = 1.99, f(0.999) = 1.999
- f(1.1) = 2.1, f(1.01) = 2.01, f(1.001) = 2.001
So the limit as x approaches 1 is 2.

## Finding limits graphically
Trace the graph toward x = a from the left and from the right. If both paths head to the same height, that height is the limit. An open circle at that height does not change the limit.

## One-sided limits
- **Left-hand limit:** x approaches a from values below a, written lim (x to a-) f(x).
- **Right-hand limit:** x approaches a from values above a, written lim (x to a+) f(x).
- The two-sided limit exists **only if both one-sided limits exist and are equal**.

## When a limit does not exist
- The left and right limits are different (a jump).
- The function grows without bound near a (a vertical asymptote), written as infinity. We say the limit is infinity or does not exist as a finite number.
- The function oscillates forever, like sin(1/x) near 0.

## Limits at infinity
lim (x to infinity) f(x) describes the end behavior. For example, lim (x to infinity) 1/x = 0, and lim (x to infinity) (3x + 1) / (x + 2) = 3, a horizontal asymptote at y = 3.

## Worked examples
1. A function has f(2) = 5, but f(x) approaches 3 from both sides as x approaches 2. Then the limit is **3**, not 5.
2. Let f(x) = x + 1 for x less than 2 and f(x) = x^2 for x of 2 or more. The left limit at 2 is 3, the right limit is 4. They differ, so the limit **does not exist**.
3. Find lim (x to 0) 1/x^2. As x gets near 0, 1/x^2 becomes huge and positive from both sides, so the limit is **infinity**.

## Common mistakes
- Thinking the limit equals f(a). They can differ, or f(a) may not exist.
- Checking only one side.
- Saying a limit "equals infinity" and treating infinity as a real number.
