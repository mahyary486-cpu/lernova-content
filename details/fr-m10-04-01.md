# Fonctions affines : variations et signe

## Rappel
Une fonction affine est de la forme f(x) = ax + b. Sa courbe est une droite de coefficient directeur a et d’ordonnée à l’origine b.

## Variations
- Si a > 0, f est strictement croissante sur ℝ.
- Si a < 0, f est strictement décroissante sur ℝ.
- Si a = 0, f est constante.
Exemple : f(x) = −3x + 2 est décroissante, g(x) = 4x est croissante.

## Signe
f(x) = ax + b s’annule en x = −b/a.
- Si a > 0 : f(x) < 0 avant −b/a et f(x) > 0 après.
- Si a < 0 : f(x) > 0 avant −b/a et f(x) < 0 après.
Exemple : f(x) = −2x + 6 s’annule en x = 3 ; elle est positive pour x < 3 et négative pour x > 3.

## Retrouver a et b
Si on connaît f(x1) et f(x2), a = (f(x2) − f(x1))/(x2 − x1), puis b = f(x1) − a × x1.
Exemple : f(1) = 5 et f(3) = 11 donnent a = 3 et b = 2.

## Erreur fréquente
Confondre le signe du coefficient directeur (qui donne le sens de variation) avec le signe de f(x).
