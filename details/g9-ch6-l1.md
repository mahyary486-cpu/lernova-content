# Graphing Quadratic Functions

A quadratic function has the form **y = ax^2 + bx + c** with a not equal to 0. Its graph is a U-shaped curve called a **parabola**.

## Key features
- **Direction:** if a > 0 the parabola opens up and has a minimum; if a < 0 it opens down and has a maximum.
- **Axis of symmetry:** the vertical line x = -b/(2a).
- **Vertex:** the turning point. Its x-coordinate is -b/(2a); substitute it into the function to get y.
- **y-intercept:** the point (0, c).
- **x-intercepts (zeros):** where y = 0. There can be two, one or none.
- **Width:** a larger |a| makes the parabola narrower.

## Vertex form
y = a(x - h)^2 + k has vertex (h, k) and axis x = h.

## Worked examples
**Example 1.** Graph y = x^2 - 4x + 3.
1. a = 1 > 0, so it opens up.
2. Axis: x = -(-4)/(2*1) = 2.
3. Vertex: y = 4 - 8 + 3 = -1, so (2, -1).
4. y-intercept: (0, 3).
5. x-intercepts: x^2 - 4x + 3 = (x - 1)(x - 3) = 0, so x = 1 and x = 3.
6. Plot these points and the mirror image of (0, 3), which is (4, 3), then draw the curve.

**Example 2.** Find the vertex of y = -2x^2 + 8x + 1.
1. x = -8/(2*(-2)) = 2.
2. y = -2(4) + 16 + 1 = 9.
3. Vertex (2, 9). Since a < 0, this is the maximum value.

**Example 3.** State the vertex of y = 3(x + 1)^2 - 5.
Write it as 3(x - (-1))^2 + (-5). The vertex is (-1, -5).

## Domain and range
The domain is all real numbers. For Example 1 the range is y >= -1.

## Common mistakes
- Forgetting the negative sign in -b/(2a).
- Reading the vertex of y = (x + 1)^2 as (1, 0). It is (-1, 0).
- Stopping at the x-coordinate and not finding y.
- Drawing a parabola with a pointed bottom instead of a smooth curve.
