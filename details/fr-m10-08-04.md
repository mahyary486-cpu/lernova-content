# Fonctions et listes en Python

## Fonctions
def f(x):
    return 2*x + 1
f(3) vaut 7. Le mot-clé def définit la fonction, return renvoie le résultat.
Une fonction peut contenir une boucle :
def g(n):
    s = 0
    for k in range(n):
        s = s + k
    return s
g(5) vaut 0 + 1 + 2 + 3 + 4 = 10.

## Listes
L = [4, 7, 9]
- L[0] vaut 4, L[1] vaut 7 : les indices commencent à 0.
- len(L) vaut 3 : le nombre d’éléments.
- L.append(10) ajoute 10 à la fin : L = [4, 7, 9, 10].
- max(L) vaut 9 et min(L) vaut 4.
- sum(L) vaut 20.

## Parcourir une liste
for x in L:
    print(x)
Calculer une moyenne : sum(L)/len(L).

## Construire une liste de carrés
L = []
for i in range(1, 6):
    L.append(i ** 2)
On obtient [1, 4, 9, 16, 25].

## Bonnes pratiques
Donner des noms clairs, tester la fonction avec plusieurs valeurs, vérifier les cas limites.

## Erreur fréquente
Oublier return : la fonction ne renvoie rien (elle renvoie None) et on ne peut pas utiliser son résultat.
