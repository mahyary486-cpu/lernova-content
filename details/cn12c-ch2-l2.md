# 离子反应综合与离子推断

## 离子不能大量共存的情况

- 生成**沉淀**：Ba²⁺ 与 SO₄²⁻，Ag⁺ 与 Cl⁻；
- 生成**气体**：H⁺ 与 CO₃²⁻、HCO₃⁻；
- 生成**弱电解质**：H⁺ 与 OH⁻、CH₃COO⁻；
- **氧化还原**：Fe³⁺ 与 I⁻，MnO₄⁻、H⁺ 与 Fe²⁺；
- **双水解**：Al³⁺ 与 HCO₃⁻；
- **络合**：Fe³⁺ 与 SCN⁻。

## 隐含条件

- "无色透明"：不含有色离子（Cu²⁺ 蓝、Fe³⁺ 黄、Fe²⁺ 浅绿、MnO₄⁻ 紫）；
- "强酸性"：不含 OH⁻、CO₃²⁻ 等；"强碱性"：不含 H⁺、NH₄⁺、Fe³⁺ 等。

## 离子方程式的正误判断

**例：** 铁与稀盐酸：

- 正确：Fe + 2H⁺ = Fe²⁺ + H₂↑；
- 错误：2Fe + 6H⁺ = 2Fe³⁺ + 3H₂↑（H⁺ 只能把 Fe 氧化为 Fe²⁺）。

## 离子推断的四原则

1. **肯定性**：根据实验现象肯定存在的离子；
2. **互斥性**：与已肯定离子不能共存的离子排除；
3. **电中性**：溶液中阴阳离子电荷总数相等；
4. **进出性**：实验中加入的试剂可能引入新离子。
