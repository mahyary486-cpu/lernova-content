# Avancement et état final

## Rappel
Pour a A + b B → c C + d D, on décrit le système par un tableau d’avancement :
- n(A) = n₀(A) − a × x ;
- n(B) = n₀(B) − b × x ;
- n(C) = n₀(C) + c × x ;
- n(D) = n₀(D) + d × x.

## Avancement maximal
Il correspond à l’épuisement du réactif limitant : xmax = la plus petite valeur parmi n₀(A) ÷ a et n₀(B) ÷ b.
Pour une transformation totale, l’état final est l’état atteint pour x = xmax.

## Mélange stœchiométrique
Les réactifs sont introduits dans les proportions de l’équation : n₀(A) ÷ a = n₀(B) ÷ b. Ils sont alors consommés simultanément.

## Exemple
Zn + 2 H⁺ → Zn²⁺ + H₂ avec n₀(Zn) = 0,10 mol et n₀(H⁺) = 0,15 mol.
- Zn : 0,10 ÷ 1 = 0,10 ; H⁺ : 0,15 ÷ 2 = 0,075 ; xmax = 0,075 mol, donc H⁺ est le réactif limitant.
- État final : n(Zn) = 0,10 − 0,075 = 0,025 mol ; n(H⁺) = 0 ; n(H₂) = 0,075 mol.
- Volume de H₂ à 24 L/mol : V = 0,075 × 24 = 1,8 L.

## Erreur fréquente
Le réactif limitant n’est pas toujours celui qui a la plus petite quantité de matière initiale : on divise par le coefficient stœchiométrique.
