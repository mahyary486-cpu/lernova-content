# 向量的概念与线性运算

## 向量的概念

既有**大小**又有**方向**的量叫向量。向量 a 的大小叫**模**，记作 |a|。

- 零向量：模为 0，方向任意；
- 单位向量：模为 1；
- 相等向量：方向相同、模相等；
- 相反向量：方向相反、模相等。

## 线性运算

- **加法**：三角形法则 AB + BC = AC；平行四边形法则；
- **减法**：AB − AC = CB；
- **数乘**：λa 的模为 |λ||a|，λ > 0 时方向与 a 相同，λ < 0 时方向相反。

## 共线定理

a ∥ b（b ≠ 0）⇔ 存在**唯一**实数 λ，使 a = λb。

**例：** 点 O 是线段 AB 的中点，则 OA + OB = 0，且对平面内任意一点 P，PO = ½(PA + PB)。
