# 带电粒子在复合场中的运动

## 速度选择器

电场力与洛伦兹力平衡时，粒子沿直线通过：

qE = qvB，**v = E / B**。

**例：** E = 1000 V/m，B = 0.1 T：v = 10⁴ m/s。

与粒子的电荷量、电性、质量**无关**。

## 质谱仪

- 加速：qU = ½mv²；
- 偏转：qvB = mv²/r，**r = (1/B)√(2mU/q)**。

不同的 m/q 对应不同的 r，可以分离同位素。

## 回旋加速器

- 粒子在磁场中做圆周运动，周期 **T = 2πm / (qB)**，与速度无关，所以加速电场的频率等于粒子的回旋频率；
- 最大速度 v_m = qBR / m，**最大动能 Eₖₘ = q²B²R² / (2m)**，与加速电压无关。

**例：** 质子，B = 1 T，R = 0.5 m：

v_m = 1.6×10⁻¹⁹ × 1 × 0.5 / 1.67×10⁻²⁷ ≈ 4.8×10⁷ m/s。

## 解题思路

1. 受力分析：重力（是否忽略）、电场力、洛伦兹力；
2. 判断运动形式：直线、圆周、一般曲线；
3. 选规律：平衡条件、牛顿定律、动能定理。
