# İkinci dereceden denklemler ve kökler

## Genel biçim

a ≠ 0 olmak üzere **ax² + bx + c = 0** denklemine ikinci dereceden denklem denir.

## Çözüm yöntemleri

1. **Çarpanlara ayırma:** x² − 7x + 10 = (x − 2)(x − 5) = 0 → x = 2 veya x = 5.
2. **Ortak çarpan:** x² − 4x = x(x − 4) = 0 → x = 0 veya x = 4.
3. **İki kare farkı:** x² − 9 = (x − 3)(x + 3) → x = ±3.
4. **Tam kare:** x² + 4x + 4 = (x + 2)² → x = −2 (çift katlı kök).
5. **Diskriminant ile:** x₁,₂ = (−b ± √Δ) / (2a)

## Diskriminant

| Δ = b² − 4ac | Kök durumu |
|---|---|
| Δ > 0 | İki farklı gerçek kök |
| Δ = 0 | Eşit (çift katlı) iki kök |
| Δ < 0 | Gerçek kök yok |

**Örnek:** x² − 2x − 3 = 0 için Δ = 4 + 12 = 16 > 0 olduğundan iki farklı kök vardır: x = 3 ve x = −1.

## Kökler ile katsayılar arasındaki bağıntılar

- Kökler toplamı: x₁ + x₂ = −b/a
- Kökler çarpımı: x₁·x₂ = c/a
- x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂

**Örnek:** x₁ + x₂ = 5 ve x₁x₂ = 6 ise x₁² + x₂² = 25 − 12 = 13.

## Kökleri verilen denklem

Kökleri x₁ ve x₂ olan denklem: x² − (x₁ + x₂)x + x₁x₂ = 0. Kökleri 3 ve 4 olan denklem x² − 7x + 12 = 0 dır.

## İpuçları

- Denklemi önce sıfıra eşitleyin.
- Önce ortak çarpan, sonra özdeşlik arayın.
- Çift katlı kök için Δ = 0 koşulundan parametreyi bulun.
