# هیدروکربن‌ها: آلکان‌ها و آلکن‌ها

## این درس درباره‌ی چیست؟

نفت خام منبع سوخت‌ها و مواد اولیه‌ی پلاستیک و پارچه است. ترکیب اصلی آن هیدروکربن‌هاست.

## هیدروکربن

ترکیبی که فقط از کربن و هیدروژن ساخته شده است. اتم کربن چهار پیوند می‌سازد و می‌تواند زنجیر بلند بسازد.

## آلکان‌ها (سیرشده)

فقط پیوند یگانه C–C دارند. فرمول عمومی: **CₙH₂ₙ₊₂**.

- n = ۱: متان CH₄
- n = ۲: اتان C₂H₆
- n = ۳: پروپان C₃H₈
- n = ۴: بوتان C₄H₁₀
- n = ۵: پنتان C₅H₁₂

با افزایش طول زنجیر، نقطه‌ی جوش بالاتر می‌رود (نیروی بین مولکولی بیشتر). متان تا بوتان در دمای اتاق گازند و بعدی‌ها مایع.

## ایزومرها

ترکیب‌هایی با فرمول مولکولی یکسان و ساختار متفاوت. مثلاً **بوتان** (زنجیر راست) و **۲-متیل‌پروپان** (ایزوبوتان، شاخه‌دار) هر دو C₄H₁₀ هستند و خواص فیزیکی متفاوت دارند.

## آلکن‌ها (سیرنشده)

دست‌کم یک پیوند دوگانه‌ی C=C دارند. فرمول عمومی: **CₙH₂ₙ**.

- اتن (اتیلن) C₂H₄
- پروپن C₃H₆

آلکن‌ها واکنش‌پذیرتر از آلکان‌ها هستند.

## واکنش‌ها

- **سوختن کامل:** هیدروکربن + O₂ → CO₂ + H₂O. مثال: CH₄ + ۲O₂ → CO₂ + ۲H₂O.
- **سوختن ناقص:** در کمبود اکسیژن CO و دوده (C) هم تولید می‌شود.
- **افزایشی (آلکن‌ها):** پیوند دوگانه شکسته می‌شود و اتم‌ها اضافه می‌شوند. مثال: C₂H₄ + H₂ → C₂H₆ و C₂H₄ + Br₂ → C₂H₄Br₂.

آلکن‌ها رنگ محلول قهوه‌ای برم را بی‌رنگ می‌کنند و آلکان‌ها نه؛ این آزمون برای تشخیص سیرنشدگی است.

## جمع‌بندی

آلکان‌ها CₙH₂ₙ₊₂ و آلکن‌ها CₙH₂ₙ هستند. با سوختن CO₂ و H₂O می‌دهند و آلکن‌ها واکنش افزایشی دارند و برم را بی‌رنگ می‌کنند.
