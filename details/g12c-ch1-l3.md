# pH Calculations for Strong and Weak Acids and Bases

A weak acid of the same concentration as a strong acid has a much higher pH because it gives far fewer H3O+ ions.

## Key ideas
- Strong acid: **pH = -log C**.
- Strong base: **pOH = -log [OH-]**, pH = 14 - pOH.
- Weak acid: **x = sqrt(Ka C)** when x is small.
- Weak base: **[OH-] = sqrt(Kb C)**.
- **Percent ionization** = x / C x 100%.
- Salt of **weak acid + strong base** = **basic**; **strong acid + weak base** = **acidic**.

## Worked examples
**Example 1: Strong acid.** pH of 0.010 M HCl.
1. [H3O+] = 0.010 = 10^-2.
2. pH = 2.00.

**Example 2: Weak acid.** pH of 0.10 M acetic acid (Ka = 1.8 x 10^-5).
1. x = sqrt(1.8 x 10^-5 x 0.10) = 1.34 x 10^-3.
2. pH = -log(1.34 x 10^-3) = 2.87.

**Example 3: Strong base.** pH of 0.020 M Ba(OH)2.
1. [OH-] = 2 x 0.020 = 0.040 M; pOH = 1.40.
2. pH = 14 - 1.40 = 12.60.

## Common mistakes
- Forgetting that Ba(OH)2 gives two OH-.
- Using the strong-acid shortcut for weak acids.
- Forgetting to check that x is small.
