# The Mole and Avogadro's Number

Atoms and molecules are far too small to count one by one. A single drop of water holds more than a billion billion molecules, and no one could ever count them. Chemists solve this problem by counting in huge groups called moles. The mole, with the symbol mol, is the SI unit for the amount of a substance, and it works the way the word dozen works. A dozen always means 12 items, whether they are eggs or pencils, and a mole always means the same enormous number of particles, whatever they are.

## Key ideas

One mole of any substance contains 6.02 x 10^23 representative particles. This number is called Avogadro's number, and it is written N_A. It is defined this way so that the mass of one mole in grams equals the atomic or molecular mass in atomic mass units, which is what makes the mole so useful in the laboratory. A representative particle is whatever unit makes up the substance. It is an atom for an element such as aluminum, a molecule for a covalent substance such as water, and a formula unit for an ionic compound such as NaCl.

Two simple relationships link moles to particles. To find the number of particles, multiply the moles by Avogadro's number: particles = moles x 6.02 x 10^23. To find the moles, divide the number of particles by Avogadro's number: moles = particles / (6.02 x 10^23). In both cases the conversion factor is 6.02 x 10^23 particles per 1 mol, and the units tell you which way to use it. If the unit you want is on top, the units cancel correctly. A quick check helps too: since Avogadro's number is huge, a few moles must give a very large number of particles, and a very large number of particles must give a small number of moles.

Subscripts in a formula count the atoms inside one particle, so they also count moles of atoms inside one mole of particles. In 1 mol of H2O there are 2 mol of hydrogen atoms and 1 mol of oxygen atoms, which makes 3 mol of atoms in total. This idea is needed for the calculations of the following lessons.

Equal numbers of moles contain equal numbers of particles, whatever the substance. One mole of helium and one mole of copper each hold 6.02 x 10^23 atoms, but they have very different masses, because a copper atom is much heavier than a helium atom. The mole is therefore the link between the invisible world of particles and the masses we can measure on a balance.

## Worked examples

**Example 1: Atoms from moles.** How many atoms are in 2.50 mol of aluminum?
1. The question asks for a number of particles, so multiply the moles by Avogadro's number.
2. 2.50 mol x 6.02 x 10^23 atoms/mol = 15.05 x 10^23 atoms.
3. In scientific notation, with three significant figures, this is 1.51 x 10^24 atoms.

**Example 2: Moles from particles.** A sample contains 3.01 x 10^24 atoms of zinc. How many moles is this?
1. The question asks for moles, so divide the number of atoms by Avogadro's number.
2. 3.01 x 10^24 / 6.02 x 10^23 = 5.00 mol.
3. The answer is reasonable, because 3.01 x 10^24 is ten times 3.01 x 10^23, which is half of one mole.

**Example 3: Atoms inside molecules.** How many atoms are in 0.500 mol of CO2?
1. The number of molecules is 0.500 x 6.02 x 10^23 = 3.01 x 10^23 molecules.
2. Each molecule has 3 atoms, 1 carbon and 2 oxygen.
3. The number of atoms is 3 x 3.01 x 10^23 = 9.03 x 10^23 atoms.

## Common mistakes

A frequent error is to multiply when you should divide, or the reverse. The check described above prevents it, because a few moles should always give an enormous number of particles. Another is to forget that a mole of molecules contains more atoms than particles, so that 1 mol of CO2 contains 3 mol of atoms. Some students mix up the sign of the exponent, but Avogadro's number is 10 to the power of plus 23, and not minus 23. Finally, the mole is a count, like a dozen, and not a mass, so a mole is not a number of grams.
