# 常见的酸

## 盐酸和硫酸

- **盐酸（HCl 的水溶液）**：浓盐酸有挥发性，打开瓶盖会看到白雾；
- **硫酸（H₂SO₄）**：浓硫酸有吸水性（可作干燥剂）、脱水性和强腐蚀性。

**稀释浓硫酸**：一定要把**浓硫酸沿器壁慢慢注入水中**，并不断搅拌。切不可把水倒进浓硫酸里。

## 酸的通性

酸溶液中都含有 H⁺，所以化学性质相似：

1. 使紫色石蕊溶液变**红**，无色酚酞溶液不变色；
2. 与活泼金属反应生成盐和氢气：Zn + 2HCl = ZnCl₂ + H₂↑；
3. 与金属氧化物反应：Fe₂O₃ + 6HCl = 2FeCl₃ + 3H₂O，用于**除铁锈**，溶液变黄色；
4. 与碱发生中和反应；
5. 与某些盐反应：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑。
