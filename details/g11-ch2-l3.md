# Completing the Square

## The idea
Some quadratics are not easy to factor. Completing the square turns x^2 + bx into a **perfect square trinomial**, which can be written as (x + b/2)^2.

To complete the square, add **(b/2)^2**.
- x^2 + 6x needs +9, because (6/2)^2 = 9. Then x^2 + 6x + 9 = (x + 3)^2.
- x^2 - 8x needs +16. Then x^2 - 8x + 16 = (x - 4)^2.
- x^2 + 10x + 25 = (x + 5)^2.

## Solving by completing the square (a = 1)
Solve x^2 + 6x - 7 = 0.
1. Move the constant: x^2 + 6x = 7.
2. Add (6/2)^2 = 9 to **both sides**: x^2 + 6x + 9 = 16.
3. Factor: (x + 3)^2 = 16.
4. Square root: x + 3 = 4 or x + 3 = -4.
5. **x = 1 or x = -7.**

## When a is not 1
Divide every term by a first.
Solve 2x^2 + 8x - 10 = 0. Divide by 2: x^2 + 4x - 5 = 0. Then x^2 + 4x = 5, add 4: (x + 2)^2 = 9, so x + 2 = 3 or -3 and **x = 1 or x = -5**.

## Finding vertex form
y = x^2 + 4x + 1. Add and subtract 4: y = (x^2 + 4x + 4) - 4 + 1 = **(x + 2)^2 - 3**. The vertex is (-2, -3).

When a is not 1, factor a out of the x-terms first.
y = 2x^2 - 12x + 7 = 2(x^2 - 6x) + 7. Inside, add 9, which is really adding 2 * 9 = 18, so subtract 18: y = 2(x - 3)^2 - 18 + 7 = **2(x - 3)^2 - 11**. The vertex is (3, -11).

## Worked example
Solve x^2 - 4x - 5 = 0. Then x^2 - 4x = 5, so x^2 - 4x + 4 = 9, which is (x - 2)^2 = 9. So **x = 5 or x = -1**.

## Common mistakes
- Adding (b/2)^2 to only one side of the equation.
- Using b instead of b/2, or forgetting to square it.
- Forgetting to divide by a before completing the square.
- When a is not 1, forgetting that the number you add inside the parentheses is multiplied by a.
