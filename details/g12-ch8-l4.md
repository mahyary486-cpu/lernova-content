# Limit Laws and Continuity

## Limit laws
Suppose lim f(x) = A and lim g(x) = B as x approaches a, with A and B finite. Then:
- Sum and difference: lim (f + g) = A + B and lim (f - g) = A - B
- Constant multiple: lim (c f) = cA
- Product: lim (f g) = AB
- Quotient: lim (f / g) = A / B, provided B is not 0
- Power: lim (f^n) = A^n
- Root: lim sqrt(f) = sqrt(A), when A is not negative

## Direct substitution
For polynomials and many standard functions, lim (x to a) f(x) = f(a). Just substitute.

## Indeterminate form 0/0
If substitution gives 0/0, the limit may still exist. Simplify first.
- **Factor and cancel.**
- **Rationalize** when a square root is present: multiply top and bottom by the conjugate.
- **Combine fractions** over a common denominator.

## Continuity
A function f is **continuous at x = a** if all three hold:
1. f(a) is defined.
2. lim (x to a) f(x) exists.
3. lim (x to a) f(x) = f(a).

Types of discontinuity: **removable** (a hole, the limit exists), **jump** (the one-sided limits differ) and **infinite** (a vertical asymptote). Polynomials are continuous everywhere. Rational functions are continuous except where the denominator is 0.

## Worked examples
1. Find lim (x to 3) (x^2 - 9) / (x - 3).
   1. Substitution gives 0/0.
   2. Factor: (x - 3)(x + 3) / (x - 3) = x + 3.
   3. The limit is 3 + 3 = 6.
2. Find lim (x to 0) (sqrt(x + 4) - 2) / x.
   1. Multiply by the conjugate: (x + 4 - 4) / (x(sqrt(x + 4) + 2)).
   2. Cancel x: 1 / (sqrt(x + 4) + 2).
   3. At x = 0 this is 1/4.
3. For what value of k is f continuous at 2, if f(x) = x^2 + 1 for x less than 2 and f(x) = kx - 1 for x of 2 or more?
   1. Left limit = 4 + 1 = 5.
   2. f(2) = 2k - 1.
   3. Set 2k - 1 = 5, so k = 3.

## Common mistakes
- Stopping at 0/0 and saying the limit does not exist.
- Applying the quotient law when the denominator limit is 0.
- Saying a function is continuous because the limit exists, without checking f(a).
- Forgetting that a nonzero number divided by 0 signals an asymptote, not 0/0.
