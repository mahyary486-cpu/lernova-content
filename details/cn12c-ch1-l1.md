# 物质的量计算综合

## 核心公式

**n = m / M = V / Vm = N / N_A = c · V**

标准状况下气体：Vm = 22.4 L/mol。

## 例题

**例 1：** 标准状况下 4.48 L 某气体的质量为 8.8 g：

n = 4.48 / 22.4 = 0.2 mol，M = 8.8 / 0.2 = 44 g/mol。

**例 2：** 0.5 mol/L MgCl₂ 溶液 200 mL 中，n(Cl⁻) = 0.5 × 2 × 0.2 = 0.2 mol。

## 阿伏加德罗常数的常见陷阱

- 标准状况下，水、SO₃、CCl₄ 等不是气体，不能用 22.4 L/mol；
- 1 mol Na₂O₂ 含离子 3 mol（2 个 Na⁺ 和 1 个 O₂²⁻）；
- 只给浓度不给体积，无法求物质的量；
- 弱电解质、能水解的离子，实际数目要少。

## 混合气体的平均摩尔质量

**M̄ = m总 / n总**

**例：** CO 和 CO₂ 的混合气体，标准状况下 11.2 L，质量 18 g：

- n = 0.5 mol，M̄ = 36 g/mol；
- 设 CO 为 x mol：28x + 44(0.5 − x) = 18，得 x = 0.25；
- 所以 CO 和 CO₂ 各 0.25 mol。
