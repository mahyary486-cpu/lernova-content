# Raisonnement par récurrence

## Principe
Pour montrer qu’une propriété P(n) est vraie pour tout entier n ≥ n_0 :
1. Initialisation : on vérifie que P(n_0) est vraie.
2. Hérédité : on suppose P(n) vraie pour un entier n ≥ n_0 (hypothèse de récurrence) et on démontre que P(n + 1) est vraie.
3. Conclusion : P(n) est vraie pour tout entier n ≥ n_0.

## Exemple 1 : 2^n ≥ n + 1
- Initialisation : pour n = 0, 2^0 = 1 ≥ 1, c’est vrai.
- Hérédité : supposons 2^n ≥ n + 1. Alors 2^(n+1) = 2 × 2^n ≥ 2(n + 1) = 2n + 2 ≥ n + 2, car n ≥ 0.
- Conclusion : 2^n ≥ n + 1 pour tout entier n.

## Exemple 2 : somme des entiers
Montrons que 1 + 2 + … + n = n(n + 1)/2. Pour n = 1 : 1 = 1 × 2/2. Si la formule est vraie au rang n, alors 1 + … + n + (n + 1) = n(n + 1)/2 + (n + 1) = (n + 1)(n + 2)/2.

## Suites définies par récurrence
Pour u_0 = 1 et u_(n+1) = u_n/2 + 1, on montre par récurrence que 0 ≤ u_n ≤ 2 pour tout n : si 0 ≤ u_n ≤ 2 alors 1 ≤ u_n/2 + 1 ≤ 2.

## Rédaction
On énonce clairement P(n), on indique où l’hypothèse de récurrence est utilisée, et on termine par une conclusion.

## Erreur fréquente
Oublier l’initialisation : sans elle, la propriété peut être héréditaire mais fausse (par exemple « n = n + 1 »).
