# Plotting points and reading coordinates

To plot (a, b), start at the origin, move a units along the x-axis (right if positive, left if negative), then b units parallel to the y-axis (up if positive, down if negative).

The distance of a point (a, b) from the y-axis is |a| and from the x-axis is |b|. Points with the same x-coordinate lie on a vertical line, points with the same y-coordinate lie on a horizontal line.

Example: A(1, 2), B(3, 2), C(3, 5), D(1, 5) form a rectangle with sides 2 and 3.
