# Équations, inéquations et études de fonctions avec exp

## Équations
- e^a = e^b équivaut à a = b.
- (x − 2)e^x = 0 équivaut à x − 2 = 0, car e^x ne s’annule jamais : x = 2.
- e^(2x) = e^x équivaut à 2x = x, donc x = 0.

## Inéquations
L’exponentielle est strictement croissante : e^a ≤ e^b équivaut à a ≤ b.
Exemples : e^x > e^2 donne x > 2 ; e^(2x) ≤ e^6 donne x ≤ 3.

## Signe d’un produit avec exp
Comme e^x > 0, le signe de P(x)e^x est celui de P(x).
Exemple : le signe de (x − 3)e^x est celui de x − 3.

## Étude d’une fonction
Soit f(x) = (x − 1)e^x.
1. f’(x) = e^x + (x − 1)e^x = x e^x.
2. e^x > 0, donc f’ a le signe de x.
3. f décroît sur ]−∞ ; 0] et croît sur [0 ; +∞[ ; minimum f(0) = −1.

Soit g(x) = x e^(−x). g’(x) = e^(−x) − x e^(−x) = (1 − x)e^(−x). g’ a le signe de 1 − x : g croît sur ]−∞ ; 1] et décroît sur [1 ; +∞[ ; maximum g(1) = e^(−1) ≈ 0,37.

## Suites
Les suites u_n = e^(na) sont géométriques de raison e^a.

## Erreur fréquente
Diviser par e^x est toujours possible (e^x ≠ 0), mais diviser par x ne l’est pas sans précaution.
