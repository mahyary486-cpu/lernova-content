# Inductance, Transformers and AC

Power stations send electricity at very high voltage to reduce losses, and transformers lower it again for homes.

## Key ideas
- **emf = -L delta I / delta t**; unit **henry (H)**.
- Energy in an inductor: **1/2 L I^2**.
- Transformer: **V_s / V_p = N_s / N_p**; ideal: **V_p I_p = V_s I_s**.
- **V_rms = V_peak / sqrt(2)**.
- Average AC power **P = I_rms V_rms**.
- Transformers work only with **changing** (AC) current.

## Worked examples
**Example 1: Transformer.** A transformer has 200 primary turns and 1000 secondary turns with a 12 V primary.
1. V_s = V_p N_s / N_p = 12 x 1000 / 200.
2. V_s = 60 V.

**Example 2: Current.** The secondary supplies 0.5 A in the above case (ideal).
1. V_p I_p = V_s I_s gives I_p = 60 x 0.5 / 12.
2. I_p = 2.5 A.

**Example 3: RMS value.** The peak voltage is 311 V.
1. V_rms = 311 / 1.414.
2. V_rms = 220 V.

## Common mistakes
- Using the peak value as the rms value.
- Thinking a transformer increases power.
- Using it with DC.
