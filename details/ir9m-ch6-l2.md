# Equation of a line

An equation of a line is a rule that is true for every point on the line and false for every point off the line.

## Key ideas

- A linear equation in two variables has the form ax + by = c. Its graph is a straight line. Two points are enough to draw it.
- The slope of a line measures how steep it is: m = (y2 - y1)/(x2 - x1) = rise/run. A positive slope goes up from left to right. A negative slope goes down. A horizontal line has slope 0. A vertical line has no slope.
- Slope-intercept form: y = mx + b. Here m is the slope and b is the y-intercept, the point (0, b) where the line meets the y-axis.
- Point-slope form: y - y1 = m(x - x1), for a line with slope m through the point (x1, y1).
- The x-intercept is found by setting y = 0. The y-intercept is found by setting x = 0.
- Horizontal line: y = k. Vertical line: x = k.
- Parallel lines have equal slopes. Perpendicular lines have slopes whose product is -1.

## Worked examples

Example 1. Find the equation of the line through (1, 2) and (3, 8).

Step 1: Slope m = (8 - 2)/(3 - 1) = 6/2 = 3.
Step 2: Use point-slope form with (1, 2): y - 2 = 3(x - 1).
Step 3: Expand: y - 2 = 3x - 3, so y = 3x - 1.
Step 4: Check with (3, 8): 3 × 3 - 1 = 8. It works.

Example 2. For the line 2x + 3y = 12, find both intercepts and the slope, then describe how to draw it.

Step 1: Put y = 0: 2x = 12, so x = 6. The x-intercept is (6, 0).
Step 2: Put x = 0: 3y = 12, so y = 4. The y-intercept is (0, 4).
Step 3: Solve for y: 3y = -2x + 12, so y = (-2/3)x + 4. The slope is -2/3.
Step 4: Mark (6, 0) and (0, 4) and draw the straight line through them. The line goes down as you move to the right, which matches the negative slope. Check: from (0, 4) to (6, 0) the rise is -4 and the run is 6, and -4/6 = -2/3.

Example 3. Find the line through (3, -1) that is (a) parallel and (b) perpendicular to y = 2x + 1.

Step 1: The given slope is 2.
Step 2 (parallel): The slope is also 2. y - (-1) = 2(x - 3), so y + 1 = 2x - 6, so y = 2x - 7. Check: 2 × 3 - 7 = -1.
Step 3 (perpendicular): The slope m satisfies 2m = -1, so m = -1/2. Then y + 1 = (-1/2)(x - 3), so y = (-1/2)x + 3/2 - 1, so y = (-1/2)x + 1/2.
Step 4: Check: (-1/2) × 3 + 1/2 = -3/2 + 1/2 = -1. It works.

## Common mistakes

- Subtracting the coordinates in a different order in the numerator and the denominator. If you start with y2 on top, start with x2 on the bottom.
- Reading the slope from 3y = -2x + 12 as -2. You must divide by 3 first to get y alone.
- Saying that a vertical line has slope 0. A horizontal line has slope 0. A vertical line has no slope.
- Mixing up the intercepts. The y-intercept has x = 0 and the x-intercept has y = 0.

## Remember

- y = mx + b shows the slope m and the y-intercept b at a glance.
- Two points always give the slope and then the whole equation.
- Parallel lines: same slope. Perpendicular lines: product of slopes is -1.
