# 碳的单质

## 金刚石、石墨和 C₆₀

- **金刚石**：无色透明的正八面体，是天然存在**最硬**的物质，用于切割玻璃、钻头；
- **石墨**：深灰色、质软、有滑腻感，能导电，用于铅笔芯、电极、润滑剂；
- **C₆₀**：由 60 个碳原子构成的分子，形似足球。

它们物理性质差异很大，原因是**碳原子的排列方式不同**。

## 碳的化学性质

1. **常温下稳定**：古代字画用墨书写，保存很久不变色；
2. **可燃性**：充分燃烧 C + O₂ =(点燃)= CO₂；不充分燃烧 2C + O₂ =(点燃)= 2CO；
3. **还原性**：C + 2CuO =(高温)= 2Cu + CO₂↑，黑色固体变成红色。

## 吸附性

木炭和活性炭具有疏松多孔的结构，有很强的吸附性，可用来除去色素和异味。
