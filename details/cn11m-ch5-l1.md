# 导数的概念与运算

## 导数的概念

函数 y = f(x) 在 x = x₀ 处的导数：

**f′(x₀) = lim(Δx→0) [f(x₀ + Δx) − f(x₀)] / Δx**

- 物理意义：瞬时变化率（如瞬时速度）；
- **几何意义**：曲线在点 (x₀, f(x₀)) 处的**切线斜率**。

## 基本初等函数的导数

- (C)′ = 0；(xⁿ)′ = nxⁿ⁻¹；
- (sin x)′ = cos x；(cos x)′ = −sin x；
- (eˣ)′ = eˣ；(aˣ)′ = aˣ ln a；
- (ln x)′ = 1/x。

## 运算法则

- (u ± v)′ = u′ ± v′；
- (uv)′ = u′v + uv′；
- (u/v)′ = (u′v − uv′) / v²；
- 复合函数：y = f(g(x)) 的导数为 f′(g(x)) · g′(x)。

## 例题

**例 1：** f(x) = x³ − 2x，f′(x) = 3x² − 2，f′(1) = 1。

**例 2：** 曲线 y = x² 在点 (1, 1) 处的切线：斜率 k = 2x = 2，切线方程 y − 1 = 2(x − 1)，即 y = 2x − 1。
