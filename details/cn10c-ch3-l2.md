# 气体摩尔体积

## 概念

单位物质的量的气体所占的体积叫**气体摩尔体积**，符号 Vm，单位 L/mol。

在**标准状况**（0℃，101 kPa）下，1 mol 任何气体的体积都约为 **22.4 L**，即 Vm = 22.4 L/mol。

**n = V / Vm**

## 阿伏加德罗定律

在相同的温度和压强下，相同体积的任何气体都含有相同数目的分子。

## 注意事项

- 22.4 L/mol 只适用于**标准状况**；
- 只适用于**气体**。标准状况下，水、SO₃、CCl₄ 等不是气体，不能用；
- 混合气体也适用。

## 例题

**例：** 标准状况下 11.2 L CO₂：

- n = 11.2 / 22.4 = 0.5 mol；
- m = 0.5 × 44 = 22 g；
- 分子数 = 0.5 × 6.02×10²³ = 3.01×10²³。
