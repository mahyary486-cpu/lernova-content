# Logaritmos y sus propiedades

## Definición
log_a(x) = y ⟺ aʸ = x (a > 0, a ≠ 1, x > 0).

## Ejemplos
- log₂ 8 = 3, porque 2³ = 8.
- log₁₀ 1000 = 3.
- log_a 1 = 0 y log_a a = 1.

## Propiedades
- log(x·y) = log x + log y.
- log(x/y) = log x − log y.
- log(xⁿ) = n·log x.
- Cambio de base: log_a x = log x / log a.

## Función logarítmica
f(x) = log_a x es la inversa de aˣ. Su dominio es (0; +∞).

## Error frecuente
log(x + y) no es log x + log y.
