# 不等式的性质与基本不等式

## 不等式的基本性质

- 传递性：a > b，b > c ⇒ a > c；
- 加法：a > b ⇒ a + c > b + c；
- 乘法：a > b，c > 0 ⇒ ac > bc；**c < 0 时不等号方向改变**，ac < bc；
- 同向相加：a > b，c > d ⇒ a + c > b + d。

**比较大小**：作差法，a − b > 0 ⇔ a > b。

## 基本不等式

设 a > 0，b > 0，则 **√(ab) ≤ (a + b)/2**，当且仅当 a = b 时等号成立。

使用时记住"一正、二定、三相等"：

- 和为定值时，积有最大值：ab ≤ ((a + b)/2)²；
- 积为定值时，和有最小值：a + b ≥ 2√(ab)。

**例 1：** x > 0 时，x + 1/x ≥ 2，当 x = 1 时取最小值 2。

**例 2：** 用 20 m 长的篱笆围矩形，设长宽分别为 a、b，a + b = 10，则 ab ≤ 25，最大面积为 25 m²。
