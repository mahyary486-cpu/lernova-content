# Accuracy, precision and errors

Absolute error = ∣mean value − measured value∣, relative error = absolute error / mean value and percentage error = relative error × 100. Errors add for sums and differences; fractional errors add for products and quotients; for a power xⁿ the fractional error is multiplied by n.

The least count of a vernier caliper is about 0.1 mm and of a screw gauge about 0.01 mm.
