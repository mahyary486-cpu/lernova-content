# Variations, tableau de variations et extremums

## Définitions (sur un intervalle I)
- f est croissante sur I si, pour tous x1 < x2 de I, f(x1) ≤ f(x2).
- f est décroissante sur I si, pour tous x1 < x2 de I, f(x1) ≥ f(x2).
- f est constante sur I si f(x1) = f(x2).
Une fonction croissante conserve l’ordre, une fonction décroissante l’inverse.

## Tableau de variations
Il indique, par des flèches montantes ou descendantes, le sens de variation sur chaque intervalle, avec les valeurs de f aux changements de sens.
Exemple : f croissante de −2 à 1 (f(1) = 4), puis décroissante de 1 à 5. Alors f admet un maximum égal à 4 atteint en x = 1.

## Extremums
- Maximum de f sur I : la plus grande valeur f(a) prise par f, atteinte en x = a.
- Minimum de f sur I : la plus petite valeur prise par f.
Exemple : sur [−3 ; 3], f(x) = x² a pour minimum 0 (en x = 0) et pour maximum 9 (en x = −3 et x = 3).

## Utilisation
Si f est décroissante sur [0 ; 4], alors f(1) ≥ f(3). Si f est décroissante sur ]−∞ ; 0], alors pour −2 < −1 on a f(−2) ≥ f(−1).

## Erreur fréquente
Un extremum est une valeur de f (une ordonnée), pas la valeur de x où il est atteint.
