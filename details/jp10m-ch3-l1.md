# 二次関数のグラフと平方完成

## 標準形

y = a(x − p)² + q のグラフは、y = ax² を x 軸方向に p、y 軸方向に q 平行移動した放物線。頂点は (p, q)、軸は直線 x = p。a > 0 で下に凸、a < 0 で上に凸。

## 平方完成

y = x² + 6x + 1 = (x + 3)² − 9 + 1 = (x + 3)² − 8。頂点は (−3, −8)。

一般に、y = ax² + bx + c の頂点の x 座標は −b/(2a)。

**例：** y = 2x² + 8x + 3 = 2(x + 2)² − 5。頂点 (−2, −5)。

## 平行移動と対称移動

- y = f(x) を x 軸方向に p、y 軸方向に q 移動：y − q = f(x − p)
- x 軸について対称：y を −y に、y 軸について対称：x を −x に。
