# 三角函数的图象与性质

## 正弦函数与余弦函数

| 性质 | y = sin x | y = cos x |
|---|---|---|
| 定义域 | R | R |
| 值域 | [−1, 1] | [−1, 1] |
| 最小正周期 | 2π | 2π |
| 奇偶性 | 奇函数 | 偶函数 |

y = sin x 在 [−π/2 + 2kπ, π/2 + 2kπ] 上单调递增。

## 正切函数

y = tan x，定义域 {x | x ≠ π/2 + kπ}，最小正周期 π，奇函数。

## y = A sin(ωx + φ)

- 振幅 A，最小正周期 T = 2π / ω，最大值 A，最小值 −A；
- 图象变换：左加右减（对 x 而言）。

**例：** y = 2 sin(2x + π/3)：振幅 2，最小正周期 π，最大值 2。
