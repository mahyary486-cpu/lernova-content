# Электромагнитная индукция

**Магнитный поток:** Φ = B · S · cos α. Единица — вебер (Вб). При B = 0,2 Тл и S = 0,5 м² (перпендикулярно полю) Φ = 0,1 Вб. Для рамки площадью 0,1 м² в поле 0,5 Тл, повёрнутой на 60° к нормали, Φ = 0,05 · 0,5 = 0,025 Вб.

**Закон Фарадея:** ε = −ΔΦ / Δt. При изменении потока на 0,3 Вб за 0,1 с модуль ЭДС равен 3 В.

**Правило Ленца.** Индукционный ток направлен так, чтобы его магнитное поле препятствовало изменению породившего его потока.

**ЭДС в движущемся проводнике:** ε = B · l · v · sin α. При B = 0,2 Тл, l = 0,5 м и v = 4 м/с получаем 0,4 В.
