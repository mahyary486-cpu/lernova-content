# 水的组成

## 电解水实验

通直流电使水分解：

2H₂O =(通电)= 2H₂↑ + O₂↑

- 与电源**正极**相连的试管得到**氧气**（能使带火星的木条复燃）；
- 与电源**负极**相连的试管得到**氢气**（能燃烧，产生淡蓝色火焰）；
- 体积比 **V(H₂) : V(O₂) = 2 : 1**（口诀：正氧负氢，氢二氧一）；
- 质量比 m(H₂) : m(O₂) = 1 : 8。

## 结论

水是由**氢元素和氧元素**组成的。在化学变化中，分子可以再分，原子不能再分。

## 氢气

- 氢气燃烧：2H₂ + O₂ =(点燃)= 2H₂O；
- 氢气是密度最小的气体，具有可燃性；
- 点燃氢气前**必须检验纯度**，否则可能爆炸。
