# 波的图象与振动图象

## 两种图象的区别

| | 振动图象 | 波的图象 |
|---|---|---|
| 横坐标 | 时间 t | 位置 x |
| 描述对象 | 一个质点在不同时刻的位移 | 许多质点在同一时刻的位移 |
| 能读出 | 周期 T、振幅 A | 波长 λ、振幅 A |

## 综合问题

由波的图象读出 λ，由振动图象读出 T，则

**v = λ / T**

**例：** 波形图中 λ = 8 m，某质点的振动图象中 T = 4 s：

- 波速 v = 8 / 4 = 2 m/s；
- 3 s 内波传播的距离 Δx = vΔt = 6 m。

## 判断传播方向

先在振动图象上读出该质点在某时刻的振动方向，再在波的图象上用"同侧法"判断波的传播方向。

## 周期性与多解

波的图象每经过一个周期 T（或传播一个波长 λ）重复一次，所以题目中的时间或距离往往有**多种可能**：Δt = nT + Δt₀。
