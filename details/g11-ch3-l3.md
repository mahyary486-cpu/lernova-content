# Dividing Polynomials

## Long division
Dividing polynomials works like long division of numbers: divide the first terms, multiply, subtract, bring down the next term, and repeat. The result is
dividend = divisor * quotient + remainder.
Always write the dividend in standard form and put in **0** for any missing power.

## Synthetic division
A shortcut for dividing by **x - c**.
1. Write c and the coefficients of the dividend (use 0 for missing powers).
2. Bring down the first coefficient.
3. Multiply by c and add to the next coefficient. Repeat.
4. The last number is the **remainder**. The others are the coefficients of the quotient, which has degree one less.

To divide by x + 3, use **c = -3**.

## Example 1: remainder 0
(x^3 + 2x^2 - 5x - 6) / (x - 2), c = 2, coefficients 1, 2, -5, -6.
Bring down 1. Then 2*1 = 2, and 2 + 2 = 4. Then 2*4 = 8, and -5 + 8 = 3. Then 2*3 = 6, and -6 + 6 = 0.
Quotient **x^2 + 4x + 3**, remainder **0**.

## Example 2: nonzero remainder
(2x^3 + 3x^2 - x + 5) / (x + 1), c = -1, coefficients 2, 3, -1, 5.
Bring down 2. Then -1*2 = -2, and 3 - 2 = 1. Then -1*1 = -1, and -1 - 1 = -2. Then -1*(-2) = 2, and 5 + 2 = 7.
Quotient 2x^2 + x - 2, remainder 7. Write it as **2x^2 + x - 2 + 7/(x + 1)**.

## Example 3: missing terms
(x^3 - 27) / (x - 3). Coefficients 1, 0, 0, -27 with c = 3: 1, 3, 9, and 27 - 27 = 0. Quotient **x^2 + 3x + 9**, remainder 0.

## Example 4: factoring a difference
(x^4 - 1) / (x + 1). Coefficients 1, 0, 0, 0, -1 with c = -1: 1, -1, 1, -1, 0. Quotient **x^3 - x^2 + x - 1**, remainder 0.

## Example 5
(3x^3 - 2x + 4) / (x - 2). Coefficients 3, 0, -2, 4 with c = 2: 3, 6, 10, 24. Quotient **3x^2 + 6x + 10**, remainder **24**.

## Common mistakes
- Forgetting to write 0 for a missing power.
- Using c = 3 for x + 3. It must be c = -3.
- Using synthetic division when the divisor is not of the form x - c.
- Forgetting to write the remainder over the divisor.
