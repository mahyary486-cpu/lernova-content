# 距离公式

## 两点间的距离

P₁(x₁, y₁)，P₂(x₂, y₂)：

**|P₁P₂| = √((x₁ − x₂)² + (y₁ − y₂)²)**

## 点到直线的距离

点 P(x₀, y₀) 到直线 Ax + By + C = 0 的距离：

**d = |Ax₀ + By₀ + C| / √(A² + B²)**

**例：** 点 (1, 2) 到直线 3x + 4y − 5 = 0 的距离 d = |3 + 8 − 5| / 5 = 6/5。

## 两条平行直线间的距离

Ax + By + C₁ = 0 与 Ax + By + C₂ = 0（x、y 的系数要化成相同）：

**d = |C₁ − C₂| / √(A² + B²)**

**例：** 3x + 4y − 5 = 0 与 3x + 4y + 5 = 0 的距离 d = 10/5 = 2。
