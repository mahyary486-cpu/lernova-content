# 糖类、油脂、蛋白质与合成高分子

## 糖类

- **葡萄糖** C₆H₁₂O₆：多羟基醛，能发生银镜反应；
- **蔗糖** C₁₂H₂₂O₁₁：水解生成葡萄糖和果糖，**不能**发生银镜反应；
- **麦芽糖**：能发生银镜反应；
- **淀粉、纤维素** (C₆H₁₀O₅)ₙ：水解最终生成葡萄糖；淀粉遇碘单质变**蓝**。

## 油脂

高级脂肪酸与甘油形成的酯。碱性条件下水解叫**皂化反应**，生成高级脂肪酸盐（肥皂）和甘油。

## 蛋白质

- 由氨基酸缩合而成，水解最终生成 α-氨基酸；
- **盐析**：加入饱和 (NH₄)₂SO₄ 或 Na₂SO₄ 溶液，蛋白质析出，**可逆**；
- **变性**：加热、重金属盐、强酸强碱、甲醛，**不可逆**；
- 颜色反应：遇浓硝酸变黄。

## 合成高分子

- **加聚反应**：不饱和单体聚合，没有小分子生成。例：nCH₂=CH₂ → ［CH₂—CH₂］ₙ（聚乙烯）；
- **缩聚反应**：单体之间脱去小分子（如 H₂O）。

平均相对分子质量 = n × 链节的式量。

**例：** 聚乙烯，n = 1000，链节式量 28，平均相对分子质量 = 28000。
