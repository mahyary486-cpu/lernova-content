# 因数分解と平方根の考え方で解く

## 2次方程式

移項して整理したとき、ax² + bx + c = 0（a ≠ 0）の形になる方程式を**2次方程式**といいます。方程式を成り立たせる x の値を**解**といいます。

## 因数分解で解く

AB = 0 ならば A = 0 または B = 0 を使います。

**例：** x² + 5x + 6 = 0 → (x + 2)(x + 3) = 0 → x = −2、−3

**例：** x² − 5x = 0 → x(x − 5) = 0 → x = 0、5

## 平方根の考え方で解く

- x² = k（k > 0）のとき x = ±√k
- (x + a)² = k のとき x + a = ±√k なので x = −a ± √k

**例：** x² = 49 → x = ±7

**例：** (x − 1)² = 5 → x = 1 ± √5

## 確かめ

求めた解を元の方程式に代入して、成り立つか確かめましょう。
