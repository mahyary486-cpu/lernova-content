# Lenguaje simbólico y expresiones algebraicas

## Del lenguaje coloquial al simbólico
- El doble de un número: 2x.
- Un número aumentado en 5: x + 5.
- El cuadrado de la suma de dos números: (a + b)².
- Tres números consecutivos: x, x + 1, x + 2.

## Términos semejantes
Tienen la misma parte literal. 3x + 5x = 8x, pero 3x + 5x² no se puede reducir.

## Propiedad distributiva
a(b + c) = ab + ac. Por ejemplo 3(x − 2) = 3x − 6.

## Valor numérico
Para x = 4, la expresión 2x + 3 vale 2 · 4 + 3 = 11.

## Error frecuente
Olvidar multiplicar todos los términos del paréntesis: 3(x − 2) no es 3x − 2.
