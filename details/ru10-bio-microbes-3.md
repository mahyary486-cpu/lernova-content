# Грибы

**Грибы** — эукариоты-гетеротрофы. Их тело образовано нитями — **гифами**, которые составляют **мицелий (грибницу)**. Клеточная стенка содержит **хитин**.

**Размножение** — спорами, вегетативно и (у дрожжей) почкованием.

**Группы.**

- **Шляпочные грибы** (белый гриб, подосиновик, шампиньон). Ядовит, например, бледная поганка.
- **Плесневые грибы** (мукор, пеницилл). Из пеницилла А. Флеминг получил первый антибиотик — пенициллин.
- **Дрожжи** — одноклеточные грибы, вызывают брожение.

**Симбиоз.** **Микориза** — сожительство гриба с корнями растений. **Лишайник** — симбиоз гриба и водоросли (или цианобактерии).
