# Unidad imaginaria y forma binómica

## Definición
i² = −1. z = a + bi.

## Operaciones
- Suma: (a + bi) + (c + di) = (a + c) + (b + d)i.
- Producto: (a + bi)(c + di) = (ac − bd) + (ad + bc)i.
- Conjugado: z̄ = a − bi; z·z̄ = a² + b².

## Potencias de i
i, −1, −i, 1 (se repiten cada 4).

## Error frecuente
Creer que i² = 1.
