# Quadratwurzeln und Rechenregeln

## Definition

Die **Quadratwurzel √a** (für a ≥ 0) ist diejenige **nichtnegative** Zahl, deren Quadrat a ergibt.

- √49 = 7, denn 7² = 49
- √100 = 10
- √0 = 0

Die Gleichung x² = 49 hat zwei Lösungen (x = 7 und x = −7), aber √49 bezeichnet nur die positive Zahl 7.

Für jede Zahl a gilt: **√(a²) = Betrag von a**. Zum Beispiel ist √((−5)²) = √25 = 5.

Zahlen wie 1, 4, 9, 16, 25, 36, 49, 64 heißen **Quadratzahlen**.

## Rechenregeln

- **√(a · b) = √a · √b** (a, b ≥ 0)
- **√(a / b) = √a / √b** (a ≥ 0, b > 0)
- **√a · √a = a**

**Achtung:** Für Summen gibt es keine solche Regel!
√(9 + 16) = √25 = 5, aber √9 + √16 = 3 + 4 = 7.

## Teilweise Wurzeln ziehen

Man zerlegt den Radikanden in einen Quadratzahl-Faktor und einen Rest:

- √50 = √(25 · 2) = 5√2
- √12 = √(4 · 3) = 2√3
- √72 − √18 = 6√2 − 3√2 = 3√2

## Nenner rational machen

Ein Bruch mit Wurzel im Nenner wird mit dieser Wurzel erweitert:

- 1/√2 = √2 / (√2 · √2) = √2 / 2
- 6/√3 = 6√3 / 3 = 2√3

## Dritte binomische Formel mit Wurzeln

(√3 + 1)(√3 − 1) = (√3)² − 1² = 3 − 1 = 2.

## Abschätzen

Weil 16 < 20 < 25 gilt, liegt √20 zwischen 4 und 5.
