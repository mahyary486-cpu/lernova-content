# Variaciones, combinaciones y números combinatorios

## ¿Importa el orden?
- Sí: variaciones. V(n; k) = n!/(n − k)!.
- No: combinaciones. C(n; k) = n!/(k!·(n − k)!).

## Ejemplos
- Elegir presidente y vicepresidente entre 5 personas: V(5; 2) = 20.
- Elegir 2 representantes entre 5 personas: C(5; 2) = 10.

## Propiedades de los números combinatorios
- C(n; 0) = C(n; n) = 1.
- C(n; k) = C(n; n − k).
- C(n; k) + C(n; k + 1) = C(n + 1; k + 1) (triángulo de Pascal).

## Binomio de Newton
(a + b)ⁿ = Σ C(n; k) aⁿ⁻ᵏ bᵏ. Por ejemplo (a + b)³ = a³ + 3a²b + 3ab² + b³.

## Error frecuente
Usar combinaciones cuando los cargos distinguen a las personas.
