# Propriétés de l’intégrale

## Linéarité
Pour f et g continues sur [a ; b] et k réel :
- ∫_a^b (f + g) = ∫_a^b f + ∫_a^b g ;
- ∫_a^b (k f) = k ∫_a^b f.
Exemple : ∫_0^1 (3x² + 2x + 1) dx = 1 + 1 + 1 = 3.

## Relation de Chasles
Pour a, b, c dans un intervalle où f est continue : ∫_a^c f = ∫_a^b f + ∫_b^c f.
Exemple : si ∫_0^3 f = 5 et ∫_0^2 f = 2, alors ∫_2^3 f = 3.

## Positivité
Si f ≥ 0 sur [a ; b] avec a ≤ b, alors ∫_a^b f ≥ 0.

## Comparaison
Si f ≤ g sur [a ; b] (a ≤ b), alors ∫_a^b f ≤ ∫_a^b g.

## Symétrie
Pour f impaire sur [−a ; a], ∫_(−a)^a f = 0. Par exemple ∫_(−1)^1 x³ dx = 0.

## Inégalité de la moyenne
Si m ≤ f ≤ M sur [a ; b], alors m(b − a) ≤ ∫_a^b f ≤ M(b − a).

## Remarque
Un encadrement de l’intégrale peut servir à estimer une aire sans calculer de primitive.

## Erreur fréquente
∫ f × g n’est pas égal à (∫ f) × (∫ g) : l’intégrale n’est linéaire que pour les sommes.
