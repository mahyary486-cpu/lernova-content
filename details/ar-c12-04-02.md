# Equilibrio químico

## Constante
Para a A + b B ⇌ c C + d D:
Kc = [C]^c·[D]^d / ([A]^a·[B]^b)

## Interpretación
- Kc grande: predominan los productos.
- Kc pequeña: predominan los reactivos.
- Q < Kc: avanza a la derecha.

## Error frecuente
Pensar que en el equilibrio la reacción se detiene: ambas reacciones siguen ocurriendo.
