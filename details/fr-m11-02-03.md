# Signe d’un trinôme et inéquations du second degré

## Règles de signe (a ≠ 0)
- Δ > 0, racines x1 < x2 : le trinôme est du signe de a pour x < x1 et x > x2, et du signe contraire de a entre les racines.
- Δ = 0 : le trinôme est du signe de a, sauf en x0 où il s’annule.
- Δ < 0 : le trinôme est du signe de a pour tout réel x.

## Exemples
- x² − x − 6 ≥ 0 : racines −2 et 3, a > 0. Solution : ]−∞ ; −2] ∪ [3 ; +∞[.
- −x² + 4x − 3 > 0 : racines 1 et 3, a < 0. Solution : ]1 ; 3[.
- x² − 4 < 0 : solution ]−2 ; 2[.
- x² + x + 1 > 0 pour tout x car Δ < 0 et a > 0.

## Méthode
1. On met l’inéquation sous la forme ax² + bx + c ≷ 0.
2. On calcule Δ et les racines éventuelles.
3. On applique la règle du signe, on tient compte des bornes (inégalité stricte ou large).

## Paramètre
x² + mx + 1 = 0 n’a pas de solution si Δ = m² − 4 < 0, c’est-à-dire −2 < m < 2.

## Application : problème de géométrie
Un rectangle a une longueur égale à la largeur plus 3 et une aire de 40. Avec la largeur w : w(w + 3) = 40, soit w² + 3w − 40 = 0, Δ = 169 et w = 5.

## Erreur fréquente
Écrire que le trinôme est négatif à l’extérieur des racines alors que a > 0.
