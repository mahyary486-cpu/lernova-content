# 任意角与弧度制

## 任意角

- 按逆时针方向旋转形成的角叫**正角**，按顺时针方向旋转形成的角叫**负角**，不旋转形成**零角**；
- 与角 α 终边相同的角：**β = α + k · 360°**（k ∈ Z）；
- 象限角：终边在第几象限就叫第几象限角。

## 弧度制

弧长等于半径的圆弧所对的圆心角叫 **1 弧度**的角。

- 180° = π rad，360° = 2π rad；
- 30° = π/6，45° = π/4，60° = π/3，90° = π/2。

## 弧长与扇形面积

圆心角 α（弧度）、半径 r：

- 弧长 **l = |α| · r**；
- 扇形面积 **S = ½lr = ½|α|r²**。

**例：** 半径 2、圆心角 π/3 的扇形，弧长 l = 2π/3，面积 S = ½ × (2π/3) × 2 = 2π/3。
