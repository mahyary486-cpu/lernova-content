# 盐类的水解与沉淀溶解平衡

## 盐类的水解

盐电离出的**弱酸阴离子**或**弱碱阳离子**，与水电离出的 H⁺ 或 OH⁻ 结合，生成弱电解质的反应。

规律：**有弱才水解，无弱不水解；谁强显谁性，都强显中性**。

- CH₃COONa：CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻，**碱性**；
- NH₄Cl：NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺，**酸性**；
- NaCl：中性。

影响因素：**越热越水解，越稀越水解**。

应用：明矾净水（Al³⁺ 水解生成 Al(OH)₃ 胶体）；热的纯碱溶液去油污；配制 FeCl₃ 溶液时加盐酸抑制水解。

## 沉淀溶解平衡

AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)

**Ksp = c(Ag⁺) · c(Cl⁻) = 1.8×10⁻¹⁰**（25℃）。

- 离子积 Qc > Ksp：有沉淀析出；Qc = Ksp：饱和；Qc < Ksp：沉淀溶解；
- AgCl 饱和溶液：c(Ag⁺) = √Ksp = √(1.8×10⁻¹⁰) ≈ 1.34×10⁻⁵ mol/L。
