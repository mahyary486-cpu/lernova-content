# Mutlak değer ve eşitsizlikler

## Mutlak değer

- x ≥ 0 için ∣x∣ = x; x < 0 için ∣x∣ = −x
- ∣−7∣ = 7
- ∣x∣ her zaman 0 veya pozitiftir.

## Mutlak değerli denklemler

∣x − 3∣ = 5 ise x − 3 = 5 veya x − 3 = −5 olur; çözüm kümesi {−2, 8} dir.

∣A∣ = ∣B∣ ise A = B veya A = −B alınır.

## Eşitsizlikler

- −2x > 6 ise iki taraf −2 ile bölünür ve yön değişir: x < −3.
- −3 < 2x + 1 ≤ 9 ise her yerden 1 çıkarılır, 2'ye bölünür: −2 < x ≤ 4.

## Mutlak değerli eşitsizlikler

- ∣x∣ < a (a > 0) ise −a < x < a
- ∣x∣ > a (a > 0) ise x < −a veya x > a

**Örnek:** ∣x − 2∣ ≤ 3 ise −1 ≤ x ≤ 5 tir.
