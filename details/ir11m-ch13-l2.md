# میانگین نمونه و خطای معیار

## این درس درباره‌ی چیست؟

میانگین نمونه‌ها از نمونه‌ای به نمونه‌ی دیگر کمی تغییر می‌کند.

## خطای معیار

**SE = σ/√n** نشان می‌دهد میانگین نمونه چقدر تغییر می‌کند.

**مثال:** σ = 20 و n = 100 ⇒ SE = 2. اگر n چهار برابر شود SE نصف می‌شود.

## نسبت نمونه

برای نسبت: p̂ = x/n و **SE = √(p̂(1 − p̂)/n)**. از 400 نفر 120 موافق: p̂ = 0٫3.
