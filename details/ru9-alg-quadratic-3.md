# Квадратные неравенства

Чтобы решить неравенство ax² + bx + c > 0 (или <, ≥, ≤), выполните три шага.

1. Найдите нули выражения ax² + bx + c (решите уравнение).
2. Схематично изобразите параболу: ветви вверх при a > 0, вниз при a < 0.
3. Прочитайте ответ по графику: для «> 0» берите значения x, при которых парабола выше оси x, для «< 0» — ниже. Нули включайте в ответ только при знаках ≥ и ≤.

**Пример.** x² − 5x + 6 ≤ 0. Нули: 2 и 3. Ветви вверх, значит, между нулями парабола лежит не выше оси x. Ответ: [2; 3].

**Особые случаи.** Если D < 0 и a > 0, то ax² + bx + c > 0 при всех x. Если D = 0, парабола касается оси x в одной точке, поэтому (x − 2)² > 0 верно при всех x, кроме x = 2.
