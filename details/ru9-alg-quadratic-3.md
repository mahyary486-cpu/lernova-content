# Quadratic inequalities

To solve ax² + bx + c > 0 (or <, ≥, ≤) follow three steps.

1. Find the zeros of ax² + bx + c (solve the equation).
2. Sketch the parabola: branches up if a > 0, down if a < 0.
3. Read the answer from the graph: for "> 0" take the x-values where the parabola is above the x-axis, for "< 0" where it is below. Include the zeros only when the sign is ≥ or ≤.

**Example.** x² − 5x + 6 ≤ 0. Zeros: 2 and 3. Branches up, so the parabola is below or on the axis between the zeros. Answer: [2; 3].

**Special cases.** If D < 0 and a > 0, then ax² + bx + c > 0 for every x. If D = 0 the parabola touches the axis at one point, so (x − 2)² > 0 holds for all x except x = 2.
