# Geometric progression

In a **geometric progression** each term is the previous one multiplied by the same nonzero number q, the **common ratio**: bₙ₊₁ = bₙ · q.

**nth term:** bₙ = b₁ · qⁿ⁻¹.

Example: 2, 6, 18, … has q = 3. For b₁ = 3 and q = −2: b₅ = 3 · (−2)⁴ = 48. If q is negative the signs alternate.

**Characteristic property.** For terms with positive values, bₙ² = bₙ₋₁ · bₙ₊₁. So if 1, x, 9 is a geometric progression with x > 0, then x² = 9 and x = 3.
