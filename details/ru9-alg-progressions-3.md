# Геометрическая прогрессия

В **геометрической прогрессии** каждый член получается из предыдущего умножением на одно и то же ненулевое число q — **знаменатель прогрессии**: bₙ₊₁ = bₙ · q.

**Формула n-го члена:** bₙ = b₁ · qⁿ⁻¹.

Пример: у прогрессии 2, 6, 18, … знаменатель q = 3. При b₁ = 3 и q = −2 получаем b₅ = 3 · (−2)⁴ = 48. Если q отрицателен, знаки членов чередуются.

**Характеристическое свойство.** Для положительных членов bₙ² = bₙ₋₁ · bₙ₊₁. Поэтому если 1, x, 9 — геометрическая прогрессия и x > 0, то x² = 9 и x = 3.
