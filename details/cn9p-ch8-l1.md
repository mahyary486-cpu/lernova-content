# 磁现象与磁场

## 磁体与磁极

- 磁体能吸引铁、钴、镍等物质；
- 磁体上磁性最强的部分叫**磁极**，分为 N 极和 S 极；
- **同名磁极相互排斥，异名磁极相互吸引**；
- 使原来没有磁性的物体获得磁性的过程叫**磁化**。

## 磁场

磁体周围存在一种看不见、摸不着的特殊物质，叫**磁场**。磁场对放入其中的磁体有力的作用。

- 小磁针静止时 **N 极所指的方向**，就是该点的磁场方向；
- **磁感线**：为了形象描述磁场而画的假想曲线，磁体外部从 N 极出发回到 S 极。

## 地磁场

地球周围存在地磁场。地磁的北极在地理的**南极**附近，地磁的南极在地理的北极附近。我国宋代的沈括最早发现磁偏角。
