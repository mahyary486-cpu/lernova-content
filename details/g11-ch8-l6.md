# Solving Trigonometric Equations

## Basic equations
Isolate the trig function, find the **reference angle**, use the quadrants where the function has the right sign, then list the solutions in the interval.

On [0, 2π):
- **sin x = 1/2.** Sine is positive in QI and QII, reference angle π/6. Solutions: **x = π/6 and x = 5π/6**.
- **cos x = 1/2.** Cosine is positive in QI and QIV. Solutions: **x = π/3 and x = 5π/3**.
- **cos x = -sqrt(2)/2.** Negative in QII and QIII, reference angle π/4. Solutions: **x = 3π/4 and x = 5π/4**.
- **tan x = 1.** Positive in QI and QIII. Solutions: **x = π/4 and x = 5π/4**.
- **sin x = 1.** Solution: **x = π/2**.
- **sin x = 2.** Sine is never greater than 1, so there is **no solution**.

## All solutions
Because the functions repeat, the general solution adds multiples of the period.
sin x = 1/2: **x = π/6 + 2πn or x = 5π/6 + 2πn**, where n is any integer.
tan x = 1: x = π/4 + πn.

## Equations in quadratic form
Treat sin x or cos x as a variable and factor.

**2 sin² x - sin x - 1 = 0.** Factor: (2 sin x + 1)(sin x - 1) = 0. So sin x = -1/2 or sin x = 1.
- sin x = -1/2: x = 7π/6 or x = 11π/6.
- sin x = 1: x = π/2.
Solutions: **π/2, 7π/6, 11π/6**.

**2 cos² x = cos x.** Do **not** divide by cos x. Move everything: cos x (2 cos x - 1) = 0. So cos x = 0 (x = π/2, 3π/2) or cos x = 1/2 (x = π/3, 5π/3). Solutions: **π/3, π/2, 3π/2, 5π/3**.

**Using an identity.** 2 sin² x + cos x - 1 = 0. Replace sin² x with 1 - cos² x: 2 - 2 cos² x + cos x - 1 = 0, which becomes 2 cos² x - cos x - 1 = 0. Factor: (2 cos x + 1)(cos x - 1) = 0. So cos x = -1/2 (x = 2π/3, 4π/3) or cos x = 1 (x = 0). Solutions: **0, 2π/3, 4π/3**.

## Multiple angles
**sin 2x = sqrt(3)/2 on [0, 2π).** Then 2x must be in [0, 4π). The angles with sine sqrt(3)/2 are π/3, 2π/3, 7π/3 and 8π/3. Divide by 2: **x = π/6, π/3, 7π/6, 4π/3**.

## Common mistakes
- Dividing by a trig function and losing solutions.
- Giving only one solution when two quadrants work.
- Forgetting that for sin 2x the interval for 2x is twice as long.
- Accepting an answer like sin x = 2. The values of sine and cosine are always between -1 and 1.
