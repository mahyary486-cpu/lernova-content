# 钠及其化合物

## 钠的性质

钠是银白色金属，质软，密度比水小（0.97 g/cm³），比煤油大，熔点低。**保存在煤油中**。

- 与氧气：常温 4Na + O₂ = 2Na₂O（白色）；加热 2Na + O₂ =(△)= Na₂O₂（淡黄色）；
- 与水：2Na + 2H₂O = 2NaOH + H₂↑。现象：**浮、熔、游、响、红**（滴入酚酞变红）。

## 过氧化钠

- 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑
- 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂

可用作呼吸面具和潜水艇的供氧剂。

## 碳酸钠和碳酸氢钠

- 碳酸钠 Na₂CO₃：俗称纯碱、苏打；
- 碳酸氢钠 NaHCO₃：俗称小苏打，受热易分解：2NaHCO₃ =(△)= Na₂CO₃ + H₂O + CO₂↑；
- 溶解度：Na₂CO₃ > NaHCO₃；与盐酸反应，NaHCO₃ 更剧烈。

## 焰色试验

钠的焰色为**黄色**；钾的焰色为**紫色**（透过蓝色钴玻璃观察）。
