# Instructions conditionnelles if, elif et else

## Syntaxe
if x > 0:
    print('positif')
elif x == 0:
    print('nul')
else:
    print('négatif')
Les deux-points terminent la ligne de condition, et le bloc est décalé (indentation).

## Comparaisons
==, !=, <, <=, >, >=.
Conditions composées : and (et), or (ou), not (non).
Exemple : x > 0 and x < 10 est vrai si x est strictement entre 0 et 10.

## Ordre des tests
Python s’arrête au premier test vrai. Avec x = 10 :
if x > 5: y = 1
elif x > 8: y = 2
else: y = 3
y vaut 1, car x > 5 est déjà vrai : le test x > 8 n’est jamais examiné.

## Exemple : parité
if x % 2 == 0:
    print('pair')
else:
    print('impair')

## Exemple : valeur absolue
def val_abs(x):
    if x >= 0:
        return x
    else:
        return -x

## Erreur fréquente
Écrire if x = 5 au lieu de if x == 5. Le simple = est une affectation et provoque une erreur dans une condition.
