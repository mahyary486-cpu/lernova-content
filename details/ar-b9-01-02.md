# Estructura y organelas

| Organela | Función |
|---|---|
| Núcleo | Contiene el ADN |
| Mitocondria | Respiración celular (ATP) |
| Ribosoma | Síntesis de proteínas |
| Retículo endoplasmático | Síntesis y transporte |
| Aparato de Golgi | Empaqueta y distribuye |
| Lisosoma | Digestión |
| Cloroplasto | Fotosíntesis (solo vegetales) |

## Diferencias
La célula vegetal posee pared celular, cloroplastos y vacuola central.

## Error frecuente
Decir que la célula animal no respira: tiene mitocondrias.
