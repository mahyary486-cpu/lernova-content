# 基本不等式与最值问题

## 一正、二定、三相等

使用基本不等式 a + b ≥ 2√(ab)（a > 0，b > 0）求最值时：

- **一正**：各项为正；
- **二定**：和为定值（积有最大值）或积为定值（和有最小值）；
- **三相等**：等号能取到。

## 常用技巧：常数代换

**例 1：** x > 0，y > 0，x + 2y = 1，求 1/x + 1/y 的最小值。

(1/x + 1/y)(x + 2y) = 1 + 2y/x + x/y + 2 = 3 + 2y/x + x/y ≥ 3 + 2√2。

当 x/y = 2y/x，即 x = √2 y 时取等号，最小值为 **3 + 2√2**。

## 配凑

**例 2：** x > 1，求 x + 1/(x − 1) 的最小值。

x + 1/(x − 1) = (x − 1) + 1/(x − 1) + 1 ≥ 2 + 1 = 3，当 x = 2 时取等号。

## 提示

若等号取不到，要改用函数的单调性求最值。
