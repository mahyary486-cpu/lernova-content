# Координаты вектора

Если A(x₁; y₁) и B(x₂; y₂), то вектор AB имеет координаты (x₂ − x₁; y₂ − y₁). Для A(1; 2) и B(4; 6) получаем AB = (3; 4).

**Действия в координатах.** Для a = (x₁; y₁) и b = (x₂; y₂):

- a + b = (x₁ + x₂; y₁ + y₂), например (1; 2) + (3; −1) = (4; 1)
- a − b = (x₁ − x₂; y₁ − y₂)
- ka = (kx₁; ky₁), например 2 · (3; −1) = (6; −2)

**Длина.** |a| = √(x² + y²). Для (3; 4) длина равна 5.

**Коллинеарность.** Векторы a = (x₁; y₁) и b = (x₂; y₂) коллинеарны, когда их координаты пропорциональны: x₁ / x₂ = y₁ / y₂. Поэтому (2; 4) и (1; k) коллинеарны при k = 2.
