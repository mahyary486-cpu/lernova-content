# Coordinates of a vector

If A(x₁; y₁) and B(x₂; y₂), the vector AB has coordinates (x₂ − x₁; y₂ − y₁). For A(1; 2) and B(4; 6) we get AB = (3; 4).

**Operations in coordinates.** For a = (x₁; y₁) and b = (x₂; y₂):

- a + b = (x₁ + x₂; y₁ + y₂), for example (1; 2) + (3; −1) = (4; 1)
- a − b = (x₁ − x₂; y₁ − y₂)
- ka = (kx₁; ky₁), for example 2 · (3; −1) = (6; −2)

**Length.** |a| = √(x² + y²). For (3; 4) the length is 5.

**Collinearity.** a = (x₁; y₁) and b = (x₂; y₂) are collinear when their coordinates are proportional: x₁ / x₂ = y₁ / y₂. So (2; 4) and (1; k) are collinear for k = 2.
