# Principio de Le Châtelier

## Perturbaciones
- Concentración: se consume el agregado.
- Temperatura: se favorece el sentido endotérmico al calentar.
- Presión: se favorece el lado con menos moles de gas.
- Catalizador: no cambia el equilibrio.

## Ejemplo
Haber: alta presión favorece el NH₃.

## Error frecuente
Creer que un catalizador cambia Kc.
