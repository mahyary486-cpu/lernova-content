# Equations of Motion with Constant Acceleration

When the acceleration is constant, a small set of equations connects displacement d, initial velocity v0, final velocity v, acceleration a and time t. These are often called the kinematic equations.

## Key ideas
1. v = v0 + at (no displacement)
2. d = v0 t + (1/2) a t^2 (no final velocity)
3. v^2 = v0^2 + 2ad (no time)
4. d = ((v0 + v) / 2) t (no acceleration)

**Problem-solving plan:** list the known and unknown quantities with signs, pick the equation that contains the unknown and leaves out the quantity you do not have, then solve and check the units. These equations are valid only when acceleration is constant.

## Worked examples
**Example 1: Distance from rest.** A bike starts from rest and accelerates at 4.0 m/s^2 for 3.0 s.
1. Known: v0 = 0, a = 4.0 m/s^2, t = 3.0 s.
2. d = v0 t + (1/2) a t^2 = 0 + 0.5 x 4.0 x 9.0.
3. d = 18 m.

**Example 2: Stopping distance.** A car at 20 m/s brakes at -5.0 m/s^2 until it stops.
1. Known: v0 = 20 m/s, v = 0, a = -5.0 m/s^2.
2. Use v^2 = v0^2 + 2ad: 0 = 400 + 2(-5.0)d.
3. 10d = 400, so d = 40 m.
4. Doubling v0 would make d four times as large, since d depends on v0^2.

**Example 3: Stopping before the time ends.** A car at 15 m/s brakes at -3.0 m/s^2. How far does it go in 7.0 s?
1. Time to stop = 15 / 3.0 = 5.0 s, so it is at rest before 7.0 s.
2. d = v0^2 / (2 x 3.0) = 225 / 6.0 = 37.5 m.
3. Using t = 7.0 s in equation 2 would give 31.5 m, which is wrong because the car would be reversing.

## Common mistakes
- Using the equations when acceleration is not constant.
- Ignoring signs: braking acceleration must be negative if the velocity is positive.
- Forgetting the factor one half in d = (1/2) a t^2 or the factor 2 in 2ad.
- Taking v^2 and forgetting the square root at the end.
- Continuing to apply the equations after the object has stopped.
