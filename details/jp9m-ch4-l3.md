# 関数 y = ax² の利用

## 身のまわりの2乗に比例する関数

- 自由落下：落ちる距離 y m は時間 x 秒の2乗に比例（例：y = 5x²）。
- 制動距離：速さの2乗にほぼ比例する。

**例：** y = 5x² で 3 秒間に落ちる距離は 5 × 9 = 45 m。

**比で考える：** 速さが2倍になると制動距離は 2² = 4 倍になります。

## 放物線と直線

y = x² と直線 y = x + 2 の交点の x 座標は、x² = x + 2 を解いて求めます。

x² − x − 2 = 0、(x + 1)(x − 2) = 0 より x = −1、2。交点は (−1, 1) と (2, 4)。

## 座標と面積

放物線上の2点 A(−1, 1)、B(2, 4) と原点 O で、△OAB の面積は、直線 AB と y 軸との交点 C(0, 2) を使って分けて考えます。

△OAB = △OCA + △OCB = 2 × 1 ÷ 2 + 2 × 2 ÷ 2 = 3
