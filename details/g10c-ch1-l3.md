# Atomic Number, Mass Number and Isotopes

Every atom is described by two whole numbers, and atoms of one element can come in different forms called isotopes.

## Key ideas
- **Atomic number (Z)** = number of protons. It defines the element.
- **Mass number (A)** = protons + neutrons, so neutrons N = A - Z.
- In a neutral atom, electrons = protons. For an ion, electrons = Z - charge (a 3+ ion has 3 fewer electrons).
- **Isotopes** are atoms of the same element (same Z) with different numbers of neutrons. They are written like carbon-14 or 14C.
- **Average atomic mass** is a weighted average: sum of (isotope mass x fractional abundance). It is the number shown on the periodic table.

## Worked examples
**Example 1: Particles in 27Al^3+** (Z = 13).
1. Protons = 13.
2. Neutrons = 27 - 13 = 14.
3. Electrons = 13 - 3 = 10.

**Example 2: Average atomic mass of boron.** B-10 is 10.013 amu (19.9 percent) and B-11 is 11.009 amu (80.1 percent).
1. 0.199 x 10.013 = 1.993 amu.
2. 0.801 x 11.009 = 8.818 amu.
3. Sum = 10.81 amu.

**Example 3: Finding abundance.** Copper has Cu-63 (62.93 amu) and Cu-65 (64.93 amu), average 63.55 amu. Let x be the fraction of Cu-63.
1. 62.93x + 64.93(1 - x) = 63.55.
2. 64.93 - 2.00x = 63.55, so x = 1.38 / 2.00 = 0.69.
3. Cu-63 is 69 percent, and Cu-65 is 31 percent.

## Common mistakes
- Taking a simple average of isotope masses instead of a weighted one.
- Adding the atomic number and mass number to find neutrons. Subtract them.
- Adding electrons for a positive ion. A positive ion has lost electrons.
- Thinking isotopes have different numbers of protons. If the protons change, the element changes.
- Mixing up atomic number (a whole number) with average atomic mass (a decimal).
