# Writing Two-Column Proofs

## What a proof is
A **proof** is a logical argument that shows a statement is true. In a **two-column proof**:
- the **left** column lists the **statements**, one step at a time;
- the **right** column gives the **reason** that justifies each statement.

## Parts of a proof
- **Given:** the facts you start with.
- **Prove:** the statement you want to show.
- A diagram, when there is one.

## Reasons you can use
- The **Given** information.
- **Definitions** (such as the definition of midpoint or angle bisector).
- **Postulates** (such as the Segment Addition Postulate).
- **Properties of equality**: reflexive (a = a), symmetric (if a = b then b = a), transitive (if a = b and b = c then a = c), addition, subtraction, multiplication, division, substitution and distributive.
- **Theorems** that were already proved (such as Vertical Angles Theorem).

## Example 1: a linear pair
**Given:** angle 1 and angle 2 are a linear pair, and m angle 1 = 65.
**Prove:** m angle 2 = 115.

| Statement | Reason |
|---|---|
| 1. Angle 1 and angle 2 are a linear pair | 1. Given |
| 2. m angle 1 + m angle 2 = 180 | 2. Linear pair postulate (supplementary) |
| 3. m angle 1 = 65 | 3. Given |
| 4. 65 + m angle 2 = 180 | 4. Substitution property |
| 5. m angle 2 = 115 | 5. Subtraction property of equality |

## Example 2: a midpoint
**Given:** B is the midpoint of AC, and AB = 5.
**Prove:** AC = 10.

| Statement | Reason |
|---|---|
| 1. B is the midpoint of AC | 1. Given |
| 2. AB = BC | 2. Definition of midpoint |
| 3. AB = 5 | 3. Given |
| 4. BC = 5 | 4. Substitution property |
| 5. AB + BC = AC | 5. Segment Addition Postulate |
| 6. 5 + 5 = AC | 6. Substitution property |
| 7. AC = 10 | 7. Simplify |

## Tips
1. Mark the given information on the diagram.
2. Plan backward: ask what you need to know just before the last step.
3. Every statement needs a reason. Write the reason in words, not only a symbol.

## Common mistakes
- Using the statement you are trying to prove as a reason (this is circular reasoning).
- Skipping a step, or giving "it looks true in the diagram" as a reason.
- Writing a reason that does not match the statement, for example calling a step the "distributive property" when it uses substitution.
