# اتحادهای مثلثاتی و زاویه‌های مرتبط

## این درس درباره‌ی چیست؟

اتحادها روابطی‌اند که برای همه‌ی زاویه‌ها درست‌اند و ساده‌سازی را آسان می‌کنند.

## اتحادهای اصلی

- **sin²x + cos²x = 1**
- **1 + tan²x = 1/cos²x**
- tan x = sin x / cos x

## زاویه‌های مرتبط

- sin(−x) = −sin x و cos(−x) = cos x
- sin(π − x) = sin x و cos(π − x) = −cos x
- sin(π + x) = −sin x و cos(π + x) = −cos x
- sin(π/2 − x) = cos x و cos(π/2 − x) = sin x

## ربع‌ها

برای علامت، ببینید زاویه در کدام ربع است: sin در ربع اول و دوم مثبت، cos در ربع اول و چهارم مثبت و tan در ربع اول و سوم مثبت است.
