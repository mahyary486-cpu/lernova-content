# Suites arithmétiques

## Définition
(u_n) est arithmétique de raison r si, pour tout n, u_(n+1) = u_n + r. On passe d’un terme au suivant en ajoutant toujours le même nombre r.
Exemple : 5, 8, 11, 14 est arithmétique de raison 3.

## Terme général
u_n = u_0 + n r. Plus généralement, u_n = u_p + (n − p) r.
Exemple : u_0 = 4 et r = 3 donnent u_10 = 4 + 30 = 34.
Exemple : u_2 = 8 et u_5 = 17 donnent r = (17 − 8)/3 = 3.

## Variation
- r > 0 : suite croissante.
- r < 0 : suite décroissante.
- r = 0 : suite constante.
Exemple : u_0 = 10 et r = −3 donnent u_n = 10 − 3n ; u_n < 0 dès que n > 10/3, donc à partir de n = 4.

## Reconnaître une suite arithmétique
On calcule u_(n+1) − u_n. Si le résultat est une constante r, la suite est arithmétique.
Pour u_n = 2n + 1 : u_(n+1) − u_n = 2, donc arithmétique de raison 2.

## Lien avec les fonctions affines
Le terme général u_n = u_0 + n r est de la forme affine, et les points (n ; u_n) sont alignés.

## Erreur fréquente
Confondre la raison d’une suite arithmétique (on additionne) avec celle d’une suite géométrique (on multiplie).
