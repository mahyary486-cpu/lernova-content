# Bohr's model and the hydrogen spectrum

Electrons move in stationary orbits; the energy is Eₙ = −13.6/n² eV and the radius is proportional to n². Emission series: Lyman (to n = 1, UV), Balmer (to n = 2, visible), Paschen (to n = 3).

The longest wavelength Balmer line is the transition n = 3 to n = 2.
