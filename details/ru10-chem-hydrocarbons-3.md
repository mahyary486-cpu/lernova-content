# Алкены и алкины

**Алкены** содержат двойную связь, их общая формула CₙH₂ₙ. Простейший — этилен (этен) C₂H₄.

**Алкины** содержат тройную связь, общая формула CₙH₂ₙ₋₂. Простейший — ацетилен (этин) C₂H₂. Пропин C₃H₄ имеет 4 атома водорода.

**Реакции присоединения** (характерны для непредельных углеводородов):

- гидрирование: C₂H₄ + H₂ → C₂H₆;
- галогенирование: C₂H₄ + Br₂ → C₂H₄Br₂ (1,2-дибромэтан). Бромная вода при этом обесцвечивается, это качественная реакция на двойную связь;
- гидратация: C₂H₄ + H₂O → C₂H₅OH (этанол);
- полимеризация: n CH₂=CH₂ → (–CH₂–CH₂–)ₙ.

Ацетилен используют при сварке и резке металлов.
