# Wendepunkte und Krümmung

## Krümmung

- f″(x) > 0: **Linkskrümmung** (konvex), die Steigung nimmt zu
- f″(x) < 0: **Rechtskrümmung** (konkav), die Steigung nimmt ab

## Wendepunkte

Ein **Wendepunkt** ist ein Punkt, an dem sich die Krümmung ändert.

- **Notwendig:** f″(x₀) = 0
- **Hinreichend:** f″(x₀) = 0 und f‴(x₀) ≠ 0 (oder Vorzeichenwechsel von f″)

Die Tangente im Wendepunkt heißt **Wendetangente**.

Ist zusätzlich f′(x₀) = 0, spricht man von einem **Sattelpunkt** (z. B. f(x) = x³ bei x = 0).

## Beispiele

**Beispiel 1:** f(x) = x³ − 3x.
f″(x) = 6x = 0 ergibt x = 0. Wendepunkt (0, 0).

**Beispiel 2:** f(x) = x³ − 6x² + 9x.
f″(x) = 6x − 12 = 0 ergibt x = 2. Wendepunkt (2, 2).
Wendetangente: f′(2) = −3, also y = −3x + 8.

**Beispiel 3:** f(x) = x⁴ − 2x².
f″(x) = 12x² − 4 = 0 ergibt x = ±1/√3 ≈ ±0,58.
