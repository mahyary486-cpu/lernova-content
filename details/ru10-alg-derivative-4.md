# Монотонность и экстремумы

**Признак монотонности.** Если f′(x) > 0 на промежутке, функция на нём возрастает. Если f′(x) < 0, функция убывает.

**Критические точки** — точки, в которых f′(x) = 0. Экстремум может быть только в критической точке.

- Если при переходе через точку производная меняет знак с «+» на «−», это **точка максимума**.
- Если знак меняется с «−» на «+», это **точка минимума**.

**Пример.** f(x) = x² − 4x. f′(x) = 2x − 4 = 0 при x = 2. При x < 2 производная отрицательна, при x > 2 положительна, поэтому x = 2 — точка минимума, а функция убывает на (−∞; 2].

**Пример.** f(x) = x³ − 3x. f′(x) = 3x² − 3 = 0 при x = ±1. При x = −1 максимум, при x = 1 минимум.

**Наибольшее и наименьшее значения** на промежутке ищут среди значений в критических точках и на концах промежутка. Для f(x) = −x² + 4x + 1 вершина x = 2 даёт наибольшее значение 5.
