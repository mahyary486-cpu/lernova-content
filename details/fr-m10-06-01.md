# Vecteur directeur et équation cartésienne d’une droite

## Vecteur directeur
Un vecteur directeur d’une droite d est un vecteur non nul qui a la même direction que d. Une droite a une infinité de vecteurs directeurs, tous colinéaires entre eux.
Exemple : AB→ est un vecteur directeur de (AB).

## Équation cartésienne
Toute droite du plan admet une équation de la forme ax + by + c = 0, avec a et b non tous les deux nuls. Réciproquement, un ensemble d’équation ax + by + c = 0 est une droite.
Le vecteur u→(−b ; a) est un vecteur directeur de cette droite.
Exemple : 3x + 2y − 6 = 0 a pour vecteur directeur (−2 ; 3).

## Droites particulières
- x = k (ou x − k = 0) : droite verticale.
- y = k : droite horizontale.
Exemple : la droite verticale passant par (3 ; 5) a pour équation x − 3 = 0.

## Un point appartient-il à une droite ?
On remplace x et y par ses coordonnées. Le point A(2 ; −1) est sur la droite x + 2y = 0 car 2 + 2 × (−1) = 0.

## Trouver une équation
Pour une droite passant par A(xA ; yA) de vecteur directeur u→(−b ; a), on écrit ax + by + c = 0 puis on remplace x et y par les coordonnées de A pour trouver c.

## Erreur fréquente
Ne pas confondre le vecteur directeur (−b ; a) avec le vecteur (a ; b), qui est perpendiculaire à la droite dans un repère orthonormé.
