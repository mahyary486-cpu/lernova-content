# Équations produit nul

## Propriété
Un produit de facteurs est nul si, et seulement si, au moins un de ses facteurs est nul.
A × B = 0 équivaut à A = 0 ou B = 0.

## Exemple
(x − 3)(2x + 8) = 0
x − 3 = 0 donne x = 3.
2x + 8 = 0 donne 2x = −8, donc x = −4.
Les solutions sont 3 et −4.

## Méthode pour une équation du second degré
1. On met tout dans un seul membre pour obtenir 0 de l’autre côté.
2. On factorise.
3. On applique la propriété du produit nul.

Exemple : x² − 5x = 0.
On factorise : x(x − 5) = 0, donc x = 0 ou x = 5.

Exemple avec une identité remarquable : x² − 16 = 0.
(x + 4)(x − 4) = 0, donc x = −4 ou x = 4.

## Attention
- Il faut que l’autre membre soit 0. L’équation (x − 2)(x − 3) = 6 ne se résout pas en disant x − 2 = 6 ou x − 3 = 6.
- Une équation produit nul peut avoir une seule solution : (x − 1)² = 0 donne x = 1.

## Rédaction
On écrit « Un produit est nul si l’un de ses facteurs est nul », puis on résout chaque équation et on donne l’ensemble des solutions.
