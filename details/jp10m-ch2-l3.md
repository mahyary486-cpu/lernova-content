# 逆・裏・対偶と証明

## 逆・裏・対偶

命題「p ならば q」に対して

- **逆**：q ならば p
- **裏**：p でない ならば q でない
- **対偶**：q でない ならば p でない

元の命題とその対偶は、真偽が必ず一致します。逆や裏は、真偽が一致するとは限りません。

**例：** 「x が 4 の倍数ならば x は偶数」の対偶は「x が偶数でないならば x は 4 の倍数でない」（真）。

## 対偶による証明

「n² が偶数ならば n は偶数」は、対偶「n が奇数ならば n² は奇数」を示すことで証明できます。n = 2k + 1 のとき n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 は奇数。

## 背理法

結論を否定して矛盾を導く証明方法です（例：√2 が無理数であることの証明）。
