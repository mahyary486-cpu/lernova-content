# 金属及其化合物的转化

## 钠及其化合物

Na → Na₂O / Na₂O₂ → NaOH → Na₂CO₃ ⇌ NaHCO₃。

## 铝及其化合物

Al → Al₂O₃ → AlCl₃ ⇌ Al(OH)₃ → NaAlO₂（偏铝酸钠）。

**向 AlCl₃ 溶液中滴加 NaOH 溶液（图象）：**

- Al³⁺ + 3OH⁻ = Al(OH)₃↓（先生成白色沉淀）；
- Al(OH)₃ + OH⁻ = AlO₂⁻ + 2H₂O（后沉淀溶解）。

**例：** 1 mol AlCl₃：

- 沉淀最多时消耗 NaOH 3 mol；
- 沉淀恰好完全溶解时共消耗 NaOH **4 mol**。

## 铁及其化合物

Fe ⇌ Fe²⁺ ⇌ Fe³⁺。

- Fe³⁺ 的检验：KSCN 溶液显红色；
- 2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺（FeCl₃ 溶液腐蚀铜制电路板）；
- 4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃。

## 铜及其化合物

Cu + 2H₂SO₄（浓）=(△)= CuSO₄ + SO₂↑ + 2H₂O。
