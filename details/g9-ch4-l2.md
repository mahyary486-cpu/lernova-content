# Zero and Negative Exponents

## Zero exponent
For any nonzero a: **a^0 = 1**.

Why? Using the quotient rule, a^3 / a^3 = a^(3-3) = a^0. But any nonzero number divided by itself is 1. So a^0 = 1. The expression 0^0 is left undefined in this course.

## Negative exponents
For nonzero a and a whole number n: **a^(-n) = 1 / a^n**.

A negative exponent does not make the number negative. It means "take the reciprocal." So 2^(-3) = 1/2^3 = 1/8.

Useful fact: a factor can move between numerator and denominator if you change the sign of its exponent. For example, 1 / x^(-4) = x^4.

For fractions: (a/b)^(-n) = (b/a)^n. So (2/3)^(-2) = (3/2)^2 = 9/4.

All the laws from the previous lesson still work with negative and zero exponents.

## Simplified form
A fully simplified expression has no zero or negative exponents, and each base appears once.

## Worked examples
**Example 1.** Evaluate 5^(-2) + 4^0.
1. 5^(-2) = 1/25.
2. 4^0 = 1.
3. Sum: 1/25 + 1 = 26/25.

**Example 2.** Simplify (3x^(-2) y^4) / (6 x^3 y^(-1)) using positive exponents.
1. Coefficients: 3/6 = 1/2.
2. x: x^(-2) / x^3 = x^(-5) = 1/x^5.
3. y: y^4 / y^(-1) = y^5.
4. Result: y^5 / (2x^5).

**Example 3.** Evaluate (2/5)^(-2).
1. Flip the fraction and make the exponent positive: (5/2)^2.
2. Square: 25/4.

## Common mistakes
- Thinking a^0 = 0. It equals 1.
- Thinking 2^(-3) = -8 or -6. The correct value is 1/8.
- Moving a coefficient with the variable: in 3x^(-2), only x moves, giving 3/x^2, not 1/(3x^2).
- Forgetting that (-3)^0 = 1 but -3^0 = -1, because the negative sign is not part of the base.
