# Атом Бора и спектры

**Планетарная модель** атома, предложенная **Резерфордом**, не объясняла устойчивость атомов и линейчатые спектры. **Н. Бор** дополнил её постулатами:

1. Атом может находиться только в стационарных состояниях с определёнными энергиями.
2. При переходе с верхнего уровня на нижний атом **испускает** фотон, энергия которого равна разности уровней: hν = E₂ − E₁. При переходе вверх фотон поглощается.

**Атом водорода:** Eₙ = −13,6 / n² эВ. При n = 1 получаем −13,6 эВ, а при n = 2 — −3,4 эВ.

**Спектры.** Нагретые газы дают **линейчатые спектры**, по которым определяют состав вещества.
