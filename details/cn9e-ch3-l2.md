# 不同时态的被动语态

## 常用时态的被动结构

| 时态 | 结构 | 例句 |
|---|---|---|
| 一般现在时 | am / is / are + 过去分词 | English is spoken here. |
| 一般过去时 | was / were + 过去分词 | The window was broken. |
| 一般将来时 | will be + 过去分词 | The bridge will be built next year. |
| 现在完成时 | has / have been + 过去分词 | The work has been finished. |
| 现在进行时 | am / is / are being + 过去分词 | The road is being repaired. |
| 含情态动词 | 情态动词 + be + 过去分词 | The problem can be solved. |

## 记忆方法

被动语态里一定有 **be 的某种形式** + **过去分词**。时态的变化体现在 be 上：

- 将来：will **be**；
- 完成：have **been**；
- 情态动词后：**be**。

## 常见错误

- ❌ The bridge will build next year.
- ✅ The bridge will **be built** next year.
