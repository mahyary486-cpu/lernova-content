# Zeroes of a linear polynomial

A zero of p(x) is a value of x for which p(x) = 0. For ax + b the zero is x = −b/a. A linear polynomial has exactly one zero.

Graphically, the zero is the x-coordinate of the point where the line meets the x-axis. Example: for 2x − 6 the zero is 3, so the graph of y = 2x − 6 crosses the x-axis at (3, 0).

To find the value of p at a number, substitute: if p(x) = 4x − 7 then p(2) = 1.
