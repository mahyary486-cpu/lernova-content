# Quadrants and signs

The axes divide the plane into four quadrants.

- First quadrant: x > 0, y > 0
- Second quadrant: x < 0, y > 0
- Third quadrant: x < 0, y < 0
- Fourth quadrant: x > 0, y < 0

Points on the x-axis have y = 0 and points on the y-axis have x = 0. These points lie on the axes and in no quadrant. If x · y > 0 the point lies in the first or third quadrant; if x · y < 0 it lies in the second or fourth.
