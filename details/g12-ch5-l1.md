# Fundamental Identities

An identity is an equation that is true for every value of the variable where both sides are defined. Trigonometric identities let us rewrite expressions in simpler forms and prove that two expressions are equal.

## Key ideas
- **Reciprocal:** csc x = 1/sin x, sec x = 1/cos x, cot x = 1/tan x.
- **Quotient:** tan x = sin x / cos x and cot x = cos x / sin x.
- **Pythagorean:** sin^2 x + cos^2 x = 1, 1 + tan^2 x = sec^2 x, 1 + cot^2 x = csc^2 x.
- **Even and odd (negative angle):** cos(-x) = cos x, sec(-x) = sec x. The other four functions are odd: sin(-x) = -sin x, tan(-x) = -tan x, and so on.
- **Cofunction:** sin(pi/2 - x) = cos x and cos(pi/2 - x) = sin x.

## Proving an identity
1. Start with the more complicated side.
2. Rewrite everything in terms of sine and cosine if you are stuck.
3. Use common denominators, factoring, and the Pythagorean identities.
4. Work on one side only until it matches the other side. Do not move terms across the equals sign.

## Worked examples
**Example 1.** Simplify (1 - cos^2 x) / sin x.
1. 1 - cos^2 x = sin^2 x.
2. sin^2 x / sin x = sin x.

**Example 2.** Prove tan x + cot x = sec x csc x.
1. Left side = sin x / cos x + cos x / sin x = (sin^2 x + cos^2 x) / (sin x cos x).
2. The numerator is 1, so the left side is 1 / (sin x cos x).
3. That equals (1/cos x)(1/sin x) = sec x csc x.

**Example 3.** If sin x = 3/5 and x is in Quadrant II, find cos x and tan x.
1. cos^2 x = 1 - 9/25 = 16/25.
2. Cosine is negative in Quadrant II, so cos x = -4/5.
3. tan x = (3/5) / (-4/5) = -3/4.

## Common mistakes
- Writing sin^2 x + cos^2 x = 1 as sin x + cos x = 1. Squares matter.
- Canceling a term that is only part of a sum, such as the sin x in (sin x + 1) / sin x.
- Treating sin(2x) as 2 sin x, or sin^2 x as sin(x^2).
- Working on both sides of the equals sign at once when proving an identity.
- Forgetting the plus or minus sign when taking a square root in the Pythagorean identity.
