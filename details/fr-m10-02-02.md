# Équations avec quotients et valeurs interdites

## Valeurs interdites
Un quotient A/B n’existe pas quand B = 0. On cherche d’abord les valeurs de x qui annulent le dénominateur.
- Dans 1/(x − 5), la valeur interdite est 5.
- Dans (x + 1)/(2x − 6), la valeur interdite est 3.
- Dans 1/(x² − 4), les valeurs interdites sont 2 et −2.

## Quotient nul
A/B = 0 équivaut à A = 0 et B ≠ 0.
Exemple : (x + 2)/(x − 1) = 0 donne x = −2 (et 1 est interdit, ce qui n’est pas gênant ici).

## Produit en croix
A/B = C/D équivaut à A × D = B × C (avec B et D non nuls).
Exemple : 1/(x − 2) = 3/(x + 4) donne x + 4 = 3(x − 2), donc x + 4 = 3x − 6, donc x = 5. Ni 2 ni −4 : la solution est valable.

## Équation 1/x = k
1/x = 2 donne x = 1/2. L’équation 1/x = 0 n’a pas de solution.

## Rédaction
On écrit « Valeurs interdites : … », on résout, puis on vérifie que la solution trouvée n’est pas une valeur interdite avant de conclure.
