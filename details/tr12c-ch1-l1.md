# Yükseltgenme–indirgenme ve galvanik piller

## Yükseltgenme basamağı

Bir atomun bileşikteki sanal yüküdür.

- Serbest elementlerde 0 (Zn, O₂, H₂).
- Bileşiklerde H genellikle +1, O genellikle −2 (peroksitte −1).
- Toplam yük = bileşiğin yükü.

**Örnekler:** KMnO₄ → Mn +7; K₂Cr₂O₇ → Cr +6; SO₄²⁻ → S +6; NH₃ → N −3; CO₂ → C +4; H₂O₂ → O −1.

## Redoks tepkimeleri

- **Yükseltgenme:** e⁻ kaybı, basamak artar. **İndirgenme:** e⁻ kazancı, basamak azalır.
- **İndirgen:** e⁻ veren (kendisi yükseltgenir). **Yükseltgen:** e⁻ alan (kendisi indirgenir).

Zn + Cu²⁺ → Zn²⁺ + Cu: Zn yükseltgenir (indirgen), Cu²⁺ indirgenir (yükseltgen).
Fe + 2HCl → FeCl₂ + H₂: Fe 0 → +2, H +1 → 0.
2Al + 3Cu²⁺ → 2Al³⁺ + 3Cu: toplam 6 elektron aktarılır.

## Galvanik pil

Kendiliğinden gerçekleşen redoks tepkimesinden elektrik enerjisi elde eden düzenek.

- **Anot (−):** Yükseltgenme.
- **Katot (+):** İndirgenme; elektrot kütlesi artar.
- **Elektron akışı:** Anot → dış devre → katot.
- **Tuz köprüsü** (KNO₃, KCl): İyon geçişiyle yük dengesini sağlar, devreyi tamamlar.

## Standart elektrot potansiyeli

- Standart koşullar: 25 °C, 1 M, 1 atm.
- Standart hidrojen elektrodu E° = 0 V.
- **E°pil = E°katot − E°anot**
- Zn–Cu: E°pil = 0,34 − (−0,76) = 1,10 V.
- E°pil > 0 → tepkime kendiliğinden gerçekleşir.
- E° büyük olan elektrot katot olur (indirgenme eğilimi fazla).
