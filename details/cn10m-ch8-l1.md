# 用样本估计总体

## 抽样方法

- **简单随机抽样**：每个个体被抽到的概率相等；
- **分层抽样**：按各层个体数的比例抽取。

**例：** 高一有 300 人，高二有 200 人，共抽取 50 人，则抽样比为 50/500 = 1/10，高一抽 30 人，高二抽 20 人。

## 频率分布直方图

- 每个小矩形的面积 = 组距 × 高 = 这一组的频率；
- 所有小矩形面积的和为 1。

## 数字特征

- **平均数**：x̄ = (x₁ + x₂ + … + xₙ) / n；
- **中位数**：把数据按大小排列后，位于中间的数（偶数个时取中间两数的平均）；
- **众数**：出现次数最多的数；
- **方差**：s² = (1/n) · Σ(xᵢ − x̄)²，**标准差** s = √(s²)。方差越大，数据越分散。

**例：** 数据 2，4，6，8：平均数 5，中位数 5，方差 = (9 + 1 + 1 + 9)/4 = 5。
