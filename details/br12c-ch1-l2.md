# Funções orgânicas

Cada **grupo funcional** dá propriedades características ao composto.

| Função | Grupo | Exemplo |
|---|---|---|
| Álcool | –OH | etanol |
| Aldeído | –CHO | metanal |
| Cetona | C=O entre carbonos | propanona (acetona) |
| Ácido carboxílico | –COOH | ácido acético (vinagre) |
| Éter | –O– entre carbonos | éter etílico |
| Éster | –COO– | acetato de etila |
| Amina | –NH₂ | metilamina |

## Reações importantes

- **Esterificação:** ácido carboxílico + álcool → éster + água.
- **Combustão do etanol:** C₂H₅OH + 3 O₂ → 2 CO₂ + 3 H₂O.

## Massa molar

Etanol, C₂H₆O (C = 12; H = 1; O = 16): 2 · 12 + 6 + 16 = 46 g/mol.

## Quiralidade

Um **carbono quiral** tem quatro grupos diferentes ligados a ele e origina isômeros ópticos.
