# 最大・最小と式の決定

## 最大値・最小値

定義域がある二次関数では、頂点が定義域に入っているかを調べ、頂点の値と端の値を比べます。

**例：** y = (x − 1)² + 4（−1 ≦ x ≦ 3）：頂点 x = 1 は範囲内。最小値 4（x = 1）。端：x = −1 で 8、x = 3 で 8。最大値 8。

a < 0 のときは頂点で最大値をとります。

## 式の決定

- 頂点 (p, q) と通る点がわかる → y = a(x − p)² + q に点を代入して a を求める。
- 3点がわかる → y = ax² + bx + c に代入して連立方程式を解く。

## 文章題

ロープで長方形をつくるとき、縦を x とおいて面積を x の二次関数で表し、最大値を求めます。
