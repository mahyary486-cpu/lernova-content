# Trigonometrik fonksiyonlar

## Açı ölçüleri

π rad = 180°. 90° = π/2, 60° = π/3, 45° = π/4, 30° = π/6 rad.

## Birim çember

Yarıçapı 1 olan çemberde x ekseninin pozitif yönüyle α açısı yapan noktanın koordinatları (cos α, sin α) dır.

| α | 0° | 30° | 45° | 60° | 90° |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | √2/2 | √3/2 | 1 |
| cos | 1 | √3/2 | √2/2 | 1/2 | 0 |
| tan | 0 | √3/3 | 1 | √3 | tanımsız |

## Temel bağıntılar

- **sin²x + cos²x = 1**
- tan x = sin x / cos x
- sin(−x) = −sin x (tek), cos(−x) = cos x (çift)
- sin(180° − x) = sin x, cos(180° − x) = −cos x

**Örnek:** sin x = 3/5 ve x dar açı ise cos²x = 16/25 → cos x = 4/5.

## Bölgelere göre işaret

1. bölge: hepsi +; 2. bölge: sin +; 3. bölge: tan +; 4. bölge: cos +.

## Fonksiyon özellikleri

- f(x) = sin x ve cos x: görüntü kümesi [−1, 1], periyot 2π.
- f(x) = a·sin(bx) + c: periyot 2π/∣b∣, görüntü kümesi [c − ∣a∣, c + ∣a∣].
- f(x) = 3 sin x + 1 için görüntü kümesi [−2, 4].
- f(x) = sin 2x için periyot π.

## Trigonometrik denklemler

sin x = 1/2, 0 ≤ x ≤ 2π: referans açı π/6; sinüs 1. ve 2. bölgede pozitif → x = π/6 ve x = 5π/6.

cos x = −1/2 ve 90° < x < 180° → x = 120°.

**Strateji:** Referans açıyı bulun, işarete göre bölgeleri belirleyin, aralığa uygun çözümleri yazın.
