# Диссотсиатсияи электролитӣ

## Электролитҳо ва ғайриэлектролитҳо

- **Электролитҳо:** кислотаҳо, асосҳо (ишқорҳо) ва намакҳо дар маҳлул ё гудозиш.
- **Ғайриэлектролитҳо:** қанд (сахароза), глюкоза, спирти этил ва ғайра.

## Диссотсиатсия

Тақсимшавии электролит ба ионҳо дар об.

- HCl → H⁺ + Cl⁻
- NaOH → Na⁺ + OH⁻
- Na₂SO₄ → 2Na⁺ + SO₄²⁻

## Электролитҳои қавӣ ва суст

- **Қавӣ:** HCl, H₂SO₄, HNO₃, NaOH, KOH, аксари намакҳо.
- **Суст:** CH₃COOH, H₂CO₃, H₂S, NH₃·H₂O.

## Таърифҳо

Кислота — электролите, ки аз катионҳо танҳо H⁺ медиҳад. Асос — электролите, ки аз анионҳо танҳо OH⁻ медиҳад.
