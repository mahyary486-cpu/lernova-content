# Статистика: среднее, медиана, мода, размах

Для списка чисел:

- **Среднее** = сумма, делённая на количество. Для 2, 4, 6 среднее равно 4.
- **Медиана** = среднее значение упорядоченного списка. Для 1, 3, 5, 7, 9 она равна 5. При чётном количестве чисел берут среднее арифметическое двух средних: для 2, 4, 7, 9 это (4 + 7) / 2 = 5,5.
- **Мода** = наиболее часто встречающееся значение. Для 2, 3, 3, 5, 7 она равна 3.
- **Размах** = наибольшее значение минус наименьшее. Для 3, 8, 1, 12, 6 он равен 12 − 1 = 11.

Одно экстремальное значение не влияет на медиану, но влияет на среднее.

Если среднее пяти чисел равно 8, их сумма равна 40. Если четыре из них — 6, 7, 9, 10 (сумма 32), то пятое число равно 8.
