# Первообразная

Функцию F называют **первообразной** функции f, если F′(x) = f(x). Все первообразные f имеют вид F(x) + C.

**Таблица первообразных.**

- ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C (n ≠ −1), например ∫ x² dx = x³ / 3 + C
- ∫ cos x dx = sin x + C
- ∫ sin x dx = −cos x + C
- ∫ (1 / x) dx = ln |x| + C
- ∫ eˣ dx = eˣ + C

**Пример.** Для f(x) = 2x первообразные: x² + C. Если график первообразной проходит через (1; 3), то 1 + C = 3, откуда C = 2 и F(x) = x² + 2.
