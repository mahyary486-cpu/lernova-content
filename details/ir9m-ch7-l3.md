# Rational equations

A rational equation is an equation in which the unknown appears in the denominator of at least one fraction, and we solve it by clearing the fractions.

## Key ideas

An example of a rational equation is 3/x = 5/(x + 4). Because the unknown is in the denominators, some values of x are not allowed.

Steps for solving:
1. Factor the denominators and write down the values of x that make any denominator zero. These are the excluded values.
2. Multiply both sides of the equation by the LCD. This removes all the denominators.
3. Solve the new equation. It is often linear, but it can be quadratic.
4. Reject any solution that is an excluded value. Such a solution is called an extraneous solution.
5. Check the remaining solutions in the original equation.

A quick method for an equation of the form a/b = c/d is cross multiplication: a · d = b · c. It works only when there is exactly one fraction on each side.

Rational equations also appear in word problems, such as problems about speed, work, or mixing. In these problems, the unknown is often a time or a speed, and the equation compares two fractions.

## Worked examples

Example 1. Solve 3/x = 5/(x + 4).

Step 1: Excluded values: x ≠ 0 and x ≠ -4.
Step 2: Cross multiply: 3(x + 4) = 5x.
Step 3: Expand: 3x + 12 = 5x.
Step 4: Subtract 3x from both sides: 12 = 2x, so x = 6.
Step 5: Check: 3/6 = 1/2 and 5/10 = 1/2. 
Answer: x = 6.

Example 2. Solve x^2/(x - 2) = 4/(x - 2).

Step 1: Excluded value: x ≠ 2.
Step 2: Multiply both sides by (x - 2): x^2 = 4.
Step 3: Solve: x = 2 or x = -2.
Step 4: The value x = 2 is excluded, because it makes the denominator zero. It is rejected.
Step 5: Check x = -2: left side = 4/(-4) = -1 and right side = 4/(-4) = -1.
Answer: x = -2 only.

Example 3. Solve 1/x + 1/(x + 2) = 3/4.

Step 1: Excluded values: x ≠ 0 and x ≠ -2.
Step 2: The LCD is 4x(x + 2). Multiply every term by it:
4(x + 2) + 4x = 3x(x + 2).
Step 3: Expand both sides: 4x + 8 + 4x = 3x^2 + 6x, so 8x + 8 = 3x^2 + 6x.
Step 4: Move everything to one side: 3x^2 - 2x - 8 = 0.
Step 5: Factor: (3x + 4)(x - 2) = 0, so x = -4/3 or x = 2.
Step 6: Neither value is excluded.
Step 7: Check x = 2: 1/2 + 1/4 = 3/4. Check x = -4/3: -3/4 + 1/(2/3) = -3/4 + 3/2 = 3/4. 
Answer: x = 2 or x = -4/3.

## Common mistakes

- Forgetting to check the solutions. A value that makes a denominator zero is never a solution.
- Multiplying only one side, or only some terms, by the LCD. Every term on both sides must be multiplied.
- Cross multiplying when a side has a sum of fractions. First combine the fractions on that side.
- Dropping the brackets when expanding, for example writing 3x + 4 instead of 3(x + 4).

## Remember

- Write the excluded values before you start.
- Multiply by the LCD to clear all denominators, then solve.
- Reject extraneous solutions and check the rest.
