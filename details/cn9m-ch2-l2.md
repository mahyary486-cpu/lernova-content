# 二次函数与一元二次方程

## 图象与 x 轴的交点

抛物线 y = ax² + bx + c 与 x 轴交点的横坐标，就是方程 ax² + bx + c = 0 的根。

- Δ > 0：与 x 轴有两个交点；
- Δ = 0：与 x 轴有一个交点（顶点在 x 轴上）；
- Δ < 0：与 x 轴没有交点。

**例：** y = x² − 2x − 3 = (x − 3)(x + 1)，与 x 轴交于 (−1, 0) 和 (3, 0)。

## 用图象解不等式

- ax² + bx + c > 0 的解集：抛物线在 x 轴**上方**部分对应的 x 的范围；
- ax² + bx + c < 0 的解集：抛物线在 x 轴**下方**部分对应的 x 的范围。

**例：** x² − 2x − 3 < 0，开口向上，两个交点是 −1 和 3，所以解集是 −1 < x < 3。
