# Nullstellen und Linearfaktoren

## Satz vom Nullprodukt

Ein Produkt ist 0, wenn mindestens ein Faktor 0 ist.

**Beispiel:** f(x) = (x − 1)(x + 2)(x − 3) hat die Nullstellen 1, −2 und 3.

## Verfahren

- **Ausklammern:** x³ − 4x = x · (x − 2) · (x + 2) hat die Nullstellen −2, 0 und 2.
- **Quadratische Gleichungen:** x² − 5x + 6 = (x − 2)(x − 3) hat die Nullstellen 2 und 3.
- **Substitution:** Bei x⁴ − 5x² + 4 = 0 setzt man z = x². Dann gilt z² − 5z + 4 = 0, also z = 1 oder z = 4 und damit x = ±1 oder x = ±2.

## Linearfaktoren

Ist f(a) = 0, dann ist (x − a) ein **Linearfaktor** von f(x).

## Vielfachheit

- **Einfache Nullstelle:** Der Graph schneidet die x-Achse mit Vorzeichenwechsel.
- **Doppelte Nullstelle:** Der Graph berührt die x-Achse.

**Beispiel:** f(x) = (x + 1)² · (x − 3) hat die doppelte Nullstelle −1 und die einfache Nullstelle 3.

## Keine reellen Nullstellen

x⁴ + 4x² + 3 = 0 liefert z² + 4z + 3 = 0 mit z = −1 oder z = −3. Da z = x² nicht negativ sein kann, gibt es keine reelle Nullstelle.
