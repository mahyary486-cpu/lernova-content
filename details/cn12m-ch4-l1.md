# 递推数列的通项公式

## 常见类型与方法

- **aₙ₊₁ − aₙ = f(n)**：累加法；
- **aₙ₊₁ / aₙ = f(n)**：累乘法；
- **aₙ₊₁ = paₙ + q**（p ≠ 1）：构造等比数列 aₙ₊₁ + λ = p(aₙ + λ)，λ = q / (p − 1)；
- **aₙ₊₁ = aₙ / (1 + aₙ)**：取倒数。

## 例题

**例 1：** a₁ = 1，aₙ₊₁ = 2aₙ + 1：

aₙ₊₁ + 1 = 2(aₙ + 1)，{aₙ + 1} 是首项 2、公比 2 的等比数列，所以 aₙ + 1 = 2ⁿ，aₙ = 2ⁿ − 1。

**例 2：** a₁ = 1，aₙ₊₁ = aₙ + n：

累加：aₙ = 1 + 1 + 2 + … + (n − 1) = 1 + n(n − 1)/2。

**例 3：** a₁ = 1，aₙ₊₁ = aₙ / (1 + aₙ)：

取倒数 1/aₙ₊₁ = 1/aₙ + 1，{1/aₙ} 是首项 1、公差 1 的等差数列，1/aₙ = n，aₙ = 1/n。
