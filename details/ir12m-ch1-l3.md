# قاعده‌های مشتق‌گیری

## این درس درباره‌ی چیست؟

مشتق‌گیری با تعریف طولانی است. خوشبختانه چند قاعده‌ی ساده آن را سریع می‌کند.

## قاعده‌های پایه

- **ثابت:** مشتق عدد ثابت صفر است. (۵)′ = ۰
- **توان:** (xⁿ)′ = n xⁿ⁻¹. مثال: (x⁴)′ = ۴x³ و (x)′ = ۱
- **ضریب ثابت:** (c f)′ = c f′. مثال: (۳x²)′ = ۶x
- **جمع و تفاضل:** (f ± g)′ = f′ ± g′

**مثال:** f(x) = x³ − ۲x + ۷ → f′(x) = ۳x² − ۲.

## ضرب و تقسیم

- **ضرب:** (f g)′ = f′ g + f g′
- **تقسیم:** (f/g)′ = (f′ g − f g′) / g²

**مثال ضرب:** (x² · (x + ۱))′ = ۲x(x + ۱) + x²(۱) = ۳x² + ۲x.
**مثال تقسیم:** (x/(x + ۱))′ = (۱·(x + ۱) − x·۱)/(x + ۱)² = ۱/(x + ۱)².

## قاعده‌ی زنجیره‌ای

برای ترکیب تابع‌ها: (f(g(x)))′ = f′(g(x)) · g′(x).

**مثال:** (x² + ۱)⁵ → ۵(x² + ۱)⁴ · ۲x = ۱۰x(x² + ۱)⁴.

## کاربرد: مماس و سرعت

f(x) = x³ − ۲x در x = ۱: f(۱) = −۱ و f′(۱) = ۳ − ۲ = ۱. مماس: y + ۱ = ۱(x − ۱) → y = x − ۲.

اگر مکان ذره x(t) = t³ − ۶t² باشد، سرعت v(t) = ۳t² − ۱۲t است. در t = ۴: v = ۴۸ − ۴۸ = ۰.

## جمع‌بندی

(xⁿ)′ = nxⁿ⁻¹، مشتق جمع، ضرب و تقسیم قاعده‌ی خود را دارد و برای ترکیب، زنجیره‌ای به کار می‌رود. مشتق شیب مماس و سرعت لحظه‌ای را می‌دهد.
