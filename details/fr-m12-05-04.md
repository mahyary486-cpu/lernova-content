# Équations différentielles y’ = ay + b

## Résolution
Soit y’ = ay + b avec a ≠ 0. La fonction constante y_p = −b/a est une solution particulière. Les solutions sont
y(x) = C e^(ax) − b/a, C réel.

## Exemples
- y’ = 2y + 4 : y_p = −2 et y(x) = Ce^(2x) − 2.
- y’ = −2y + 4 : y_p = 2 et y(x) = Ce^(−2x) + 2.
- y’ = 2y + 6 avec y(0) = 1 : y(x) = Ce^(2x) − 3 et 1 = C − 3 donne C = 4, donc y(x) = 4e^(2x) − 3.

## Refroidissement
La température T d’un objet dans une pièce à 20 °C vérifie T’(t) = −0,5(T(t) − 20), soit T’ = −0,5T + 10. La solution est T(t) = Ce^(−0,5t) + 20. Si T(0) = 80, alors C = 60 et T(t) = 20 + 60e^(−0,5t). La température tend vers 20 °C.

## Comportement en +∞
Si a < 0, e^(ax) tend vers 0 : la solution tend vers −b/a, la valeur d’équilibre.

## Méthode de rédaction
1. On cherche la solution constante.
2. On écrit la forme générale.
3. On utilise la condition initiale pour trouver C.
4. On vérifie en dérivant.

## Erreur fréquente
Confondre la solution particulière −b/a avec la solution générale : il faut y ajouter C e^(ax).
