# 溶液中的三大守恒

## 三大守恒

- **电荷守恒**：阳离子所带正电荷总数 = 阴离子所带负电荷总数；
- **物料守恒**：某元素的各种存在形式的总量保持不变；
- **质子守恒**：水电离出的 c(H⁺) = c(OH⁻)。

## 例题：Na₂CO₃ 溶液

- **电荷守恒**：c(Na⁺) + c(H⁺) = c(OH⁻) + c(HCO₃⁻) + 2c(CO₃²⁻)；
- **物料守恒**：c(Na⁺) = 2[c(CO₃²⁻) + c(HCO₃⁻) + c(H₂CO₃)]；
- **质子守恒**：c(OH⁻) = c(H⁺) + c(HCO₃⁻) + 2c(H₂CO₃)。

质子守恒也可由前两个式子相减得到。

## 例题：CH₃COONa 溶液

- 电荷守恒：c(Na⁺) + c(H⁺) = c(CH₃COO⁻) + c(OH⁻)；
- 物料守恒：c(Na⁺) = c(CH₃COO⁻) + c(CH₃COOH)。

## 书写要点

- 电荷守恒：多价离子浓度前要乘以所带电荷数（如 2c(CO₃²⁻)）；
- 物料守恒：先看原溶质中元素的原子个数比。
