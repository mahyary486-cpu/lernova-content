# Механические колебания

**Гармонические колебания** происходят по закону x = A · cos(ωt). Циклическая частота ω = 2π / T = 2πν.

**Периоды.**

- Математический маятник: T = 2π√(l / g). При l = 0,4 м и g = 10 м/с² получаем T = 2π · 0,2 = 0,4π с.
- Пружинный маятник: T = 2π√(m / k). При m = 0,1 кг и k = 10 Н/м получаем T = 2π · 0,1 = 0,2π с.

**Резонанс** — резкое возрастание амплитуды вынужденных колебаний при совпадении частоты внешней силы с собственной частотой системы.

Если T = 0,02 с, то частота ν = 50 Гц.
