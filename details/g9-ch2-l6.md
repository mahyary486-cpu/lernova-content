# Functions and Function Notation

## What is a function?
A **function** assigns each input exactly **one** output. The **domain** is the set of all inputs (x-values). The **range** is the set of all outputs (y-values).

**Example.** {(1, 2), (3, 4), (5, 6)}
- Domain: {1, 3, 5}
- Range: {2, 4, 6}
- It is a function, because each input appears once.

**Not a function.** {(1, 2), (1, 3), (2, 4)}. The input 1 gives two different outputs, 2 and 3.

**Still a function.** {(1, 2), (2, 2), (3, 2)}. Different inputs may share the same output.

## Vertical line test
If every vertical line crosses the graph at most once, the graph is a function. If some vertical line crosses it twice, it is not.

## Function notation
f(x) is read "f of x". It is the output when the input is x.

If f(x) = 2x + 1:
- f(3) = 2(3) + 1 = 7.

If g(x) = x^2 - 4:
- g(-3) = (-3)^2 - 4 = 9 - 4 = 5.

## Solving for an input
If f(x) = 3x - 2 and f(a) = 10, then 3a - 2 = 10, so 3a = 12 and a = 4.

## Composition
f(g(x)) means use g first, then put the result into f.
If f(x) = 2x - 1 and g(x) = x + 4, then g(1) = 5 and f(g(1)) = f(5) = 2(5) - 1 = 9.

## Common mistakes
- Reading f(3) as f times 3. It means "the value of f when x = 3".
- Forgetting parentheses with negatives: g(-3) = (-3)^2 - 4, not -3^2 - 4.
- Doing the outside function first in a composition.
