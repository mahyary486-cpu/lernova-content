# Ecuaciones cuadráticas incompletas y por factoreo

## Forma general
ax² + bx + c = 0, con a ≠ 0.

## Sin término lineal (b = 0)
x² − 16 = 0 → x² = 16 → x = 4 o x = −4.

## Sin término independiente (c = 0)
x² − 5x = 0 → x(x − 5) = 0 → x = 0 o x = 5.

## Por factoreo
x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 o x = 3.

## Error frecuente
Dividir por x en x² = 5x: se pierde la solución x = 0. Conviene pasar todo a un miembro y factorear.
