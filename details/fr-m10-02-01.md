# Résoudre une équation par factorisation

## Règle du produit nul
A × B = 0 équivaut à A = 0 ou B = 0.

## Méthode
1. On amène tous les termes dans le même membre pour avoir 0 de l’autre côté.
2. On factorise (facteur commun ou identité remarquable).
3. On applique la règle du produit nul et on résout chaque équation simple.

## Exemples
- x² − 5x = 0 donne x(x − 5) = 0 : x = 0 ou x = 5.
- x² − 9 = 0 donne (x − 3)(x + 3) = 0 : x = 3 ou x = −3.
- x² − 6x + 9 = 0 donne (x − 3)² = 0 : x = 3 (solution unique).
- 4x² − 9 = 0 donne (2x − 3)(2x + 3) = 0 : x = 3/2 ou x = −3/2.

## L’équation x² = a
- Si a > 0 : deux solutions √a et −√a.
- Si a = 0 : une solution 0.
- Si a < 0 : aucune solution réelle. Par exemple x² + 4 = 0 n’a pas de solution.

## Erreur fréquente
Pour x(x − 3) = 4x, on ne divise pas par x : on perdrait la solution x = 0. On écrit x² − 7x = 0, soit x(x − 7) = 0, donc x = 0 ou x = 7.
