# 建立空间直角坐标系解立体几何

## 解题步骤

1. **建系**：找到从同一点出发的三条两两垂直的直线；
2. **写坐标**：写出相关点的坐标；
3. **求向量**：求出需要的方向向量；
4. **求法向量**：设 n = (x, y, z)，让它与平面内两个不共线的向量的数量积为 0，再取特殊值；
5. **计算**：用公式求角或距离；
6. **答**：注意角的范围。

## 例题

棱长为 1 的正方体 ABCD − A₁B₁C₁D₁，求异面直线 A₁B 与 AD₁ 所成的角。

以 D 为原点，DA、DC、DD₁ 分别为 x、y、z 轴：

- A(1, 0, 0)，B(1, 1, 0)，D₁(0, 0, 1)，A₁(1, 0, 1)；
- A₁B = (0, 1, −1)，AD₁ = (−1, 0, 1)；
- cos θ = |0 + 0 − 1| / (√2 × √2) = 1/2；
- 所以 θ = 60°。

## 提示

- 异面直线所成角、线面角用绝对值，范围分别是 (0, π/2] 和 [0, π/2]；
- 二面角要判断是锐角还是钝角。
