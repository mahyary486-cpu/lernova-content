# 分式不等式与恒成立问题

## 分式不等式

分式不等式要化成整式不等式来解：

- f(x)/g(x) > 0 ⇔ f(x)·g(x) > 0；
- f(x)/g(x) ≥ 0 ⇔ f(x)·g(x) ≥ 0 且 g(x) ≠ 0。

**例：** (x − 1)/(x + 2) > 0 ⇔ (x − 1)(x + 2) > 0，解集为 {x | x < −2 或 x > 1}。

**注意**：不能直接去分母，因为分母的符号不确定。

## 恒成立问题

- ax² + bx + c > 0 对一切实数 x 恒成立 ⇔ a > 0 且 Δ < 0（a ≠ 0 时）；
- ax² + bx + c < 0 恒成立 ⇔ a < 0 且 Δ < 0。

**例：** kx² − kx + 1 > 0 对一切实数 x 恒成立，求 k 的范围。

- k = 0 时，不等式为 1 > 0，成立；
- k ≠ 0 时，需 k > 0 且 Δ = k² − 4k < 0，得 0 < k < 4。

综上，0 ≤ k < 4。

**易错点**：二次项系数含参数时，要先讨论是否为 0。
