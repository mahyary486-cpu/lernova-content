# Fonctions polynômes du second degré

## Définition
f(x) = ax² + bx + c, avec a ≠ 0 : forme développée. Sa courbe est une parabole.

## Forme canonique
f(x) = a(x − α)² + β.
- Le sommet de la parabole est S(α ; β).
- Si a > 0 : f décroissante sur ]−∞ ; α], croissante sur [α ; +∞[ ; minimum β en x = α.
- Si a < 0 : f croissante puis décroissante ; maximum β en x = α.
Exemple : f(x) = (x − 2)² + 3 a pour sommet (2 ; 3) et minimum 3.
Exemple : f(x) = −(x + 1)² + 4 a pour maximum 4, atteint en x = −1.

## Passage à la forme canonique
x² − 6x + 5 = (x − 3)² − 9 + 5 = (x − 3)² − 4. Le minimum est −4, atteint en x = 3.

## Forme factorisée
f(x) = a(x − x1)(x − x2). Les racines x1 et x2 sont les solutions de f(x) = 0, et l’axe de symétrie est x = (x1 + x2)/2.
Exemple : f(x) = (x − 1)(x − 5) a pour racines 1 et 5, pour abscisse du sommet 3 et pour minimum f(3) = −4.

## Signe
Si a > 0, f(x) est négatif entre les racines et positif à l’extérieur. Si a < 0, c’est l’inverse.

## Erreur fréquente
Le sommet est (α ; β) avec α de signe opposé à celui écrit dans la parenthèse : (x + 1)² correspond à α = −1.
