# Polynomial Inequalities

## Method (sign analysis)
1. Move everything to one side so the other side is **0**.
2. Factor and find the **zeros** (critical numbers).
3. The zeros split the number line into intervals. Test one number in each interval.
4. Keep the intervals with the correct sign. Include a zero only if the inequality has the "or equal" sign.

## Example 1
Solve (x + 2)(x - 1)(x - 4) > 0. The zeros are -2, 1 and 4.
| Interval | Test x | Sign of the product |
|---|---|---|
| x < -2 | -3 | (-)(-)(-) = negative |
| -2 < x < 1 | 0 | (+)(-)(-) = positive |
| 1 < x < 4 | 2 | (+)(+)(-) = negative |
| x > 4 | 5 | (+)(+)(+) = positive |
Solution: **(-2, 1) and (4, infinity)**.
For ≥ 0 the zeros are included: **[-2, 1] and [4, infinity)**.

## Example 2
Solve x^3 - 4x ≤ 0. Factor: x(x - 2)(x + 2) ≤ 0, with zeros -2, 0 and 2. Testing gives negative on x < -2, positive on (-2, 0), negative on (0, 2), positive on x > 2.
Solution: **(-infinity, -2] and [0, 2]**.

## Example 3: x(x - 3)(x + 2) > 0
Zeros -2, 0, 3. The product is positive on **(-2, 0) and (3, infinity)**.

## Repeated factors
A factor with an **even** power does not change the sign. Solve (x - 1)^2 (x + 3) < 0. Since (x - 1)^2 is never negative, the sign is decided by (x + 3), and the product is negative only when x < -3 (and x is not 1, where the product is 0). Solution: **x < -3**.

## Quadratics with no real zeros
- x^2 + 1 > 0 is true for **all real numbers**.
- x^2 + 4 < 0 has **no real solution**.

## Common mistakes
- Not moving everything to one side first.
- Dividing both sides by an expression that contains x. This can change the direction of the inequality or lose solutions.
- Including the zeros when the sign is strict (< or >).
- Forgetting that a double zero does not change the sign.
