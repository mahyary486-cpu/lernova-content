# Laws of Exponents

## Basics
In a^n, **a** is the base and **n** is the exponent. It means a is multiplied by itself n times. So 2^4 = 2 x 2 x 2 x 2 = 16.

## The laws
For nonzero a and b and whole numbers m and n:
- **Product rule:** a^m x a^n = a^(m+n). Same base, add exponents.
- **Quotient rule:** a^m / a^n = a^(m-n). Same base, subtract exponents.
- **Power of a power:** (a^m)^n = a^(mn). Multiply exponents.
- **Power of a product:** (ab)^n = a^n x b^n.
- **Power of a quotient:** (a/b)^n = a^n / b^n.

The rules work because exponents count repeated factors. For example, x^3 x x^2 = (x x x x x) x (x x x) with 5 factors in all, so it equals x^5.

## Worked examples
**Example 1.** Simplify (2x^3)(5x^4).
1. Multiply the coefficients: 2 x 5 = 10.
2. Add the exponents of x: 3 + 4 = 7.
3. Result: 10x^7.

**Example 2.** Simplify (3x^2 y)^3.
1. Apply the exponent 3 to every factor: 3^3 x (x^2)^3 x y^3.
2. 3^3 = 27, and (x^2)^3 = x^6.
3. Result: 27x^6 y^3.

**Example 3.** Simplify 12x^7 / (4x^2).
1. Divide the coefficients: 12 / 4 = 3.
2. Subtract the exponents: 7 - 2 = 5.
3. Result: 3x^5.

## Order matters
(-2)^2 = 4 because the base is -2. But -2^2 = -4 because only the 2 is squared and then the negative is applied.

## Common mistakes
- Multiplying the exponents in a product rule: x^3 x x^2 is x^5, not x^6.
- Adding bases: 2^3 x 2^4 is 2^7, not 4^7.
- Forgetting to raise the coefficient to the power: (3x)^2 = 9x^2, not 3x^2.
- Adding exponents when you should multiply in (x^3)^2, which is x^6 and not x^5.
- Using the product rule on different bases, such as x^2 x y^3, which cannot be combined.
