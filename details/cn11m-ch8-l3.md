# 列联表与独立性检验

## 2 × 2 列联表

| | Y = 0 | Y = 1 | 合计 |
|---|---|---|---|
| X = 0 | a | b | a + b |
| X = 1 | c | d | c + d |
| 合计 | a + c | b + d | n |

## χ² 统计量

**χ² = n(ad − bc)² / [(a + b)(c + d)(a + c)(b + d)]**

## 判断

把 χ² 与临界值比较：

- χ² ≥ 3.841（α = 0.05）：有 95% 的把握认为两个变量**有关**；
- χ² ≥ 6.635（α = 0.01）：有 99% 的把握认为两个变量有关；
- χ² 小于临界值：没有充分证据说明有关。

## 例题

a = 20，b = 10，c = 10，d = 20，n = 60：

- ad − bc = 400 − 100 = 300；
- χ² = 60 × 300² / (30 × 30 × 30 × 30) = 5400000 / 810000 ≈ 6.67；
- 6.67 > 6.635，所以有 99% 的把握认为两个变量有关。
