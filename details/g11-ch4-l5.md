# Solving Rational Equations

## Steps
1. Find the **excluded values** (anything that makes a denominator 0).
2. Multiply **every term** by the LCD to clear the denominators.
3. Solve the resulting equation.
4. **Reject** any answer that is an excluded value (an extraneous solution).

## Examples
**Proportion.** 3/x = 6/(x + 2). Cross multiply: 3(x + 2) = 6x, so 3x + 6 = 6x and **x = 2**.

**Clearing with the LCD.** 1/x + 1/2 = 5/(2x). Multiply by 2x: 2 + x = 5, so **x = 3**.

**Becomes a quadratic.** x + 6/x = 5. Multiply by x: x^2 + 6 = 5x, so x^2 - 5x + 6 = 0 and **x = 2 or x = 3**.

**Cross multiplying.** 2/(x - 1) = 4/(x + 1). Then 2(x + 1) = 4(x - 1), so 2x + 2 = 4x - 4 and **x = 3**.

**Combining fractions.** 2/(x + 1) + 1/(x - 1) = 5/(x^2 - 1). The LCD is (x + 1)(x - 1). Multiply: 2(x - 1) + (x + 1) = 5, so 3x - 1 = 5 and **x = 2**. This is allowed (it does not make any denominator 0).

**No solution.** x/(x - 3) = 3/(x - 3) + 2. Multiply by (x - 3): x = 3 + 2(x - 3), so x = 2x - 3 and x = 3. But x = 3 makes the denominator 0, so it is extraneous. There is **no solution**.

## Work problems
If A finishes a job in 3 hours and B in 6 hours, their rates add: 1/3 + 1/6 = 1/2 of the job per hour. Together they need **2 hours**.

## Common mistakes
- Forgetting to check for excluded values.
- Multiplying only some of the terms by the LCD.
- Adding the times in a work problem. Add the **rates** instead.
