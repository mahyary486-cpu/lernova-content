# Arithmetic progression

In an **arithmetic progression** each term is the previous one plus the same number d, the **common difference**: aₙ₊₁ = aₙ + d.

**nth term:** aₙ = a₁ + (n − 1)d.

Example: 3, 7, 11, … has d = 4. For a₁ = −4 and d = 5: a₁₀ = −4 + 9 · 5 = 41.

**Characteristic property.** Every term except the first is the arithmetic mean of its neighbors: aₙ = (aₙ₋₁ + aₙ₊₁) / 2. So if x, 7, 13 is an arithmetic progression, then 7 − x = 13 − 7 and x = 1.

If d > 0 the progression increases; if d < 0 it decreases.
