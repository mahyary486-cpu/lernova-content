# Арифметическая прогрессия

В **арифметической прогрессии** каждый член получается из предыдущего прибавлением одного и того же числа d — **разности прогрессии**: aₙ₊₁ = aₙ + d.

**Формула n-го члена:** aₙ = a₁ + (n − 1)d.

Пример: у прогрессии 3, 7, 11, … разность d = 4. При a₁ = −4 и d = 5 получаем a₁₀ = −4 + 9 · 5 = 41.

**Характеристическое свойство.** Каждый член, кроме первого, равен среднему арифметическому соседних: aₙ = (aₙ₋₁ + aₙ₊₁) / 2. Поэтому если x, 7, 13 — арифметическая прогрессия, то 7 − x = 13 − 7 и x = 1.

При d > 0 прогрессия возрастает, при d < 0 — убывает.
