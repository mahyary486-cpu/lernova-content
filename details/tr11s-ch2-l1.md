# Homeostazi, endokrin sistem ve dolaşım

## Homeostazi

Canlının iç ortam koşullarını (sıcaklık, pH, kan şekeri, su-tuz dengesi, kan basıncı) belirli sınırlarda tutmasıdır.

**Negatif geri bildirim:** Değişim algılanır, sapmayı azaltacak yönde tepki verilir ve denge korunur.

## Endokrin sistem

Hormonlar kanla taşınır ve hedef hücrelerde etki eder.

| Bez | Hormon | Görev |
|---|---|---|
| Hipofiz | ADH, büyüme hormonu vb. | "Ana bez"; birçok bezi yönetir |
| Tiroit | Tiroksin | Metabolizma hızı |
| Pankreas | İnsülin, glukagon | Kan şekeri dengesi |
| Böbreküstü | Adrenalin | Stres tepkisi |

### Kan şekeri dengesi
- Kan şekeri yükselir → pankreas **insülin** salgılar → glikoz hücrelere alınır, karaciğerde glikojen depolanır → kan şekeri düşer.
- Kan şekeri düşer → **glukagon** → glikojen yıkılır → kan şekeri yükselir.

### Sağlık sorunları
- **Diabetes mellitus:** İnsülin yetersizliği veya etkisizliği; kan şekeri yüksek kalır.
- **Diabetes insipidus:** ADH eksikliği; su geri emilimi azalır, çok seyreltik idrar atılır.
- **Obezite:** Aşırı yağ birikimi; VKİ = kütle (kg)/boy² (m²). 70 kg, 1,75 m → ≈ 22,9.

## Dolaşım sistemi

- **Kalp:** 2 kulakçık + 2 karıncık (4 odacık).
- **Büyük dolaşım:** Sol karıncık → vücut → sağ kulakçık. **Küçük dolaşım:** Sağ karıncık → akciğer → sol kulakçık.
- **Alyuvar:** Hemoglobinle O₂ taşır. **Akyuvar:** Savunma. **Trombosit:** Pıhtılaşma.
- **Kan basıncı:** Sistolik (kalp kasılırken), diyastolik (gevşerken).
- **Hipertansiyon:** Kan basıncının normalin üzerinde olması.
