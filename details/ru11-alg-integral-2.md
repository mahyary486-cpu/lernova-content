# Определённый интеграл

**Формула Ньютона — Лейбница:** ∫ₐᵇ f(x) dx = F(b) − F(a), где F — любая первообразная функции f.

**Примеры.**

- ∫₀³ x² dx = 3³ / 3 − 0 = 9
- ∫₁² 2x dx = 2² − 1² = 3
- ∫₀^π sin x dx = −cos π + cos 0 = 1 + 1 = 2
- ∫₀² 3x² dx = 2³ = 8
- ∫₀¹ eˣ dx = e − 1
- ∫₁^e (1 / x) dx = ln e − ln 1 = 1

**Свойства.** Интеграл суммы равен сумме интегралов, постоянный множитель выносится за знак интеграла. Интеграл нечётной функции по симметричному промежутку равен нулю: ∫₋₁¹ x³ dx = 0.
