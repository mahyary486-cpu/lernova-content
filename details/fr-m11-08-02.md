# Fonctions, paramètres et valeurs renvoyées

## Définition
def f(x):
    return x + 1
f(2) vaut 3. Les paramètres (ici x) sont les entrées, return donne la sortie.

## Plusieurs paramètres
def aire(L, l):
    return L * l
aire(5, 3) vaut 15.

## Variables locales
Une variable créée dans la fonction n’existe pas en dehors.

## Fonction sans return
def affiche(x):
    print(x)
Cette fonction affiche une valeur mais renvoie None : on ne peut pas utiliser son résultat dans un calcul.

## Fonction avec test
def val_abs(x):
    if x >= 0:
        return x
    else:
        return -x

## Fonction avec boucle
def somme_carres(n):
    s = 0
    for i in range(1, n + 1):
        s = s + i * i
    return s
somme_carres(4) vaut 1 + 4 + 9 + 16 = 30.

## Opérations utiles
a, b = 3, 4 ; a * b + a % b vaut 12 + 3 = 15.

## Tester une fonction
On l’essaie avec des valeurs simples, des cas limites (0, négatif) et on compare avec le résultat attendu.

## Erreur fréquente
Écrire print au lieu de return : le résultat s’affiche mais ne peut pas être réutilisé.
