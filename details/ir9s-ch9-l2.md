# Pulleys and inclined planes

Pulleys and inclined planes are simple machines that let us lift or move a load with a smaller force.

## Key ideas

- A pulley is a wheel with a groove that holds a rope. The rope passes over the wheel and changes the way the force acts.
- A fixed pulley is attached to a support. It only changes the direction of the force, so pulling down lifts the load up. Its mechanical advantage is 1.
- A movable pulley moves together with the load. The load is held by two rope segments, so the effort is half of the load. The mechanical advantage is 2.
- A block and tackle (a pulley system) uses several pulleys. If n rope segments support the load, the ideal effort is load / n and the ideal mechanical advantage is n.
- The price of a smaller force is a longer rope pull. If n segments support the load, you pull n times as much rope as the load rises.
- An inclined plane is a slope, such as a ramp. It lets us raise a load by pushing it along a longer path instead of lifting it straight up.
- For an ideal ramp with no friction, effort = load × height / length. The mechanical advantage is length / height.
- A longer and gentler ramp needs a smaller force but a longer distance. Wedges, screws and mountain roads are related to the inclined plane.

## Examples

Example 1: A movable pulley. A 500 N load is lifted 3 m with one movable pulley. Ignore friction and the weight of the pulley.
- Two rope segments support the load, so effort = 500 / 2 = 250 N.
- Rope pulled = 2 × 3 m = 6 m.
- Check the work: 250 N × 6 m = 1500 J, and 500 N × 3 m = 1500 J. They are equal.

Example 2: A ramp. A worker pushes an 800 N barrel up a ramp 4 m long and 1 m high. Ignore friction.
- Effort = load × height / length = 800 × 1 / 4 = 200 N.
- Mechanical advantage = 4 / 1 = 4.
- Check the work: 200 N × 4 m = 800 J, and 800 N × 1 m = 800 J.

Example 3: A block and tackle. Four rope segments support a 1200 N load. The load must rise 2 m.
- Effort = 1200 / 4 = 300 N.
- Rope pulled = 4 × 2 = 8 m.
- Work done by the effort = 300 × 8 = 2400 J, and the work on the load = 1200 × 2 = 2400 J.

## Common mistakes

- Counting the rope segment that you pull when it only passes over a fixed pulley. Count only the segments that hold up the load.
- Thinking a fixed pulley makes the lifting easier. It only changes direction.
- Using the horizontal distance of a ramp instead of its sloping length.
- Forgetting that real machines have friction, so the real effort is larger than the ideal effort.

## Remember

- Ideal pulley mechanical advantage = number of supporting rope segments.
- Ideal ramp mechanical advantage = length / height.
- Simple machines trade force for distance. The work stays the same in an ideal case.
