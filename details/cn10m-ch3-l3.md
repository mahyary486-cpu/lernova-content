# 函数的奇偶性与幂函数

## 奇偶性

设函数 f(x) 的定义域 I 关于原点对称：

- 若对任意 x ∈ I，f(−x) = f(x)，则 f(x) 是**偶函数**，图象关于 **y 轴**对称；
- 若对任意 x ∈ I，f(−x) = −f(x)，则 f(x) 是**奇函数**，图象关于**原点**对称。

判断奇偶性要先看定义域是否关于原点对称。

**例：** f(x) = x³ 是奇函数，f(x) = x² 和 f(x) = |x| 是偶函数。

**性质：** 奇函数若在 x = 0 处有定义，则 f(0) = 0。

**例：** f(x) 是奇函数，f(2) = 3，则 f(−2) = −3；若 f(x) 是偶函数，f(2) = 5，则 f(−2) = 5。

## 幂函数

形如 y = xᵅ 的函数叫**幂函数**。常见的有 y = x，y = x²，y = x³，y = x^(1/2)，y = x⁻¹。

它们的图象都经过点 (1, 1)。
