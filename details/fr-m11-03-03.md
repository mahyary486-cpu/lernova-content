# Dérivée d’un produit, d’un quotient et d’une fonction f(ax + b)

## Produit
(uv)’ = u’v + uv’.
Exemple : f(x) = (x + 2)(x² − 1). Avec u = x + 2 et v = x² − 1 : f’(x) = (x² − 1) + (x + 2) × 2x = 3x² + 4x − 1.
Exemple : f(x) = x√x : f’(x) = √x + x/(2√x) = 3√x/2.

## Inverse
(1/v)’ = −v’/v².
Exemple : f(x) = 1/(2x + 1) : f’(x) = −2/(2x + 1)².

## Quotient
(u/v)’ = (u’v − uv’)/v².
Exemple : f(x) = (x² + 1)/(x − 1). Avec u’ = 2x et v’ = 1 :
f’(x) = (2x(x − 1) − (x² + 1))/(x − 1)² = (x² − 2x − 1)/(x − 1)².
Exemple : f(x) = x/(x + 1) : f’(x) = ((x + 1) − x)/(x + 1)² = 1/(x + 1)².

## Fonction f(ax + b)
Si g(x) = f(ax + b), alors g’(x) = a f’(ax + b).
Exemple : g(x) = (3x − 2)² avec f(x) = x² : g’(x) = 3 × 2(3x − 2) = 18x − 12.

## Méthode
On identifie u et v, on calcule u’ et v’, puis on applique la formule en prenant soin des parenthèses.

## Erreur fréquente
Dans (u/v)’, le numérateur est u’v − uv’ (et non u’v + uv’).
