# 命題と条件

## 命題

「p ならば q」の形の文を**命題**といい、真か偽かが決まります。偽であることを示すには、p が成り立つのに q が成り立たない**反例**を1つ示します。

**例：** 「x² = 4 ならば x = 2」は、x = −2 が反例なので偽。

## 必要条件と十分条件

p ⇒ q が真のとき、p は q の**十分条件**、q は p の**必要条件**。p ⇒ q と q ⇒ p がともに真のとき、**必要十分条件**。

**例：** p：x > 5、q：x > 3 のとき p ⇒ q は真、q ⇒ p は偽なので、p は q の十分条件であるが必要条件ではない。

## 条件の否定

「p かつ q」の否定は「p でない または q でない」。「p または q」の否定は「p でない かつ q でない」。
