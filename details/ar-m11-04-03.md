# Parábola y elipse

## Parábola
Lugar de los puntos que equidistan de un foco y de una recta directriz.
- y² = 4px: vértice (0; 0), foco (p; 0), directriz x = −p.
- Ejemplo: y² = 8x → p = 2, foco (2; 0), directriz x = −2.

## Elipse
Lugar de los puntos cuya suma de distancias a dos focos es constante (2a).
- x²/a² + y²/b² = 1, con a > b.
- Vértices (±a; 0), eje mayor 2a, eje menor 2b.
- c² = a² − b² y los focos son (±c; 0).
- Ejemplo: x²/25 + y²/9 = 1 → a = 5, b = 3, c = 4.

## Aplicaciones
Antenas parabólicas, espejos, órbitas de los planetas (elipses).

## Error frecuente
Confundir a² y b²: a² es siempre el mayor.
