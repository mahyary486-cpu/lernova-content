# Progressão geométrica (PG)

Uma PG é uma sequência em que o quociente entre termos consecutivos é constante: a **razão q**.

Exemplo: (2, 4, 8, 16, ...) tem q = 2.

## Termo geral

**aₙ = a₁ · qⁿ⁻¹**

O 6º termo de uma PG com a₁ = 2 e q = 3 é 2 · 3⁵ = 486.

## Soma dos termos

- Finita: **Sₙ = a₁ · (qⁿ − 1) / (q − 1)**. Para (1, 2, 4, 8): S₄ = (2⁴ − 1)/(2 − 1) = 15.
- Infinita, com |q| < 1: **S = a₁ / (1 − q)**. Para (8, 4, 2, 1, ...): 8/(1/2) = 16.

## Propriedade

Três termos a, b, c em PG: **b² = a · c**. Se (2, x, 18) é PG de termos positivos, x² = 36 e x = 6.

## Aplicações

- Bactérias que triplicam a cada hora: 500 · 3³ = 13 500 após 3 h.
- Juros compostos de 10% ao mês sobre R$ 1 000: 1 000 · 1,1³ = R$ 1.331,00.
- Uma bola que sobe metade da altura anterior a cada quique forma uma PG de razão 1/2.
