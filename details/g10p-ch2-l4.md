# Projectile Motion Launched Horizontally

A projectile is an object moving only under the pull of gravity (we ignore air resistance). Its path is a curve called a parabola.

## Key ideas
- Horizontal and vertical motions are independent and share the same time t.
- Horizontal: no acceleration, so the velocity stays constant and x = vx t.
- Vertical: acceleration g = 9.8 m/s^2 downward. For a launch with no vertical speed: vy = g t and y = (1/2) g t^2.
- Time to fall a height h: t = sqrt(2h / g). It does not depend on the horizontal speed.
- A ball rolled off a table and a ball dropped from the same height hit the ground at the same time.
- Speed at any instant: v = sqrt(vx^2 + vy^2).

## Worked examples
**Example 1: off a table.** A ball leaves a 1.5 m high table horizontally at 4.0 m/s.
1. Fall time: t = sqrt(2 x 1.5 / 9.8) = 0.553 s.
2. Horizontal distance: x = 4.0 x 0.553 = 2.2 m.

**Example 2: off a cliff.** A stone is thrown horizontally at 12 m/s from a 45 m high cliff.
1. Fall time: t = sqrt(2 x 45 / 9.8) = 3.03 s.
2. Range: x = 12 x 3.03 = 36 m.
3. Vertical speed on landing: vy = 9.8 x 3.03 = 29.7 m/s.
4. Impact speed: v = sqrt(12^2 + 29.7^2) = 32 m/s.

**Example 3: conceptual comparison.** Two balls leave the same height horizontally, one at 3 m/s and one at 6 m/s.
1. Both have the same vertical motion, so both fall for the same time.
2. The faster ball travels twice as far horizontally in that time.

## Common mistakes
- Thinking a faster horizontal launch makes the object fall more slowly.
- Using the horizontal speed in the fall-time formula.
- Adding gravity to the horizontal motion. Horizontal acceleration is zero.
- Forgetting that the final speed includes both components.
