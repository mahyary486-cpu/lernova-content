# Tangente und Normale

## Tangente

Die Tangente an f im Punkt (x₀, f(x₀)) hat die Gleichung

**y = f(x₀) + f′(x₀) · (x − x₀)**

## Normale

Die **Normale** steht im Berührpunkt senkrecht auf der Tangente. Ist m die Tangentensteigung, hat die Normale die Steigung **−1/m**.

## Beispiele

**Beispiel 1:** f(x) = x² bei x = 2.
f(2) = 4, f′(2) = 4. Tangente: y = 4x − 4.

**Beispiel 2:** f(x) = x³ bei x = 1.
f(1) = 1, f′(1) = 3. Tangente: y = 3x − 2.

**Beispiel 3:** f(x) = x² bei x = 1.
Tangentensteigung 2, Normalensteigung −1/2.

## Lineare Näherung

In der Nähe von x₀ gilt f(x) ≈ f(x₀) + f′(x₀) · (x − x₀).

**Beispiel:** f(x) = √x bei x₀ = 4. Es gilt f(4) = 2 und f′(4) = 1/4.
√4,1 ≈ 2 + 0,25 · 0,1 = 2,025.

## Waagrechte Tangenten

Gesucht sind die Lösungen von f′(x) = 0.

**Beispiel:** f(x) = x² − 4x. f′(x) = 2x − 4 = 0 ergibt x = 2.
