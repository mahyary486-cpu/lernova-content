# Permutations, arrangements, combinations

**Permutations.** The number of ways to order n different objects is n! = 1 · 2 · … · n. So 3! = 6 and 5! = 120.

**Arrangements.** Choosing k of n objects when the order matters: A(n, k) = n · (n − 1) · … · (n − k + 1). For example A(5, 2) = 20 and A(5, 3) = 60. That is why there are 60 three-digit numbers with distinct digits from 1, 2, 3, 4, 5.

**Combinations.** Choosing k of n objects when the order does not matter: C(n, k) = A(n, k) / k!. For example C(5, 2) = 10 and C(6, 3) = 20.

Ask yourself: if I swap two chosen items, do I get a different result? If yes, use arrangements. If no, use combinations.
