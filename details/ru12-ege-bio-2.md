# Генетика

**Законы Менделя.** Первый закон — единообразие гибридов первого поколения. При Aa × Aa расщепление по фенотипу 3 : 1.

**Анализирующее скрещивание** проводят с рецессивной гомозиготой.

**Закон Харди — Вайнберга.** p + q = 1, p² + 2pq + q² = 1. Если q² = 0,04, то q = 0,2.

Группы крови системы АВ0: людей с I группой считают универсальными донорами по эритроцитам.
