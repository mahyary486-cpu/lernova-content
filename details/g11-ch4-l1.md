# Roots and Rational Exponents

## nth roots
The **nth root** of a number a is a number that, raised to the power n, gives a. We write it as the nth root of a, or as **a^(1/n)**.
- The square root of 81 is 9, because 9^2 = 81.
- The cube root of 27 is 3, because 3^3 = 27.
- 8^(1/3) = **2**.

With an **even** root, the number under the root must not be negative if you want a real answer (the square root of -4 is not real). With an **odd** root, negative numbers are fine: the cube root of -8 is -2.

## Rational exponents
**a^(m/n) = (the nth root of a)^m = the nth root of (a^m)**

The denominator n is the root and the numerator m is the power. Taking the root first keeps the numbers small.
- 27^(2/3) = (cube root of 27)^2 = 3^2 = **9**
- 16^(3/4) = (fourth root of 16)^3 = 2^3 = **8**
- x^(1/2) is the same as the square root of x

## Negative rational exponents
A negative exponent means the reciprocal: a^(-m/n) = 1 / a^(m/n).
- 4^(-1/2) = 1 / 4^(1/2) = **1/2**

## Exponent laws still work
- x^(1/2) * x^(1/3) = x^(1/2 + 1/3) = **x^(5/6)**
- (x^(1/2))^4 = x^2
- x^(2/3) / x^(1/3) = x^(1/3)

## Solving equations with rational exponents
Raise both sides to the **reciprocal** power. If the exponent is even in the numerator, remember both signs.
x^(2/3) = 4. Take the cube root of the base: (cube root of x)^2 = 4, so the cube root of x = 2 or -2. Therefore **x = 8 or x = -8**.

## Common mistakes
- Reading x^(1/2) as x divided by 2.
- Using the root and the power in the wrong order: x^(m/n) has the n-th **root** and the m-th **power**.
- Forgetting the negative exponent means a reciprocal, not a negative number.
- Losing the second answer when the numerator of the exponent is even.
