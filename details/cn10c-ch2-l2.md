# 氯气及氯的化合物

## 氯气的物理性质

黄绿色、有刺激性气味的有毒气体，密度比空气大，能溶于水。

## 化学性质

- 与金属：2Fe + 3Cl₂ =(点燃)= 2FeCl₃（棕红色烟）；Cu + Cl₂ =(点燃)= CuCl₂（棕黄色烟）；
- 与氢气：H₂ + Cl₂ =(点燃)= 2HCl（苍白色火焰）；
- 与水：Cl₂ + H₂O ⇌ HCl + HClO。

## 氯水与次氯酸

氯水中含有 Cl₂、H₂O、HClO、H⁺、Cl⁻、ClO⁻、OH⁻。

HClO 是弱酸，有**强氧化性**，能漂白；不稳定，见光分解：2HClO =(光照)= 2HCl + O₂↑。

## 与碱反应

- Cl₂ + 2NaOH = NaCl + NaClO + H₂O（用于尾气吸收，也是 84 消毒液的制法）；
- 漂白粉：Cl₂ 与石灰乳反应，有效成分是 **Ca(ClO)₂**。
