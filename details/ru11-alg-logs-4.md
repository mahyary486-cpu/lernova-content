# Логарифмические неравенства и производные

**Логарифмические неравенства.**

- При **a > 1** знак неравенства сохраняется: log₂ x > 3 даёт x > 8.
- При **0 < a < 1** знак меняется на противоположный: log_{1/2} x > 1 даёт 0 < x < 1/2.

Всегда учитывайте область определения (x > 0).

**Показательные неравенства.** При a > 1: 3ˣ > 9 даёт x > 2.

**Производные:** (eˣ)′ = eˣ, (aˣ)′ = aˣ · ln a, (ln x)′ = 1 / x, (log_a x)′ = 1 / (x · ln a).
