# Séparation des constituants d’un mélange

## Mélanges hétérogènes
- Décantation : on laisse reposer ; le constituant le plus dense se dépose. On peut séparer huile et eau avec une ampoule à décanter.
- Filtration : on retient les particules solides avec un filtre (papier filtre). Le liquide qui traverse est le filtrat.

## Mélanges homogènes
- Évaporation : on chauffe pour faire partir le solvant ; on récupère le soluté (sel d’eau salée).
- Distillation : on chauffe le mélange ; le constituant qui a la plus basse température d’ébullition se vaporise le premier, puis on le condense dans un réfrigérant. Le liquide recueilli est le distillat.
Exemple : on peut distiller de l’eau salée pour obtenir de l’eau distillée.

## Chromatographie
La chromatographie sépare les espèces colorées d’un mélange. L’éluant migre sur le papier ou la plaque en entraînant plus ou moins les espèces.

## Choisir la méthode
- Sable dans l’eau : filtration.
- Eau et huile : décantation.
- Sel dans l’eau : évaporation ou distillation.
- Encres de feutres : chromatographie.

## Sécurité
Les montages de chauffage demandent des lunettes, des gants et un chauffe-ballon stable.

## Erreur fréquente
La filtration ne sépare pas un soluté d’un solvant : le sel dissous traverse le filtre.
