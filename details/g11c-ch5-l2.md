# Rate Laws and Reaction Order

The rate law is found by experiment. It tells which concentrations control the speed of the reaction.

## Key ideas
- **rate = k [A]^m [B]^n**; orders come from **experiments**.
- **Overall order** = m + n.
- Doubling [A] doubles the rate: **first order**; quadruples: **second order**; no change: **zero order**.
- **First order**: **t(1/2) = 0.693 / k**.
- Units of k: first order **s^-1**; second order **L/(mol s)**.
- The **slowest step** determines the rate.

## Worked examples
**Example 1: Finding the order.** Doubling [A] changes the rate from 2.0 to 8.0 M/s.
1. The rate is 4 times larger: 2^m = 4.
2. m = 2; the reaction is second order in A.

**Example 2: Using the rate law.** rate = k [A]^2 with k = 0.50 L/(mol s) and [A] = 0.20 M.
1. rate = 0.50 x (0.20)^2 = 0.50 x 0.04.
2. rate = 0.020 M/s.

**Example 3: Half-life.** A first-order reaction has k = 0.0693 per minute.
1. t(1/2) = 0.693 / k = 0.693 / 0.0693.
2. t(1/2) = 10 min.

## Common mistakes
- Taking the orders from the coefficients.
- Using the wrong units for k.
- Thinking half-life depends on concentration in first order.
