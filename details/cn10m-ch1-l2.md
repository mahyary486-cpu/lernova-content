# 集合的基本运算

## 三种运算

- **交集** A ∩ B：属于 A 且属于 B 的元素组成的集合；
- **并集** A ∪ B：属于 A 或属于 B 的元素组成的集合；
- **补集** ∁ᵤA：全集 U 中不属于 A 的元素组成的集合。

## 例题

**例 1：** A = {1, 2, 3}，B = {2, 3, 4}：

- A ∩ B = {2, 3}
- A ∪ B = {1, 2, 3, 4}

**例 2：** 全集 U = R，A = {x | x > 1}，则 ∁ᵤA = {x | x ≤ 1}。

## 常用性质

- A ∩ A = A，A ∪ ∅ = A；
- A ⊆ B ⇔ A ∩ B = A ⇔ A ∪ B = B；
- ∁ᵤ(A ∩ B) = (∁ᵤA) ∪ (∁ᵤB)，∁ᵤ(A ∪ B) = (∁ᵤA) ∩ (∁ᵤB)。

**提示：** 数集的运算用数轴表示，注意端点处是否取到（实心点、空心点）。
