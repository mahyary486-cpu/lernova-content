# Medidas de dispersión

## Rango
Rango = máximo − mínimo.

## Varianza y desvío estándar
- Varianza: σ² = Σ(xᵢ − media)²/n.
- Desvío estándar: σ = √σ².

## Ejemplo
Datos: 2, 4, 4, 6. Media = 4.
Desvíos: −2, 0, 0, 2. Cuadrados: 4, 0, 0, 4.
σ² = 8/4 = 2 y σ = √2 ≈ 1,41.

## Interpretación
Con la misma media, el conjunto con menor desvío estándar es más homogéneo.

## Error frecuente
Olvidar la raíz cuadrada: la varianza y el desvío no son lo mismo.
