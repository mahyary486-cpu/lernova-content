# Окислительно-восстановительные реакции

**ОВР** — реакции, в которых меняются степени окисления элементов. **Окисление** — отдача электронов, **восстановление** — присоединение электронов.

**Окислитель** принимает электроны (и восстанавливается), **восстановитель** отдаёт электроны (и окисляется).

**Степени окисления.** У простого вещества она равна 0. В KMnO₄ у марганца +7, потому что +1 + x + 4 · (−2) = 0.

**Пример.** Zn + CuSO₄ → ZnSO₄ + Cu. Цинк отдаёт два электрона (Zn⁰ → Zn²⁺), это восстановитель. Ионы Cu²⁺ принимают электроны (Cu²⁺ → Cu⁰), это окислитель.

**Электронный баланс.** В реакции 2Fe + 3Cl₂ → 2FeCl₃ железо отдаёт 3 электрона (Fe⁰ → Fe³⁺). Сумма коэффициентов равна 2 + 3 + 2 = 7.
