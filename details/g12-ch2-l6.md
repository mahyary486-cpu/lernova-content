# Descartes' Rule of Signs and Bounds on Zeros

## Descartes' Rule of Signs
For a polynomial f with real coefficients, written in descending powers:
- The number of **positive** real zeros is equal to the number of **sign changes** in the coefficients of f(x), or less than that by an **even number**.
- The number of **negative** real zeros is found the same way from f(-x).
Zero coefficients are skipped.

## Example 1
f(x) = x^3 - 2x^2 - 5x + 6. The signs are +, -, -, +. The sign changes are + to - (1) and - to + (2), so there are **2 or 0** positive zeros.
f(-x) = -x^3 - 2x^2 + 5x + 6. The signs are -, -, +, +, with **1** change, so there is exactly **1** negative zero.
(The actual zeros are 1, -2 and 3: two positive and one negative.)

## Example 2
f(x) = x^4 + 3x^2 + 2. There are no sign changes in f(x) and none in f(-x), so there are **no real zeros**.

## Example 3
f(x) = x^3 + x - 1. The signs are +, +, -, which is **1** change, so exactly **1** positive zero. In f(-x) = -x^3 - x - 1 there are no changes, so no negative zeros.

## Bounds on the zeros (Upper and Lower Bound Theorem)
Use synthetic division by x - c.
- **Upper bound:** if c > 0 and **all numbers in the bottom row are 0 or positive**, then c is an upper bound: no real zero is greater than c.
- **Lower bound:** if c < 0 and the numbers in the bottom row **alternate in sign** (0 counts as either), then c is a lower bound: no real zero is less than c.

Example: f(x) = x^3 - 2x^2 - 5x + 6 divided by x - 4. Coefficients 1, -2, -5, 6 give 1, 2, 3, 18. All are positive, so **4 is an upper bound**.
Divide by x + 3 (c = -3): 1, -5, 10, -24. The signs alternate, so **-3 is a lower bound**.
All real zeros of f lie in the interval **[-3, 4]**, and indeed -2, 1 and 3 are inside it.

## Using these tools together
1. List the possible rational zeros (Rational Root Theorem).
2. Use Descartes to see how many positive and negative zeros to expect.
3. Use the bounds to rule out candidates that are too large or too small.
4. Test the remaining candidates with synthetic division.

## Common mistakes
- Forgetting to use f(-x) for negative zeros.
- Forgetting the "or less by an even number" part.
- Using the bounds test with the wrong sign of c.
- Counting a repeated zero once. Descartes counts zeros with multiplicity.
