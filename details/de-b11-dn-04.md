# Translation und genetischer Code

## Ort
Die Translation findet an Ribosomen im Zytoplasma statt. Die mRNA-Basensequenz wird in eine Aminosäurekette übersetzt.

## Ablauf
1. Das Ribosom bindet die mRNA am Startcodon AUG (Methionin).
2. Die tRNA mit passendem Antikodon bringt die zugehörige Aminosäure.
3. Das Ribosom verknüpft die Aminosäuren durch Peptidbindungen.
4. An einem Stoppcodon (UAA, UAG, UGA) endet die Translation.

## Eigenschaften des Codes
Der Code ist ein Triplettcode, universell (bei fast allen Lebewesen gleich), degeneriert (mehrere Codons je Aminosäure) und eindeutig (ein Codon kodiert nur eine Aminosäure).

## Mutationen
Punktmutationen können still, Missense oder Nonsense sein. Der Verlust einzelner Basen kann das Leseraster verschieben.
