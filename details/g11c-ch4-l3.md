# Hess's Law and Standard Enthalpies of Formation

If you cannot measure a reaction directly, you can combine other reactions whose heats are known.

## Key ideas
- **Hess's law**: delta H is the same for any path.
- Reverse a step: **change sign**; multiply a step: **multiply delta H**.
- **delta H_f** of an element in its standard state = **0**.
- **delta H_rxn = sum n delta H_f (products) - sum n delta H_f (reactants)**.
- Enthalpy is a **state function**.
- Check that the intermediates cancel.

## Worked examples
**Example 1: Using Hess's law.** C + O2 -> CO2 (-393 kJ) and CO + 1/2 O2 -> CO2 (-283 kJ). Find delta H for C + 1/2 O2 -> CO.
1. Reverse the second: CO2 -> CO + 1/2 O2, delta H = +283 kJ.
2. Add: -393 + 283 = -110 kJ.

**Example 2: Enthalpies of formation.** CH4 + 2 O2 -> CO2 + 2 H2O(l): delta H_f of CH4 = -75, CO2 = -393, H2O(l) = -286 kJ/mol.
1. Products: -393 + 2 x (-286) = -965 kJ. Reactants: -75 kJ.
2. delta H = -965 - (-75) = -890 kJ.

**Example 3: Element in standard state.** What is delta H_f of O2(g)?
1. O2 is an element in its standard state.
2. delta H_f = 0.

## Common mistakes
- Forgetting to multiply delta H_f by coefficients.
- Subtracting in the wrong order.
- Giving elements a nonzero delta H_f.
