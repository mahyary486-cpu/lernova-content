# Droites de l’espace : représentation paramétrique

## Définition
Soit A un point et u(a ; b ; c) un vecteur non nul. La droite d passant par A de vecteur directeur u est l’ensemble des points M tels que AM = t u, avec t réel.
On obtient la représentation paramétrique :
x = x_A + t a
y = y_A + t b
z = z_A + t c
avec t décrivant ℝ.

## Exemple
La droite passant par A(1 ; 2 ; 3) de vecteur directeur u(2 ; −1 ; 4) a pour représentation paramétrique x = 1 + 2t, y = 2 − t, z = 3 + 4t. Pour t = 1, on obtient le point (3 ; 1 ; 7).

## Droite définie par deux points
La droite (AB) a pour vecteur directeur AB. Avec A(1 ; 2 ; 3) et B(3 ; 2 ; 7) : AB(2 ; 0 ; 4), donc x = 1 + 2t, y = 2, z = 3 + 4t.

## Appartenance d’un point
Pour savoir si un point appartient à la droite, on cherche un unique t qui convient aux trois équations.

## Droites parallèles
Deux droites sont parallèles si leurs vecteurs directeurs sont colinéaires.

## Position relative de deux droites
Deux droites de l’espace sont soit parallèles (confondues ou disjointes), soit sécantes, soit non coplanaires.

## Erreur fréquente
Un même paramètre t doit être utilisé pour les trois coordonnées d’un même point.
