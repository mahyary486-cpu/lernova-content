# Équations différentielles y’ = ay

## Équation y’ = ay
Une équation différentielle est une équation dont l’inconnue est une fonction y. Les solutions de y’ = ay (a réel) sont les fonctions
y(x) = C e^(ax), C réel quelconque.

## Condition initiale
Pour y(0) = y_0, on obtient C = y_0, donc y(x) = y_0 e^(ax). La solution est alors unique.
Exemples :
- y’ = y : solutions C e^x.
- y’ = 2y : solutions C e^(2x).
- y’ = 3y avec y(0) = 2 : y(x) = 2e^(3x).
- y’ = −y avec y(0) = 1 : y(x) = e^(−x).

## Modélisation
- Population : la vitesse de croissance est proportionnelle à la taille, N’(t) = kN(t), d’où N(t) = N_0 e^(kt).
- Désintégration : N’(t) = −0,1N(t) avec N(0) = 500 donne N(t) = 500e^(−0,1t). La quantité décroît vers 0.

## Interprétation du signe de a
- a > 0 : croissance exponentielle.
- a < 0 : décroissance exponentielle vers 0.

## Vérification
Si y(x) = C e^(ax), alors y’(x) = aC e^(ax) = a y(x).

## Erreur fréquente
Oublier de déterminer C avec la condition initiale lorsque l’énoncé la donne.
