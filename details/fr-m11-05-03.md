# Fonctions cosinus et sinus : parité et périodicité

## Définition
Les fonctions cos : x ↦ cos x et sin : x ↦ sin x sont définies sur ℝ, à valeurs dans [−1 ; 1].

## Périodicité
cos(x + 2π) = cos x et sin(x + 2π) = sin x : les fonctions sont périodiques de période 2π. Il suffit de les étudier sur un intervalle de longueur 2π, par exemple [−π ; π].

## Parité
- cos(−x) = cos x : le cosinus est paire. Sa courbe est symétrique par rapport à l’axe des ordonnées.
- sin(−x) = −sin x : le sinus est impaire. Sa courbe est symétrique par rapport à l’origine.

## Variations sur [0 ; π]
- cos est décroissante de 1 à −1.
- sin est croissante sur [0 ; π/2] de 0 à 1, puis décroissante sur [π/2 ; π] de 1 à 0.

## Courbes
Les courbes de cos et de sin sont des sinusoïdes. La courbe de sin se déduit de celle de cos par une translation de π/2 vers la droite.

## Conséquences
- Maximum de cos : 1, atteint en 0 (à 2kπ près). Minimum : −1, atteint en π.
- sin x = 1 pour x = π/2 + 2kπ ; sin x = −1 pour x = −π/2 + 2kπ.

## Phénomènes périodiques
Les fonctions de la forme A cos(ωx + φ) modélisent des phénomènes périodiques (marées, sons, courant alternatif). La période est 2π/ω.

## Erreur fréquente
Le sinus est impaire (pas paire) : sin(−x) = −sin x.
