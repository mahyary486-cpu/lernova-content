# اعمال روی مجموعه‌ها و شمارش

اجتماع، اشتراک، تفاضل و متمم را به‌کار می‌بریم و با نمودار ون تعداد عضوها را می‌شماریم.

## نکته‌های کلیدی

- A ∪ B همه‌ی عضوهای دو مجموعه، A ∩ B عضوهای مشترک، A − B عضوهای A که در B نیستند و A' متمم A نسبت به مجموعه‌ی مرجع U است.
- A − B = A ∩ B'.
- قوانین دمورگان: (A ∪ B)' = A' ∩ B' و (A ∩ B)' = A' ∪ B'.
- شمارش دو مجموعه: n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
- شمارش سه مجموعه: n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C).
- برای حل مسئله‌های شمارش، از وسط‌ترین ناحیه (اشتراک همه) شروع می‌کنیم و بیرون می‌آییم.

## مثال‌های حل‌شده

**مثال ۱.** U = {۱، ۲، ...، ۱۰}، A = {۱، ۲، ۳، ۴} و B = {۳، ۴، ۵، ۶}. حاصل (A ∪ B)' را با دمورگان و مستقیم بیابید.
گام ۱: A' = {۵، ۶، ۷، ۸، ۹، ۱۰} و B' = {۱، ۲، ۷، ۸، ۹، ۱۰}. گام ۲: A' ∩ B' = {۷، ۸، ۹، ۱۰}. گام ۳: مستقیم: A ∪ B = {۱، ...، ۶} و متمم آن {۷، ۸، ۹، ۱۰} است. هر دو راه یکی شد.

**مثال ۲.** در یک کلاس ۴۰ نفره، ۲۵ نفر ریاضی، ۲۰ نفر فیزیک دوست دارند و ۸ نفر هیچ‌کدام. چند نفر هر دو را دوست دارند؟
گام ۱: کسانی که حداقل یکی را دوست دارند: ۴۰ − ۸ = ۳۲. گام ۲: ۳۲ = ۲۵ + ۲۰ − (هر دو). گام ۳: هر دو = ۴۵ − ۳۲ = ۱۳. پاسخ: ۱۳ نفر.

**مثال ۳.** n(A) = ۱۲، n(B) = ۱۰، n(C) = ۸، n(A ∩ B) = ۴، n(A ∩ C) = ۳، n(B ∩ C) = ۲ و n(A ∩ B ∩ C) = ۱. حاصل n(A ∪ B ∪ C) را بیابید.
گام ۱: جمع تک‌تک: ۱۲ + ۱۰ + ۸ = ۳۰. گام ۲: کم‌کردن اشتراک‌های دوتایی: ۳۰ − (۴ + ۳ + ۲) = ۲۱. گام ۳: اضافه‌کردن اشتراک سه‌تایی: ۲۱ + ۱ = ۲۲. پاسخ: ۲۲.

## اشتباه‌های رایج

- جمع‌کردن n(A) + n(B) بدون کم‌کردن اشتراک.
- در دمورگان فراموش‌کردن عوض‌شدن ∪ و ∩ بعد از متمم.
- فراموش‌کردن اضافه‌کردن n(A ∩ B ∩ C) در قاعده‌ی سه مجموعه.

## به یاد داشته باشید

- n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
- دمورگان: متمم اجتماع = اشتراک متمم‌ها و متمم اشتراک = اجتماع متمم‌ها.
- A − B = A ∩ B'.
