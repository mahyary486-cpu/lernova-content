# The Periodic Table

The periodic table is a map of the elements. Its position tells you the properties of an element before you test it.

## Key ideas
- Elements are arranged by increasing **atomic number**.
- A horizontal row is a **period**; a vertical column is a **group (family)**.
- Elements in the same group have **similar properties** and the same number of **valence electrons**.
- The **period number** equals the number of occupied shells.
- Most elements are **metals**; nonmetals are on the right; **metalloids** lie between.
- Each element has a **symbol**: Na (sodium), Fe (iron), K (potassium), Au (gold).

## Worked examples
**Example 1: Group and period.** An element has the arrangement 2, 8, 7.
1. Seven valence electrons put it in Group 17.
2. Three shells put it in period 3.

**Example 2: Similar elements.** Which pair is most similar: lithium and sodium, or sodium and chlorine?
1. Lithium and sodium are in the same group, Group 1.
2. So lithium and sodium have similar properties.

**Example 3: Across a period.** What happens to the atomic number from left to right across a period?
1. Each element has one more proton than the one before.
2. The atomic number increases.

## Common mistakes
- Mixing up periods (rows) and groups (columns).
- Thinking elements in the same period are similar.
- Thinking the table is arranged by color or state.
