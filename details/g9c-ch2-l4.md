# The Periodic Table

The periodic table is a map of all the known elements. Its position tells you a great deal about an element before you have done a single test: whether it is a metal, how many valence electrons it has and which other elements it resembles. Chemists use the table every day, and learning how it is organized is like learning how to read a map. This lesson shows what the rows and the columns mean and how to read an element's position.

## Key ideas

The elements are arranged in order of increasing atomic number, so that each element has one more proton than the one before it. The table has a shape with rows and columns. A horizontal row is called a period, and a vertical column is called a group, or a family. There are 7 periods and 18 groups.

The period number tells how many electron shells are occupied. An element in period 3 has electrons in three shells, such as sodium with 2, 8, 1. The group number tells about the valence electrons. For the main groups, elements in the same group have the same number of valence electrons: Group 1 elements have 1, Group 2 elements have 2, and Group 17 elements have 7. Because chemical behavior is controlled by valence electrons, elements in the same group have similar properties. Lithium, sodium and potassium are all soft, reactive metals, and fluorine, chlorine and bromine are all reactive nonmetals. Elements in the same period are not similar, since they have different numbers of valence electrons.

The table is also divided into regions. Most elements are metals, found on the left and in the center. They are shiny, malleable and good conductors. Nonmetals are on the right side, and they are usually dull and poor conductors. Between them, along a diagonal line, lie the metalloids, which have properties of both. Hydrogen is placed alone at the top, because it has special properties.

Each element has a symbol of one or two letters, the first one capitalized. Many come from the English name, like O for oxygen and H for hydrogen, but some come from older Latin names, such as Na for sodium, K for potassium, Fe for iron and Au for gold. The table also shows the atomic number and the average atomic mass of each element.

## Worked examples

**Example 1: Group and period.** An element has the electron arrangement 2, 8, 7. Where is it on the table?
1. It has 7 valence electrons, so it belongs to Group 17.
2. It has three occupied shells, so it is in period 3. The element is chlorine, atomic number 17.

**Example 2: Similar elements.** Which pair is most similar: lithium and sodium, or sodium and chlorine?
1. Lithium (2, 1) and sodium (2, 8, 1) are in Group 1, and both have 1 valence electron.
2. Sodium and chlorine are in the same period but in different groups, so they have different properties. Lithium and sodium are the more similar pair.

**Example 3: Across a period.** What happens to the atomic number from left to right across a period?
1. Each element has one more proton than the element before it.
2. The atomic number increases by 1 at every step, and the number of valence electrons also increases from left to right.

## Common mistakes

Students often mix up periods and groups. Periods are the rows, and groups are the columns. A second mistake is to think that elements in the same period are similar, when it is the elements in the same group that share properties. Finally, remember that the table is arranged by atomic number and not by color, state or the order in which the elements were found.
