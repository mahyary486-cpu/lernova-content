# Rational Functions: Intercepts, Holes and Asymptotes

## A full analysis
For f(x) = P(x)/Q(x), do these steps:
1. **Factor** the top and the bottom and cancel common factors (each cancelled factor leaves a **hole**).
2. **Domain:** exclude every x that makes the original denominator 0.
3. **Vertical asymptotes:** the zeros of the remaining denominator.
4. **x-intercepts:** the zeros of the remaining numerator.
5. **y-intercept:** f(0), if 0 is in the domain.
6. **End behavior:** horizontal or slant asymptote from the degrees.

## Example
f(x) = (x^2 - 4)/(x^2 - x - 6) = (x - 2)(x + 2) / ((x - 3)(x + 2)).
- The factor x + 2 cancels, so there is a **hole at x = -2**. Its height is (-2 - 2)/(-2 - 3) = 4/5, so the hole is at **(-2, 4/5)**.
- Vertical asymptote: **x = 3**.
- x-intercept: **x = 2**.
- y-intercept: f(0) = -4/-6 = **2/3**.
- Horizontal asymptote: **y = 1** (equal degrees, leading coefficients 1 and 1).

## Horizontal asymptotes
Compare the degree n of the top with the degree m of the bottom:
- n < m: y = 0. Example: (x + 1)/(x^2 + 1).
- n = m: y = ratio of leading coefficients. Example: (3x^2 - 1)/(2x^2 + 5) gives **y = 3/2**.
- n > m: no horizontal asymptote.

## Slant asymptotes
If n = m + 1, divide to find the line. f(x) = (2x^2 + 1)/(x - 1): dividing gives 2x + 2 with remainder 3, so f(x) = 2x + 2 + 3/(x - 1) and the slant asymptote is **y = 2x + 2**. Another example is (x^2 + 1)/x = x + 1/x, with slant asymptote y = x.

## Another example
f(x) = (x - 1)/(x + 2): vertical asymptote x = -2, horizontal asymptote y = 1, x-intercept 1, y-intercept **-1/2**.

## Behavior near a vertical asymptote
Check the sign on each side. For (x - 1)/(x + 2) near x = -2: just to the right (x = -1.9) the value is negative large; just to the left (x = -2.1) it is positive large. The graph goes to -infinity on one side and +infinity on the other.

## Common mistakes
- Calling a cancelled factor a vertical asymptote. It is a hole.
- Finding the horizontal asymptote before cancelling when it matters for degree comparison.
- Forgetting that the graph can cross a horizontal asymptote in the middle.
- Having both a horizontal and a slant asymptote. A function has at most one of them.
