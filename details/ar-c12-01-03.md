# Reacciones orgánicas básicas

## Tipos
- Combustión: CH4 + 2 O2 → CO2 + 2 H2O.
- Sustitución: CH4 + Cl2 → CH3Cl + HCl.
- Adición: CH2=CH2 + Br2 → CH2BrCH2Br.
- Esterificación: ácido + alcohol ⇌ éster + agua.

## Aplicaciones
Combustibles, solventes, fármacos y perfumes.

## Error frecuente
Confundir adición con sustitución: en la adición no se pierde ningún átomo.
