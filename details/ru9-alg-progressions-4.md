# Sums of progressions

**Arithmetic progression.** Sₙ = (a₁ + aₙ) · n / 2, or Sₙ = (2a₁ + (n − 1)d) · n / 2.

Example: 1 + 2 + … + 10 = (1 + 10) · 10 / 2 = 55. For a₁ = 2 and d = 3: S₂₀ = (4 + 19 · 3) · 10 = 610.

**Geometric progression (q ≠ 1).** Sₙ = b₁(qⁿ − 1) / (q − 1). For b₁ = 1 and q = 2: S₆ = (64 − 1) / 1 = 63.

**Infinite geometric progression with |q| < 1.** The sum of all its terms is S = b₁ / (1 − q). Example: 1 + 1/2 + 1/4 + … = 1 / (1 − 1/2) = 2.
