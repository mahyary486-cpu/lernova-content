# Суммы прогрессий

**Арифметическая прогрессия.** Sₙ = (a₁ + aₙ) · n / 2 или Sₙ = (2a₁ + (n − 1)d) · n / 2.

Пример: 1 + 2 + … + 10 = (1 + 10) · 10 / 2 = 55. При a₁ = 2 и d = 3: S₂₀ = (4 + 19 · 3) · 10 = 610.

**Геометрическая прогрессия (q ≠ 1).** Sₙ = b₁(qⁿ − 1) / (q − 1). При b₁ = 1 и q = 2: S₆ = (64 − 1) / 1 = 63.

**Бесконечная геометрическая прогрессия при |q| < 1.** Сумма всех её членов равна S = b₁ / (1 − q). Пример: 1 + 1/2 + 1/4 + … = 1 / (1 − 1/2) = 2.
