# Concepto de función, dominio e imagen

## Idea clave
Una función f asigna a cada x del dominio exactamente un valor f(x).

## Dominio
- f(x) = 1/(x − 3): x ≠ 3, dominio ℝ − {3}.
- f(x) = √(x + 2): x + 2 ≥ 0, dominio [−2; +∞).
- Los polinomios tienen dominio ℝ.

## Imagen
f(x) = x² + 1 toma valores desde 1: imagen [1; +∞).

## Criterio de la recta vertical
Si alguna recta vertical corta la gráfica en dos puntos, no es la gráfica de una función.

## Error frecuente
Olvidar que el radicando de una raíz cuadrada debe ser mayor o igual que 0.
