# Степени с рациональным показателем

Для a > 0 и дроби m / n: a^(m/n) = ⁿ√(aᵐ).

**Примеры.** 8^(1/3) = ³√8 = 2. 9^(3/2) = (√9)³ = 27.

**Другие показатели.** a⁰ = 1 при a ≠ 0, а a^(−n) = 1 / aⁿ. Поэтому 2^(−3) = 1/8.

**Правила.** aᵖ · aᵠ = aᵖ⁺ᵠ, aᵖ / aᵠ = aᵖ⁻ᵠ, (aᵖ)ᵠ = aᵖᵠ. Поэтому a^(1/2) · a^(1/3) = a^(5/6), а 2⁵ · 2^(−2) = 2³ = 8.
