# معادله‌های نمایی و لگاریتمی

## این درس درباره‌ی چیست؟

در این درس معادله‌هایی را حل می‌کنیم که مجهول در توان یا داخل لگاریتم است.

## معادله‌ی نمایی

1. دو طرف را به یک پایه برسانید و توان‌ها را برابر کنید.
2. در غیر این صورت از دو طرف لگاریتم بگیرید.

**مثال:** 2^(x+1) = 16 ⇒ x + 1 = 4 ⇒ x = 3.

معادله‌ی 4ˣ − 3·2ˣ + 2 = 0 با t = 2ˣ به t² − 3t + 2 = 0 می‌رسد؛ x = 0 یا x = 1.

## معادله‌ی لگاریتمی

لگاریتم‌ها را با خاصیت‌ها یکی کنید، سپس به شکل توان درآورید. **جواب‌ها را با دامنه بسنجید.**

**مثال:** log₂(x + 1) + log₂(x − 1) = 3 ⇒ x² − 1 = 8 ⇒ x = 3 (x = −3 غیرقابل قبول).

## نامعادله

برای a > 1 جهت نامساوی حفظ می‌شود (2ˣ > 8 ⇒ x > 3) و برای 0 < a < 1 جهت نامساوی عوض می‌شود.
