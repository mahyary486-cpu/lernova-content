# General equation and distance from a line

The general equation is Ax + By + C = 0 with slope −A/B. The distance of (x₁, y₁) from it is ∣Ax₁ + By₁ + C∣/√(A² + B²). The distance between parallel lines Ax + By + C₁ = 0 and Ax + By + C₂ = 0 is ∣C₁ − C₂∣/√(A² + B²).

Example: the distance of the origin from 3x + 4y − 5 = 0 is 1.
