# حل معادله‌های مثلثاتی

## این درس درباره‌ی چیست؟

در معادله‌ی مثلثاتی جواب‌ها در یک بازه یا به صورت عمومی بیان می‌شوند.

## معادله‌ی ساده

برای sin x = 1/2 در [0 , 2π]: x = π/6 یا x = 5π/6. برای cos x = 0: x = π/2 یا 3π/2. برای tan x = √3: x = π/3 + kπ.

## معادله‌ی درجه‌ی دوم برحسب sin یا cos

مثلاً 2cos²x − cos x − 1 = 0 را با تغییر t = cos x به (2t + 1)(t − 1) = 0 تبدیل می‌کنیم؛ cos x = 1 یا cos x = −1/2.

## نکته

همیشه دوره‌ی تناوب را در نظر بگیرید: sin و cos هر 2π و tan هر π تکرار می‌شود. جواب‌ها را در بازه‌ی خواسته‌شده بنویسید.
