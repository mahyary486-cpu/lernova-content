# Solving Radical Equations

## Steps
1. **Isolate** the radical on one side.
2. Raise both sides to the power that matches the root (square for a square root, cube for a cube root).
3. Solve the new equation.
4. **Check every answer** in the original equation. Squaring can create **extraneous solutions**.

## Examples
**One-step.** sqrt(x + 3) = 5. Square: x + 3 = 25, so **x = 22**.

**Cube root.** The cube root of (x - 2) = 3. Cube both sides: x - 2 = 27, so **x = 29**. (Odd roots usually do not create extraneous solutions.)

**Isolate first.** sqrt(x - 1) + 4 = 7. Subtract 4: sqrt(x - 1) = 3. Square: x - 1 = 9, so x = 10.

**Two radicals.** sqrt(x + 5) = sqrt(2x - 3). Square both sides: x + 5 = 2x - 3, so **x = 8**. Check: both sides equal sqrt(13).

**Extraneous solution.** sqrt(2x - 1) = x - 2. Square: 2x - 1 = x^2 - 4x + 4, so x^2 - 6x + 5 = 0 and x = 1 or x = 5.
- x = 1: sqrt(1) = 1, but x - 2 = -1. **Fails.**
- x = 5: sqrt(9) = 3 and x - 2 = 3. **Works.**
The solution is **x = 5**.

**Another example.** sqrt(x + 6) = x gives x + 6 = x^2, so x^2 - x - 6 = 0 and x = 3 or x = -2. Only **x = 3** works, because sqrt(4) = 2 is not -2.

**Radical and a variable outside.** sqrt(x) + 2 = x. Isolate: sqrt(x) = x - 2. Square: x = x^2 - 4x + 4, so x^2 - 5x + 4 = 0 and x = 1 or x = 4. Check: x = 1 gives 1 + 2 = 3, not 1 (fails). x = 4 gives 2 + 2 = 4 (works). **x = 4**.

**Rational exponent.** (x - 1)^(2/3) = 4. Then the cube root of (x - 1) is 2 or -2, so x - 1 = 8 or -8 and **x = 9 or x = -7**.

## Common mistakes
- Squaring before isolating the radical.
- Squaring a sum incorrectly: (x - 2)^2 is x^2 - 4x + 4, not x^2 + 4.
- Not checking the answers. This is the most common error.
- Losing the plus-or-minus when solving with an even numerator exponent.
