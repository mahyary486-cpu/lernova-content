# Üslü ve köklü sayılar

## Üslü ifadeler

- aᵐ · aⁿ = aᵐ⁺ⁿ ve aᵐ / aⁿ = aᵐ⁻ⁿ
- (aᵐ)ⁿ = aᵐ·ⁿ ve (a·b)ⁿ = aⁿ·bⁿ
- a ≠ 0 için a⁰ = 1; a⁻ⁿ = 1/aⁿ
- Negatif tabanın çift kuvveti pozitif, tek kuvveti negatiftir: (−2)² = 4, (−2)³ = −8.

**Örnek:** 2³ · 2⁴ / 2⁵ = 2³⁺⁴⁻⁵ = 2² = 4.

## Üslü denklemler

Tabanlar eşitlenir, sonra üsler eşitlenir. 4ˣ = 8 için 2²ˣ = 2³ olur ve x = 3/2 bulunur.

## Köklü ifadeler

- √(a·b) = √a · √b (a, b ≥ 0)
- Sadeleştirme: √72 = √(36·2) = 6√2
- Toplama ve çıkarma yalnızca kök içleri aynıysa yapılır: 3√5 + 2√5 = 5√5.
- Paydayı kökten kurtarma: 1/√3 = √3/3. 1/(√3 − √2) için pay ve payda (√3 + √2) ile genişletilir.

## Bilimsel gösterim

Büyük veya küçük sayılar a·10ⁿ biçiminde yazılır (1 ≤ a < 10). 0,00045 = 4,5·10⁻⁴.
