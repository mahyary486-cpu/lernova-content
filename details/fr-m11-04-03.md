# Fonctions de la forme exp(ax + b) et exp(−x)

## Formule générale
Si g(x) = e^(ax + b), alors g’(x) = a e^(ax + b).
Exemples :
- (e^(2x))’ = 2e^(2x).
- (e^(3x + 1))’ = 3e^(3x + 1).
- (e^(−x))’ = −e^(−x).

## Variations
- a > 0 : g est strictement croissante.
- a < 0 : g est strictement décroissante.
Exemple : x ↦ e^(−x) est décroissante, positive, et vaut 1 en x = 0.

## Comparaison avec e^x
Les courbes de e^x et de e^(−x) sont symétriques par rapport à l’axe des ordonnées.

## Modèles
Une grandeur qui évolue selon C(t) = C_0 e^(−0,1t) décroît de plus en plus lentement vers 0 sans l’atteindre.

## Résolution d’équations
- e^(2x) = e^(x+3) donne 2x = x + 3, donc x = 3.
- e^(x²) = e^(3x−2) donne x² − 3x + 2 = 0, donc x = 1 ou x = 2.

## Dérivée d’un produit
f(x) = (x − 1)e^x donne f’(x) = e^x + (x − 1)e^x = x e^x. Le signe de f’ est celui de x : f décroît sur ]−∞ ; 0] puis croît ; son minimum est f(0) = −1.

## Erreur fréquente
Pour dériver e^(ax + b), ne pas oublier de multiplier par a.
