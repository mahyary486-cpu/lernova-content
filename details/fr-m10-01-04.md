# Ordre dans ℝ, encadrements et comparaisons

## Règles de calcul sur les inégalités
Soit a < b.
- a + c < b + c pour tout réel c.
- Si c > 0 : ac < bc.
- Si c < 0 : ac > bc (l’ordre est inversé).
- −a > −b.

## Comparer deux nombres
On étudie le signe de la différence a − b.
Exemple : 3/7 − 4/9 = (27 − 28)/63 = −1/63, qui est négatif. Donc 3/7 < 4/9.

## Carré et inverse
- Si 0 ≤ a < b, alors a² < b².
- Si a < b ≤ 0, alors a² > b².
- Si 0 < a < b, alors 1/a > 1/b.

## Encadrements
On encadre un nombre par deux valeurs simples.
Exemple : 3² = 9 < 10 < 16 = 4², donc 3 < √10 < 4.
Si x ∈ [2 ; 5], alors 1/5 ≤ 1/x ≤ 1/2.

## Erreur fréquente
Multiplier une inégalité par un nombre négatif oblige à changer le sens : 2 < 3 mais −4 > −6 après multiplication par −2.
