# 醛、酮、羧酸及其衍生物

## 醛

官能团 **—CHO**（醛基）。乙醛 CH₃CHO：

- **银镜反应**：CH₃CHO + 2Ag(NH₃)₂OH →(水浴加热) CH₃COONH₄ + 2Ag↓ + 3NH₃ + H₂O；
- 与**新制 Cu(OH)₂ 悬浊液**共热，生成**砖红色** Cu₂O 沉淀；
- 氧化生成乙酸，还原生成乙醇。

这两个反应都用来检验醛基。

## 酮

官能团是羰基，如丙酮 CH₃COCH₃，不能发生银镜反应。

## 羧酸

官能团 **—COOH**（羧基），具有酸性，能与醇发生酯化反应。

## 酯的水解

酯在酸性条件下水解是**可逆**的；在碱性条件下水解**进行到底**（皂化反应）：

CH₃COOCH₂CH₃ + NaOH →(△) CH₃COONa + CH₃CH₂OH

## 转化关系

醇 ⇌ 醛 → 羧酸；醇 + 羧酸 ⇌ 酯 + 水。
