# Grad, Verhalten im Unendlichen und Symmetrie

## Ganzrationale Funktionen

Eine ganzrationale Funktion hat die Form

**f(x) = aₙ · xⁿ + … + a₁ · x + a₀**

Der **Grad** n ist die höchste vorkommende Potenz von x (mit aₙ ≠ 0).

- Grad 0: konstante Funktion
- Grad 1: Gerade
- Grad 2: Parabel
- Eine Funktion vom Grad n hat **höchstens n Nullstellen**.

## Verhalten für x → ±∞

Den Ausschlag gibt der Term mit der höchsten Potenz (Leitterm).

- Gerader Grad, positiver Leitkoeffizient: beide Enden nach oben.
- Gerader Grad, negativer Leitkoeffizient: beide Enden nach unten.
- Ungerader Grad, positiver Leitkoeffizient: links unten, rechts oben.
- Ungerader Grad, negativer Leitkoeffizient: links oben, rechts unten.

## Symmetrie

- Nur gerade Exponenten: **achsensymmetrisch zur y-Achse**, es gilt f(−x) = f(x).
- Nur ungerade Exponenten: **punktsymmetrisch zum Ursprung**, es gilt f(−x) = −f(x).
- Gemischt: weder noch.

## y-Achsenabschnitt

Der y-Achsenabschnitt ist f(0), also das Absolutglied a₀.

## Beispiele

**Beispiel 1:** f(x) = x⁴ − x² ist achsensymmetrisch.

**Beispiel 2:** f(x) = x³ + x ist punktsymmetrisch.

**Beispiel 3:** f(x) = −2x³ + x geht für x → −∞ nach +∞ und für x → +∞ nach −∞.
