# Calculs et preuves avec le calcul littéral

## Programme de calcul
Programme : choisir un nombre, ajouter 3, multiplier le résultat par 2, soustraire le double du nombre de départ.
Avec x comme nombre de départ : 2(x + 3) − 2x = 2x + 6 − 2x = 6.
Le résultat est toujours 6, quel que soit le nombre choisi.

## Prouver une propriété
Pour montrer qu’une propriété est vraie pour tous les nombres, un exemple ne suffit pas : on utilise une lettre.
Exemple : la somme de trois entiers consécutifs est un multiple de 3.
On note n, n + 1 et n + 2 ces entiers. Leur somme est n + n + 1 + n + 2 = 3n + 3 = 3(n + 1). C’est un multiple de 3.

## Entiers pairs et impairs
- Un entier pair s’écrit 2n.
- Un entier impair s’écrit 2n + 1.
- La somme de deux nombres impairs : (2n + 1) + (2m + 1) = 2(n + m + 1) est paire.

## Contre-exemple
Pour montrer qu’une propriété est fausse, un seul exemple suffit. L’affirmation « (x + 2)² = x² + 4 » est fausse : pour x = 1, (1 + 2)² = 9 mais 1 + 4 = 5.

## Rédaction
On précise le choix de la lettre, on écrit les calculs ligne par ligne, puis on conclut par une phrase.
