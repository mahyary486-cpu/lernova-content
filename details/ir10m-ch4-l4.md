# نامعادله‌های خطی و درجه‌ی دوم

## این درس درباره‌ی چیست؟

در زندگی اغلب با «بیشتر از» و «کمتر از» سروکار داریم، نه فقط «برابر با». مثلاً: «چند دقیقه مکالمه کنم تا هزینه‌ام از ۵۰ هزار تومان کمتر شود؟» پاسخ این پرسش‌ها نامعادله است و جوابشان معمولاً یک بازه است.

## نامعادله‌ی خطی

مثل معادله حل می‌شود، با یک تفاوت مهم: **اگر دو طرف را در عدد منفی ضرب یا بر عدد منفی تقسیم کنیم، جهت نامساوی برعکس می‌شود.**

**مثال:** −۳x + ۶ ≥ ۱۵
−۳x ≥ ۹
x ≤ −۳ (جهت برگشت)
جواب: x ∈ (−∞, −۳]

## نامعادله‌ی درجه‌ی دوم: روش تعیین علامت

**مثال:** x² − x − ۶ < ۰

۱) ریشه‌ها را پیدا کنید: (x − ۳)(x + ۲) = ۰ → x = ۳ و x = −۲
۲) ریشه‌ها را روی محور بگذارید؛ سه ناحیه ساخته می‌شود.
۳) علامت عبارت را در هر ناحیه بیازمایید:
- x < −۲ (مثلاً x = −۳): (−۳)² + ۳ − ۶ = ۶ > ۰
- بین −۲ و ۳ (مثلاً x = ۰): −۶ < ۰
- x > ۳ (مثلاً x = ۴): ۱۶ − ۴ − ۶ = ۶ > ۰
۴) ما عبارت منفی می‌خواهیم، پس جواب ناحیه‌ی وسط است: **(−۲, ۳)**

نکته‌ی کلی برای a > ۰: سهمی بین دو ریشه منفی و بیرون آن‌ها مثبت است.

## وقتی نامساوی کامل (≤ یا ≥) است

ریشه‌ها هم جزو جواب‌اند. برای x² − x − ۶ ≤ ۰ جواب [−۲, ۳] می‌شود.

## نامعادله‌ی کسری

برای نامعادله‌هایی مثل (x − ۱)/(x + ۲) > ۰ نیز علامت صورت و مخرج را روی محور بررسی می‌کنیم. ریشه‌ی مخرج هرگز جزو جواب نیست.
ریشه‌ها: x = ۱ و x = −۲. نتیجه: x < −۲ یا x > ۱.

## خطاهای رایج

- فراموش‌کردن برگرداندن جهت نامساوی هنگام ضرب در منفی
- تقسیم دو طرف بر x یا بر عبارتی که علامتش نامعلوم است
- نوشتن جواب نهایی بدون بازه یا بدون در نظر گرفتن باز و بسته‌بودن سرها

## جمع‌بندی

نامعادله را با تعیین علامت حل کنید: ریشه‌ها، ناحیه‌ها، آزمون یک نقطه در هر ناحیه، و در پایان جواب را به صورت بازه بنویسید.
