# تابع قدرمطلق، جزء صحیح و تابع چندضابطه‌ای

## این درس درباره‌ی چیست؟

این توابع ضابطه‌ی واحد ندارند و رفتارشان با بازه‌ها تغییر می‌کند.

## قدرمطلق

|x| = x برای x ≥ 0 و |x| = −x برای x < 0. نمودار |x| شکل V است.

معادله‌ی |A| = k (k > 0) دو جواب دارد: A = k یا A = −k.

**مثال:** |2x − 1| = 5 ⇒ x = 3 یا x = −2.

## جزء صحیح

[x] بزرگ‌ترین عدد صحیح کوچک‌تر یا مساوی x است. مثلاً [3٫7] = 3 و [−1٫5] = −2.

[x] = n ⇔ n ≤ x < n + 1.

## تابع چندضابطه‌ای

برای هر ورودی ابتدا تعیین می‌کنیم در کدام بازه است و سپس از همان ضابطه استفاده می‌کنیم.
