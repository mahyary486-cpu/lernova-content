# 常见的碱

## 氢氧化钠和氢氧化钙

- **氢氧化钠（NaOH）**：俗称火碱、烧碱、苛性钠。白色固体，易吸收空气中的水分而**潮解**，溶于水**放热**，有强腐蚀性；
- **氢氧化钙（Ca(OH)₂）**：俗称熟石灰、消石灰。微溶于水。由生石灰与水反应得到：CaO + H₂O = Ca(OH)₂，放出大量的热。

## 碱的通性

碱溶液中都含有 OH⁻，所以化学性质相似：

1. 使紫色石蕊溶液变**蓝**，使无色酚酞溶液变**红**；
2. 与非金属氧化物反应：CO₂ + 2NaOH = Na₂CO₃ + H₂O；
3. 与酸发生中和反应；
4. 与某些盐反应：Ca(OH)₂ + Na₂CO₃ = CaCO₃↓ + 2NaOH。

**注意**：氢氧化钠敞口放置会吸收空气中的二氧化碳而变质，所以要密封保存。
