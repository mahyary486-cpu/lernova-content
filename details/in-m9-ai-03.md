# Difference of squares and (x + a)(x + b)

a² − b² = (a + b)(a − b). For instance x² − 9 = (x + 3)(x − 3) and 51² − 49² = 100 × 2 = 200. Also 103 × 97 = (100 + 3)(100 − 3) = 9991.

(x + a)(x + b) = x² + (a + b)x + ab. So (x + 3)(x + 2) = x² + 5x + 6, and (x + 4)(x − 3) = x² + x − 12. Reading the identity backwards factorises a quadratic: find two numbers with product ab and sum a + b.
