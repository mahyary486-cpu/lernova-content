# 光的色散与增透膜

## 光的色散

白光通过三棱镜后被分解成七种色光（红、橙、黄、绿、青、蓝、紫），叫光的色散。

从红光到紫光：

- 频率逐渐**增大**；
- 波长逐渐**减小**；
- 同一介质中的折射率逐渐**增大**；
- 在介质中的传播速度逐渐**减小**；
- 临界角逐渐**减小**。

**例：** 红光和紫光比较，同一介质中红光的折射率较小，速度较大，波长较长。

## 增透膜

镜头表面涂的薄膜，让特定色光（如绿光）的反射光发生干涉相消，增加透射光。

最小厚度：**d = λ膜 / 4 = λ / (4n)**（λ 为光在真空中的波长，n 为膜的折射率）。

**例：** 对 λ = 550 nm 的光，膜的折射率 n = 1.38：

d = 550 / (4 × 1.38) ≈ 99.6 nm，约 100 nm。

## 激光

激光的特点：相干性好、平行度好、亮度高，用于光纤通信、测距、切割、全息照相。
