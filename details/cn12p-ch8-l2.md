# 氢原子能级与玻尔模型

## 能级公式

**Eₙ = −13.6 / n² eV**

- n = 1（基态）：−13.6 eV；n = 2：−3.4 eV；n = 3：−1.51 eV。

## 跃迁

**hν = Eₘ − Eₙ**（m > n）。

- n = 3 → 1：ΔE = −1.51 − (−13.6) = 12.09 eV；
- n = 2 → 1：ΔE = 10.2 eV；
- n = 3 → 2：ΔE = 1.89 eV。

## 光子的波长

λ = hc / ΔE ≈ 1240 eV·nm / ΔE。

**例：** n = 2 → 1：λ = 1240 / 10.2 ≈ 121.6 nm（紫外线）。

## 电离

基态氢原子电离需要 **13.6 eV**，能量大于等于这个值的光子都能使它电离。

## 跃迁的种类

一群氢原子处于第 n 能级，最多辐射 Cₙ² 种频率的光：n = 3 时有 3 种，n = 4 时有 6 种。

**吸收光子**：跃迁时只能吸收**恰好等于**能级差的光子（电离除外）。
