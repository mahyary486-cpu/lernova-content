# ユークリッドの互除法と n進法

## ユークリッドの互除法

a を b でわった余りを r とすると、gcd(a, b) = gcd(b, r)。余りが 0 になるまで繰り返し、そのときのわる数が最大公約数。

**例：** gcd(253, 161)：253 = 161×1 + 92、161 = 92×1 + 69、92 = 69×1 + 23、69 = 23×3 + 0。よって 23。

## n進法

- n 進法 → 10進法：各位に nᵏ をかけて足す。例：1011₍₂₎ = 8 + 0 + 2 + 1 = 11。
- 10進法 → n 進法：n で繰り返しわり、余りを下から順に読む。例：25 = 121₍₄₎（25 = 4×6 + 1、6 = 4×1 + 2、1 = 4×0 + 1）。
