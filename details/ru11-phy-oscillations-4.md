# Электромагнитные волны

**Электромагнитная волна** — распространяющееся в пространстве переменное электромагнитное поле. Существование таких волн предсказал Максвелл, а Герц получил их на опыте.

**Скорость в вакууме** c = 3 · 10⁸ м/с. Для волны c = λ · ν. Для частоты 100 МГц длина волны равна 3 м, а волна длиной 300 м имеет частоту 1 МГц.

**Радиолокация.** Если отражённый сигнал вернулся через 4 · 10⁻⁴ с, расстояние до цели s = c · t / 2 = 60 км.

**Применение:** радио- и телевизионная связь, мобильная связь, радиолокация.

**Шкала волн:** радиоволны, инфракрасное, видимый свет, ультрафиолет, рентген, гамма-излучение.
