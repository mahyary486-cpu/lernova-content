# مفهوم تابع، دامنه و برد

## این درس درباره‌ی چیست؟

تابع قاعده‌ای است که به هر ورودی دقیقاً یک خروجی نسبت می‌دهد.

## دامنه و برد

- **دامنه**: مجموعه‌ی ورودی‌های مجاز
- **برد**: مجموعه‌ی خروجی‌هایی که تابع می‌گیرد

محدودیت‌های رایج: مخرج ≠ 0، زیر رادیکال با فرجه‌ی زوج ≥ 0.

## مثال‌ها

- f(x) = 1/(x − 2): دامنه x ≠ 2
- f(x) = √x: دامنه x ≥ 0 و برد y ≥ 0
- f(x) = x² − 4: برد y ≥ −4
- f(x) = 1/(x − 3) + √x: دامنه x ≥ 0 و x ≠ 3

## آزمون خط قائم

نمودار یک تابع است اگر هر خط قائم آن را حداکثر در یک نقطه قطع کند.
