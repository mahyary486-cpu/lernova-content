# Coordonnées d’un vecteur et opérations

## Coordonnées de AB→
AB→ a pour coordonnées (xB − xA ; yB − yA).
Exemple : A(1 ; 2) et B(4 ; 6) donnent AB→(3 ; 4).
Pour retrouver B : si AB→(3 ; −2) et A(1 ; 4), alors B(4 ; 2).

## Opérations
Pour u→(x ; y) et v→(x’ ; y’) :
- u→ + v→ a pour coordonnées (x + x’ ; y + y’).
- k u→ a pour coordonnées (kx ; ky).
- L’opposé de u→ a pour coordonnées (−x ; −y).
Exemple : u→(2 ; 3) et v→(−1 ; 4) donnent 2u→ − v→ = (4 + 1 ; 6 − 4) = (5 ; 2).

## Égalité
Deux vecteurs sont égaux si et seulement si leurs coordonnées sont égales.

## Parallélogramme
ABCD est un parallélogramme si AB→ = DC→ : xB − xA = xC − xD et yB − yA = yC − yD, donc C = B + D − A. Pour A(0 ; 0), B(4 ; 1) et D(1 ; 3) : C(5 ; 4).

## Norme
Dans un repère orthonormé, la norme de u→(x ; y) est √(x² + y²). Pour u→(3 ; 4), la norme est 5.

## Erreur fréquente
Les coordonnées de AB→ sont « arrivée moins départ » : B − A, et non A − B.
