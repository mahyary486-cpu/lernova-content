# Opérations sur les limites et théorème des gendarmes

## Opérations
On peut additionner, multiplier, diviser des limites quand le résultat est défini. Les formes indéterminées sont : ∞ − ∞, 0 × ∞, ∞/∞ et 0/0. Dans ces cas, on transforme l’expression.

## Lever une indétermination
- Polynôme : on factorise le terme de plus haut degré. n² − 3n + 5 = n²(1 − 3/n + 5/n²), donc lim = +∞.
- Quotient : (3n + 1)/(n + 2) = (3 + 1/n)/(1 + 2/n), donc lim = 3.
- (2n² + 1)/(n² + 3) a pour limite 2.
- (n + 1)/(n² + 1) a pour limite 0.
- Différence de racines : √(n + 1) − √n = 1/(√(n + 1) + √n), donc lim = 0.
- Suites géométriques : 3^n − 2^n = 3^n(1 − (2/3)^n), donc lim = +∞. Et (2^n + 3^n)/3^n = (2/3)^n + 1 a pour limite 1.

## Théorème de comparaison
Si u_n ≥ n pour tout n, alors lim u_n = +∞. Si v_n ≤ u_n et lim u_n = −∞, alors lim v_n = −∞.

## Théorème des gendarmes
Si u_n ≤ v_n ≤ w_n et lim u_n = lim w_n = ℓ, alors lim v_n = ℓ.
Exemple : −1/n ≤ cos(n)/n ≤ 1/n, donc lim cos(n)/n = 0.

## Somme géométrique
1 + 1/2 + … + 1/2^n = (1 − (1/2)^(n+1))/(1/2) a pour limite 2.

## Erreur fréquente
Écrire « ∞ − ∞ = 0 » : c’est une forme indéterminée, il faut transformer l’écriture.
