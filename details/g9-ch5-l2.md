# Multiplying Polynomials

To multiply polynomials, multiply every term of one by every term of the other, then combine like terms.

## Key ideas
- **Product of powers:** x^m * x^n = x^(m+n). For example x^3 * x^4 = x^7.
- **Monomial times polynomial:** distribute. 3x(2x^2 - 5) = 6x^3 - 15x.
- **Binomial times binomial:** use FOIL (First, Outer, Inner, Last), which is just the distributive property done in an organized way.
- **Larger products:** distribute each term of the first polynomial across the second, or use an area box.

## Worked examples
**Example 1.** Multiply (x + 3)(x + 5).
1. First: x * x = x^2.
2. Outer: x * 5 = 5x.
3. Inner: 3 * x = 3x.
4. Last: 3 * 5 = 15.
5. Add and combine: x^2 + 5x + 3x + 15 = x^2 + 8x + 15.

**Example 2.** Multiply (2x - 1)(x + 4).
1. First: 2x^2. Outer: 8x. Inner: -x. Last: -4.
2. Combine: 2x^2 + 8x - x - 4 = 2x^2 + 7x - 4.

**Example 3.** Multiply (x + 2)(x^2 - 3x + 1).
1. Distribute x: x^3 - 3x^2 + x.
2. Distribute 2: 2x^2 - 6x + 2.
3. Add: x^3 - 3x^2 + 2x^2 + x - 6x + 2.
4. Combine: x^3 - x^2 - 5x + 2.

## Checking your work
Pick a number, such as x = 1. In Example 1, (1 + 3)(1 + 5) = 24 and 1 + 8 + 15 = 24. The two agree.

## Common mistakes
- Multiplying exponents instead of adding them: x^2 * x^3 = x^5, not x^6.
- Forgetting a term. A trinomial times a binomial gives 6 products before combining.
- Sign errors with negatives: (-4)(-3) = +12.
- Writing (x + 3)^2 = x^2 + 9. The middle term is missing; see the next lesson.
