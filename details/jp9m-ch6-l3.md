# 内接四角形と接線（発展）

この単元は、高校の数学A につながる発展的な内容です。

## 円に内接する四角形

四角形 ABCD が円に内接するとき

- 向かい合う角の和は 180°（∠A + ∠C = 180°）。
- 1つの外角は、それと向かい合う内角に等しい。

**例：** ∠A = 62° のとき ∠C = 118°。

## 円の接線

- 接線は、接点を通る半径に垂直。
- 円の外の点 P から2本の接線 PA、PB を引くと PA = PB。

**例：** ∠APO = 37° のとき、直角三角形 OAP で ∠AOP = 90° − 37° = 53°。

**例：** ∠APB = 80° のとき、△PAB は PA = PB の二等辺三角形なので ∠PAB = (180° − 80°) ÷ 2 = 50°。
