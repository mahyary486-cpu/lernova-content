# Parabolas

A parabola is the set of all points that are the same distance from a fixed point, the **focus**, and a fixed line, the **directrix**. The point halfway between the focus and the directrix is the **vertex**. The line through the focus and vertex is the **axis of symmetry**.

## Key ideas
Let p be the directed distance from the vertex to the focus.

**Vertex at the origin**
- x^2 = 4py: opens up if p > 0 and down if p < 0. Focus (0, p), directrix y = -p.
- y^2 = 4px: opens right if p > 0 and left if p < 0. Focus (p, 0), directrix x = -p.

**Vertex at (h, k)**
- (x - h)^2 = 4p(y - k): axis is vertical, focus (h, k + p), directrix y = k - p.
- (y - k)^2 = 4p(x - h): axis is horizontal, focus (h + p, k), directrix x = h - p.

The width of the parabola at the focus (the latus rectum) is |4p|.

## Worked examples

**Example 1. Find the focus and directrix of y^2 = 8x.**
1. Compare with y^2 = 4px: 4p = 8, so p = 2.
2. The parabola opens right.
3. Focus (2, 0), directrix x = -2.

**Example 2. Write the equation with vertex (2, 1) and directrix y = -3.**
1. The directrix is below the vertex, so the parabola opens up. The distance from vertex to directrix is 1 - (-3) = 4, so p = 4.
2. Use (x - h)^2 = 4p(y - k).
3. Equation: (x - 2)^2 = 16(y - 1). The focus is (2, 5).

**Example 3. Convert y = x^2 - 4x + 7 to standard form.**
1. Complete the square: y = (x^2 - 4x + 4) + 3 = (x - 2)^2 + 3.
2. Rewrite: (x - 2)^2 = y - 3, so 4p = 1 and p = 1/4.
3. Vertex (2, 3), focus (2, 13/4), directrix y = 11/4.

## Real-world use
A satellite dish or a car headlight is shaped like a paraboloid. Signals arriving parallel to the axis reflect to the focus, and light from a bulb at the focus leaves as a parallel beam.

## Common mistakes
- Using p as the full distance between focus and directrix. That distance is 2p.
- Forgetting that the sign of p decides the direction of opening.
- Mixing up which variable is squared: the squared variable is the one perpendicular to the axis.
- Writing (x + h) when the vertex is (h, k). Use x - h and y - k.
