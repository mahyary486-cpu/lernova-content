# 复数的运算

## 四则运算

- 加减：(a + bi) ± (c + di) = (a ± c) + (b ± d)i；
- 乘法：(a + bi)(c + di) = (ac − bd) + (ad + bc)i（按多项式乘法展开，把 i² 换成 −1）；
- 除法：分子、分母同乘分母的**共轭复数**。

## 例题

**例 1：** (1 + 2i)(3 − i) = 3 − i + 6i − 2i² = 3 + 5i + 2 = 5 + 5i。

**例 2：** (1 + i)² = 1 + 2i + i² = 2i。

**例 3：** (2 + i)/(1 − i) = (2 + i)(1 + i) / [(1 − i)(1 + i)] = (1 + 3i)/2 = 1/2 + (3/2)i。

## i 的幂

i¹ = i，i² = −1，i³ = −i，i⁴ = 1，周期为 4。

**例：** i²⁰²⁶：2026 除以 4 余 2，所以 i²⁰²⁶ = i² = −1。

## 常用结论

- z · z̄ = |z|²；
- z 为实数 ⇔ z = z̄。
