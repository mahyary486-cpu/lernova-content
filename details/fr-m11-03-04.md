# Dérivée et variations, extremums

## Théorème
Soit f dérivable sur un intervalle I.
- Si f’(x) > 0 sur I, f est strictement croissante sur I.
- Si f’(x) < 0 sur I, f est strictement décroissante sur I.
- Si f’(x) = 0 sur I, f est constante.

## Extremum local
Si f’ s’annule en a en changeant de signe, f admet un extremum local en a : un maximum si f’ passe de + à −, un minimum si f’ passe de − à +.

## Méthode d’étude
1. On calcule f’(x).
2. On étudie son signe (tableau de signes).
3. On en déduit les variations et on calcule les valeurs aux changements de sens.

## Exemples
- f(x) = x² − 4x : f’(x) = 2x − 4. f décroît sur ]−∞ ; 2], croît sur [2 ; +∞[ ; son minimum est f(2) = −4.
- f(x) = x³ − 3x : f’(x) = 3x² − 3 = 3(x − 1)(x + 1). f croît sur ]−∞ ; −1], décroît sur [−1 ; 1], croît sur [1 ; +∞[. Maximum local f(−1) = 2, minimum local f(1) = −2.
- Bénéfice B(x) = −x² + 8x − 7 : B’(x) = −2x + 8 s’annule en 4 ; le maximum est B(4) = 9.

## Problème d’optimisation
On modélise la grandeur à optimiser par une fonction, on étudie ses variations sur l’intervalle autorisé et on interprète le résultat.

## Erreur fréquente
f’(a) = 0 ne suffit pas pour avoir un extremum : il faut que f’ change de signe (x³ en 0 en est un contre-exemple).
