# 电势、电势能与电势差

## 电势差与电场力做功

**U_AB = W_AB / q = φ_A − φ_B**

电场力做功与路径无关，**W = qU**。

**例：** q = 2×10⁻⁶ C 的电荷从 A 移到 B，电场力做功 4×10⁻⁴ J：

U_AB = 4×10⁻⁴ / 2×10⁻⁶ = 200 V。

## 电势能

- Eₚ = qφ；
- 电场力做正功，电势能**减少**：**W = −ΔEₚ**；
- 电场力做负功，电势能增加。

## 电势

- 沿电场线方向，电势**逐渐降低**；
- 等势面与电场线垂直，在等势面上移动电荷，电场力不做功。

## 匀强电场中的关系

**E = U / d**（d 是沿电场线方向的距离）。

**例：** 沿电场线方向相距 0.1 m 的两点电势差 200 V，场强 E = 200 / 0.1 = 2000 V/m。

## 比较方法

- 比较电势：沿电场线方向降低；
- 比较电势能：正电荷在电势高处电势能大，负电荷相反。
