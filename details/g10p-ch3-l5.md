# Friction and Inclined Planes

Friction is the contact force that resists sliding between two surfaces. Together with the weight components on a slope, it decides whether objects speed up, slow down or stay still.

## Key ideas
- **Static friction** acts when there is no sliding and adjusts up to a maximum: f_s,max = mu_s N.
- **Kinetic friction** acts while sliding: f_k = mu_k N. Usually mu_k is smaller than mu_s.
- Friction points opposite to the (attempted) sliding and is parallel to the surface. N is the normal force, so on a level floor with no vertical pushes N = mg.
- On an incline of angle theta, resolve the weight into a component along the slope, mg sin(theta), and a component perpendicular to it, mg cos(theta).
- So N = mg cos(theta). Without friction a = g sin(theta) down the slope.
- With friction sliding down: a = g sin(theta) - mu_k g cos(theta).
- At constant speed on an incline, mu_k = tan(theta).

## Worked examples
**Example 1: pushing a crate.** A 50 kg crate on a level floor has mu_s = 0.40 and mu_k = 0.30. Use g = 9.8 m/s^2.
1. N = mg = 50 x 9.8 = 490 N.
2. Maximum static friction = 0.40 x 490 = 196 N.
3. Kinetic friction = 0.30 x 490 = 147 N.
4. A 250 N push exceeds 196 N, so it slides: a = (250 - 147) / 50 = 2.06, about 2.1 m/s^2.

**Example 2: frictionless ramp.** A 20 kg block on a 25 degree frictionless incline.
1. Force along the slope = mg sin(25 degrees) = 20 x 9.8 x 0.4226 = 82.8 N.
2. a = g sin(25 degrees) = 9.8 x 0.4226 = 4.1 m/s^2.
3. Normal force = 20 x 9.8 x cos(25 degrees) = 177.6 N, about 178 N.

**Example 3: ramp with friction.** The same block now has mu_k = 0.10.
1. Friction = 0.10 x 177.6 = 17.8 N up the slope.
2. Net = 82.8 - 17.8 = 65.0 N.
3. a = 65.0 / 20 = 3.25, about 3.3 m/s^2.

## Common mistakes
- Using f = mu N with N = mg on a slope. There N = mg cos(theta).
- Mixing sine and cosine for the slope components.
- Using the weight as the friction force. Friction is mu times N.
- Assuming static friction always equals mu_s N. It equals only what is needed, up to that limit.
