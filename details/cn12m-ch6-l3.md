# 最值与范围问题

## 常用方法

- **几何法**：利用圆锥曲线的定义和几何性质；
- **代数法**：把目标表示成某个变量的函数，求函数的最值，或用基本不等式；
- **参数法**：设曲线上的点的参数坐标。

## 椭圆上的点到焦点的距离

椭圆上任意一点 P 到焦点 F 的距离范围是 **[a − c, a + c]**。

**例：** 椭圆 x²/25 + y²/9 = 1，右焦点 (4, 0)：

- 最小值 a − c = 5 − 4 = 1；
- 最大值 a + c = 5 + 4 = 9。

## 抛物线上的点到直线的距离

**例：** 抛物线 y² = 4x 上的点 P 到直线 x − y + 4 = 0 的距离的最小值。

设 P(t², 2t)，距离 d = |t² − 2t + 4| / √2 = ((t − 1)² + 3) / √2。

当 t = 1 时，d 最小，为 3/√2 = 3√2/2。

## 注意

设变量时要注明取值范围，求最值时要验证等号能否取到。
