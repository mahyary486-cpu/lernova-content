# Partial Fraction Decomposition

## The idea
Adding fractions combines them: 2/(x + 1) + 3/(x + 2) = (5x + 7)/((x + 1)(x + 2)).
**Partial fractions** do the reverse: they break a complicated rational expression into a sum of simpler fractions.

## Distinct linear factors
If the denominator is a product of different linear factors and the numerator has a smaller degree, write
**P(x)/((x - a)(x - b)) = A/(x - a) + B/(x - b)**.
Multiply both sides by the denominator, then find A and B by substituting the zeros.

## Example 1
(5x + 7)/((x + 1)(x + 2)) = A/(x + 1) + B/(x + 2).
Multiply: 5x + 7 = A(x + 2) + B(x + 1).
- x = -1: 2 = A(1), so **A = 2**.
- x = -2: -3 = B(-1), so **B = 3**.
Answer: **2/(x + 1) + 3/(x + 2)**.
Check: 2(x + 2) + 3(x + 1) = 5x + 7.

## Example 2
1/((x - 1)(x + 1)) = A/(x - 1) + B/(x + 1). Then 1 = A(x + 1) + B(x - 1). With x = 1: 1 = 2A, so A = 1/2. With x = -1: 1 = -2B, so B = -1/2.
Answer: **(1/2)/(x - 1) - (1/2)/(x + 1)**.

## Example 3
1/(x(x + 3)) = **(1/3)/x - (1/3)/(x + 3)**, because 1 = A(x + 3) + Bx gives A = 1/3 (x = 0) and B = -1/3 (x = -3).

## Example 4: factor first
(3x + 1)/(x^2 - x - 2). Factor the denominator: (x - 2)(x + 1). Then 3x + 1 = A(x + 1) + B(x - 2).
- x = 2: 7 = 3A, so A = 7/3.
- x = -1: -2 = -3B, so B = 2/3.
Answer: **(7/3)/(x - 2) + (2/3)/(x + 1)**.

## If the numerator is too big
When the degree of the numerator is **at least** the degree of the denominator, divide first. Then decompose the remainder fraction.

## Why it is useful
Simple fractions are much easier to work with. They are used to add long sums, to graph, and later in calculus to find integrals.

## Common mistakes
- Not factoring the denominator first.
- Forgetting to divide when the fraction is improper.
- Mixing up which constant goes with which factor. Substitute the zero of that factor.
- Not checking the answer by adding the fractions back.
