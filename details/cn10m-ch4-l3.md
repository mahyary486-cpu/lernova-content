# 函数的零点与二分法

## 函数的零点

使 f(x) = 0 的实数 x 叫作函数 y = f(x) 的**零点**。

方程 f(x) = 0 有实数根 ⇔ 函数 y = f(x) 的图象与 x 轴有交点 ⇔ 函数 y = f(x) 有零点。

## 零点存在定理

如果函数 y = f(x) 在区间 [a, b] 上的图象是连续不断的，并且 **f(a) · f(b) < 0**，那么函数在区间 (a, b) 内**至少有一个**零点。

**例 1：** f(x) = x² − 2：f(1) = −1 < 0，f(2) = 2 > 0，所以在 (1, 2) 内有零点，它就是 √2。

**例 2：** f(x) = 2ˣ + x − 4：f(1) = −1 < 0，f(2) = 2 > 0，零点在 (1, 2) 内。

## 二分法

对于在区间 [a, b] 上连续不断且 f(a) · f(b) < 0 的函数，不断把区间一分为二，使两个端点逐步逼近零点，得到零点的近似值。

## 指数增长模型

增长率为 p、初始量为 N 的量，x 期后的量为 y = N(1 + p)ˣ。例如某细菌每小时增长一倍，初始 100 个，3 小时后为 100 × 2³ = 800 个。
