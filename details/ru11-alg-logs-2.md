# Логарифмическая функция

Функция **y = log_a x** (a > 0, a ≠ 1) определена при x > 0, а множество её значений — все действительные числа.

**Свойства.**

- график проходит через точку (1; 0);
- при a > 1 функция **возрастает**, при 0 < a < 1 — **убывает**;
- график лежит правее оси y и приближается к ней.

Функция y = log_a x является **обратной** к показательной функции y = aˣ: графики симметричны относительно прямой y = x.

**Область определения** сложной функции находят из условия, что выражение под логарифмом положительно. Для y = log₃ (x − 2) нужно x − 2 > 0, то есть x > 2.
