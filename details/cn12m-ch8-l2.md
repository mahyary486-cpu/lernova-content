# 不等式恒成立与绝对值不等式

## 绝对值不等式

- |x − a| < b ⇔ a − b < x < a + b（b > 0）；
- |x − a| > b ⇔ x < a − b 或 x > a + b；
- 三角不等式：|a| + |b| ≥ |a ± b|。

**例 1：** |x − 1| < 2，解得 −1 < x < 3。

**例 2：** |x − 1| + |x + 2| 的最小值：

|x − 1| + |x + 2| ≥ |(x + 2) − (x − 1)| = 3，当 −2 ≤ x ≤ 1 时取等号，最小值为 3。

## 分段讨论法

**例 3：** 解 |x − 1| + |x + 2| ≤ 5。

- x < −2：−(x − 1) − (x + 2) = −2x − 1 ≤ 5，x ≥ −3，所以 −3 ≤ x < −2；
- −2 ≤ x ≤ 1：3 ≤ 5 恒成立；
- x > 1：2x + 1 ≤ 5，x ≤ 2，所以 1 < x ≤ 2。

综上，解集为 [−3, 2]。

## 恒成立问题

f(x) ≥ a 恒成立 ⇔ f(x)ₘᵢₙ ≥ a；f(x) ≤ a 恒成立 ⇔ f(x)ₘₐₓ ≤ a。
