# Limites en l’infini et asymptotes

## Limites usuelles en +∞
- lim x = +∞, lim x² = +∞, lim √x = +∞.
- lim 1/x = 0, lim 1/x² = 0.
- lim e^x = +∞ ; lim e^(−x) = 0.
En −∞ : lim e^x = 0 et lim 1/x = 0.

## Asymptote horizontale
Si lim(x→+∞) f(x) = ℓ (nombre fini), la droite d’équation y = ℓ est asymptote horizontale à la courbe de f en +∞ (de même en −∞).
Exemple : lim(x→+∞) (2 + 1/x) = 2 : asymptote y = 2.

## Polynômes et fractions rationnelles
- En l’infini, un polynôme a la même limite que son terme de plus haut degré : lim(x→+∞) (3x² − x + 1) = +∞ et lim(x→+∞) (x − x²) = −∞.
- Une fraction rationnelle se comporte comme le quotient des termes de plus haut degré : (2x + 1)/(x − 3) a pour limite 2 ; (x² + 1)/(x³ + 2) a pour limite 0 ; (5x² − 3x)/(2x² + 7) a pour limite 5/2.

## Exemple de f(x) = (2x + 1)/(x − 1)
- lim(x→±∞) f(x) = 2 : asymptote horizontale y = 2.
- Le dénominateur s’annule en 1 : asymptote verticale x = 1.

## Racines
lim(x→+∞) (√(x + 1) − √x) = 0, car √(x + 1) − √x = 1/(√(x + 1) + √x).

## Erreur fréquente
Une asymptote est une droite dont la courbe se rapproche indéfiniment ; la courbe peut la traverser.
