# 金属材料与铝

## 合金

合金是由两种或两种以上的金属（或金属与非金属）熔合而成的具有金属特性的物质。合金的硬度一般大于它的成分金属，熔点一般低于它的成分金属。

常见合金：生铁、钢、不锈钢、铝合金、钛合金、储氢合金。

## 铝的性质

铝在常温下与氧气反应，表面形成致密的氧化膜，保护内部的铝。

- 与酸：2Al + 6HCl = 2AlCl₃ + 3H₂↑；
- 与强碱：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑。

## 氧化铝和氢氧化铝

**Al₂O₃** 是两性氧化物，**Al(OH)₃** 是两性氢氧化物，既能与酸反应，也能与强碱反应：

- Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O
- Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O

因此铝制品不宜长时间盛放酸性、碱性或咸的食物。
