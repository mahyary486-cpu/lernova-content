# Linear relations and slope

A **linear relation** has a graph that is a straight line.

**Slope** measures steepness: slope = rise / run = (y₂ − y₁) / (x₂ − x₁). Through (1, 2) and (3, 8), the slope is 6 / 2 = 3. Through (0, 0) and (2, 4), the slope is 2.

**Parallel and perpendicular lines.** Parallel lines have equal slopes. Perpendicular lines have slopes that are negative reciprocals: if one slope is 2/3, the other is −3/2.

The **y-intercept** is where the line crosses the y-axis.
