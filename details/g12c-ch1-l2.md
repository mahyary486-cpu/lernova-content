# Strength of Acids and Bases: Ka, Kb and Kw

Strength is about how far an acid ionizes, not how concentrated it is.

## Key ideas
- **Strong acids**: HCl, HBr, HI, HNO3, H2SO4, HClO4.
- **Ka = [H3O+][A-] / [HA]**; larger Ka = stronger acid.
- **Kw = [H3O+][OH-] = 1.0 x 10^-14**; **pH + pOH = 14**.
- **Ka x Kb = Kw** for a conjugate pair.
- **pKa = -log Ka**; smaller pKa = stronger.
- Weak acids ionize **partly**.

## Worked examples
**Example 1: Kb from Ka.** Acetic acid has Ka = 1.8 x 10^-5. Find Kb of acetate.
1. Kb = Kw / Ka = 1.0 x 10^-14 / 1.8 x 10^-5.
2. Kb = 5.6 x 10^-10.

**Example 2: pKa.** Find pKa for Ka = 1.8 x 10^-5.
1. pKa = -log(1.8 x 10^-5).
2. pKa = 4.74.

**Example 3: Compare.** Which is stronger: HF (Ka = 7.2 x 10^-4) or HCN (Ka = 6.2 x 10^-10)?
1. A larger Ka means a stronger acid.
2. HF is stronger.

## Common mistakes
- Confusing strong with concentrated.
- Using Ka for a base.
- Forgetting that Kw changes with temperature.
