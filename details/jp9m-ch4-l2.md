# 変化の割合と変域

## 変化の割合

変化の割合 = (y の増加量) ÷ (x の増加量)

y = ax² で x が p から q まで増加するとき

変化の割合 = (aq² − ap²) ÷ (q − p) = **a(p + q)**

**例：** y = 2x² で x が 1 から 3 まで増加するとき 2 × (1 + 3) = 8

1次関数と違って、変化の割合は一定ではありません。

## 変域

x の変域に対する y の変域を求めるときは、グラフをかいて考えます。

**例：** y = x² で −2 ≦ x ≦ 3 のとき

x = 0 で最小値 0、x = 3 で最大値 9。よって 0 ≦ y ≦ 9。

**注意：** 変域に 0 がふくまれるときは、y の最小値（または最大値）は端の値ではなく、x = 0 での 0 です。
