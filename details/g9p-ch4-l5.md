# Simple Machines and Efficiency

Using a ramp to load a heavy box takes less effort than lifting it, but you must push it a longer way. The work stays about the same.

## Key ideas
- A **machine** changes the size or direction of a force; it does not create energy.
- **Simple machines**: lever, pulley, wheel and axle, inclined plane, wedge, screw.
- **Mechanical advantage** = output force (load) / input force (effort).
- **Work out is never greater than work in.**
- **Efficiency** = (useful work out / work in) x 100%, always below 100% for real machines.
- Less force means a greater distance: an inclined plane trades force for distance.

## Worked examples
**Example 1: Mechanical advantage.** A lever lifts a 100 N load with a 20 N effort.
1. MA = load / effort = 100 / 20.
2. MA = 5.

**Example 2: Efficiency.** A machine takes 400 J of input work and gives 300 J of output work.
1. Efficiency = 300 / 400 x 100%.
2. Efficiency = 75%.

**Example 3: A ramp.** A ramp is used to raise a load instead of lifting it straight up.
1. The ramp is longer than the height.
2. So the force needed is smaller but the distance is greater; the work is about the same.

## Common mistakes
- Thinking a machine can give more work out than work in.
- Giving an efficiency above 100%.
- Forgetting that less force always needs more distance.
