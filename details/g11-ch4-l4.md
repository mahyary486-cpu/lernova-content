# Rational Expressions

## What is a rational expression?
A **rational expression** is a fraction whose top and bottom are polynomials. It is **undefined** where the denominator is 0, so those x-values are excluded.
(x + 1) / (x - 4) is undefined at **x = 4**.

## Simplifying
Factor the top and the bottom, then cancel **common factors** (not common terms).
- (x^2 - 9) / (x - 3) = (x - 3)(x + 3) / (x - 3) = **x + 3** (with x not 3)
- 6x^3 / (3x) = **2x^2**
- (x^2 - 9) / (x^2 + x - 6) = (x - 3)(x + 3) / ((x + 3)(x - 2)) = **(x - 3) / (x - 2)**. The excluded values from the **original** are **x = -3 and x = 2**.

## Multiplying
Factor everything, cancel, then multiply what is left.
(x / (x + 1)) * ((x^2 - 1) / x^2) = x(x - 1)(x + 1) / ((x + 1) x^2) = **(x - 1) / x**.

## Dividing
Multiply by the **reciprocal** of the second fraction.
((x^2 - 4) / (x + 3)) divided by ((x - 2) / (x^2 - 9)) = ((x - 2)(x + 2) / (x + 3)) * ((x - 3)(x + 3) / (x - 2)) = **(x + 2)(x - 3)**.

## Adding and subtracting
Find the **least common denominator (LCD)**, rewrite each fraction, then combine the tops.
- 1/x + 2/(x + 1): LCD is x(x + 1). The top is (x + 1) + 2x = 3x + 1. Answer: **(3x + 1) / (x(x + 1))**.
- 3/(x - 2) - 1/(x + 2): LCD is (x - 2)(x + 2). The top is 3(x + 2) - (x - 2) = 3x + 6 - x + 2 = 2x + 8. Answer: **(2x + 8) / ((x - 2)(x + 2))**.

## Common mistakes
- Cancelling terms instead of factors, such as cancelling the x in (x + 3)/x.
- Forgetting to distribute the minus sign when subtracting a fraction.
- Forgetting the excluded values.
- Adding the denominators together.
