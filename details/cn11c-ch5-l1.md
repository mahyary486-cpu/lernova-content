# 原子结构

## 能层与能级

- 电子层叫**能层**：K、L、M、N…（n = 1、2、3、4…）；
- 每个能层的**能级**数等于能层序数：第三能层有 3s、3p、3d 三个能级；
- 每个能级最多容纳的电子数：s 为 2，p 为 6，d 为 10，f 为 14。

## 构造原理

电子填充顺序：1s → 2s → 2p → 3s → 3p → **4s** → **3d** → 4p → 5s…

## 基态原子的电子排布

- Cl：1s²2s²2p⁶3s²3p⁵；
- Fe：1s²2s²2p⁶3s²3p⁶3d⁶4s²（价层电子 3d⁶4s²）。

## 泡利原理与洪特规则

- **泡利原理**：一个原子轨道里最多容纳 2 个电子，且自旋相反；
- **洪特规则**：电子在能量相同的轨道上优先**单独占据**且自旋相同。

**特例**（全满、半满更稳定）：

- Cr：3d⁵4s¹（不是 3d⁴4s²）；
- Cu：3d¹⁰4s¹（不是 3d⁹4s²）。
