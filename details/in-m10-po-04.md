# Cubic polynomials and the division algorithm

For ax³ + bx² + cx + d with zeroes α, β, γ: α + β + γ = −b/a, αβ + βγ + γα = c/a and αβγ = −d/a. For x³ − 6x² + 11x − 6 the zeroes are 1, 2, 3.

Division algorithm: p(x) = g(x)q(x) + r(x), where r(x) = 0 or degree r < degree g. If r(x) = 0, then g(x) is a factor of p(x).
