# Titrations, Indicators and Solubility Equilibria

A titration curve shows how pH rises as base is added, and the steep part marks the equivalence point.

## Key ideas
- **M_a V_a = M_b V_b** at equivalence (1:1).
- Strong-strong: **pH 7**; weak acid-strong base: **pH > 7**.
- At **half-equivalence** (weak acid): **pH = pKa**.
- Choose an indicator that changes color near the **equivalence point**.
- **Ksp** of AgCl = [Ag+][Cl-] = **1.8 x 10^-10**.
- Precipitate if **Q > Ksp**; the **common-ion effect** lowers solubility.

## Worked examples
**Example 1: Titration.** 25.0 mL of HCl is neutralized by 20.0 mL of 0.100 M NaOH.
1. Moles NaOH = 0.100 x 0.0200 = 0.00200 mol = moles HCl.
2. M(HCl) = 0.00200 / 0.0250 = 0.0800 M.

**Example 2: Solubility.** Find the molar solubility of AgCl (Ksp = 1.8 x 10^-10).
1. Ksp = s^2, so s = sqrt(1.8 x 10^-10).
2. s = 1.3 x 10^-5 mol/L.

**Example 3: Precipitation.** Does a precipitate form if [Ag+] = 1.0 x 10^-4 and [Cl-] = 1.0 x 10^-4?
1. Q = 1.0 x 10^-8.
2. Q > Ksp (1.8 x 10^-10), so AgCl precipitates.

## Common mistakes
- Choosing a poorly matched indicator.
- Forgetting the mole ratio for diprotic acids.
- Confusing Q with Ksp.
