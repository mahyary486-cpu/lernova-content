# 乙醇和乙酸

## 乙醇

结构简式 CH₃CH₂OH，官能团是**羟基**（—OH）。

- 与钠反应：2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑；
- 燃烧：CH₃CH₂OH + 3O₂ =(点燃)= 2CO₂ + 3H₂O；
- **催化氧化**：2CH₃CH₂OH + O₂ =(Cu, △)= 2CH₃CHO + 2H₂O。

## 乙酸

结构简式 CH₃COOH，官能团是**羧基**（—COOH）。

- 具有酸性（酸性比碳酸强）：2CH₃COOH + CaCO₃ = (CH₃COO)₂Ca + H₂O + CO₂↑；
- **酯化反应**：

CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O（浓硫酸、加热）

生成的**乙酸乙酯**有香味，用**饱和 Na₂CO₃ 溶液**收集，可以除去乙酸和乙醇，并降低乙酸乙酯的溶解度。

酯化反应属于取代反应，是可逆反应。
