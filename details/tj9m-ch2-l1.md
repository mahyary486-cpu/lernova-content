# Прогрессияи арифметикӣ

## Таъриф

Пайдарпаии a₁, a₂, a₃, … ки дар он aₙ₊₁ = aₙ + d, прогрессияи арифметикӣ аст. d — **фарқият** (тафовут).

## Формулаҳо

- Ҳади n-ум: **aₙ = a₁ + (n − 1)d**
- Суми n ҳади аввал: **Sₙ = n(2a₁ + (n − 1)d) / 2** ё **Sₙ = n(a₁ + aₙ) / 2**
- Хосият: ҳар ҳад миёнаи арифметикии ҳамсояҳояш аст: aₙ = (aₙ₋₁ + aₙ₊₁) / 2.

**Мисол:** a₁ = 3, d = 4. Пас a₅ = 3 + 4 · 4 = 19.

**Мисол:** Суми 10 ҳади аввали 1, 3, 5, … = 10 · (2 + 18) / 2 = 100.
