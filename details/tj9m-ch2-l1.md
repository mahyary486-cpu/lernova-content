# Прогрессияи арифметикӣ

Пайдарпаии ададҳо, ки дар он ҳар ҳад аз ҳади қаблӣ бо илова кардани як адади доимӣ d ҳосил мешавад, прогрессияи арифметикӣ ном дорад. d фарқият аст ва мусбат (афзоянда) ё манфӣ (кам шаванда) буда метавонад. Масалан, 2, 5, 8, 11, … фарқияташ 3 аст.

Ҳади n-ум бо формулаи aₙ = a₁ + (n − 1)·d ёфта мешавад, зеро аз ҳади якум то ҳади n-ум ҳамагӣ (n − 1) қадами d мегузарем. Суми n ҳади аввал: Sₙ = n(a₁ + aₙ) / 2 ё Sₙ = n(2a₁ + (n − 1)d) / 2.

Хосияти муҳим: ҳар ҳад миёнаи арифметикии ду ҳадди ҳамсояи худ аст: aₙ = (aₙ₋₁ + aₙ₊₁) / 2. Масалан, барои ададҳои 6, 8, 10 ҳади миёна 8 = (6 + 10) / 2 аст.
