# 原电池与化学反应速率

## 原电池

把**化学能转化为电能**的装置。

构成条件：

1. 两个活泼性不同的电极；
2. 电解质溶液；
3. 形成闭合回路；
4. 能自发发生氧化还原反应。

**例：Zn - Cu - 稀 H₂SO₄ 原电池**

- **负极**（Zn，较活泼）：Zn − 2e⁻ = Zn²⁺，发生氧化反应；
- **正极**（Cu）：2H⁺ + 2e⁻ = H₂↑，发生还原反应；
- 电子由负极经导线流向正极，电流方向与之相反。

## 化学反应速率

**v = Δc / Δt**，单位 mol/(L·s) 或 mol/(L·min)。

**例：** 某反应物的浓度在 2 s 内由 1.0 mol/L 降到 0.6 mol/L，v = 0.4 / 2 = 0.2 mol/(L·s)。

## 影响因素

浓度（增大）、温度（升高）、催化剂、固体表面积（增大）、压强（有气体参加时增大压强）都能加快反应速率。
