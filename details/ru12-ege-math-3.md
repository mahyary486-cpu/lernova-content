# Функции, производная и интеграл

**Производные:** (xⁿ)′ = nxⁿ⁻¹, (sin x)′ = cos x, (cos x)′ = −sin x, (eˣ)′ = eˣ, (ln x)′ = 1 / x.

**Касательная.** Угловой коэффициент касательной равен значению производной в точке. Для y = x² в точке x = 3 он равен 6.

**Наибольшее и наименьшее значения.** Находят значения функции в критических точках (f′ = 0) и на концах отрезка. Для f(x) = x³ − 12x на [−3; 3]: f′ = 3x² − 12 = 0 при x = ±2. f(−3) = 9, f(−2) = 16, f(2) = −16, f(3) = −9. Наибольшее значение 16, наименьшее −16.

**Интеграл.** ∫ 2x dx = x² + C, а площадь вычисляют по формуле Ньютона — Лейбница.
