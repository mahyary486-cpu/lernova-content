# Иррациональные уравнения

В **иррациональном уравнении** неизвестное стоит под знаком корня, например √(x + 2) = x.

1. Уедините корень в одной части уравнения.
2. Возведите обе части в квадрат (для квадратного корня).
3. Решите полученное уравнение.
4. **Обязательно проверьте** каждый корень подстановкой в исходное уравнение, так как возведение в квадрат может добавить посторонние корни.

**Пример.** √(x + 2) = x даёт x + 2 = x², то есть x² − x − 2 = 0, откуда x = 2 или x = −1. Проверка: при x = 2 равенство √4 = 2 верно. При x = −1 получаем √1 = 1 ≠ −1, поэтому −1 — посторонний корень. Ответ: x = 2.
