# اعمال روی رادیکال‌ها

رادیکال‌ها عبارت‌هایی با علامت جذر هستند، مانند √۲ یا ۳√۵، و این درس نشان می‌دهد چگونه آن‌ها را ساده کنیم و با آن‌ها محاسبه کنیم.

## نکته‌های کلیدی

- قاعده‌ی ضرب: √a · √b = √(ab)، برای a ≥ ۰ و b ≥ ۰.
- قاعده‌ی تقسیم: √a / √b = √(a/b)، برای a ≥ ۰ و b > ۰.
- √(a^۲) = a وقتی a ≥ ۰. برای نمونه √۳۶ = ۶.
- برای ساده‌کردن رادیکال، بزرگ‌ترین مربع کاملی را که زیر رادیکال بر عدد بخش‌پذیر است پیدا می‌کنیم و جذر آن را بیرون می‌آوریم: √۷۲ = √(۳۶ · ۲) = ۶√۲.
- برای جمع یا تفریق رادیکال‌ها، عدد زیر رادیکال باید یکسان باشد. √۵ را مانند یک متغیر در نظر بگیرید: ۳√۵ + ۲√۵ = ۵√۵. گاهی باید اول رادیکال‌ها را ساده کرد.
- برای ضرب رادیکال‌ها، عددهای بیرون را جدا و عددهای داخل را جدا ضرب می‌کنیم: (۲√۳)(۵√۶) = ۱۰√۱۸ = ۱۰ · ۳√۲ = ۳۰√۲.
- گویاسازی مخرج یعنی حذف رادیکال از مخرج کسر. برای ۶/√۳، صورت و مخرج را در √۳ ضرب می‌کنیم.
- برای مخرجی مانند a - √b، از مزدوج a + √b و اتحاد (a - b)(a + b) = a^۲ - b^۲ استفاده می‌کنیم.

## مثال‌های حل‌شده

مثال ۱. √۷۲ را ساده کنید.
گام ۱: بزرگ‌ترین مربع کامل را که عامل ۷۲ است پیدا می‌کنیم. ۷۲ = ۳۶ · ۲ و ۳۶ مربع کامل است.
گام ۲: √۷۲ = √۳۶ · √۲.
گام ۳: √۳۶ = ۶ پس √۷۲ = ۶√۲.
بررسی: ۶√۲ تقریباً ۶ · ۱٫۴۱۴ = ۸٫۴۹ و √۷۲ هم تقریباً ۸٫۴۹ است.

مثال ۲. حاصل √۱۲ + √۲۷ را بیابید.
گام ۱: هر رادیکال را ساده می‌کنیم. √۱۲ = √(۴ · ۳) = ۲√۳.
گام ۲: √۲۷ = √(۹ · ۳) = ۳√۳.
گام ۳: حالا هر دو جمله √۳ دارند، پس ضریب‌ها را جمع می‌کنیم: ۲√۳ + ۳√۳ = ۵√۳.
بررسی: √۱۲ + √۲۷ تقریباً ۳٫۴۶۴ + ۵٫۱۹۶ = ۸٫۶۶۰ و ۵√۳ هم تقریباً ۸٫۶۶۰ است.

مثال ۳. مخرج ۱/(√۳ - ۱) را گویا کنید.
گام ۱: مزدوج √۳ - ۱ برابر √۳ + ۱ است. صورت و مخرج را در آن ضرب می‌کنیم.
گام ۲: صورت: ۱ · (√۳ + ۱) = √۳ + ۱.
گام ۳: مخرج: (√۳ - ۱)(√۳ + ۱) = (√۳)^۲ - ۱^۲ = ۳ - ۱ = ۲.
گام ۴: نتیجه (√۳ + ۱)/۲ است.
بررسی: ۱/(۱٫۷۳۲ - ۱) تقریباً ۱٫۳۶۶ و (۱٫۷۳۲ + ۱)/۲ هم تقریباً ۱٫۳۶۶ است.

## اشتباه‌های رایج

- نوشتن √(a + b) = √a + √b. این نادرست است. برای نمونه √(۹ + ۱۶) = ۵ ولی √۹ + √۱۶ = ۷.
- جمع رادیکال‌هایی که عدد زیر رادیکالشان فرق دارد، مانند √۲ + √۳ = √۵. این اشتباه است.
- توقف پیش از ساده‌شدن کامل رادیکال. برای نمونه √۷۲ ساده نشده است ولی ۶√۲ ساده شده است.
- فراموش‌کردن ضرب صورت و مخرج هر دو هنگام گویاسازی.

## به یاد داشته باشید

- از √a · √b = √(ab) و √a / √b = √(a/b) استفاده کنید.
- فقط رادیکال‌هایی را می‌توان جمع یا تفریق کرد که عدد زیر رادیکالشان یکسان باشد.
- مخرج را با ضرب در کسر مناسبی که برابر ۱ است گویا کنید.
