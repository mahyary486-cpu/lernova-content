# Operations with radicals

Radicals are expressions with square roots, such as √2 or 3√5, and this lesson shows how to simplify them and calculate with them.

## Key ideas

- Product rule: √a · √b = √(ab), for a ≥ 0 and b ≥ 0.
- Quotient rule: √a / √b = √(a/b), for a ≥ 0 and b > 0.
- √(a^2) = a when a ≥ 0. For example, √36 = 6.
- To simplify a radical, find the largest perfect square that divides the number under the root, and take its root outside: √72 = √(36 · 2) = 6√2.
- To add or subtract radicals, they must have the same number under the root. Treat √5 like a variable: 3√5 + 2√5 = 5√5. Sometimes the radicals must be simplified first.
- To multiply radicals, multiply the outside numbers and the inside numbers separately: (2√3)(5√6) = 10√18 = 10 · 3√2 = 30√2.
- Rationalizing the denominator means removing the radical from the bottom of a fraction. For 6/√3, multiply the top and bottom by √3.
- For a denominator like a - √b, use the conjugate a + √b and the identity (a - b)(a + b) = a^2 - b^2.

## Worked examples

Example 1. Simplify √72.
Step 1: Find the largest perfect square factor of 72. We have 72 = 36 · 2, and 36 is a perfect square.
Step 2: √72 = √36 · √2.
Step 3: √36 = 6, so √72 = 6√2.
Check: 6√2 is about 6 · 1.414 = 8.49, and √72 is about 8.49.

Example 2. Calculate √12 + √27.
Step 1: Simplify each radical. √12 = √(4 · 3) = 2√3.
Step 2: √27 = √(9 · 3) = 3√3.
Step 3: Now both terms have √3, so add the numbers in front: 2√3 + 3√3 = 5√3.
Check: √12 + √27 is about 3.464 + 5.196 = 8.660, and 5√3 is about 8.660.

Example 3. Rationalize the denominator of 1/(√3 - 1).
Step 1: The conjugate of √3 - 1 is √3 + 1. Multiply the top and bottom by it.
Step 2: Top: 1 · (√3 + 1) = √3 + 1.
Step 3: Bottom: (√3 - 1)(√3 + 1) = (√3)^2 - 1^2 = 3 - 1 = 2.
Step 4: The result is (√3 + 1)/2.
Check: 1/(1.732 - 1) is about 1.366, and (1.732 + 1)/2 is about 1.366.

## Common mistakes

- Writing √(a + b) = √a + √b. This is false. For example, √(9 + 16) = 5, but √9 + √16 = 7.
- Adding radicals with different numbers under the root, such as √2 + √3 = √5. This is wrong.
- Stopping before the radical is fully simplified. For example, √72 is not simplified, but 6√2 is.
- Forgetting to multiply both the top and the bottom when rationalizing.

## Remember

- Use √a · √b = √(ab) and √a / √b = √(a/b).
- Only radicals with the same number under the root can be added or subtracted.
- Rationalize a denominator by multiplying by a suitable fraction equal to 1.
