# 气体的制备、净化与收集

## 发生装置

- **固体 + 固体，加热**：O₂（KMnO₄）、NH₃；
- **固体 + 液体，不加热**：H₂、CO₂、O₂（H₂O₂）；
- **固体 + 液体，加热**：Cl₂。

## 净化与干燥

- 除去 Cl₂ 中的 HCl：**饱和食盐水**；
- 除去 CO₂ 中的 HCl：**饱和 NaHCO₃ 溶液**；
- 干燥：浓硫酸（不能干燥 NH₃）、**碱石灰**（可干燥 NH₃，不能干燥酸性气体）、无水 CaCl₂（不能干燥 NH₃）。

## 收集

- **排水法**：难溶于水的气体（O₂、H₂、NO）；
- **向上排空气法**：密度比空气大（Cl₂、CO₂、O₂）；
- **向下排空气法**：密度比空气小（H₂、NH₃）；
- NO 遇空气中的 O₂ 反应，**只能用排水法**。

## 尾气处理

- Cl₂：NaOH 溶液；
- NH₃、HCl：用倒扣漏斗等**防倒吸**装置吸收；
- CO、NO：点燃或转化。

## 实验顺序

连接仪器 → **检查气密性** → 装药品 → 发生 → 净化 → 收集 → 尾气处理。
