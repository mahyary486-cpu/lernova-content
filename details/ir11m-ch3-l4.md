# تابع یک‌به‌یک و وارون تابع

## این درس درباره‌ی چیست؟

تابعی وارون دارد که هر خروجی‌اش فقط از یک ورودی ساخته شود.

## یک‌به‌یک

تابع f یک‌به‌یک است اگر f(a) = f(b) فقط وقتی a = b. آزمون خط افقی: هر خط افقی نمودار را حداکثر یک بار قطع کند.

مثال: 2x + 1 یک‌به‌یک است؛ x² روی همه‌ی اعداد حقیقی یک‌به‌یک نیست ولی روی x ≥ 0 هست.

## یافتن وارون

1. y = f(x) را بنویسید.
2. x را برحسب y بیابید.
3. جای x و y را عوض کنید.

**مثال:** f(x) = 2x − 4 ⇒ f⁻¹(x) = (x + 4)/2.

## ویژگی

نمودار f⁻¹ قرینه‌ی نمودار f نسبت به خط y = x است و f(f⁻¹(x)) = x.
