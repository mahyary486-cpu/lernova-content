# Primitives : définition et primitives usuelles

## Définition
Soit f définie sur un intervalle I. Une primitive de f sur I est une fonction F dérivable sur I telle que F’(x) = f(x) pour tout x de I.
Exemple : F(x) = x² + 5 est une primitive de f(x) = 2x.

## Ensemble des primitives
Si F est une primitive de f sur I, alors toutes les primitives de f sont les fonctions F + C, avec C constante réelle. Deux primitives diffèrent d’une constante.
Pour imposer une condition, on détermine C : la primitive de f(x) = 1/x sur ]0 ; +∞[ qui prend la valeur 2 en 1 est ln x + 2.

## Primitives usuelles
- f(x) = k (constante) : F(x) = kx.
- f(x) = x^n (n ≠ −1) : F(x) = x^(n+1)/(n + 1). Par exemple x² → x³/3.
- f(x) = 1/x sur ]0 ; +∞[ : F(x) = ln x.
- f(x) = 1/x² : F(x) = −1/x.
- f(x) = 1/√x : F(x) = 2√x.
- f(x) = e^x : F(x) = e^x.
- f(x) = e^(−x) : F(x) = −e^(−x).

## Exemples
- 3x² + 2x a pour primitive x³ + x².
- x³ − x a pour primitive x⁴/4 − x²/2.
- e^(2x) a pour primitive e^(2x)/2.

## Existence
Toute fonction continue sur un intervalle admet des primitives.

## Erreur fréquente
Oublier la constante C quand on cherche toutes les primitives.
