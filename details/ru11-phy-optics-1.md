# Геометрическая оптика

**Закон отражения.** Угол падения равен углу отражения.

**Закон преломления.** n₁ · sin α = n₂ · sin β. **Абсолютный показатель преломления** n = c / v. Для стекла n = 1,5, поэтому скорость света в нём v = 3 · 10⁸ / 1,5 = 2 · 10⁸ м/с. При падении из воздуха на стекло под углом 30° получаем sin β = 0,5 / 1,5 = 1/3.

**Полное внутреннее отражение** возникает при переходе в среду с меньшим показателем преломления, когда угол падения больше предельного: sin α₀ = 1 / n. Для стекла sin α₀ = 2/3.

Скорость света в вакууме c = 3 · 10⁸ м/с.
