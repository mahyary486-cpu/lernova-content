# Der Kondensator

## Kapazität
Ein Kondensator speichert Ladung. Die Kapazität C = Q / U wird in Farad (F) gemessen. Beim Plattenkondensator gilt C = ε0 · εr · A / d.

## Energie
Die gespeicherte Energie beträgt W = ½ · C · U².

## Schaltung
Parallel addieren sich die Kapazitäten: C = C1 + C2. In Reihe gilt 1/C = 1/C1 + 1/C2.

## Dielektrikum
Ein Isolator zwischen den Platten erhöht die Kapazität. Halbiert man den Plattenabstand, verdoppelt sich C.
