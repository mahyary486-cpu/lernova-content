# Reglas de derivación

## Básicas
(xⁿ)' = n·xⁿ⁻¹; (c)' = 0; (f ± g)' = f' ± g'.

## Producto y cociente
(f·g)' = f'g + fg'.
(f/g)' = (f'g − fg')/g².

## Cadena
(f(g(x)))' = f'(g(x))·g'(x).

## Usuales
(sen x)' = cos x; (cos x)' = −sen x; (eˣ)' = eˣ; (ln x)' = 1/x.

## Error frecuente
Derivar un producto como el producto de las derivadas.
