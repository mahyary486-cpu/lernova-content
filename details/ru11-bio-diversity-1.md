# Принципы систематики

**Систематика** — наука о классификации организмов. Основы заложил **К. Линней**, введя **бинарную номенклатуру**: название вида состоит из двух слов (рода и вида), например Homo sapiens.

**Иерархия таксонов** (от меньшего к большему): вид → род → семейство → отряд (порядок) → класс → тип (у растений — отдел) → царство → домен.

**Основная единица** классификации — вид.

**Пример: человек.** Тип Хордовые, класс Млекопитающие, отряд Приматы, семейство Гоминиды, род Homo, вид Homo sapiens.
