# Forme canonique et sommet d’une parabole

## Forme canonique
Tout trinôme f(x) = ax² + bx + c (a ≠ 0) peut s’écrire f(x) = a(x − α)² + β avec
α = −b/(2a) et β = f(α).
Le point S(α ; β) est le sommet de la parabole, et la droite x = α est son axe de symétrie.

## Exemples
- x² − 4x + 1 = (x − 2)² − 4 + 1 = (x − 2)² − 3.
- x² − 6x + 5 = (x − 3)² − 4. Le sommet est (3 ; −4).
- x² + 2x + 3 = (x + 1)² + 2. Le minimum est 2.

## Variations
- Si a > 0 : f décroît sur ]−∞ ; α] puis croît sur [α ; +∞[, et admet un minimum β en x = α.
- Si a < 0 : f croît puis décroît, et admet un maximum β en x = α.

## Méthode
1. On factorise a dans les termes en x² et en x.
2. On complète le carré.
3. On regroupe les constantes.
Exemple : 2x² + 8x + 5 = 2(x² + 4x) + 5 = 2[(x + 2)² − 4] + 5 = 2(x + 2)² − 3.

## Orientation de la parabole
Si a > 0 elle est tournée vers le haut, si a < 0 vers le bas.

## Erreur fréquente
Dans (x + 1)² + 2, le sommet a pour abscisse α = −1, et non +1.
