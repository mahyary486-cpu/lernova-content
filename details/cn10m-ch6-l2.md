# 向量的坐标运算与数量积

## 坐标运算

设 a = (x₁, y₁)，b = (x₂, y₂)：

- a ± b = (x₁ ± x₂, y₁ ± y₂)，λa = (λx₁, λy₁)；
- 模：|a| = √(x₁² + y₁²)；
- 平行：a ∥ b ⇔ **x₁y₂ − x₂y₁ = 0**。

## 数量积

a · b = |a||b|cos θ = **x₁x₂ + y₁y₂**（θ 为两向量夹角）。

- a ⊥ b ⇔ **a · b = 0**；
- 夹角：cos θ = a · b / (|a||b|)。

## 例题

**例 1：** a = (1, 2)，b = (3, −1)：a · b = 3 − 2 = 1，|a| = √5。

**例 2：** a = (2, 3)，b = (m, −4)，若 a ⊥ b，则 2m − 12 = 0，m = 6。

**例 3：** a = (1, 2)，b = (2, k)，若 a ∥ b，则 k − 4 = 0，k = 4。
