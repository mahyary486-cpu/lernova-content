# 热机

## 热机

把燃料燃烧产生的**内能转化为机械能**的机器叫**热机**。常见的有蒸汽机、内燃机、汽轮机、喷气发动机。

## 汽油机的四个冲程

内燃机（汽油机、柴油机）的一个工作循环有四个冲程：

1. **吸气冲程**：吸入汽油和空气的混合物；
2. **压缩冲程**：活塞压缩气体，**机械能转化为内能**；
3. **做功冲程**：火花塞点火，高温高压燃气推动活塞，**内能转化为机械能**；
4. **排气冲程**：排出废气。

## 要点

- 一个工作循环：4 个冲程，活塞往复 **2** 次，曲轴（飞轮）转 **2** 圈，对外做功 **1** 次；
- 只有做功冲程对外做功，其他三个冲程靠飞轮的惯性完成；
- 汽油机用火花塞点火，柴油机是压燃式。
