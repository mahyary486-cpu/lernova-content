# 化学平衡

## 可逆反应与平衡状态

在相同条件下，既能向正反应方向进行，又能向逆反应方向进行的反应叫**可逆反应**。

当**正反应速率等于逆反应速率**，反应混合物中各组分的浓度**保持不变**时，反应达到化学平衡。

特征：逆、等、动（动态平衡）、定、变。

## 平衡状态的判断

- v正 = v逆；
- 各组分的浓度、质量分数保持不变；
- 对于气体分子数改变的反应，总压强、平均摩尔质量不变。

## 化学平衡常数

对于 aA + bB ⇌ cC + dD，**K = c^c(C) · c^d(D) / [c^a(A) · c^b(B)]**。

- K 只与**温度**有关；
- 固体和纯液体的浓度不写；
- K 越大，反应进行的程度越大。

**例：** N₂ + 3H₂ ⇌ 2NH₃：K = c²(NH₃) / [c(N₂) · c³(H₂)]。

某温度下平衡时 c(N₂) = 1，c(H₂) = 1，c(NH₃) = 2（mol/L）：K = 4 / 1 = 4。

## 浓度商 Q

Q < K：反应向正方向进行；Q = K：平衡；Q > K：反应向逆方向进行。
