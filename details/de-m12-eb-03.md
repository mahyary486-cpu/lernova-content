# Lage von Ebenen und Schnittgeraden

## Lagen zweier Ebenen

- **identisch**
- **echt parallel**
- **schneidend** (in einer Geraden)

Parallel sind Ebenen, wenn die **Normalenvektoren Vielfache** voneinander sind. Senkrecht sind sie, wenn die Normalenvektoren **senkrecht** aufeinander stehen.

## Beispiele

- x + y + z = 1 und 2x + 2y + 2z = 5: echt parallel
- x + y + z = 1 und 2x + 2y + 2z = 2: identisch
- x = 0 und y = 0: senkrecht, Schnittgerade ist die z-Achse

## Schnittgerade

Man löst das Gleichungssystem aus beiden Koordinatengleichungen. Eine Variable wird als Parameter t gewählt.

**Beispiel:** x + y + z = 3 und z = 0.
Dann gilt x + y = 3, also x = t und y = 3 − t.
Schnittgerade: x = (0; 3; 0) + t · (1; −1; 0).

## Ebene aus zwei Geraden

Schneiden sich zwei Geraden, bilden der Schnittpunkt (Stützvektor) und beide Richtungsvektoren (Spannvektoren) eine Ebene.

## Lotgerade

Steht eine Gerade senkrecht auf einer Ebene, ist ihr Richtungsvektor der Normalenvektor. Für P(1; 2; 3) und x − y + 2z = 0 gilt x = (1; 2; 3) + t · (1; −1; 2).
