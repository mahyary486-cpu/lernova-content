# 2次方程式の利用

## 解き方の手順

1. 求めるものを x とおく。
2. 数量の関係から方程式をつくる。
3. 方程式を解く。
4. 解が問題に合うか（正の数、整数など）を確かめて答える。

## 例1：連続する整数

連続する2つの正の整数の積が 56 のとき、小さい方を x とすると x(x + 1) = 56。

x² + x − 56 = 0、(x + 8)(x − 7) = 0 より x = 7、−8。正の整数なので x = 7 で、2数は 7 と 8。

## 例2：長方形の面積

縦が横より 3 cm 長く、面積が 40 cm² の長方形で、横を x cm とすると x(x + 3) = 40。

x² + 3x − 40 = 0、(x + 8)(x − 5) = 0 より x = 5、−8。長さは正なので横は 5 cm。

## 注意

解がすべて問題に合うとは限りません。負の数や、図形の範囲を超える解は、不適として除きます。
