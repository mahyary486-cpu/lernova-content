# Растения

**Основные группы:** водоросли, мхи, папоротники, голосеменные, покрытосеменные.

**Чередование поколений.** У мхов преобладает гаметофит, у папоротников — **спорофит** (растение с листьями — вайями).

**Семя** — признак голосеменных и покрытосеменных. У покрытосеменных есть **цветок** и **плод**.

**Двойное оплодотворение** характерно только для покрытосеменных: один спермий сливается с яйцеклеткой (образуется зародыш), второй — с центральной клеткой зародышевого мешка (образуется эндосперм — запас питательных веществ семени).

**Классы покрытосеменных:** однодольные (пшеница, лук, с параллельным жилкованием) и двудольные (горох, подсолнечник, картофель).
