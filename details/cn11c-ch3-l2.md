# 水的电离与溶液的酸碱性

## 水的离子积

H₂O ⇌ H⁺ + OH⁻

**Kw = c(H⁺) · c(OH⁻) = 1×10⁻¹⁴**（25℃）。温度升高，Kw 增大。

## pH

**pH = −lg c(H⁺)**

- pH < 7：酸性；pH = 7：中性；pH > 7：碱性（25℃）。

**例 1：** 0.01 mol/L HCl：c(H⁺) = 10⁻²，pH = 2。

**例 2：** 0.001 mol/L NaOH：c(OH⁻) = 10⁻³，c(H⁺) = 10⁻¹¹，pH = 11。

**稀释**：pH = 2 的强酸稀释 10 倍，pH = 3；酸稀释无论多少倍，pH 都不会超过 7。

## 酸碱中和滴定

用已知浓度的酸（碱）滴定未知浓度的碱（酸）：

**c(待) = c(标) · V(标) / V(待)**

**例：** 用 0.1000 mol/L HCl 滴定 20.00 mL NaOH 溶液，消耗 15.00 mL：

c(NaOH) = 0.1000 × 15.00 / 20.00 = 0.075 mol/L。

指示剂：酚酞（变色范围 8.2 ~ 10）、甲基橙（3.1 ~ 4.4）。
