# 离子反应

## 电解质

- **电解质**：在水溶液里或熔融状态下能够导电的化合物，如酸、碱、盐、水、活泼金属氧化物；
- **非电解质**：在水溶液里和熔融状态下都不能导电的化合物，如蔗糖、酒精、CO₂、NH₃；
- 单质和混合物既不是电解质，也不是非电解质。

## 电离方程式

- NaCl = Na⁺ + Cl⁻
- H₂SO₄ = 2H⁺ + SO₄²⁻
- Ba(OH)₂ = Ba²⁺ + 2OH⁻

## 离子方程式的书写：写、拆、删、查

1. 写出化学方程式；
2. 把易溶于水且易电离的物质（强酸、强碱、可溶性盐）**拆**成离子；
3. 删去两边相同的离子；
4. 检查原子个数和电荷是否守恒。

**例：** HCl + NaOH = NaCl + H₂O 的离子方程式为 H⁺ + OH⁻ = H₂O。

**例：** BaCl₂ + Na₂SO₄ = BaSO₄↓ + 2NaCl 的离子方程式为 Ba²⁺ + SO₄²⁻ = BaSO₄↓。

## 离子共存

离子之间如果能生成**沉淀、气体或水（弱电解质）**，就不能大量共存。
