# Potências e raízes

## Propriedades das potências

Para a ≠ 0:

- aᵐ · aⁿ = aᵐ⁺ⁿ
- aᵐ ÷ aⁿ = aᵐ⁻ⁿ
- (aᵐ)ⁿ = aᵐ·ⁿ
- a⁰ = 1
- a⁻ⁿ = 1/aⁿ

## Expoente fracionário

a^(1/n) = ⁿ√a e a^(m/n) = (ⁿ√a)ᵐ. Por exemplo, 8^(2/3) = (∛8)² = 2² = 4.

## Simplificação de raízes

√50 = √(25·2) = 5√2. Para somar raízes, elas precisam ser semelhantes: √12 + √27 = 2√3 + 3√3 = 5√3.

## Notação científica

Escrevemos o número como k · 10ⁿ, com 1 ≤ k < 10. Exemplos: 45 000 = 4,5 · 10⁴ e 0,000032 = 3,2 · 10⁻⁵.

## Exemplo

Calcule 2⁻³: 2⁻³ = 1/2³ = 1/8.
