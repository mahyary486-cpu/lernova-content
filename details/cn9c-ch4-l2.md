# 化学方程式的书写

## 化学方程式

用化学式来表示化学反应的式子叫化学方程式。

## 表示的意义

以 2H₂ + O₂ =(点燃)= 2H₂O 为例：

- 氢气和氧气在点燃的条件下反应生成水；
- 质量比：4 : 32 : 36 = 1 : 8 : 9；
- 粒子个数比：2 : 1 : 2。

## 书写步骤：写、配、注、等

1. **写**：左边写反应物，右边写生成物，中间画短线；
2. **配**：使两边各种原子的个数相等；
3. **注**：注明反应条件，生成物是气体标"↑"，沉淀标"↓"；
4. **等**：把短线改成等号。

## 常见方程式

- C + O₂ =(点燃)= CO₂
- 4P + 5O₂ =(点燃)= 2P₂O₅
- 2H₂O₂ =(MnO₂)= 2H₂O + O₂↑

**注意**：反应物中有气体时，生成物中的气体不标"↑"；溶液中的反应，反应物中有固体时，生成物中的固体不标"↓"。
