# Le Chatelier's Principle and Equilibrium Calculations

Industrial chemists want the maximum yield of a product at a reasonable cost, and they cannot get it by guessing. Le Chatelier's principle tells how a system at equilibrium responds when something disturbs it, and so it shows how to change the conditions in favor of the product. The second half of the lesson turns to calculations, where an ICE table is used to find the concentrations at equilibrium from the starting amounts and the value of K.

## Key ideas

Le Chatelier's principle states that when a system at equilibrium is disturbed, it shifts in the direction that reduces the disturbance. Adding a reactant, or removing a product, moves the equilibrium to the right, because the system uses up the added substance, or replaces the removed one. Removing a reactant, or adding a product, moves it to the left. The value of K does not change in these cases, because only the concentrations are changed, and the system returns to the same value of K with new concentrations.

A change in pressure, made by changing the volume, affects only reactions that involve gases whose number of moles differs on the two sides. Higher pressure shifts the equilibrium toward the side with fewer moles of gas, because this reduces the pressure. Only the gas moles are counted, and not solids or liquids. If the numbers of gas moles are equal, pressure has no effect.

A change in temperature is different, because it changes K itself. A higher temperature favors the endothermic direction, since the system absorbs the added heat. For an exothermic reaction, therefore, heating moves the equilibrium to the left and lowers K. A catalyst does not shift the equilibrium at all, since it speeds up the forward and reverse reactions equally.

The Haber process, N2 + 3 H2 <-> 2 NH3, with delta H negative, shows all of these effects. High pressure favors the side with fewer gas moles, so it raises the yield of ammonia. A low temperature would favor the exothermic direction, but it would make the reaction too slow, so a moderate temperature is used with an iron catalyst, as a compromise.

For calculations, an ICE table is used, with the rows Initial, Change and Equilibrium. The change for each substance is written as a multiple of an unknown x, with the coefficients as multiples, and signs showing what is used up and what is formed. The equilibrium values are then put into the expression for K, and the equation is solved for x.

## Worked examples

**Example 1: Changing a concentration.** More N2 is added to N2 + 3 H2 <-> 2 NH3 at equilibrium.
1. The system reduces the disturbance by using up some of the added N2.
2. The equilibrium shifts to the right, forming more NH3.

**Example 2: Changing the pressure.** The pressure is raised for N2 + 3 H2 <-> 2 NH3.
1. The reactants have 1 + 3 = 4 mol of gas, and the products have 2 mol.
2. The equilibrium shifts to the right, toward fewer moles of gas.

**Example 3: An ICE table.** For H2 + I2 <-> 2 HI, K = 4. The starting concentrations are [H2] = [I2] = 1.0 M and [HI] = 0. Find the equilibrium concentrations.
1. Let x mol/L of H2 react. Then [H2] = [I2] = 1.0 - x and [HI] = 2x.
2. K = (2x)^2 / (1 - x)^2 = 4, and taking the square root of both sides gives 2x / (1 - x) = 2.
3. Then 2x = 2 - 2x, so x = 0.5.
4. At equilibrium [H2] = [I2] = 0.5 M and [HI] = 1.0 M. Check: 1.0^2 / (0.5 x 0.5) = 4.

## Common mistakes

A very common error is to think that a catalyst moves the equilibrium, but it only makes the system reach equilibrium sooner. Another is to count solids or liquids when deciding the effect of pressure, because only the gas moles matter. Students also believe that K changes when a concentration is changed, but only a change of temperature changes K. Finally, when you build an ICE table, remember that the changes follow the coefficients, so a product with the coefficient 2 changes by 2x.
