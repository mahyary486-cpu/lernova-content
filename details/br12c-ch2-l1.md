# Equilíbrio químico

## Reação reversível

Ocorre nos **dois sentidos**. No **equilíbrio dinâmico** as velocidades direta e inversa são **iguais** e as concentrações ficam constantes.

## Constante de equilíbrio

Para N₂ + 3 H₂ ⇌ 2 NH₃:

**Kc = [NH₃]² / ([N₂] · [H₂]³)**

- Kc grande: predominam os produtos;
- N₂O₄ ⇌ 2 NO₂ com [N₂O₄] = 0,5 mol/L e [NO₂] = 1 mol/L: Kc = 1²/0,5 = 2;
- Se Kc = 4 e [A] = 0,5 mol/L (A ⇌ B): [B] = 2 mol/L.

## Princípio de Le Chatelier

O sistema se desloca para **minimizar** a perturbação:

- **Aumentar um reagente:** desloca para os produtos;
- **Aumentar a temperatura:** favorece o sentido endotérmico;
- **Aumentar a pressão:** desloca para o lado com menor número de mols gasosos (em N₂ + 3 H₂ ⇌ 2 NH₃, para o NH₃);
- **Catalisador:** não desloca o equilíbrio;
- **Gás inerte a volume constante:** não altera o equilíbrio.

A reação 2 NO₂ ⇌ N₂O₄ é exotérmica no sentido direto: aquecer desloca para NO₂.
