# 函数 y = A sin(ωx + φ) 的图象与性质

## 参数的意义

- 振幅 A；
- 最小正周期 T = 2π / ω；
- 初相 φ。

## 由图象求解析式

1. A = (最大值 − 最小值) / 2；
2. 由周期 T 求 ω = 2π / T；
3. 代入一个特殊点（最高点或已知点）求 φ，注意 φ 的范围。

**例：** A = 2，T = π，图象过点 (0, 1)，|φ| < π/2：

ω = 2π/π = 2，2 sin φ = 1，sin φ = 1/2，φ = π/6，所以 y = 2 sin(2x + π/6)。

## 图象变换

y = sin x → 左（右）平移 |φ| 个单位 → 横坐标变为原来的 1/ω → 纵坐标变为原来的 A 倍。

**例：** 把 y = sin 2x 向左平移 π/6 个单位，得 y = sin 2(x + π/6) = sin(2x + π/3)。

**注意**："左加右减"是对 **x** 本身而言。

## 单调区间

令 −π/2 + 2kπ ≤ 2x + π/6 ≤ π/2 + 2kπ，解得单调递增区间 [kπ − π/3, kπ + π/6]（k ∈ Z）。
