# 二项式定理

## 二项式定理

**(a + b)ⁿ = Cₙ⁰aⁿ + Cₙ¹aⁿ⁻¹b + … + Cₙᵏaⁿ⁻ᵏbᵏ + … + Cₙⁿbⁿ**

- 通项：**T_{k+1} = Cₙᵏ aⁿ⁻ᵏ bᵏ**（第 k + 1 项）；
- Cₙᵏ 叫二项式系数；
- 二项式系数的和为 **2ⁿ**；
- 求各项系数的和，通常令 x = 1。

## 例题

**例 1：** (x + 1)⁴ = x⁴ + 4x³ + 6x² + 4x + 1，x² 项的系数为 C₄² = 6。

**例 2：** (x + 2)⁵ 中 x³ 项的系数：

T_{k+1} = C₅ᵏ x⁵⁻ᵏ 2ᵏ，令 5 − k = 3，k = 2，系数为 C₅² × 2² = 10 × 4 = 40。

**例 3：** (1 + x)⁵ 的二项式系数之和为 2⁵ = 32。

## 注意

"二项式系数"与"项的系数"不同：项的系数还包括 a、b 中的常数。
