# Types of Chemical Reactions and Balancing Equations

Every reaction can be written as an equation, and every equation must be balanced.

## Key ideas
- **Law of conservation of mass**: atoms are neither created nor destroyed.
- Balance by changing **coefficients**, never **subscripts**.
- **Synthesis**: A + B -> AB; **decomposition**: AB -> A + B.
- **Single replacement**: A + BC -> AC + B; **double replacement**: AB + CD -> AD + CB.
- **Combustion**: fuel + O2 -> CO2 + H2O.
- State symbols: **(s)**, **(l)**, **(g)**, **(aq)**.

## Worked examples
**Example 1: Balancing.** Balance H2 + O2 -> H2O.
1. Oxygen needs 2 on the right: H2 + O2 -> 2 H2O.
2. Then hydrogen needs 2 on the left: 2 H2 + O2 -> 2 H2O.

**Example 2: Combustion.** Balance CH4 + O2 -> CO2 + H2O.
1. Carbon: 1 on each side. Hydrogen: 4 needs 2 H2O.
2. Oxygen: 2 + 2 = 4, so 2 O2: CH4 + 2 O2 -> CO2 + 2 H2O.

**Example 3: Reaction type.** Classify 2 KClO3 -> 2 KCl + 3 O2.
1. One reactant breaks into simpler substances.
2. This is a decomposition reaction.

## Common mistakes
- Changing a subscript to balance an equation.
- Forgetting to balance oxygen last in combustion.
- Leaving fractions without clearing them.
