# Photons and the Photoelectric Effect

A solar panel works because photons give their energy to electrons in a single interaction.

## Key ideas
- **E = h f = h c / lambda**; h = **6.63 x 10^-34 J s**.
- **KE_max = h f - phi**; phi = **h f0**.
- No emission below the **threshold frequency**.
- More **intensity** = more electrons, same maximum energy.
- **Stopping potential**: **e V_s = KE_max**.
- **1 eV = 1.6 x 10^-19 J**.

## Worked examples
**Example 1: Photon energy.** Light has a wavelength of 500 nm.
1. E = h c / lambda = 6.63 x 10^-34 x 3 x 10^8 / 5 x 10^-7.
2. E = 3.98 x 10^-19 J = 2.49 eV.

**Example 2: Maximum kinetic energy.** Photons of 4.0 eV hit a metal with a work function of 2.5 eV.
1. KE_max = E - phi = 4.0 - 2.5.
2. KE_max = 1.5 eV.

**Example 3: Stopping potential.** For the above KE_max = 1.5 eV.
1. e V_s = KE_max.
2. V_s = 1.5 V.

## Common mistakes
- Thinking brighter light can eject electrons below the threshold frequency.
- Mixing joules and electron-volts.
- Using the frequency in the wrong unit.
