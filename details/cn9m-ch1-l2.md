# 根的判别式与根与系数的关系

## 根的判别式

对于 ax² + bx + c = 0（a ≠ 0），记 **Δ = b² − 4ac**。

- Δ > 0：有两个不相等的实数根；
- Δ = 0：有两个相等的实数根；
- Δ < 0：没有实数根。

**例：** 方程 x² − 3x + m = 0 有两个不相等的实数根，则 Δ = 9 − 4m > 0，得 m < 9/4。

## 根与系数的关系（韦达定理）

若 x₁、x₂ 是 ax² + bx + c = 0 的两个根，则

**x₁ + x₂ = −b/a，x₁x₂ = c/a**

**例：** 2x² − 4x − 1 = 0 的两根满足 x₁ + x₂ = 2，x₁x₂ = −1/2。

## 常用变形

- x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂
- 例：上面的方程中 x₁² + x₂² = 4 + 1 = 5

使用韦达定理之前，要先确认方程有实数根（Δ ≥ 0）。
