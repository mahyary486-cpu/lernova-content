# Dérivées des fonctions usuelles et opérations

## Dérivées usuelles
- f(x) = k (constante) : f’(x) = 0.
- f(x) = x : f’(x) = 1.
- f(x) = x² : f’(x) = 2x ; f(x) = x³ : f’(x) = 3x².
- f(x) = x^n (n entier ≥ 1) : f’(x) = n x^(n−1).
- f(x) = 1/x (x ≠ 0) : f’(x) = −1/x².
- f(x) = √x (x > 0) : f’(x) = 1/(2√x).

## Opérations
Si u et v sont dérivables et k un réel :
- (u + v)’ = u’ + v’ ;
- (k u)’ = k u’.

## Exemples
- f(x) = x³ − 2x² + x donne f’(x) = 3x² − 4x + 1.
- f(x) = 5x + 2 donne f’(x) = 5.
- f(x) = 4x² donne f’(x) = 8x.
- f(x) = x² + 1/x donne f’(x) = 2x − 1/x².
- f(x) = 3/x donne f’(x) = −3/x².
- f(x) = 2√x donne f’(x) = 1/√x.
- f(x) = x⁴ − 2x² donne f’(x) = 4x³ − 4x.

## Valeur d’un nombre dérivé
Pour f(x) = x² − 3x + 1, f’(x) = 2x − 3 donc f’(2) = 1.

## Développer avant de dériver
(3x − 2)² = 9x² − 12x + 4 donne une dérivée 18x − 12.

## Erreur fréquente
La dérivée d’un produit n’est pas le produit des dérivées : on utilise une formule spécifique.
