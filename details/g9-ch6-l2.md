# Solving Quadratics by Factoring

A quadratic equation has the form ax^2 + bx + c = 0. Its solutions are also called roots or zeros, and they are the x-intercepts of the graph.

## Zero Product Property
If A * B = 0, then A = 0 or B = 0. This lets us turn one hard equation into two easy ones.

## Steps
1. Move every term to one side so the other side is 0.
2. Factor completely.
3. Set each factor equal to 0.
4. Solve each small equation.
5. Check in the original equation.

## Worked examples
**Example 1.** Solve x^2 + 5x + 6 = 0.
1. Factor: (x + 2)(x + 3) = 0.
2. x + 2 = 0 gives x = -2. x + 3 = 0 gives x = -3.
3. Check x = -2: 4 - 10 + 6 = 0. It works.

**Example 2.** Solve x^2 = 3x + 10.
1. Move everything to one side: x^2 - 3x - 10 = 0.
2. Factor: (x - 5)(x + 2) = 0.
3. Solutions: x = 5 and x = -2.

**Example 3.** Solve 2x^2 - 8x = 0.
1. Factor out the GCF: 2x(x - 4) = 0.
2. 2x = 0 gives x = 0. x - 4 = 0 gives x = 4.
3. Do not divide both sides by x; that would lose the solution x = 0.

**Example 4.** Solve 9x^2 - 25 = 0.
1. Difference of squares: (3x + 5)(3x - 5) = 0.
2. x = -5/3 or x = 5/3.

## Double roots
x^2 - 6x + 9 = 0 factors as (x - 3)^2 = 0, so x = 3 is the only solution. The parabola just touches the x-axis there.

## Common mistakes
- Setting the product equal to a nonzero number and then setting each factor equal to it. For (x - 1)(x - 2) = 6, you cannot say x - 1 = 6.
- Not rewriting the equation as = 0 first.
- Dividing by a variable and losing a solution.
- Reporting x + 2 = 0 as x = 2 instead of x = -2.
