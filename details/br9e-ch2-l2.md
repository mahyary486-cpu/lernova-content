# First conditional

## Estrutura

**If + presente simples, will + verbo base**

- If it rains tomorrow, we **will cancel** the picnic.
- If she **leaves** early, she **will catch** the bus.

Depois de *if* **não** se usa will: *If it will rain* está errado.

## Ordem das orações

A oração com *if* pode vir primeiro (com vírgula) ou depois: *We will cancel the picnic if it rains.*

## Unless

**Unless = if not**: *Unless you hurry, you will miss the train.*

## Zero conditional

Para fatos gerais: **if + presente, presente**: *If you heat ice, it melts.*

## Exemplo

*If you help me, I will help you.*
