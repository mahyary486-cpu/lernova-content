# Canlıların ortak özellikleri

## Canlıların ortak özellikleri

- Hücresel yapı
- Metabolizma (anabolizma + katabolizma)
- Homeostasi: İç dengenin korunması (örneğin terleme)
- Üreme ve kalıtım
- Büyüme ve gelişme
- Uyarılara tepki
- Adaptasyon (çevreye uyum)

## Biyolojik organizasyon

Hücre → doku → organ → sistem → organizma → popülasyon → komünite → ekosistem → biyosfer

- **Popülasyon:** Aynı türün bireyleri
- **Komünite:** Farklı türlerin popülasyonları
- **Ekosistem:** Komünite + cansız çevre

## Bilimsel yöntem

Gözlem → problem → **hipotez** → deney → sonuç → teori. Hipotez test edilebilir olmalıdır.

## Beslenme

- **Ototrof:** Kendi besinini yapar (bitki, alg).
- **Heterotrof:** Hazır besin alır (hayvan, mantar).
