# Point-Slope Form and Standard Form

## Three forms of a line
| Form | Equation | Best used for |
|---|---|---|
| Slope-intercept | y = mx + b | Graphing, reading slope and y-intercept |
| Point-slope | y - y1 = m(x - x1) | Writing an equation from a point and a slope |
| Standard | Ax + By = C | Finding intercepts quickly |

## Point-slope form
A line with slope m through (x1, y1) is **y - y1 = m(x - x1)**.

**Example.** Slope 4 through (2, 3): y - 3 = 4(x - 2).

**Example.** Through (1, 2) and (3, 8):
1. Slope = (8 - 2) / (3 - 1) = 3.
2. Use (1, 2): y - 2 = 3(x - 1).

**Example.** Slope -2 through (-1, 4): y - 4 = -2(x + 1). Notice that x - (-1) becomes x + 1. Solving for y: y = -2x - 2 + 4 = -2x + 2.

## Standard form
**Ax + By = C**, with A, B and C usually whole numbers.

Convert y = 2x + 3: subtract 2x from both sides to get -2x + y = 3, or multiply by -1 to get 2x - y = -3.

## Intercepts from standard form
For 3x + 4y = 12:
- Set y = 0: 3x = 12, so the x-intercept is 4.
- Set x = 0: 4y = 12, so the y-intercept is 3.

## Checking a point
Is (4, 1) on y + 1 = 2(x - 3)? Left side: 1 + 1 = 2. Right side: 2(4 - 3) = 2. They match, so yes.

## Common mistakes
- Writing y + 3 when the point is (x1, 3). The form is y minus the point's y-value.
- Forgetting the sign change for negative coordinates, such as x - (-1) = x + 1.
- Mixing up which intercept you get by setting x = 0 and which by setting y = 0.
