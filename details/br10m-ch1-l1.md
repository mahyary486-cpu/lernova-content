# Função afim: conceito e gráfico

## Definição

**f(x) = ax + b**, com a e b reais e **a ≠ 0**. Quando a = 0, a função é constante (f(x) = b).

## Coeficientes

- **a (coeficiente angular):** inclinação da reta;
- **b (coeficiente linear):** f(0) = b, ponto (0, b) no eixo y.

Em f(x) = 3x − 5, a = 3 e b = −5.

## Crescimento

- a > 0: **crescente**;
- a < 0: **decrescente**.

## Gráfico

O gráfico é uma **reta**. Para traçá-lo bastam dois pontos. Exemplo: f(x) = 2x + 1 passa por (0, 1) e (2, 5).

## Determinando a função

Dados dois pontos (x₁, y₁) e (x₂, y₂): a = (y₂ − y₁)/(x₂ − x₁). Para (1, 3) e (3, −1): a = −4/2 = −2 e, como 3 = −2 + b, b = 5. Logo f(x) = −2x + 5.
