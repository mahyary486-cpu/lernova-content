# Piecewise Functions and Continuity

## Piecewise functions
A **piecewise function** uses different rules on different parts of its domain. To evaluate it, find which condition the input satisfies and use that rule.

Example: f(x) = 2x - 1 if x < 0; f(x) = x^2 if 0 ≤ x ≤ 3; f(x) = 10 if x > 3.
- f(-2): -2 < 0, so 2(-2) - 1 = **-5**.
- f(3): 0 ≤ 3 ≤ 3, so 3^2 = **9**.
- f(5): 5 > 3, so **10**.

The absolute value is piecewise: |x| = x if x ≥ 0, and |x| = -x if x < 0.

## Step functions
The **floor function** gives the greatest integer less than or equal to x.
- floor(2.7) = **2**
- floor(-1.2) = **-2** (not -1, because -2 is the greatest integer that is at most -1.2)
- floor(5) = 5
Step functions model prices such as "$3 per hour or part of an hour".

## Continuity (an informal view)
A function is **continuous** at a point if you can draw its graph through that point without lifting your pencil. Three kinds of break:
- **Removable discontinuity (a hole):** f(x) = (x^2 - 1)/(x - 1) = x + 1 for x not 1. There is a **hole at x = 1**.
- **Jump discontinuity:** the graph jumps from one value to another.
- **Infinite discontinuity:** a vertical asymptote, such as 1/x at x = 0.

## Checking a piecewise function
Compare the value from the left piece and from the right piece at the break point.
- f(x) = x^2 if x ≤ 1; f(x) = 2x + 1 if x > 1. At x = 1 the left piece gives 1, and the right piece approaches 3. There is a **jump**.
- f(x) = x + 1 if x < 2; f(x) = 5 - x if x ≥ 2. At x = 2 the left piece approaches 3 and f(2) = 3. The function is **continuous** at 2.

## Choosing a constant for continuity
f(x) = kx + 1 if x < 2; f(x) = x^2 - 1 if x ≥ 2. At x = 2 the right piece gives 3, so we need 2k + 1 = 3, which gives **k = 1**.

## Common mistakes
- Using the wrong rule when the input equals the boundary value. Check whether the inequality includes the equal sign.
- Rounding the floor function instead of taking the greatest integer below the number.
- Calling a hole a vertical asymptote.
