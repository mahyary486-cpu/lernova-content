# Produit scalaire, orthogonalité et plans définis par un vecteur normal

## Produit scalaire
Pour u(x ; y ; z) et v(x’ ; y’ ; z’) : u·v = xx’ + yy’ + zz’.
Exemple : u(1 ; 2 ; 3) et v(2 ; 0 ; 1) donnent u·v = 2 + 0 + 3 = 5.
u·v = 0 équivaut à l’orthogonalité de u et v (vecteurs non nuls). Par exemple (1 ; 1 ; 0) et (1 ; −1 ; 0) sont orthogonaux.

## Angle
cos θ = u·v/(‖u‖ ‖v‖). Pour u(1 ; 0 ; 0) et v(1 ; 1 ; 0) : cos θ = 1/√2 et θ = 45°.

## Vecteur normal à un plan
Un vecteur normal à un plan P est un vecteur non nul orthogonal à tous les vecteurs de P (à deux vecteurs non colinéaires de P suffit).
Le plan passant par A de vecteur normal n(a ; b ; c) est l’ensemble des points M tels que AM·n = 0, soit ax + by + cz + d = 0.

## Exemples
- Plan passant par A(1 ; 0 ; 2) de vecteur normal n(1 ; 2 ; −1) : x + 2y − z + d = 0 avec 1 − 2 + d = 0, donc d = 1 : x + 2y − z + 1 = 0.
- Plan passant par A(1 ; 1 ; 1) orthogonal à la direction (1 ; 2 ; 3) : x + 2y + 3z − 6 = 0.
- Plan passant par A(1 ; 0 ; 0), B(0 ; 1 ; 0), C(0 ; 0 ; 1) : x + y + z = 1.
- Pour le plan 2x − y + 3z + 5 = 0, un vecteur normal est (2 ; −1 ; 3).

## Plans parallèles
Deux plans sont parallèles si leurs vecteurs normaux sont colinéaires.

## Erreur fréquente
Le vecteur normal est (a ; b ; c) et non un vecteur directeur : il est orthogonal au plan.
