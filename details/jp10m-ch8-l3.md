# 整数の割り算と不定方程式

## 余りに注目

x を 7 でわると 3 余る整数は x = 7k + 3 と表せます。x² = 49k² + 42k + 9 を 7 でわった余りは 2。

連続する整数の積は偶数、連続する3つの整数の積は 6 の倍数。

## 不定方程式

ax + by = c の整数解は、1組の解を見つけて表します。

**例：** 7x + 5y = 1 は (x, y) = (−2, 3) が解（−14 + 15 = 1）。

## 余りの条件

「7 でわると 3 余り、3 でわると 1 余る最小の自然数」：7 でわって 3 余る数 3、10、… のうち、3 でわって 1 余る最小は 10。

## 末尾の 0 の個数

n! の末尾の 0 の個数は、素因数 5 の個数（n/5 + n/25 + …）。例：25! は 5 + 1 = 6 個。
