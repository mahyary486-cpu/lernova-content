# Solving Exponential Equations

## Method 1: same base
If both sides can be written with the same base, set the exponents equal: **b^m = b^n means m = n**.
- 2^x = 32. Since 32 = 2^5, **x = 5**.
- 9^x = 27. Write both with base 3: 3^(2x) = 3^3, so 2x = 3 and **x = 3/2**.
- (1/2)^x = 8. Then 2^(-x) = 2^3, so **x = -3**.
- 4^(x + 1) = 64. Since 64 = 4^3, x + 1 = 3 and **x = 2**.

## Method 2: take a logarithm
When the bases cannot match, take the log (or ln) of both sides and use the power property.
**3^x = 20.**
1. ln(3^x) = ln(20)
2. x ln(3) = ln(20)
3. x = ln(20) / ln(3), about **2.73**.

**5 * 2^x = 40.** First divide by 5: 2^x = 8, so **x = 3**.

**e^(2x) = 7.** Take ln of both sides: 2x = ln(7), so **x = ln(7)/2**, about 0.97.

**2^(x + 1) = 15.** x + 1 = log_2(15) = ln(15)/ln(2), about 3.91, so x is about **2.91**.

## Quadratic form
**4^x - 6 * 2^x + 8 = 0.** Let u = 2^x. Then u^2 - 6u + 8 = 0, so (u - 2)(u - 4) = 0, u = 2 or u = 4. So 2^x = 2 (x = 1) or 2^x = 4 (x = 2). The solutions are **x = 1 or x = 2**.

## Applications
**Time to double.** How long for money to double at 5% compounded yearly? 2 = 1.05^t, so t = ln(2)/ln(1.05), about **14.2 years**.
**Time to reach a target.** 1000(1.04)^t = 1500 gives 1.04^t = 1.5, so t = ln(1.5)/ln(1.04), about **10.3 years**.

## Common mistakes
- Taking the log before isolating the exponential term. Divide or subtract first.
- Forgetting that the exponent comes down as a **factor**: ln(3^x) = x * ln(3), not ln(3) + x.
- Rounding too early. Keep full calculator values until the end.
- Trying to give a negative answer for something like 2^x = -4. There is no solution, because 2^x is always positive.
