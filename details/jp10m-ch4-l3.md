# 正弦定理・余弦定理と面積

△ABC の外接円の半径を R とします。

## 正弦定理

a/sinA = b/sinB = c/sinC = 2R

## 余弦定理

a² = b² + c² − 2bc cosA、cosA = (b² + c² − a²)/(2bc)

**例：** b = 3、c = 5、A = 120° のとき a² = 9 + 25 − 2×3×5×(−1/2) = 49、a = 7。

## 面積

- S = ½ bc sinA
- ヘロンの公式：S = √(s(s−a)(s−b)(s−c))、s = (a + b + c)/2
- 内接円の半径 r：S = ½ r(a + b + c)

## 測量

塔の高さは、見上げる角と水平距離から tan を使って求めます。2地点で測るときは、辺の関係の連立方程式をつくります。
