# Cosinus et sinus : valeurs remarquables et symétries

## Relation fondamentale
cos²x + sin²x = 1, et −1 ≤ cos x ≤ 1, −1 ≤ sin x ≤ 1.
Exemple : si cos x = 3/5 avec x dans [0 ; π], alors sin²x = 1 − 9/25 = 16/25 et sin x = 4/5 (positif sur [0 ; π]).

## Valeurs remarquables
- x = 0 : cos = 1 ; sin = 0.
- x = π/6 : cos = √3/2 ; sin = 1/2.
- x = π/4 : cos = √2/2 ; sin = √2/2.
- x = π/3 : cos = 1/2 ; sin = √3/2.
- x = π/2 : cos = 0 ; sin = 1.
- x = π : cos = −1 ; sin = 0.

## Symétries
- cos(−x) = cos x et sin(−x) = −sin x.
- cos(π − x) = −cos x et sin(π − x) = sin x.
- cos(π + x) = −cos x et sin(π + x) = −sin x.
- cos(π/2 − x) = sin x et sin(π/2 − x) = cos x.

## Exemples
- cos(2π/3) = cos(π − π/3) = −1/2.
- sin(5π/6) = sin(π − π/6) = 1/2.
- cos(7π/6) = cos(π + π/6) = −√3/2.
- sin(−π/6) = −1/2.
- cos(π − x) + cos x = 0.

## Méthode
On ramène l’angle dans [0 ; π/2] grâce aux symétries, puis on utilise les valeurs remarquables.

## Erreur fréquente
Le signe d’un cosinus ou d’un sinus dépend du quart de cercle où se trouve le point.
