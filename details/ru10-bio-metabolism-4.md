# Пластический обмен и хемосинтез

**Пластический обмен (ассимиляция)** — синтез органических веществ с затратой энергии, например биосинтез белка.

**По способу питания организмы делят на:**

- **автотрофов**, которые сами создают органические вещества из неорганических (растения, цианобактерии);
- **гетеротрофов**, которые питаются готовыми органическими веществами (животные, грибы).

**Хемосинтез** — синтез органических веществ за счёт энергии окисления неорганических соединений. Его осуществляют некоторые бактерии: железобактерии, серобактерии, нитрифицирующие бактерии. Хемосинтез открыл С. Н. Виноградский.
