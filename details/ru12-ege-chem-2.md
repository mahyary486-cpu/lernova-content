# Неорганическая химия

**Ряд активности.** Более активный металл вытесняет менее активный из раствора соли: цинк вытесняет медь из CuSO₄.

**Электролиз раствора NaCl:** на катоде выделяется водород, на аноде — хлор.

**Качественные реакции.** Cl⁻ + Ag⁺ → AgCl (белый осадок). SO₄²⁻ + Ba²⁺ → BaSO₄ (белый). Fe³⁺ + OH⁻ → Fe(OH)₃ (красно-бурый осадок). Cu²⁺ + OH⁻ → Cu(OH)₂ (голубой).

**Индикаторы.** Фенолфталеин в щёлочи малиновый.

**Серная кислота:** H₂SO₄. Амфотерные: Al(OH)₃, Zn(OH)₂.
