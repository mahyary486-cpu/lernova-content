# Combining Functions and Composition

## Operations on functions
For two functions f and g, new functions are built by combining their outputs:
- **Sum:** (f + g)(x) = f(x) + g(x)
- **Difference:** (f - g)(x) = f(x) - g(x)
- **Product:** (f * g)(x) = f(x) * g(x)
- **Quotient:** (f / g)(x) = f(x) / g(x), where g(x) is not 0

Example: f(x) = x + 2 and g(x) = 3x. Then (f + g)(x) = 4x + 2.

## Domain of a combination
The domain is the set of x that works in **both** f and g. For a quotient, also remove every x that makes g(x) = 0.
Example: f(x) = x + 1 and g(x) = x - 4. For (f / g)(x), x cannot be 4.

## Composition
The **composition** (f o g)(x) means f(g(x)): put g(x) inside f, so do g first and f second.
Example: f(x) = 2x + 1 and g(x) = x^2.
- (f o g)(2) = f(g(2)) = f(4) = **9**
- (g o f)(2) = g(f(2)) = g(5) = **25**

**The order matters.** In general f(g(x)) and g(f(x)) are different.

## Composition as a formula
f(x) = x^2 - 1 and g(x) = x + 2.
(f o g)(x) = f(x + 2) = (x + 2)^2 - 1 = **x^2 + 4x + 3**.
(g o f)(x) = g(x^2 - 1) = (x^2 - 1) + 2 = **x^2 + 1**.

## Domain of a composition
x must be in the domain of the inside function g, and g(x) must be in the domain of f.
Example: f(x) = sqrt(x) and g(x) = x - 5. (f o g)(x) = sqrt(x - 5), so the domain is **x ≥ 5**.

## Worked example
f(x) = x + 3 and g(x) = 2x. (g o f)(x) = g(x + 3) = 2(x + 3) = **2x + 6**.

## Common mistakes
- Doing the outside function first. In f(g(x)), g is applied first.
- Forgetting parentheses: substituting into f(x) = x^2 - 1 means (x + 2)^2, not x + 2^2.
- Ignoring the domain of the inside function.
