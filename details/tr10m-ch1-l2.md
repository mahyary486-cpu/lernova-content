# Karesel fonksiyon, eşitsizlik, karekök ve rasyonel ifadeler

## Karesel fonksiyon ve parabol

f(x) = ax² + bx + c

- **Kollar:** a > 0 yukarı, a < 0 aşağı
- **Tepe noktası:** r = −b/(2a), k = f(r)
- **y eksenini kestiği nokta:** (0, c)
- **x eksenini kestiği noktalar:** f(x) = 0 köklerinden
- **Simetri ekseni:** x = r

Tepe noktası biçimi: f(x) = a(x − r)² + k.

**Örnek:** f(x) = x² − 4x + 3 için r = 2 ve k = f(2) = −1; tepe noktası (2, −1).

## Ekstremum değer

- a > 0 ise **en küçük değer** k dır.
- a < 0 ise **en büyük değer** k dır.

f(x) = −x² + 4x + 5 için en büyük değer f(2) = 9 dur.

## Teğetlik

Parabolün x eksenine teğet olması için Δ = 0 olmalıdır. f(x) = x² + kx + 9 için k² − 36 = 0, k = ±6.

## İkinci dereceden eşitsizlikler

1. Kökleri bulun.
2. İşaret tablosu yapın: kökler arasında a'nın işaretinin tersi, dışında a'nın işareti geçerlidir.
3. İstenen işarete göre aralığı yazın.

**Örnek:** x² − 5x + 6 ≥ 0 → kökler 2 ve 3; çözüm (−∞, 2] ∪ [3, ∞).

## Karekök fonksiyonlar

√A ifadesinde A ≥ 0 olmalıdır. f(x) = √(6 − 2x) için 6 − 2x ≥ 0 → x ≤ 3.

Karekökte kare alma işlemi yapıldıktan sonra bulunan kökler denklemde **mutlaka denenmelidir**: √(x + 4) = x − 2 için x = 5 geçerlidir, x = 0 değildir.

## Rasyonel fonksiyonlar

Payda sıfır olamaz. f(x) = 1/(x − 2) için x = 2 tanımsızdır. (x² − 9)/(x − 3) ifadesi x ≠ 3 için x + 3 e sadeleşir.

Rasyonel eşitsizlikte pay ve paydanın kökleri işaret tablosunda alınır; paydanın kökü çözüme **dahil edilmez**.
