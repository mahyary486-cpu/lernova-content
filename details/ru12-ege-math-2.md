# Уравнения и неравенства

**Квадратные уравнения.** x² − 5x + 6 = 0 даёт x = 2 или x = 3 (по теореме Виета: сумма 5, произведение 6).

**Модуль.** |x − 2| = 3 даёт x − 2 = 3 или x − 2 = −3, то есть x = 5 или x = −1.

**Показательные и логарифмические.** 2ˣ = 16 даёт x = 4. log₂ (x − 1) = 3 даёт x − 1 = 8, то есть x = 9; при этом x − 1 > 0.

**Тригонометрические.** sin x = 1/2 даёт x = π/6 + 2πk или x = 5π/6 + 2πk. На отрезке [0; π] корни π/6 и 5π/6.

**Неравенства.** Решают методом интервалов; при домножении на отрицательное число знак меняется.
