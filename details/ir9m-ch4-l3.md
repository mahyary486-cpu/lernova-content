# Square roots

The square root of a non-negative number a is the non-negative number whose square equals a.

## Key ideas

- We write the square root of a as √a. For example, √49 = 7 because 7^2 = 49. The square root symbol always gives a result that is zero or positive.
- The square root is defined only for a ≥ 0 in real numbers. Since no real number squared gives a negative number, √(−4) does not exist among the real numbers.
- The equation x^2 = a with a > 0 has two solutions: x = √a and x = −√a. For example, x^2 = 49 gives x = 7 or x = −7.
- For any real number x, √(x^2) = |x|. For example, √((−5)^2) = √25 = 5.
- A number such as 1, 4, 9, 16, 25 is a perfect square. The square root of a perfect square is a whole number. Other square roots, like √2, are irrational.
- Product rule: √(a × b) = √a × √b for a ≥ 0, b ≥ 0.
- Quotient rule: √(a / b) = √a / √b for a ≥ 0, b > 0.
- To simplify a square root, take out the largest perfect square factor. Square roots with the same radical part can be added or subtracted like terms: 3√2 + 5√2 = 8√2.
- √(a + b) is not equal to √a + √b.
- To estimate a square root, find the two perfect squares around it. Then test numbers in between.

## Worked examples

Example 1. Simplify √72.

Step 1: Find the largest perfect square that divides 72. It is 36, because 72 = 36 × 2.
Step 2: √72 = √36 × √2.
Step 3: √36 = 6.
Answer: 6√2.

Example 2. Calculate √50 + √18 − √2.

Step 1: √50 = √(25 × 2) = 5√2.
Step 2: √18 = √(9 × 2) = 3√2.
Step 3: Now the sum is 5√2 + 3√2 − √2 = (5 + 3 − 1)√2.
Answer: 7√2.

Example 3. Estimate √20 to two decimal places.

Step 1: 4^2 = 16 and 5^2 = 25, so √20 is between 4 and 5.
Step 2: Test 4.5: 4.5^2 = 20.25, which is a little too big. So the root is a bit smaller than 4.5.
Step 3: Test 4.47: 4.47^2 = 19.9809. Test 4.48: 4.48^2 = 20.0704. The value 20 is closer to 19.9809.
Answer: √20 ≈ 4.47.

Example 4. Solve x^2 = 18, and then write 6/√3 without a root in the denominator.

Step 1: x = √18 or x = −√18. Since √18 = √(9 × 2) = 3√2, the solutions are x = 3√2 and x = −3√2.
Step 2: For 6/√3, multiply the top and bottom by √3: (6 × √3) / (√3 × √3) = 6√3 / 3.
Step 3: Divide 6 by 3.
Answer: x = ±3√2, and 6/√3 = 2√3.

## Common mistakes

- Writing √(a + b) = √a + √b. For example, √(9 + 16) = √25 = 5, but √9 + √16 = 3 + 4 = 7.
- Giving only one answer for x^2 = a. There are two solutions, +√a and −√a.
- Saying √16 = ±4. The symbol √16 means only 4. The ± appears when we solve an equation.
- Writing √(x^2) = x without thinking. The correct result is |x|.

## Remember

- √a ≥ 0, and (√a)^2 = a for a ≥ 0.
- √(a × b) = √a × √b, and √(a / b) = √a / √b.
- To simplify, take out the largest perfect square factor.
