# جذر

جذر عدد نامنفی a، عدد نامنفی‌ای است که مربعش برابر a شود.

## نکته‌های کلیدی

- جذر a را با √a نشان می‌دهیم. برای نمونه √۴۹ = ۷ چون ۷^۲ = ۴۹. علامت جذر همیشه جواب صفر یا مثبت می‌دهد.
- در اعداد حقیقی جذر فقط برای a ≥ ۰ تعریف می‌شود. چون هیچ عدد حقیقی‌ای وقتی به توان ۲ برسد منفی نمی‌شود، √(-۴) در اعداد حقیقی وجود ندارد.
- معادله‌ی x^۲ = a با a > ۰ دو جواب دارد: x = √a و x = -√a. برای نمونه x^۲ = ۴۹ نتیجه می‌دهد x = ۷ یا x = -۷.
- برای هر عدد حقیقی x داریم √(x^۲) = |x|. برای نمونه √((-۵)^۲) = √۲۵ = ۵.
- عددهایی مانند ۱، ۴، ۹، ۱۶، ۲۵ مربع کامل‌اند. جذر مربع کامل عددی صحیح است. جذرهای دیگر، مانند √۲، گنگ‌اند.
- قاعده‌ی ضرب: √(a × b) = √a × √b برای a ≥ ۰ و b ≥ ۰.
- قاعده‌ی تقسیم: √(a / b) = √a / √b برای a ≥ ۰ و b > ۰.
- برای ساده‌کردن جذر، بزرگ‌ترین عامل مربع کامل را بیرون می‌آوریم. جذرهایی که قسمت رادیکالی یکسان دارند مانند جمله‌های متشابه جمع و تفریق می‌شوند: ۳√۲ + ۵√۲ = ۸√۲.
- √(a + b) با √a + √b برابر نیست.
- برای تخمین جذر، دو مربع کامل اطراف آن را پیدا می‌کنیم و سپس عددهای بین آن‌ها را امتحان می‌کنیم.

## مثال‌های حل‌شده

**مثال ۱.** √۷۲ را ساده کنید.

گام ۱: بزرگ‌ترین مربع کاملی را که ۷۲ بر آن بخش‌پذیر است پیدا می‌کنیم. این عدد ۳۶ است، چون ۷۲ = ۳۶ × ۲.
گام ۲: √۷۲ = √۳۶ × √۲.
گام ۳: √۳۶ = ۶.
پاسخ: ۶√۲.

**مثال ۲.** حاصل √۵۰ + √۱۸ - √۲ را بیابید.

گام ۱: √۵۰ = √(۲۵ × ۲) = ۵√۲.
گام ۲: √۱۸ = √(۹ × ۲) = ۳√۲.
گام ۳: حالا مجموع برابر ۵√۲ + ۳√۲ - √۲ = (۵ + ۳ - ۱)√۲ است.
پاسخ: ۷√۲.

**مثال ۳.** √۲۰ را تا دو رقم اعشار تخمین بزنید.

گام ۱: ۴^۲ = ۱۶ و ۵^۲ = ۲۵ پس √۲۰ بین ۴ و ۵ است.
گام ۲: ۴٫۵ را امتحان می‌کنیم: ۴٫۵^۲ = ۲۰٫۲۵ که کمی بزرگ است. پس جذر کمی کمتر از ۴٫۵ است.
گام ۳: ۴٫۴۷ را امتحان می‌کنیم: ۴٫۴۷^۲ = ۱۹٫۹۸۰۹. و ۴٫۴۸: ۴٫۴۸^۲ = ۲۰٫۰۷۰۴. عدد ۲۰ به ۱۹٫۹۸۰۹ نزدیک‌تر است.
پاسخ: √۲۰ ≈ ۴٫۴۷.

**مثال ۴.** معادله‌ی x^۲ = ۱۸ را حل کنید، سپس ۶/√۳ را بدون جذر در مخرج بنویسید.

گام ۱: x = √۱۸ یا x = -√۱۸. چون √۱۸ = √(۹ × ۲) = ۳√۲، جواب‌ها x = ۳√۲ و x = -۳√۲ هستند.
گام ۲: برای ۶/√۳ صورت و مخرج را در √۳ ضرب می‌کنیم: (۶ × √۳) / (√۳ × √۳) = ۶√۳ / ۳.
گام ۳: ۶ را بر ۳ تقسیم می‌کنیم.
پاسخ: x = ±۳√۲ و ۶/√۳ = ۲√۳.

## اشتباه‌های رایج

- نوشتن √(a + b) = √a + √b. برای نمونه √(۹ + ۱۶) = √۲۵ = ۵ ولی √۹ + √۱۶ = ۳ + ۴ = ۷.
- دادن یک جواب برای x^۲ = a. دو جواب داریم: +√a و -√a.
- گفتن اینکه √۱۶ = ±۴. علامت √۱۶ فقط ۴ را نشان می‌دهد. ± وقتی می‌آید که معادله حل می‌کنیم.
- نوشتن √(x^۲) = x بدون فکر. نتیجه‌ی درست |x| است.

## به یاد داشته باشید

- √a ≥ ۰ و (√a)^۲ = a برای a ≥ ۰.
- √(a × b) = √a × √b و √(a / b) = √a / √b.
- برای ساده‌کردن، بزرگ‌ترین عامل مربع کامل را بیرون بیاورید.
