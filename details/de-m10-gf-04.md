# Graphen skizzieren

## Schritte

1. **Symmetrie** prüfen (gerade oder ungerade Exponenten).
2. **y-Achsenabschnitt** f(0) berechnen.
3. **Nullstellen** bestimmen (Ausklammern, Substitution, Polynomdivision).
4. **Verhalten für x → ±∞** am Leitterm ablesen.
5. Bei Bedarf eine **Wertetabelle** anlegen.
6. Punkte verbinden und dabei Schnitt- und Berührpunkte mit der x-Achse beachten.

## Beispiel: f(x) = x³ − 4x

- Nur ungerade Exponenten: punktsymmetrisch zum Ursprung.
- f(0) = 0.
- x · (x − 2) · (x + 2) = 0 ergibt die Nullstellen −2, 0 und 2 (alle einfach).
- Ungerader Grad, positiver Leitkoeffizient: links unten, rechts oben.
- Wertetabelle: f(−1) = 3, f(1) = −3, f(3) = 15.

## Beispiel: f(x) = (x + 1)² · (x − 3)

- y-Achsenabschnitt: f(0) = 1 · (−3) = −3.
- Doppelte Nullstelle −1 (Graph berührt die x-Achse), einfache Nullstelle 3.
- Ungerader Grad, positiver Leitkoeffizient: links unten, rechts oben.

## Anzahl der Nullstellen

Eine Funktion mit ungeradem Grad hat mindestens eine Nullstelle, weil ihre Enden auf verschiedenen Seiten der x-Achse liegen.
