# wish、as if 与 would rather

这些词后面的从句，用**虚拟语气**。

## wish + 宾语从句

| 与…相反 | 从句动词形式 | 例句 |
|---|---|---|
| 现在 | **过去式**（be 用 were） | I wish I **were** taller. |
| 过去 | **had done** | I wish I **had gone** there. |
| 将来 | **would / could + do** | I wish it **would stop** raining. |

## as if / as though

- 与现在相反：**过去式**：He talks **as if he knew** everything.
- 与过去相反：**had done**：He looks **as if he had seen** a ghost.

## would rather

主语**不同**时，从句用**过去式**（表示现在或将来）：

- I'd rather you **came** tomorrow.
- 主语相同时：I'd rather **go** home.（would rather do）

## It's (high) time that ...

从句用**过去式**或 should do：

- **It's time** we **went** home.

## 注意

as if 引导的从句，如果表示**真实情况**，用陈述语气：It looks as if it **is going to** rain.
