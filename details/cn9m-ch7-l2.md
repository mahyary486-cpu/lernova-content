# 相似三角形的判定

## 三个判定方法

1. **两角分别相等**的两个三角形相似；
2. **两边成比例且夹角相等**的两个三角形相似；
3. **三边成比例**的两个三角形相似。

直角三角形：有一个锐角相等的两个直角三角形相似。

## 常见模型

- "A"型、"X"型（由平行线得到）；
- 母子型（射影定理）：在 Rt△ABC 中，∠ACB = 90°，CD ⊥ AB 于 D，则 CD² = AD · DB，AC² = AD · AB。

## 例题

**例 1：** △ABC 与 △DEF 中，∠A = ∠D = 50°，∠B = ∠E = 60°，所以 △ABC ∽ △DEF。

**例 2：** AB = 4，AC = 6，AD = 2，AE = 3，且 ∠A 公共。因为 AD/AB = 1/2，AE/AC = 1/2，所以 △ADE ∽ △ABC。
