# 对数与对数函数

## 对数

如果 aˣ = N（a > 0，a ≠ 1），那么 x 叫作以 a 为底 N 的对数，记作 **x = logₐN**。

- logₐ1 = 0，logₐa = 1；
- 负数和零没有对数（真数 N > 0）。

## 运算法则（a > 0，a ≠ 1，M > 0，N > 0）

- logₐ(MN) = logₐM + logₐN
- logₐ(M/N) = logₐM − logₐN
- logₐMⁿ = n · logₐM
- 换底公式：logₐb = log꜀b / log꜀a

**例：** log₂8 = 3；log₂12 − log₂3 = log₂4 = 2；log₂3 · log₃4 = log₂4 = 2。

## 对数函数

**y = logₐx**（a > 0，a ≠ 1）：

- 定义域 (0, +∞)，值域 R；
- 图象过点 **(1, 0)**；
- a > 1 时单调递增；0 < a < 1 时单调递减。

y = aˣ 与 y = logₐx 互为反函数，图象关于直线 y = x 对称。
