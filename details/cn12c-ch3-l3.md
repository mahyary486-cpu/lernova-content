# 无机推断题

## 找突破口

**颜色：**

- 红褐色沉淀：Fe(OH)₃；蓝色沉淀：Cu(OH)₂；
- 淡黄色固体：Na₂O₂、S；黄绿色气体：Cl₂；
- Fe³⁺ 黄色，Cu²⁺ 蓝色，Fe²⁺ 浅绿色。

**特殊性质：**

- 使湿润红色石蕊试纸变蓝：NH₃；
- 使品红褪色：SO₂、Cl₂；
- 遇 KSCN 变红：Fe³⁺；遇淀粉变蓝：I₂。

**特殊反应：**

- 铝热反应：Fe₂O₃ + 2Al =(高温)= Al₂O₃ + 2Fe；
- 既能与酸又能与碱反应：Al、Al₂O₃、Al(OH)₃、NaHCO₃、(NH₄)₂CO₃。

## 解题思路

1. 读题，圈出"题眼"（颜色、特殊现象、特殊反应）；
2. 大胆猜测，代入检验；
3. 规范书写化学式、方程式。

## 例题

某白色固体 A 受热分解，产生无色气体 B（使澄清石灰水变浑浊），剩余固体 C 溶于水显碱性，焰色为黄色。

- 说明含 Na 元素，且受热分解产生 CO₂；
- A 是 **NaHCO₃**，B 是 CO₂，C 是 Na₂CO₃。

注意：Na₂CO₃ 受热不分解，所以 A 不是 Na₂CO₃。
