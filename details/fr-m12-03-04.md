# Croissances comparées

## Résultats à connaître
Pour tout entier n ≥ 1 :
- lim(x→+∞) ln x / x^n = 0 ;
- lim(x→0+) x^n ln x = 0 ;
- lim(x→+∞) e^x / x^n = +∞ ;
- lim(x→+∞) x^n e^(−x) = 0.
En particulier : ln x / x → 0, x ln x → 0 en 0+, e^x / x → +∞, x e^(−x) → 0.

## Interprétation
En +∞ : ln x ≪ x^n ≪ e^x. Les fonctions « puissance » dominent le logarithme, et l’exponentielle domine les puissances.

## Utilisation pour lever une indétermination
- lim(x→+∞) (x − ln x) = lim x(1 − ln x/x) = +∞.
- lim(x→+∞) (e^x − x²) = lim e^x(1 − x²/e^x) = +∞.
- lim(x→−∞) x e^x = 0, car en posant X = −x, x e^x = −X e^(−X) tend vers 0.

## Étude d’une fonction
Soit f(x) = x e^(−x). f’(x) = (1 − x)e^(−x). f croît sur ]−∞ ; 1], décroît sur [1 ; +∞[ ; son maximum est e^(−1) ≈ 0,37. Comme lim(x→+∞) x e^(−x) = 0, l’axe des abscisses est asymptote en +∞.

## Modélisation
Une quantité modélisée par t e^(−t) croît, atteint un maximum puis décroît vers 0 : l’exponentielle décroissante l’emporte.

## Erreur fréquente
Écrire « ∞ × 0 = 0 » : c’est une forme indéterminée, que les croissances comparées permettent de lever.
