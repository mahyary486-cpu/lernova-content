# Graphing Rational Functions

## The parent function
f(x) = 1/x has two curves (a hyperbola), a **vertical asymptote** at x = 0 and a **horizontal asymptote** at y = 0. An asymptote is a line the graph gets closer and closer to but never touches.

## Vertical asymptotes and holes
Factor the top and bottom and cancel common factors.
- A factor that **stays** in the denominator gives a **vertical asymptote**.
- A factor that **cancels** gives a **hole** in the graph.

Examples:
- f(x) = 1/(x - 4) has a vertical asymptote at **x = 4**.
- f(x) = (x^2 - 1)/(x - 1) = x + 1 for x not 1. There is a **hole at (1, 2)**, found by putting x = 1 into the simplified form x + 1.
- f(x) = (x - 2)/(x^2 - 4) = 1/(x + 2) for x not 2. There is a **hole at x = 2** and a **vertical asymptote at x = -2**.

## Horizontal asymptotes
Compare the degree of the top (n) with the degree of the bottom (m):
| Case | Horizontal asymptote |
|---|---|
| n < m | y = 0 |
| n = m | y = (leading coefficient of top) / (leading coefficient of bottom) |
| n > m | none |

Examples:
- f(x) = (2x + 1)/(x - 3): degrees are equal, so the horizontal asymptote is y = 2/1 = **2**. The vertical asymptote is **x = 3**.
- f(x) = (3x^2 + 1)/(x^2 - 5): the horizontal asymptote is **y = 3**.

## Slant asymptotes
If the top has degree **exactly one more** than the bottom, there is a **slant (oblique) asymptote**. Divide to find it.
f(x) = x^2/(x - 1) = x + 1 + 1/(x - 1), so the slant asymptote is **y = x + 1**.

## Transformations
f(x) = 1/(x - 2) + 3 is the graph of 1/x moved right 2 and up 3. The asymptotes move too: **x = 2** and **y = 3**.

## Intercepts
- x-intercepts: where the **top** is 0 (and the bottom is not).
- y-intercept: f(0), if 0 is allowed.

## Common mistakes
- Calling a hole a vertical asymptote.
- Writing a vertical asymptote as y = ... It is a vertical line x = ....
- Thinking the graph can never cross a horizontal asymptote. It can, but only near the middle; far out it gets close to it.
