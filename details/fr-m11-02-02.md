# Discriminant et racines d’un trinôme

## Discriminant
Pour ax² + bx + c avec a ≠ 0, on pose Δ = b² − 4ac.

## Résolution de ax² + bx + c = 0
- Si Δ > 0 : deux solutions distinctes x1 = (−b − √Δ)/(2a) et x2 = (−b + √Δ)/(2a).
- Si Δ = 0 : une solution double x0 = −b/(2a).
- Si Δ < 0 : aucune solution réelle.

## Exemples
- x² − 5x + 6 = 0 : Δ = 25 − 24 = 1, donc x = (5 ± 1)/2 : 2 ou 3.
- x² + 2x − 3 = 0 : Δ = 4 + 12 = 16, donc x = (−2 ± 4)/2 : 1 ou −3.
- 2x² − 3x − 2 = 0 : Δ = 9 + 16 = 25, donc x = (3 ± 5)/4 : 2 ou −1/2.
- x² + x + 1 = 0 : Δ = 1 − 4 = −3 < 0, aucune solution.
- x² − 2x − 1 = 0 : Δ = 8, donc x = 1 ± √2.

## Factorisation
Si x1 et x2 sont les racines, ax² + bx + c = a(x − x1)(x − x2). Exemple : x² − 5x + 6 = (x − 2)(x − 3).
Si Δ = 0 : ax² + bx + c = a(x − x0)².

## Paramètre
x² + 4x + m = 0 a une racine double si Δ = 16 − 4m = 0, c’est-à-dire m = 4.

## Erreur fréquente
Oublier le dénominateur 2a dans la formule des racines.
