# 阅读理解的方法

## 阅读步骤

1. **先读题目和选项**，了解要找什么信息；
2. **略读**（skimming）：快速浏览，抓住文章大意；
3. **查读**（scanning）：根据关键词找具体信息；
4. **精读**相关段落，选出答案；
5. **检查**，确认答案有依据。

## 常见题型

| 题型 | 提问方式 | 方法 |
|---|---|---|
| 细节题 | What / When / Who ...? | 回原文找关键词 |
| 主旨题 | What is the main idea? | 看首尾段、主题句 |
| 推断题 | We can infer that ... | 根据上下文合理推理 |
| 词义猜测题 | The word "..." means ... | 看上下文 |

## 根据构词法猜词

- **un-**、**dis-**、**in-**：表示"不"：unhappy = **not** happy；
- **-ful**：充满……的：careful = **full of** care；
- **-less**：没有……的：careless = **without** care；
- **-er / -or**：做……的人：teacher, visitor。

## 提示

答案一定要**以原文为依据**，不能凭自己的经验。
