# Signe de ax + b et tableaux de signes

## Signe de ax + b (a ≠ 0)
ax + b s’annule pour x = −b/a.
- Si a > 0 : négatif à gauche de −b/a, positif à droite.
- Si a < 0 : positif à gauche de −b/a, négatif à droite.
Exemples :
- 2x + 4 s’annule en −2 et est positif pour x > −2.
- −2x + 8 s’annule en 4 et est positif pour x < 4.

## Tableau de signes
Pour étudier le signe de (x − 3)(x + 2) :
1. On place les valeurs −2 et 3 dans l’ordre croissant.
2. On met une ligne par facteur avec son signe.
3. On applique la règle des signes pour la dernière ligne.
Résultat : positif sur ]−∞ ; −2[, négatif sur ]−2 ; 3[, positif sur ]3 ; +∞[, nul en −2 et en 3.

## Quotient
Dans un quotient, la valeur qui annule le dénominateur est interdite : on la marque par une double barre.
Exemple : (x − 2)/(x + 1) est positif sur ]−∞ ; −1[ et sur ]2 ; +∞[, négatif sur ]−1 ; 2[, nul en 2, non défini en −1.

## Erreur fréquente
Oublier que −2x + 8 est positif quand x est petit : le coefficient de x est négatif, donc le signe s’inverse.
