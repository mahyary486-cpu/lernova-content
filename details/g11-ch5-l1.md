# Exponential Functions and Their Graphs

## What is an exponential function?
An **exponential function** has the form **f(x) = a * b^x**, where a is not 0, b > 0 and b is not 1. The variable is in the **exponent**.
- **a** is the starting value (the y-intercept, because b^0 = 1).
- **b** is the **base**, or growth/decay factor.

Compare: x^2 is a power function (variable in the base). 2^x is exponential (variable in the exponent).

## Growth or decay?
- **b > 1:** exponential **growth**. The graph rises from left to right. Example: f(x) = 2^x.
- **0 < b < 1:** exponential **decay**. The graph falls from left to right. Example: f(x) = (1/2)^x.

## Key features of f(x) = b^x
- Domain: all real numbers. Range: **y > 0**.
- y-intercept: (0, 1).
- Horizontal asymptote: **y = 0** (the x-axis). The graph gets close to it but never touches it.
- It passes through (1, b).
- It never has an x-intercept.

## Evaluating
For f(x) = 3 * 2^x: f(0) = 3, f(1) = 6, f(2) = 12, f(3) = 24. Each time x goes up by 1, the output is **multiplied by 2**.

## Transformations
For f(x) = a * b^(x - h) + k:
- h shifts the graph right, k shifts it up.
- The horizontal asymptote moves to **y = k**.
- If a is negative, the graph is reflected over the x-axis.
Example: g(x) = 2^x + 3 has horizontal asymptote y = 3 and y-intercept (0, 4).

## Finding the equation from two points
The graph passes through (0, 5) and (1, 15). Since f(0) = a = 5, and f(1) = 5b = 15, b = 3. So **f(x) = 5 * 3^x**.

## Worked examples
1. Is f(x) = 0.8^x growth or decay? **Decay**, because 0.8 < 1.
2. f(x) = 4 * (1/2)^x. f(2) = 4 * 1/4 = **1**.
3. The range of f(x) = 2^x is **y > 0**.

## Common mistakes
- Saying the graph of 2^x touches the x-axis. It only gets closer.
- Confusing a decay base (between 0 and 1) with a negative base. The base must be positive.
- Multiplying a and b first. In a * b^x the power is done first: 3 * 2^2 = 3 * 4 = 12, not 6^2.
