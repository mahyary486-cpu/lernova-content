# Nuclear Reactions and Radioactive Decay

Nuclear equations are balanced like chemical ones, but with nucleons instead of atoms.

## Key ideas
- **Alpha**: **A - 4, Z - 2**; **beta-minus**: **Z + 1**; **positron**: **Z - 1**; **gamma**: no change.
- Balance **A** and **Z** on both sides.
- Penetration: **alpha < beta < gamma**.
- Too many neutrons: **beta-minus**.
- Too few neutrons: **positron emission / electron capture**.
- Stable heavy nuclei have **n / p** about **1.5**.

## Worked examples
**Example 1: Alpha decay.** Write the decay of radium-226 (Z = 88) by alpha emission.
1. A: 226 - 4 = 222; Z: 88 - 2 = 86.
2. 226-Ra -> 222-Rn + 4-He.

**Example 2: Beta decay.** Write the beta-minus decay of carbon-14 (Z = 6).
1. A stays 14; Z becomes 7 (nitrogen).
2. 14-C -> 14-N + e-.

**Example 3: Missing particle.** In 239-Pu -> 235-U + X, what is X?
1. A: 239 - 235 = 4; Z: 94 - 92 = 2.
2. X is an alpha particle.

## Common mistakes
- Not balancing both A and Z.
- Thinking beta decay changes A.
- Mixing up penetration powers.
