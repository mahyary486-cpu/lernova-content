# Replicación, transcripción y traducción

## Flujo de la información
ADN → (replicación) → ADN
ADN → (transcripción) → ARNm → (traducción) → proteína

## Código genético
- Codón = 3 nucleótidos.
- AUG: inicio. UAA, UAG, UGA: terminación.
- 64 codones para 20 aminoácidos (degenerado).

## Ejemplo
ADN: TAC GGT → ARNm: AUG CCA.

## Error frecuente
Creer que el ARN contiene timina.
