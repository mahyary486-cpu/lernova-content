# 导数与函数的零点

## 研究零点个数的步骤

1. 求定义域；
2. 求 f′(x)，判断单调性，找极值；
3. 判断极值的符号和函数在端点（或趋向无穷）的变化趋势；
4. 结合零点存在定理确定零点个数。

## 例题

**例 1：** f(x) = x³ − 3x + m 有三个不同的零点，求 m 的范围。

- f′(x) = 3x² − 3，极大值 f(−1) = 2 + m，极小值 f(1) = −2 + m；
- 要有三个零点，需极大值 > 0 且极小值 < 0：2 + m > 0，−2 + m < 0；
- 所以 −2 < m < 2。

**例 2：** f(x) = ln x − x 的零点个数。

- 定义域 (0, +∞)，f′(x) = 1/x − 1，x = 1 时取极大值（也是最大值）f(1) = −1 < 0；
- 所以 f(x) < 0 恒成立，没有零点，零点个数为 0。

零点问题也可转化为两个函数图象的交点个数问题（数形结合）。
