# 物质的分离与提纯

## 常用方法

| 方法 | 适用对象 |
|---|---|
| 过滤 | 固液分离 |
| 蒸发结晶 | 溶解度受温度影响小的溶质，如 NaCl |
| 冷却结晶（重结晶） | 溶解度受温度影响大的溶质，如 KNO₃ |
| 蒸馏 | 沸点不同的互溶液体 |
| 萃取分液 | 在互不相溶的溶剂中溶解度不同的物质 |
| 洗气 | 气体中的杂质 |

## 萃取分液

- 萃取剂要与原溶剂**互不相溶**，溶质在其中溶解度**更大**，不与溶质反应；
- 例：用 CCl₄ 萃取碘水中的 I₂；
- 分液时，**下层液体从下口放出，上层液体从上口倒出**。

## 除杂原则

**不增、不减、易分离、易复原**。

## 例题

- 除去 CO₂ 中的 HCl：通过饱和 NaHCO₃ 溶液洗气；
- 除去 Na₂CO₃ 固体中的 NaHCO₃：加热；
- 除去 Fe 粉中的少量 Al 粉：加入过量 NaOH 溶液，过滤。

**过滤操作要点**："一贴、二低、三靠"。
