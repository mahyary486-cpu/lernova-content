# 反比例函数中 k 的几何意义

## 矩形面积

设点 P(x, y) 在双曲线 y = k/x 上，过 P 分别作 x 轴、y 轴的垂线，与坐标轴围成的矩形面积是

**S = |x| · |y| = |xy| = |k|**。

## 三角形面积

过 P 作 x 轴的垂线，垂足为 A，则 △POA 的面积是 **|k|/2**。

## 例题

**例 1：** 点 A 在 y = 6/x 上，AB ⊥ x 轴于 B，则 S△AOB = 6/2 = 3。

**例 2：** 点 A 在反比例函数图象上，AB ⊥ x 轴于 B，S△AOB = 4，则 |k| = 8。若图象在第二象限，则 k = −8。

由面积只能求出 |k|，k 的正负要根据图象所在的象限判断。
