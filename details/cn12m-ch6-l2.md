# 中点弦与定值问题

## 点差法

设弦的两个端点 A(x₁, y₁)、B(x₂, y₂) 都在曲线上，把两点的坐标分别代入曲线方程，两式相减，得到与中点坐标、斜率有关的关系式。

椭圆 x²/a² + y²/b² = 1 中，弦中点为 (x₀, y₀)，弦的斜率

**k = −b²x₀ / (a²y₀)**。

## 例题

椭圆 x²/4 + y² = 1，求被点 (1, 1/2) 平分的弦所在的直线方程。

- a² = 4，b² = 1，斜率 k = −1 × 1 / (4 × 1/2) = −1/2；
- 直线：y − 1/2 = −1/2 (x − 1)，即 x + 2y − 2 = 0；
- 检验：直线与椭圆交于 (2, 0) 和 (0, 1)，中点正是 (1, 1/2)。

**注意**：用点差法求出的直线，一定要检验它是否与曲线相交（Δ > 0）。

## 定值问题

设出参数（如直线的斜率），用韦达定理表示相关量，化简后参数消去，结果为常数。
