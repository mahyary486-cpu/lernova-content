# Simplifying rational expressions

A rational expression is a fraction whose numerator and denominator are polynomials, and simplifying it means cancelling common factors until none are left.

## Key ideas

A rational expression has the form P/Q, where P and Q are polynomials and Q is not the zero polynomial. Examples are (x+1)/(x-2) and 5/x^2. It is like a fraction of numbers, but the letters can take many values.

The denominator can never be zero. So we must exclude every value of x that makes the denominator 0. For (x+1)/(x-2), the value x = 2 is not allowed. We often write this restriction next to the answer, for example "x ≠ 2".

To simplify, follow these steps:
1. Factor the numerator and the denominator completely. Use common factors, the difference of squares a^2 - b^2 = (a - b)(a + b), and trinomial factoring.
2. Find the values that make the original denominator zero. These are the restrictions.
3. Cancel factors that appear in both the numerator and the denominator.
4. Write what is left.

Cancelling is allowed only for factors (things that are multiplied). It is never allowed for terms (things that are added or subtracted).

Two expressions that differ only by a sign can be matched using the rule (a - b) = -(b - a). For example, (3 - x)/(x - 3) = -1 for x ≠ 3.

## Worked examples

Example 1. Simplify (6x^2)/(9x).

Step 1: Factor: 6x^2 = 2 · 3 · x · x and 9x = 3 · 3 · x.
Step 2: Restriction: 9x = 0 when x = 0, so x ≠ 0.
Step 3: Cancel 3 and x: (2 · 3 · x · x)/(3 · 3 · x) = 2x/3.
Answer: 2x/3, with x ≠ 0.

Example 2. Simplify (x^2 - 9)/(x^2 - x - 6).

Step 1: Numerator: x^2 - 9 = (x - 3)(x + 3).
Step 2: Denominator: x^2 - x - 6 = (x - 3)(x + 2), because -3 · 2 = -6 and -3 + 2 = -1.
Step 3: Restrictions: the denominator is 0 when x = 3 or x = -2.
Step 4: Cancel (x - 3): the result is (x + 3)/(x + 2).
Check with x = 1: the original gives (1 - 9)/(1 - 1 - 6) = -8/-6 = 4/3, and the answer gives 4/3. 
Answer: (x + 3)/(x + 2), with x ≠ 3 and x ≠ -2.

Example 3. Simplify (x^2 + 5x + 6)/(x^2 - 4).

Step 1: Numerator: x^2 + 5x + 6 = (x + 2)(x + 3), because 2 · 3 = 6 and 2 + 3 = 5.
Step 2: Denominator: x^2 - 4 = (x - 2)(x + 2).
Step 3: Restrictions: x ≠ 2 and x ≠ -2.
Step 4: Cancel (x + 2): the result is (x + 3)/(x - 2).
Check with x = 3: the original gives (9 + 15 + 6)/(9 - 4) = 30/5 = 6, and the answer gives 6/1 = 6.
Answer: (x + 3)/(x - 2), with x ≠ 2 and x ≠ -2.

## Common mistakes

- Cancelling terms instead of factors. For example, (x + 3)/(x + 2) cannot be changed to 3/2 by cancelling x. Only factors can be cancelled.
- Forgetting the restrictions. The restriction comes from the original denominator, even if the factor cancels later.
- Cancelling before factoring. If you do not factor first, you may miss common factors or cancel the wrong parts.
- Losing a sign when the factors are opposites. Remember that (a - b)/(b - a) = -1.

## Remember

- Factor first, then cancel common factors.
- Always state the values that make the original denominator zero.
- A simplified expression must have the same value as the original one for every allowed x.
