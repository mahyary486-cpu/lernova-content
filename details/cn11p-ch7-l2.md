# 变压器

## 理想变压器

没有能量损失的变压器。

- 电压：**U₁ / U₂ = n₁ / n₂**；
- 电流（只有一个副线圈）：**I₁ / I₂ = n₂ / n₁**；
- 功率：**P入 = P出**。

变压器只能改变**交流电**的电压，**不改变频率**。

- n₂ > n₁：升压变压器；n₂ < n₁：降压变压器。

## 例题

n₁ = 1100，n₂ = 110，原线圈电压 U₁ = 220 V：

- 副线圈电压 U₂ = 220 × 110 / 1100 = 22 V；
- 副线圈接 11 Ω 的电阻：I₂ = 22 / 11 = 2 A，P出 = U₂I₂ = 44 W；
- 原线圈电流 I₁ = P入 / U₁ = 44 / 220 = 0.2 A。

## 注意

- 原线圈电压 U₁ 决定副线圈电压 U₂；
- 副线圈电流 I₂（负载）决定原线圈电流 I₁。
