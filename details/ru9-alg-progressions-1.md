# Number sequences

A **number sequence** is a list of numbers a₁, a₂, a₃, … where each number has a position n (its index).

A sequence can be given by a **formula for the nth term**. For aₙ = 2n + 1 we get a₁ = 3, a₂ = 5, …, a₅ = 11.

It can also be given by a **recurrence rule**: the first term and a rule for finding each next term from the previous one. Example: a₁ = 1 and aₙ₊₁ = 2aₙ gives 1, 2, 4, 8, …

A sequence is **increasing** if every term is larger than the previous one, and **decreasing** if every term is smaller.
