# Числовые последовательности

**Числовая последовательность** — это список чисел a₁, a₂, a₃, …, в котором каждое число имеет свой номер n.

Последовательность можно задать **формулой n-го члена**. Для aₙ = 2n + 1 получаем a₁ = 3, a₂ = 5, …, a₅ = 11.

Можно задать её и **рекуррентно**: указать первый член и правило, по которому каждый следующий член находят через предыдущий. Пример: a₁ = 1 и aₙ₊₁ = 2aₙ дают 1, 2, 4, 8, …

Последовательность **возрастающая**, если каждый её член больше предыдущего, и **убывающая**, если каждый член меньше предыдущего.
