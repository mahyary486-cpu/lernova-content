# Produkt-, Quotienten- und Kettenregel

## Produktregel

**(u · v)′ = u′ · v + u · v′**

**Beispiel:** f(x) = x² · sin x.
f′(x) = 2x · sin x + x² · cos x.

**Beispiel:** f(x) = x · eˣ.
f′(x) = eˣ + x · eˣ = (1 + x) · eˣ.

## Quotientenregel

**(u/v)′ = (u′ · v − u · v′) : v²**

**Beispiel:** f(x) = x/(x + 1).
f′(x) = ((x + 1) − x) : (x + 1)² = 1/(x + 1)².

## Kettenregel

**(f(g(x)))′ = f′(g(x)) · g′(x)** (äußere Ableitung mal innere Ableitung)

**Beispiele:**

- (sin(2x))′ = 2 · cos(2x)
- ((x² + 1)³)′ = 6x · (x² + 1)²
- (e²ˣ)′ = 2 · e²ˣ
- (ln(x² + 1))′ = 2x/(x² + 1)
- (√(x² + 1))′ = x/√(x² + 1)
- (sin²x)′ = 2 · sin x · cos x

## Weiteres Beispiel

f(x) = x · ln x.
f′(x) = ln x + x · (1/x) = ln x + 1.
