# Magnetic Force on Currents and Magnetic Fields of Currents

A current in a coil behaves like a bar magnet, and an iron core makes it much stronger.

## Key ideas
- **F = I L B sin(theta)** on a wire.
- Straight wire: **B = mu_0 I / (2 pi r)**; mu_0 = **4 pi x 10^-7 T m/A**.
- Loop center: **B = mu_0 I / (2 R)**.
- Solenoid: **B = mu_0 n I** inside.
- Parallel currents **attract**; opposite currents **repel**.
- Use the **right-hand grip rule** for the field direction.

## Worked examples
**Example 1: Force on a wire.** A 0.5 m wire carrying 4 A is perpendicular to a 0.2 T field.
1. F = I L B = 4 x 0.5 x 0.2.
2. F = 0.4 N.

**Example 2: Field of a wire.** Find the field 0.05 m from a wire carrying 10 A.
1. B = mu_0 I / (2 pi r) = 4 pi x 10^-7 x 10 / (2 pi x 0.05).
2. B = 4 x 10^-5 T.

**Example 3: Solenoid.** A solenoid has 1000 turns per meter and carries 2 A.
1. B = mu_0 n I = 4 pi x 10^-7 x 1000 x 2.
2. B = 2.5 x 10^-3 T.

## Common mistakes
- Using the wrong value for mu_0.
- Forgetting the distance is from the wire.
- Using total turns instead of turns per meter.
