# 元素性质的周期性变化规律

## 电离能

气态基态原子失去一个电子所需的最低能量叫**第一电离能** I₁。

- 同周期从左到右，I₁ 总体呈**增大**趋势；
- 同主族从上到下，I₁ **减小**；
- **反常**：Mg > Al（Mg 的 3s² 全充满），P > S（P 的 3p³ 半充满）。

**例：** 第二周期元素第一电离能顺序：Li < B < Be < C < O < N < F < Ne，最大的是 **Ne**。

## 电负性

原子在化合物中吸引键合电子的能力。

- 同周期从左到右电负性增大，同主族从上到下减小；
- **F 的电负性最大**（4.0）；
- 一般金属电负性小于 1.8，非金属大于 1.8；
- 电负性差大的元素之间形成离子键，差小的形成共价键。

## 对角线规则

处于周期表对角线位置的元素性质相似，如 Li 与 Mg、Be 与 Al。
