# Exponent laws and scientific notation

An **exponent** shows repeated multiplication: 2³ = 2 × 2 × 2 = 8.

**Exponent laws** (same base):

- a^m × a^n = a^(m + n), so 3² × 3⁴ = 3⁶
- a^m ÷ a^n = a^(m − n)
- (a^m)^n = a^(mn)
- a⁰ = 1 for a ≠ 0, so 5⁰ = 1
- a^(−n) = 1 / aⁿ, so 2⁻² = 1/4

**Example.** (2⁵ × 2⁻²) ÷ 2² = 2^(5 − 2 − 2) = 2¹ = 2.

**Scientific notation** writes a number as a × 10ⁿ with 1 ≤ a < 10. For example 6.2 × 10⁴ = 62 000, and 1.2 × 10⁶ = 1 200 000.
