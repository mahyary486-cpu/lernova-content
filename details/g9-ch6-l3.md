# Square Roots and Completing the Square

Some quadratics do not factor nicely. Two methods still work: taking square roots and completing the square.

## Solving by square roots
If x^2 = k with k > 0, then x = sqrt(k) or x = -sqrt(k), written x = plus or minus sqrt(k). If k = 0 there is one solution, 0. If k < 0 there is no real solution.

## Completing the square
To solve x^2 + bx + c = 0:
1. Move c to the right side.
2. Add (b/2)^2 to both sides.
3. The left side becomes (x + b/2)^2.
4. Take square roots and solve.

If a is not 1, divide every term by a first.

## Worked examples
**Example 1.** Solve 2x^2 - 50 = 0.
1. 2x^2 = 50, so x^2 = 25.
2. x = 5 or x = -5.

**Example 2.** Solve (x - 3)^2 = 7.
1. x - 3 = plus or minus sqrt(7).
2. x = 3 + sqrt(7) or x = 3 - sqrt(7).

**Example 3.** Solve x^2 + 6x - 1 = 0 by completing the square.
1. Move the constant: x^2 + 6x = 1.
2. (6/2)^2 = 9. Add 9 to both sides: x^2 + 6x + 9 = 10.
3. Factor: (x + 3)^2 = 10.
4. x + 3 = plus or minus sqrt(10), so x = -3 + sqrt(10) or x = -3 - sqrt(10).

**Example 4.** Solve x^2 - 8x + 5 = 0.
1. x^2 - 8x = -5.
2. (-8/2)^2 = 16, so x^2 - 8x + 16 = 11.
3. (x - 4)^2 = 11, so x = 4 plus or minus sqrt(11).

## Why it works
(x + p)^2 = x^2 + 2px + p^2. The middle coefficient is 2p, so p is half of b and the missing last term is p^2.

## Common mistakes
- Adding (b/2)^2 to only one side.
- Forgetting the minus root when taking a square root.
- Using b instead of b/2: for x^2 + 6x the number to add is 9, not 36 or 6.
- Not dividing by a first when a is not 1.
