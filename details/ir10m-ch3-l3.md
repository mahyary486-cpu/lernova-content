# اتحادها و تجزیه‌ی عبارت‌ها

## این درس درباره‌ی چیست؟

اتحادها فرمول‌هایی هستند که ضرب چند عبارت را سریع بسط می‌دهند و تجزیه یعنی برعکس این کار: نوشتن یک عبارت به صورت حاصل‌ضرب. تجزیه در حل معادله، ساده‌کردن کسرها و پیداکردن ریشه‌ها اساسی است. هر چه اتحادها را بهتر بشناسید، تجزیه آسان‌تر می‌شود.

## اتحادهای اصلی

- مربع مجموع: (a + b)^۲ = a^۲ + ۲ab + b^۲
- مربع تفاضل: (a − b)^۲ = a^۲ − ۲ab + b^۲
- مزدوج (تفاضل دو مربع): (a + b)(a − b) = a^۲ − b^۲
- جمله‌ی مشترک: (x + a)(x + b) = x^۲ + (a + b)x + ab
- مکعب مجموع: (a + b)^۳ = a^۳ + ۳a^۲ b + ۳a b^۲ + b^۳
- مکعب تفاضل: (a − b)^۳ = a^۳ − ۳a^۲ b + ۳a b^۲ − b^۳
- مجموع مکعبات: a^۳ + b^۳ = (a + b)(a^۲ − ab + b^۲)
- تفاضل مکعبات: a^۳ − b^۳ = (a − b)(a^۲ + ab + b^۲)

برای اطمینان از این‌ها، با گذاشتن عددهای کوچک مثل a = ۲ و b = ۱ درستی‌شان را امتحان کنید.

## روش‌های تجزیه

۱. **فاکتورگیری:** اول عامل مشترک همه‌ی جمله‌ها را بیرون بکشید.
۲. **استفاده از اتحاد:** ببینید عبارت شبیه کدام اتحاد است، مثلاً x^۲ − ۴۹ تفاضل دو مربع است.
۳. **تجزیه‌ی سه‌جمله‌ای x^۲ + sx + p:** دو عدد پیدا کنید که حاصل‌ضربشان p و جمعشان s باشد.
۴. **گروه‌بندی:** جمله‌ها را دو به دو دسته کنید و از هر دسته فاکتور بگیرید تا یک عامل مشترک بماند.

همیشه بعد از تجزیه بررسی کنید که آیا هر عامل را می‌توان باز هم تجزیه کرد.

## مثال‌های حل‌شده

**مثال ۱.** عبارت x^۳ − ۸ را تجزیه کنید.
گام ۱: ۸ = ۲^۳، پس این تفاضل مکعبات است با a = x و b = ۲. گام ۲: از فرمول: x^۳ − ۸ = (x − ۲)(x^۲ + ۲x + ۴). گام ۳: عامل دوم تجزیه‌ی بیشتری ندارد، چون دو عدد با حاصل‌ضرب ۴ و جمع ۲ وجود ندارد. پاسخ: (x − ۲)(x^۲ + ۲x + ۴).

**مثال ۲.** عبارت x^۳ + x^۲ − ۴x − ۴ را با گروه‌بندی تجزیه کنید.
گام ۱: دو جمله‌ی اول و دو جمله‌ی آخر را دسته می‌کنیم: (x^۳ + x^۲) + (-۴x − ۴). گام ۲: از دسته‌ی اول x^۲ و از دسته‌ی دوم -۴ فاکتور می‌گیریم: x^۲(x + ۱) − ۴(x + ۱). گام ۳: عامل مشترک (x + ۱) را بیرون می‌کشیم: (x + ۱)(x^۲ − ۴). گام ۴: x^۲ − ۴ هم تفاضل مربع‌هاست: (x − ۲)(x + ۲). پاسخ: (x + ۱)(x − ۲)(x + ۲).

**مثال ۳.** عبارت (۲x − ۳)^۳ را بسط دهید.
گام ۱: از اتحاد مکعب تفاضل با a = ۲x و b = ۳: a^۳ = ۸x^۳ و ۳a^۲ b = ۳ × ۴x^۲ × ۳ = ۳۶x^۲ و ۳ab^۲ = ۳ × ۲x × ۹ = ۵۴x و b^۳ = ۲۷. گام ۲: علامت‌ها یک‌درمیان منفی و مثبت‌اند. پاسخ: ۸x^۳ − ۳۶x^۲ + ۵۴x − ۲۷.

## اشتباه‌های رایج و دلیلشان

- **نوشتن (a + b)^۲ = a^۲ + b^۲:** جمله‌ی میانی ۲ab فراموش شده است. با a = ۱ و b = ۲ امتحان کنید: ۹ در برابر ۵.
- **اشتباه در علامت‌های اتحاد مجموع و تفاضل مکعبات:** در عامل دوم، علامت بین a^۲ و ab برعکس علامت عامل اول و علامت آخر همیشه مثبت است.
- **متوقف‌شدن قبل از تجزیه‌ی کامل:** هر عامل را دوباره بررسی کنید.

## جمع‌بندی

اتحادها بسط و تجزیه را سریع می‌کنند. برای تجزیه ابتدا فاکتورگیری کنید، بعد اتحاد را بشناسید، سپس سه‌جمله‌ای را با جمع و ضرب دو عدد تجزیه کنید و در صورت لزوم گروه‌بندی کنید.
