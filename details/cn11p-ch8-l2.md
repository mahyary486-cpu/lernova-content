# 气体实验定律

一定质量的气体，压强 p、体积 V、热力学温度 T 之间的关系。

热力学温度：**T = t + 273**（单位 K）。

## 三个实验定律

- **玻意耳定律**（等温）：**pV = 常量**，p₁V₁ = p₂V₂；
- **查理定律**（等容）：**p / T = 常量**；
- **盖 - 吕萨克定律**（等压）：**V / T = 常量**。

## 理想气体状态方程

**p₁V₁ / T₁ = p₂V₂ / T₂**

## 例题

**例 1（等温）：** p₁ = 1 atm，V₁ = 6 L，压缩到 V₂ = 2 L：

p₂ = p₁V₁ / V₂ = 1 × 6 / 2 = 3 atm。

**例 2（等容）：** 27℃（300 K）时 p₁ = 1 atm，升温到 127℃（400 K）：

p₂ = p₁ T₂ / T₁ = 1 × 400 / 300 = 4/3 atm。

## 注意

计算时，温度必须用**热力学温度**（K），不能直接用摄氏温度。
