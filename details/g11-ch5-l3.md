# Logarithms and Logarithmic Functions

## Definition
A **logarithm** answers the question: "what exponent do I need?"

**log_b(x) = y means b^y = x** (b > 0, b is not 1, x > 0)

Examples:
- log_2(8) = 3, because 2^3 = 8.
- log_10(1000) = 3, because 10^3 = 1000.
- log_5(1/25) = -2, because 5^(-2) = 1/25.
- log_b(1) = **0**, and log_b(b) = **1**, for any base b.

## Special logarithms
- **Common logarithm:** log(x) means log_10(x).
- **Natural logarithm:** ln(x) means log_e(x). So ln(e) = 1 and ln(1) = 0.

## Converting between forms
- 3^4 = 81 is the same as log_3(81) = 4.
- log_7(49) = 2 is the same as 7^2 = 49.
- ln(x) = 5 is the same as x = e^5.

## Inverse functions
Logarithms and exponentials **undo each other**:
- log_b(b^x) = x
- b^(log_b(x)) = x
So f(x) = 2^x and g(x) = log_2(x) are inverses. Their graphs are reflections over **y = x**.

## The graph of y = log_b(x) (b > 1)
- Domain: **x > 0**. Range: all real numbers.
- x-intercept: **(1, 0)**.
- Vertical asymptote: **x = 0** (the y-axis).
- It passes through (b, 1) and rises slowly.

## Transformations
y = log_2(x - 3) + 1 is shifted right 3 and up 1. The vertical asymptote moves to **x = 3**, and the domain is **x > 3**.

## Worked examples
1. log_3(81) = **4**, because 3^4 = 81.
2. Solve log_2(x) = 5. Then x = 2^5 = **32**.
3. Domain of log(x - 4): x - 4 > 0, so **x > 4**.
4. Find the inverse of f(x) = 3^x: it is **f^-1(x) = log_3(x)**.

## Common mistakes
- Trying to take the log of 0 or a negative number. It is not defined (in the real numbers).
- Mixing up the base and the answer when converting forms. The base stays the base.
- Thinking log(x) means log_e. The common log is base 10; ln is base e.
