# Ecuaciones exponenciales y logarítmicas

## Exponenciales
- Igualando bases: 2^(x+1) = 32 → 2^(x+1) = 2⁵ → x + 1 = 5 → x = 4.
- Con logaritmos: 3ˣ = 20 → x = log 20 / log 3 ≈ 2,73.

## Logarítmicas
log₂(x + 1) = 4 → x + 1 = 2⁴ = 16 → x = 15.

## Verificación
Siempre hay que comprobar que el argumento sea positivo. En log(x) + log(x − 3) = 1 se descartan los x ≤ 3.

## Aplicación: interés compuesto
$20 000 al 10 % anual durante 2 años: M = 20 000 · 1,1² = $24 200.
