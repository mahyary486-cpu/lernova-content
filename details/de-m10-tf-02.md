# Sinus- und Kosinusfunktion

## Eigenschaften

- **Periode:** 2π, das heißt sin(x + 2π) = sin x
- **Wertebereich:** −1 ≤ y ≤ 1
- Nullstellen von sin x: 0, π, 2π, … (allgemein k · π)
- Nullstellen von cos x: π/2, 3π/2, … (allgemein π/2 + k · π)

## Symmetrie

- sin(−x) = −sin x, der Graph ist **punktsymmetrisch zum Ursprung**.
- cos(−x) = cos x, der Graph ist **achsensymmetrisch zur y-Achse**.

## Zusammenhänge

- **sin²x + cos²x = 1** (Satz des Pythagoras am Einheitskreis)
- **tan x = sin x : cos x**
- cos(x − π/2) = sin x, die Kosinuskurve ist eine um π/2 nach rechts verschobene Sinuskurve.

## Tangens

Der Tangens ist dort nicht definiert, wo cos x = 0 gilt, also bei x = π/2 + k · π. Es gilt tan(π/4) = 1.

## Beispiel

Gegeben sei sin x = 3/5 mit x im ersten Quadranten.
cos²x = 1 − 9/25 = 16/25, also cos x = 4/5.
tan x = (3/5) : (4/5) = 3/4.
