# Inequalities in two variables

The line ax + by = c divides the plane into two half-planes. To graph ax + by ≤ c, draw the line (solid for ≤ and ≥, dotted for < and >) and shade the side that contains a test point such as (0, 0) if it satisfies the inequality.

Example: (3, 3) satisfies x + y ≥ 4.
