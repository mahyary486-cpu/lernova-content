# 空间向量及其运算

## 空间向量

在空间中，具有大小和方向的量叫空间向量。平面向量的加法、减法、数乘运算及其运算律，可以推广到空间。

- **共线向量**：a ∥ b（b ≠ 0）⇔ 存在实数 λ，使 a = λb；
- **共面向量**：p 与不共线的 a、b 共面 ⇔ p = xa + yb。

## 数量积

**a · b = |a||b| cos⟨a, b⟩**。

## 坐标运算

设 a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)：

- a · b = **x₁x₂ + y₁y₂ + z₁z₂**；
- |a| = √(x₁² + y₁² + z₁²)；
- 夹角：cos⟨a, b⟩ = a · b / (|a||b|)；
- a ⊥ b ⇔ a · b = 0；a ∥ b ⇔ a = λb。

## 例题

**例 1：** a = (1, 2, 2)，b = (2, −1, 0)：a · b = 2 − 2 + 0 = 0，所以 a ⊥ b；|a| = √(1 + 4 + 4) = 3。

**例 2：** A(1, 0, 0)，B(1, 2, 2)：|AB| = √(0 + 4 + 4) = 2√2。
