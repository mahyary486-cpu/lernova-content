# Электромагнитные волны

**Электромагнитная волна** — распространяющееся в пространстве изменяющееся электромагнитное поле. Существование таких волн предсказал Максвелл, а Герц получил их на опыте.

**Скорость в вакууме** c = 3 · 10⁸ м/с. Для любой волны c = λ · ν.

**Примеры.** Радиостанция с частотой 100 МГц (10⁸ Гц) излучает волны длиной λ = 3 · 10⁸ / 10⁸ = 3 м. Если радиолокационный сигнал вернулся через 2 · 10⁻⁴ с, расстояние до цели s = c · t / 2 = 30 км.

**Шкала волн** по возрастанию частоты: радиоволны, инфракрасное, видимый свет, ультрафиолетовое, рентгеновское, гамма-излучение. Наибольшую длину волны имеют радиоволны.
