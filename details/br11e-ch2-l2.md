# Third conditional

## Uso

Para situações **irreais no passado**, imaginando como as coisas teriam sido diferentes. É muito usado para expressar **arrependimento**.

## Estrutura

**If + past perfect, would have + particípio passado**

- If I **had studied**, I **would have passed** the exam.
- If it **hadn't rained**, we **would have gone** to the beach.
- If we **had left** earlier, we **would have caught** the train.
- If she **had known**, she **would have told** us.

## Atenção

- Não se usa *would have* na oração do *if*: *If they would have called* é erro.
- O significado é o oposto do que aconteceu: *I would have helped if you had asked* quer dizer que você não pediu e eu não ajudei.

## Comparação

- **Zero:** If you heat ice, it melts.
- **First:** If it rains, I will stay home.
- **Second:** If I had wings, I would fly.
- **Third:** If I had studied, I would have passed.
