# Law of Cosines

## The idea
The Law of Cosines generalizes the Pythagorean theorem to any triangle:

**c^2 = a^2 + b^2 - 2ab cos C**

The same pattern works for the other sides: a^2 = b^2 + c^2 - 2bc cos A and b^2 = a^2 + c^2 - 2ac cos B.

## Key ideas
- Use it for **SAS** (find the third side) and **SSS** (find an angle).
- Solving for an angle: **cos C = (a^2 + b^2 - c^2) / (2ab)**.
- If C = 90 degrees, cos C = 0 and the law becomes c^2 = a^2 + b^2.
- If cos C is negative, the angle is obtuse.
- Find the largest angle first (opposite the longest side); then the Law of Sines is safe for the rest.
- **Heron's formula:** with s = (a + b + c)/2, Area = sqrt(s(s - a)(s - b)(s - c)).

## Worked example 1: SAS
a = 5, b = 8, C = 60 degrees. Find c.
1. c^2 = 25 + 64 - 2(5)(8) cos 60.
2. = 89 - 80(0.5) = 49.
3. c = 7.

## Worked example 2: SSS
Sides 5, 7, 8. Find the angle B opposite the side 7.
1. cos B = (5^2 + 8^2 - 7^2) / (2 * 5 * 8).
2. = (25 + 64 - 49)/80 = 40/80 = 0.5.
3. B = 60 degrees.

## Worked example 3: Heron's formula
Sides 13, 14, 15.
1. s = (13 + 14 + 15)/2 = 21.
2. Area = sqrt(21 * 8 * 7 * 6) = sqrt(7056).
3. Area = 84 square units.

## Common mistakes
- Dropping the 2 or the minus sign in -2ab cos C.
- Squaring wrongly: the whole right side is under c^2, then take a square root at the end.
- Using the wrong angle: C must be the angle opposite c.
- In Heron's formula, forgetting that s is the half-perimeter, not the perimeter.
