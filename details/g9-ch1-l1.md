# Real Numbers and Their Properties

## The number families
- **Natural numbers:** 1, 2, 3, ...
- **Whole numbers:** 0, 1, 2, 3, ...
- **Integers:** ..., -2, -1, 0, 1, 2, ...
- **Rational numbers:** any number that can be written as a fraction of two integers (denominator not zero). Their decimals end (0.75) or repeat (0.333...).
- **Irrational numbers:** decimals that never end and never repeat, such as the square root of 2 and pi.
- **Real numbers:** all rational and irrational numbers together.

Every natural number is a whole number, every whole number is an integer, and every integer is rational.

## Properties of real numbers
| Property | Addition | Multiplication |
|---|---|---|
| Commutative | a + b = b + a | a x b = b x a |
| Associative | (a + b) + c = a + (b + c) | (a x b) x c = a x (b x c) |
| Identity | a + 0 = a | a x 1 = a |
| Inverse | a + (-a) = 0 | a x (1/a) = 1 (a not zero) |

**Distributive property:** a(b + c) = ab + ac. It links multiplication and addition.

## Absolute value
The absolute value of a number is its distance from 0 on the number line. It is written with two bars and is never negative: the absolute value of -9 is 9, and the absolute value of 9 is 9.

## Worked examples
1. Is 0.75 rational? Yes, 0.75 = 3/4.
2. Which property is used in 7 + (3 + 5) = (7 + 3) + 5? The associative property of addition.
3. The multiplicative inverse of 2/3 is 3/2, because 2/3 x 3/2 = 1.

## Common mistakes
- Thinking a negative number has no absolute value. It does, and the result is positive.
- Mixing up commutative (order) and associative (grouping).
- Calling every decimal irrational. Only decimals that never end and never repeat are irrational.
