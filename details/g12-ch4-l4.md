# Graphs of Sine and Cosine

The graphs of y = sin x and y = cos x are smooth waves that repeat every 2pi. Sine starts at (0, 0) and rises; cosine starts at its maximum (0, 1).

## Key ideas
The general form is **y = A sin(B(x - C)) + D** (or cosine).
- **Amplitude** = |A|, the distance from the midline to a peak.
- **Period** = 2pi / |B|, the length of one full cycle.
- **Phase shift** = C. The graph moves right if C > 0 and left if C < 0.
- **Vertical shift** = D. The midline is y = D.
- Maximum = D + |A| and minimum = D - |A|.
- If A is negative, the graph is reflected over its midline.
- To read a phase shift from y = sin(Bx - E), factor: Bx - E = B(x - E/B), so the shift is E/B.

## Five key points
Divide one period into four equal parts. The five points show: start, quarter, half, three-quarter and end of a cycle. For sine the pattern is midline, max, midline, min, midline.

## Worked examples
**Example 1.** Describe y = 3 sin(2x).
1. Amplitude = 3.
2. Period = 2pi / 2 = pi.
3. Range is from -3 to 3, with no shifts.

**Example 2.** Describe y = -2 cos(x - pi/2) + 1.
1. Amplitude 2, period 2pi, shifted right pi/2, midline y = 1.
2. The negative sign reflects the wave.
3. Maximum = 1 + 2 = 3, minimum = 1 - 2 = -1.

**Example 3.** Write a cosine function with maximum 5, minimum -1, period 8, starting at a maximum when x = 0.
1. Midline D = (5 + (-1)) / 2 = 2 and amplitude A = (5 - (-1)) / 2 = 3.
2. B = 2pi / 8 = pi/4.
3. y = 3 cos(pi x / 4) + 2. Check: at x = 0, y = 3 + 2 = 5, a maximum.

## Common mistakes
- Using B as the period. The period is 2pi / B.
- Reading y = sin(2x - pi) as a shift of pi. The shift is pi/2.
- Forgetting that the vertical shift moves the midline, not the amplitude.
- Calling the amplitude the full height from minimum to maximum. It is half of that.
