# Interference and Young's Double Slit

The colors of a soap bubble come from interference of light waves reflected from its two surfaces.

## Key ideas
- **Bright fringes**: **d sin(theta) = m lambda**.
- **Dark fringes**: **d sin(theta) = (m + 1/2) lambda**.
- Fringe spacing: **delta y = lambda L / d**.
- Light from the two slits must be **coherent**.
- A **phase change of 180 degrees** occurs on reflection from a higher-index medium.
- Thin films and **anti-reflection coatings** use interference.

## Worked examples
**Example 1: Fringe spacing.** Slits 0.2 mm apart, screen 2.0 m away, lambda = 600 nm.
1. delta y = lambda L / d = 600 x 10^-9 x 2.0 / 2 x 10^-4.
2. delta y = 6 x 10^-3 m = 6 mm.

**Example 2: Finding the wavelength.** The fringe spacing is 1.2 mm for d = 0.5 mm and L = 1.0 m.
1. lambda = delta y d / L = 1.2 x 10^-3 x 5 x 10^-4 / 1.0.
2. lambda = 6.0 x 10^-7 m = 600 nm.

**Example 3: Dark fringe.** At which path difference does the first dark fringe occur?
1. Dark fringes need a half-integer number of wavelengths.
2. Path difference = lambda / 2.

## Common mistakes
- Using millimeters for the slit spacing without converting.
- Forgetting the half wavelength for dark fringes.
- Using incoherent sources.
