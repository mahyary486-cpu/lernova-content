# Азот и его соединения

**Азот N₂** составляет около 78 % объёма воздуха. Он химически малоактивен из-за прочной тройной связи в молекуле.

**Аммиак NH₃** — бесцветный газ с резким запахом, хорошо растворимый в воде. Получение: N₂ + 3H₂ → 2NH₃. Из 4 моль аммиака нужно 6 моль водорода, а из 28 г азота (1 моль) получается 2 моль, то есть 34 г NH₃.

С хлороводородом аммиак даёт соль: NH₃ + HCl → NH₄Cl.

**Азотная кислота HNO₃** — сильная кислота. Её соли — нитраты.

Азот входит в состав азотных удобрений.
