# 排列与组合

## 排列

从 n 个不同元素中取出 m 个元素，**按顺序**排成一列：

**Aₙᵐ = n(n − 1)(n − 2)…(n − m + 1) = n! / (n − m)!**

例：A₅² = 5 × 4 = 20；n 个元素全排列 Aₙⁿ = n!，如 A₅⁵ = 120。

## 组合

从 n 个不同元素中取出 m 个元素，**不考虑顺序**并成一组：

**Cₙᵐ = Aₙᵐ / m! = n! / (m!(n − m)!)**

- Cₙᵐ = Cₙⁿ⁻ᵐ；
- Cₙᵐ + Cₙᵐ⁻¹ = Cₙ₊₁ᵐ。

例：C₅² = 5 × 4 / 2 = 10。

## 区分

与顺序**有关**用排列，与顺序**无关**用组合。

## 常用技巧

- **相邻**问题：捆绑法；
- **不相邻**问题：插空法。

**例：** 3 名男生、2 名女生排成一排，2 名女生必须相邻：把 2 名女生捆成一个整体，4 个元素全排列 4!，女生内部 2!，共 4! × 2! = 48 种。
