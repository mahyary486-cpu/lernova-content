# 导数的应用

## 闭区间上的最值

函数 f(x) 在闭区间 [a, b] 上连续时：

1. 求 f′(x) = 0 的点；
2. 求这些点和端点 a、b 处的函数值；
3. 比较，最大的是最大值，最小的是最小值。

**例：** f(x) = x³ − 3x 在 [0, 2] 上：f(0) = 0，f(1) = −2，f(2) = 2。

最大值为 2，最小值为 −2。

## 优化问题

**例：** 用总长 12 m 的材料做一个长方体框架（底面是正方形），设底面边长为 x，高为 h：

- 8x + 4h = 12，所以 h = 3 − 2x（0 < x < 3/2）；
- 体积 V = x²h = 3x² − 2x³；
- V′ = 6x − 6x² = 6x(1 − x)，令 V′ = 0，得 x = 1；
- 0 < x < 1 时 V′ > 0，1 < x < 3/2 时 V′ < 0，所以 x = 1 时 V 最大，V = 1 m³。

## 步骤

设变量 → 列函数 → 求导 → 找最值点 → 作答。注意定义域。
