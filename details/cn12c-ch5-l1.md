# 热化学与盖斯定律综合

## 热化学方程式回顾

- 注明聚集状态和 ΔH；
- ΔH 与化学计量数成正比；
- 燃烧热：1 mol 纯物质完全燃烧生成指定产物放出的热量。

## 例题

**例 1：** CH₄(g) + 2O₂(g) = CO₂(g) + 2H₂O(l)　ΔH = −890.3 kJ/mol

燃烧 8 g CH₄（0.5 mol），放出热量 0.5 × 890.3 = **445.15 kJ**。

**例 2（盖斯定律）：** 已知

- ① N₂(g) + O₂(g) = 2NO(g)　ΔH₁ = +180 kJ/mol；
- ② 2NO(g) + O₂(g) = 2NO₂(g)　ΔH₂ = −114 kJ/mol。

求 N₂(g) + 2O₂(g) = 2NO₂(g) 的 ΔH：

①+② 得目标反应，ΔH = 180 + (−114) = **+66 kJ/mol**。

## 技巧

- 目标反应中的物质，在已知方程式中**只出现一次**的，先确定它的系数和方向；
- 方程式相加，ΔH 相加；反写，ΔH 变号；乘系数，ΔH 也乘。

## 键能与反应热

ΔH = 反应物键能总和 − 生成物键能总和。
