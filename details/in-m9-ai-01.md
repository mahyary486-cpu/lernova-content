# Expressions, equations and identities

An equation such as x + 2 = 5 is true only for certain values of x. An identity is true for all values of the variables; for example (x + 1)² = x² + 2x + 1.

To factorise an expression, write it as a product of simpler expressions: 2x + 4 = 2(x + 2). Always look first for a common factor, then for an identity.
