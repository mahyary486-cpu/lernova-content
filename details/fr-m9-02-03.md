# Racine carrée d’un nombre positif

## Définition
Soit a un nombre positif. La racine carrée de a, notée √a, est le nombre positif dont le carré est égal à a.
Exemples : √49 = 7 car 7² = 49 ; √0 = 0 ; √1 = 1.

## Carrés parfaits à connaître
1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225.

## Propriétés
- Pour a positif : (√a)² = a et √(a²) = a.
- Un nombre négatif n’a pas de racine carrée : √(−4) n’existe pas.
- Si √a n’est pas un entier ni une fraction, c’est un nombre irrationnel : par exemple √2 ≈ 1,414 et √3 ≈ 1,732.

## Équation x² = a
- Si a > 0 : deux solutions, √a et −√a.
- Si a = 0 : une solution, 0.
- Si a < 0 : aucune solution.
Exemple : x² = 25 a pour solutions 5 et −5.

## Valeurs approchées
La calculatrice donne des valeurs approchées. Pour √2 on peut écrire √2 ≈ 1,41 (arrondi au centième). Pour un résultat exact, on garde l’écriture √2.

## Erreur fréquente
√16 = 4 et non ±4 : le symbole √ désigne toujours le nombre positif.
