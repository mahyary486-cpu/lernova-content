# Multi-Step Equations and Variables on Both Sides

## A reliable plan
1. Distribute and remove parentheses.
2. Combine like terms on each side.
3. Move variable terms to one side (add or subtract).
4. Move number terms to the other side.
5. Divide to finish, then check.

## Worked examples
**Example 1.** 3x + 5 = x + 13
Subtract x: 2x + 5 = 13. Subtract 5: 2x = 8. Divide by 2: x = 4.

**Example 2.** 2(x - 3) = 10
Divide by 2: x - 3 = 5. Add 3: x = 8.

**Example 3.** 4(x + 1) = 2(x + 7)
Distribute: 4x + 4 = 2x + 14. Subtract 2x: 2x + 4 = 14. Subtract 4: 2x = 10. So x = 5.

**Example 4.** (x + 1) / 3 = 4
Multiply by 3: x + 1 = 12. So x = 11.

## Special cases
**No solution.** 3(2x - 1) = 6x + 4 becomes 6x - 3 = 6x + 4. Subtract 6x: -3 = 4, which is false. No value of x works.

**Infinitely many solutions.** 2(x + 4) = 2x + 8 becomes 2x + 8 = 2x + 8. Subtract 2x: 8 = 8, which is always true. Every value of x works.

## Decimals
0.5x + 2 = 0.25x + 5. Subtract 0.25x: 0.25x + 2 = 5. Subtract 2: 0.25x = 3. Divide by 0.25: x = 12.

## Common mistakes
- Forgetting to distribute to every term in the parentheses.
- Moving a term to the other side without changing its sign.
- Thinking "no solution" means the answer is 0. It means no number makes the equation true.
