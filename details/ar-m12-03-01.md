# Crecimiento, decrecimiento y extremos

## Signo de f'
- f' > 0: creciente.
- f' < 0: decreciente.

## Puntos críticos
f'(x) = 0. Se clasifican con el signo de f'' o con el cambio de signo de f'.

## Ejemplo
f(x) = x² − 6x + 5: f'(x) = 2x − 6 = 0 → x = 3 (mínimo, f(3) = −4).

## Error frecuente
Creer que f'(a) = 0 siempre implica máximo o mínimo.
