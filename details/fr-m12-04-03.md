# Dérivée seconde et convexité

## Dérivée seconde
La dérivée seconde f’’ est la dérivée de f’.
Exemples : f(x) = x³ donne f’(x) = 3x² et f’’(x) = 6x. f(x) = e^x donne f’’(x) = e^x. f(x) = ln x donne f’(x) = 1/x et f’’(x) = −1/x².

## Convexité
- f est convexe sur I si f’ est croissante sur I, c’est-à-dire f’’ ≥ 0 : la courbe est située au-dessus de chacune de ses tangentes.
- f est concave sur I si f’ est décroissante sur I, c’est-à-dire f’’ ≤ 0 : la courbe est au-dessous de ses tangentes.

## Exemples
- f(x) = x² : f’’(x) = 2 > 0, convexe sur ℝ.
- f(x) = e^x : f’’(x) = e^x > 0, convexe sur ℝ.
- f(x) = ln x : f’’(x) = −1/x² < 0, concave sur ]0 ; +∞[.
- f(x) = x³ : f’’(x) = 6x, concave sur ]−∞ ; 0] et convexe sur [0 ; +∞[.
- f(x) = x⁴ : f’’(x) = 12x² ≥ 0, convexe sur ℝ.

## Conséquence
Si f est convexe, f(x) ≥ f(a) + f’(a)(x − a). Pour f = e^x en 0 : e^x ≥ x + 1.

## Erreur fréquente
Confondre « f croissante » (f’ ≥ 0) et « f convexe » (f’’ ≥ 0).
