# Уравнение касательной

Касательная к графику функции y = f(x) в точке с абсциссой a задаётся уравнением

y = f(a) + f′(a)(x − a).

**Алгоритм.**

1. Найдите f(a).
2. Найдите f′(x) и вычислите f′(a).
3. Подставьте значения в формулу.

**Пример.** Для f(x) = x² и a = 1: f(1) = 1 и f′(1) = 2, поэтому y = 1 + 2(x − 1) = 2x − 1.

Если f′(a) = 0, касательная горизонтальна. Для f(x) = x³ − 3x это происходит там, где 3x² − 3 = 0, то есть при x = 1 и x = −1. Угловой коэффициент касательной к y = x³ в точке x = −2 равен 3 · 4 = 12.
