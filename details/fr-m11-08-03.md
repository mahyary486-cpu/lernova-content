# Suites et algorithmes de seuil en Python

## Calculer un terme
Pour u_0 = 1 et u_(n+1) = 2u_n + 1 :
u = 1
for i in range(3):
    u = 2 * u + 1
Après 3 passages, u vaut 15 (valeurs 3, 7, 15).

## Somme de termes
Pour u_n = 2n + 1, la somme de u_0 à u_4 :
s = 0
for n in range(5):
    s = s + 2 * n + 1
s vaut 1 + 3 + 5 + 7 + 9 = 25.

## Algorithme de seuil
Trouver le plus petit n tel que u_n > 100 avec u_0 = 2 et u_(n+1) = 3u_n − 1 :
u = 2
n = 0
while u <= 100:
    u = 3 * u - 1
    n = n + 1
Les valeurs de u sont 5, 14, 41, 122 : n vaut 4 à la fin.

## Seuil descendant
u = 100 ; n = 0 ; tant que u > 10 : u = u/2 ; n = n + 1. Les valeurs sont 50, 25, 12,5 et 6,25 : n vaut 4.

## Comme fonction
def seuil(S):
    u = 1
    n = 0
    while u < S:
        u = 2 * u
        n = n + 1
    return n
seuil(50) vaut 6 (64 est la première puissance de 2 supérieure ou égale à 50).

## Éviter la boucle infinie
Dans while n < 10, la variable n doit être modifiée dans la boucle.

## Erreur fréquente
Confondre « tant que u ≤ seuil » (condition de poursuite) avec « u > seuil » (condition d’arrêt).
