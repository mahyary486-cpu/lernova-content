# Limite d’une suite et suites de référence

## Idées
- (u_n) converge vers ℓ si u_n se rapproche de ℓ autant qu’on veut quand n devient grand ; on écrit lim(n→+∞) u_n = ℓ. La limite est unique.
- (u_n) tend vers +∞ si u_n dépasse tout nombre donné à partir d’un certain rang.
- Une suite qui ne converge pas est dite divergente.

## Suites de référence
- lim n = +∞, lim n² = +∞, lim √n = +∞.
- lim 1/n = 0, lim 1/n² = 0, lim 1/√n = 0.

## Suites géométriques q^n
- q > 1 : lim q^n = +∞ (par exemple 2^n).
- q = 1 : lim q^n = 1.
- −1 < q < 1 : lim q^n = 0 (par exemple (1/2)^n et (−0,5)^n).
- q ≤ −1 : pas de limite (par exemple (−1)^n qui vaut 1, −1, 1, −1…).

## Exemples
- lim (3 + 1/n) = 3.
- lim (2 − 3/n²) = 2.
- lim 1000 × 1,02^n = +∞ (un capital placé à 2 % par an croît indéfiniment).

## Remarque
Une suite convergente est bornée. La réciproque est fausse : (−1)^n est bornée mais diverge.

## Erreur fréquente
Une suite qui n’a pas de limite finie n’est pas forcément « qui tend vers l’infini » : (−1)^n n’a aucune limite.
