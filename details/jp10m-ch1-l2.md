# 実数と絶対値・平方根

## 実数の分類

実数は有理数（分数で表せる数）と無理数（分数で表せない数）に分けられます。循環小数は有理数です。

**例：** 0.272727… = 27/99 = 3/11

## 絶対値

|a| は数直線上の原点からの距離です。a ≧ 0 のとき |a| = a、a < 0 のとき |a| = −a。

- |x| = k（k > 0）のとき x = ±k
- |x| < k のとき −k < x < k、|x| > k のとき x < −k、k < x

## 根号を含む計算

- 分母の有理化：1/(√a + √b) = (√a − √b)/(a − b)
- 二重根号：√(a + b + 2√(ab)) = √a + √b（a > 0、b > 0）

**例：** √(5 + 2√6) = √3 + √2

**例：** x + 1/x = 3 のとき x² + 1/x² = 3² − 2 = 7
