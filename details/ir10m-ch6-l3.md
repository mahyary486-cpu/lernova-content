# ترکیب

## این درس درباره‌ی چیست؟

وقتی فقط انتخاب مهم است و ترتیب مهم نیست (مثل انتخاب ۳ نفر برای یک تیم)، از ترکیب استفاده می‌کنیم.

## تعریف و فرمول

تعداد روش انتخاب r شیء از n شیء متمایز، بدون توجه به ترتیب:

**C(n, r) = n! / (r! (n − r)!)**

رابطه با جایگشت: P(n, r) = C(n, r) × r! ، چون هر انتخاب را r! طور می‌توان چید.

**مثال ۱:** از ۵ نفر ۳ نفر را برای یک کمیته انتخاب می‌کنیم:
C(۵، ۳) = ۵!/(۳! × ۲!) = ۱۲۰/(۶ × ۲) = ۱۰.

**مثال ۲:** از ۶ دانش‌آموز ۲ نفر برای دست‌دادن با هم: C(۶، ۲) = ۱۵.

## ویژگی‌ها

- **C(n, r) = C(n, n − r)** (انتخاب r نفر یعنی کنار گذاشتن n − r نفر). مثلاً C(۱۰، ۸) = C(۱۰، ۲) = ۴۵.
- **C(n, ۰) = C(n, n) = ۱** و **C(n, ۱) = n**.
- تعداد همه‌ی زیرمجموعه‌های مجموعه‌ی n عضوی ۲ⁿ است.
- **قانون پاسکال:** C(n, r) = C(n − ۱، r − ۱) + C(n − ۱، r).

## مسئله‌ی ترکیبی

**مثال:** از ۴ دختر و ۳ پسر، کمیته‌ای ۳ نفره با ۲ دختر و ۱ پسر چند حالت دارد؟
C(۴، ۲) × C(۳، ۱) = ۶ × ۳ = ۱۸.

«حداقل» و «حداکثر» را معمولاً با جمع حالت‌ها یا با متمم (کل − ناخواسته) حل می‌کنیم.

## تفاوت ترکیب و جایگشت

- ترتیب مهم است (رتبه‌ها، رمز، صف) → جایگشت.
- ترتیب مهم نیست (گروه، کمیته، دست کارت) → ترکیب.

## جمع‌بندی

C(n, r) = n!/(r!(n − r)!) تعداد انتخاب‌های بدون ترتیب است. C(n, r) = C(n, n − r) و تعداد زیرمجموعه‌های n عضوی ۲ⁿ است.
