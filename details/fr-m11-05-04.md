# Équations trigonométriques simples

## Résultats généraux (k entier relatif)
- cos x = cos a équivaut à x = a + 2kπ ou x = −a + 2kπ.
- sin x = sin a équivaut à x = a + 2kπ ou x = π − a + 2kπ.

## Résolution sur [0 ; 2π]
- cos x = 1/2 : cos(π/3) = 1/2, donc x = π/3 ou x = 5π/3 (car −π/3 + 2π = 5π/3).
- sin x = 1/2 : sin(π/6) = 1/2, donc x = π/6 ou x = π − π/6 = 5π/6.
- cos x = 0 : x = π/2 ou x = 3π/2.
- sin x = −1 : x = 3π/2.
- cos x = 1 : x = 0 ou x = 2π.
- sin x = −√2/2 : x = 5π/4 ou x = 7π/4.

## Méthode
1. On reconnaît une valeur remarquable.
2. On écrit l’équation sous la forme cos x = cos a ou sin x = sin a.
3. On applique les formules et on garde les solutions de l’intervalle demandé.

## Remarque
Une équation comme cos x = 2 n’a pas de solution, car cos x est toujours dans [−1 ; 1].

## Vérification avec le cercle
On trace la droite verticale x = 1/2 (pour cos x = 1/2) : elle coupe le cercle en deux points, ce qui donne deux solutions sur [0 ; 2π].

## Erreur fréquente
Oublier la deuxième famille de solutions : un cosinus (ou un sinus) donné est atteint deux fois par tour.
