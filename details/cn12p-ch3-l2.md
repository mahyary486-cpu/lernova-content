# 机械能守恒的综合应用

## 条件

只有**重力或弹力**做功（可以有其他力，但不做功）。

## 表达式

**Eₖ₁ + Eₚ₁ = Eₖ₂ + Eₚ₂**，或 ΔEₖ = −ΔEₚ。

## 系统的机械能守恒

连接体（如用绳连接的两个物体）、物体与弹簧组成的系统，**单个物体**的机械能可能不守恒，但**系统**的机械能守恒。

## 例题（g = 10 m/s²）

**例 1：** 小球从光滑圆弧（半径 R = 1.25 m）顶端静止下滑到最低点：

mgR = ½mv²，v = √(2gR) = √25 = 5 m/s。

**例 2：** 压缩的弹簧弹性势能 Eₚ = 8 J，释放后推动光滑水平面上质量 1 kg 的物块（弹簧完全释放）：

Eₚ = ½mv²，v = √(2Eₚ / m) = 4 m/s。

## 解题步骤

1. 判断机械能是否守恒；
2. 选取零势能面；
3. 写出初、末状态的机械能；
4. 列方程。

**提示**：能用机械能守恒的问题，一般也能用动能定理，但机械能守恒更简便。
