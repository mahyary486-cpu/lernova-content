# Оптика и квантовая физика

**Оптика.** n = c / v, где c = 3 · 10⁸ м/с. Формула линзы: 1 / F = 1 / d + 1 / f, оптическая сила D = 1 / F. При F = 0,5 м получаем D = 2 дптр.

**Фотоэффект.** hν = A + Eₖ. Если энергия фотона 5 эВ, а работа выхода 2 эВ, то Eₖ = 3 эВ.

**Радиоактивность.** N = N₀ · 2^(−t / T). При T = 5 суток за 15 суток остаётся 1/8 ядер.
