# Solving Systems by Graphing

## What is a system?
A **system of linear equations** is two or more equations that use the same variables. A **solution** is an ordered pair (x, y) that makes every equation in the system true.

## Three possible outcomes
- **One solution:** the lines have different slopes and cross at exactly one point.
- **No solution:** the lines are parallel (same slope, different y-intercepts), so they never meet.
- **Infinitely many solutions:** both equations describe the same line.

## Steps for graphing a system
1. Write each equation in slope-intercept form, y = mx + b.
2. Graph each line: plot (0, b), then use rise over run.
3. Find the point where the lines cross.
4. Check the point in both original equations.

## Example 1
Solve y = x + 1 and y = -2x + 7.
- Line 1 passes through (0, 1) with slope 1.
- Line 2 passes through (0, 7) with slope -2.
- The lines cross at (2, 3).
- Check: 3 = 2 + 1 is true, and 3 = -2(2) + 7 = 3 is true. The solution is (2, 3).

## Example 2: equations not in slope-intercept form
Solve 2x + y = 5 and x - y = 1.
- Solve for y: y = -2x + 5 and y = x - 1.
- The graphs cross at (2, 1).
- Check: 2(2) + 1 = 5 and 2 - 1 = 1. Both are true.

## Checking a possible solution
Is (3, 1) a solution of x + y = 4 and x - y = 2?
- 3 + 1 = 4 is true.
- 3 - 1 = 2 is true.
- Yes, it satisfies both equations, so it is a solution.

## Common mistakes
- Checking the point in only one equation.
- Reading a crossing point carelessly from a rough graph. Always check algebraically.
- Forgetting to solve for y before using the slope and intercept.
