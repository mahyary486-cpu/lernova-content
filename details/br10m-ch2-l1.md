# Função exponencial

## Definição

**f(x) = aˣ**, com **a > 0** e **a ≠ 1**.

## Gráfico

Passa sempre por **(0, 1)**, pois a⁰ = 1.

- a > 1: **crescente** (ex.: 2ˣ);
- 0 < a < 1: **decrescente** (ex.: (1/2)ˣ).

## Equações exponenciais

Reduz-se à mesma base e igualam-se os expoentes:

- 2ˣ = 32 → 2ˣ = 2⁵ → x = 5;
- 3ˣ⁺¹ = 27 → x + 1 = 3 → x = 2;
- 4ˣ = 8 → 2²ˣ = 2³ → x = 3/2.

## Aplicações

- **Bactérias** que dobram a cada hora: de 100, após 3 h há 100 · 2³ = 800.
- **Juros compostos:** M = C · (1 + i)ᵗ. R$ 1 000 a 10% ao ano por 2 anos: 1 000 · 1,1² = R$ 1 210,00.
- **Meia-vida:** 80 g que caem pela metade a cada hora ficam com 10 g após 3 h.
