# 离散型随机变量及其分布列

## 分布列

取值可以一一列出的随机变量叫**离散型随机变量**。其分布列：

| X | x₁ | x₂ | … | xₙ |
|---|---|---|---|---|
| P | p₁ | p₂ | … | pₙ |

性质：pᵢ ≥ 0，且 **p₁ + p₂ + … + pₙ = 1**。

## 期望与方差

- **期望** E(X) = x₁p₁ + x₂p₂ + … + xₙpₙ；
- **方差** D(X) = Σ(xᵢ − E(X))² pᵢ；
- E(aX + b) = aE(X) + b；D(aX + b) = a²D(X)。

## 例题

**例 1：** 掷一枚均匀的骰子，点数 X 的期望 E(X) = (1 + 2 + … + 6) / 6 = 3.5。

**例 2：** X 取 0、1、2 的概率分别为 0.2、0.5、0.3：

- E(X) = 0 × 0.2 + 1 × 0.5 + 2 × 0.3 = 1.1；
- D(X) = (0 − 1.1)² × 0.2 + (1 − 1.1)² × 0.5 + (2 − 1.1)² × 0.3 = 0.242 + 0.005 + 0.243 = 0.49。
