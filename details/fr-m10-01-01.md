# Ensembles de nombres : entiers, décimaux, rationnels et réels

## Les ensembles usuels
- ℕ : les entiers naturels 0, 1, 2, 3…
- ℤ : les entiers relatifs …, −2, −1, 0, 1, 2…
- D : les nombres décimaux, qui s’écrivent avec un nombre fini de chiffres après la virgule (0,25 ; −3,7 ; 12).
- ℚ : les nombres rationnels, quotients a/b de deux entiers avec b non nul (1/3 ; −7/4 ; 5).
- ℝ : les nombres réels, c’est-à-dire tous les points de la droite numérique.
Inclusions : ℕ ⊂ ℤ ⊂ D ⊂ ℚ ⊂ ℝ.

## Exemples
- 1/3 = 0,333… est rationnel mais n’est pas décimal.
- √2 et π sont réels mais pas rationnels : on les dit irrationnels.
- Un réel est rationnel si et seulement si son écriture décimale est finie ou périodique.

## Irrationalité de √2 (idée de la preuve)
Supposons √2 = p/q avec p/q irréductible. Alors p² = 2q², donc p² est pair, donc p est pair : p = 2k. Alors 4k² = 2q², donc q² = 2k² est pair, donc q est pair. Ainsi p et q sont pairs, ce qui contredit le fait que la fraction est irréductible.

## Méthode
Pour situer un nombre, on cherche le plus petit ensemble qui le contient : −4 est dans ℤ, 0,75 est décimal, 2/7 est dans ℚ, √5 est dans ℝ.

## Erreur fréquente
Une calculatrice affiche un nombre fini de chiffres : elle ne permet pas de décider si un nombre est rationnel ou non.
