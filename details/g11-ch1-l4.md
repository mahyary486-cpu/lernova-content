# Absolute Value and Piecewise Functions

## Absolute value
The absolute value of a number is its distance from 0, so it is never negative. We write it with bars: |-7| = 7 and |7| = 7.

## Solving absolute value equations
If |u| = c with c > 0, then u = c **or** u = -c.
Example: |x - 3| = 4 gives x - 3 = 4 or x - 3 = -4, so **x = 7 or x = -1**.
If c is negative, there is no solution, because an absolute value cannot be negative.

## Solving absolute value inequalities
- |u| < c means -c < u < c. This is an **and** statement (a segment on the number line).
- |u| > c means u < -c **or** u > c. This is an **or** statement (two rays).

Example: |2x + 1| < 5 gives -5 < 2x + 1 < 5. Subtract 1: -6 < 2x < 4. Divide by 2: **-3 < x < 2**.

## Extraneous solutions
When the other side has a variable, always check your answers in the original equation.
Example: |x - 1| = 2x. Case 1: x - 1 = 2x gives x = -1, but then 2x = -2 is negative, so it **fails**. Case 2: x - 1 = -2x gives x = 1/3, and |1/3 - 1| = 2/3 = 2(1/3), so it **works**. The only solution is x = 1/3.

## Graphing
y = a * abs(x - h) + k is a V shape with vertex **(h, k)**. For example, y = abs(x - 2) has its vertex at (2, 0).

## Piecewise functions
A piecewise function uses different rules on different parts of the domain. To evaluate, find which interval the input is in and use that rule.
Example: f(x) = x + 1 if x < 2, and f(x) = x^2 if x ≥ 2.
- f(1): 1 < 2, so use x + 1. f(1) = **2**.
- f(3): 3 ≥ 2, so use x^2. f(3) = **9**.

## Common mistakes
- Forgetting the second case (the negative one) in an absolute value equation.
- Writing an "or" answer for |u| < c. Less-than gives "and"; greater-than gives "or".
- Not checking for extraneous solutions.
