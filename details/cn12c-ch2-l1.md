# 氧化还原方程式的配平

## 配平步骤

1. **标价态**：标出变价元素的化合价；
2. **列变化**：写出化合价升高、降低的数值；
3. **求总数**：使升降总数相等（求最小公倍数）；
4. **配系数**：先配变价元素，再配其他物质；
5. **查守恒**：检查原子、电荷（离子方程式）是否守恒。

## 例题

**例 1：** Cu + HNO₃（稀）→ Cu(NO₃)₂ + NO + H₂O

- Cu：0 → +2，失 2e⁻；N：+5 → +2，得 3e⁻；
- 最小公倍数 6：Cu 配 3，NO 配 2；
- 配平：**3Cu + 8HNO₃ = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O**。

**例 2：** KMnO₄ + HCl（浓）→ KCl + MnCl₂ + Cl₂ + H₂O

- Mn：+7 → +2，得 5e⁻；Cl：−1 → 0，失 1e⁻（每个 Cl₂ 失 2e⁻）；
- **2KMnO₄ + 16HCl（浓）= 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O**；
- 16 个 HCl 中，10 个被氧化，6 个起酸的作用。

## 氧化性、还原性强弱

- 氧化性：氧化剂 > 氧化产物；
- 还原性：还原剂 > 还原产物。
