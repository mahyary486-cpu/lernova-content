# The Quadratic Formula and Discriminant

Completing the square on ax^2 + bx + c = 0 gives a formula that solves every quadratic.

## The formula
**x = (-b plus or minus sqrt(b^2 - 4ac)) / (2a)**

Put the equation in the form ax^2 + bx + c = 0 first, then identify a, b and c with their signs.

## The discriminant
The expression **D = b^2 - 4ac** tells how many real solutions there are.
- D > 0: two different real solutions (two x-intercepts).
- D = 0: exactly one real solution (the vertex touches the x-axis).
- D < 0: no real solutions (the parabola misses the x-axis).
If D is a perfect square, the solutions are rational and the quadratic could have been factored.

## Worked examples
**Example 1.** Solve x^2 - 5x + 6 = 0.
1. a = 1, b = -5, c = 6.
2. D = 25 - 24 = 1.
3. x = (5 plus or minus 1)/2, so x = 3 or x = 2.

**Example 2.** Solve 2x^2 + 3x - 4 = 0.
1. a = 2, b = 3, c = -4.
2. D = 9 - 4(2)(-4) = 9 + 32 = 41.
3. x = (-3 plus or minus sqrt(41))/4. Approximately 0.85 and -2.35.

**Example 3.** How many real solutions does x^2 + 4x + 7 = 0 have?
1. D = 16 - 28 = -12.
2. D < 0, so there are none.

**Example 4.** For what value of k does x^2 + 6x + k = 0 have exactly one solution?
1. Set D = 0: 36 - 4k = 0.
2. k = 9.

## Choosing a method
Factor if it is easy; use square roots when there is no x term; use the formula when nothing else is quick.

## Common mistakes
- Forgetting that -b is positive when b is negative.
- Writing sqrt(b^2) - 4ac, or dividing only part of the numerator by 2a.
- Mixing up signs when c is negative: -4ac becomes positive.
- Using the formula before moving every term to one side.
