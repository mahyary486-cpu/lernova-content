# Қувваҳо дар табиат

Қувваи вазнинӣ ҷисмро ба сӯи замин мекашад: F = m·g. Масса (кг) ва вазн (Н) якхела нестанд: масса ба ҷой вобаста нест, вазн ба g вобаста аст ва дар Моҳ камтар аст. Қувваи ҷозиба байни ду ҷисм ба квадрати масофа мутаносиби чаппа аст.

Қувваи чандирӣ ҳангоми дароз ё фишурда шудани пружина пайдо мешавад: F = k·x, дар ин ҷо k — сахтии пружина (Н/м) ва x — дарозшавӣ (метр). Қувваи соиш ба фишори ҷисм ба сатҳ вобаста аст: F = μ·N. Дар сатҳи уфуқӣ N = m·g.

Агар лифт бо шитоби a ба боло ҳаракат кунад, вазни одам зиёд мешавад: P = m(g + a). Ҳангоми шитоб ба поён вазн кам мешавад: P = m(g − a). Дар афтодани озод вазн ба нул мерасад.
