# 多步反应与滴定计算

## 关系式法

多步反应中，找出起始物和最终物之间的**物质的量关系**，一步求解。

## 氧化还原滴定

MnO₄⁻ + 5Fe²⁺ + 8H⁺ = Mn²⁺ + 5Fe³⁺ + 4H₂O

**例：** 用 0.0200 mol/L KMnO₄ 滴定 20.00 mL 含 Fe²⁺ 的溶液，消耗 18.00 mL：

- n(MnO₄⁻) = 0.0200 × 0.01800 = 3.6×10⁻⁴ mol；
- n(Fe²⁺) = 5 × 3.6×10⁻⁴ = 1.8×10⁻³ mol；
- c(Fe²⁺) = 1.8×10⁻³ / 0.02000 = **0.0900 mol/L**。

KMnO₄ 本身有颜色，滴定终点是溶液由无色变为浅紫色，半分钟不褪色，不需要另加指示剂。

## 产率

**产率 = 实际产量 / 理论产量 × 100%**

**例：** 12.0 g 乙酸与足量乙醇反应，理论上得乙酸乙酯（M = 88 g/mol）：

n(乙酸) = 12.0 / 60 = 0.2 mol，理论产量 17.6 g。实际得到 13.2 g，产率 = 13.2 / 17.6 = 75%。
