# 分布列、期望与方差的应用

## 超几何分布

N 件产品中有 M 件次品，不放回地抽取 n 件，次品数 X 的分布：

**P(X = k) = C_M^k · C_(N−M)^(n−k) / C_N^n**，期望 **E(X) = nM / N**。

## 例题

10 件产品中有 3 件次品，任取 2 件，次品数为 X。

- P(X = 0) = C₇² / C₁₀² = 21/45 = 7/15；
- P(X = 1) = C₃¹C₇¹ / C₁₀² = 21/45 = 7/15；
- P(X = 2) = C₃² / C₁₀² = 3/45 = 1/15；
- E(X) = 0 × 7/15 + 1 × 7/15 + 2 × 1/15 = 9/15 = 0.6。

用公式检验：E(X) = nM/N = 2 × 3/10 = 0.6。

## 解题步骤

1. 确定 X 的所有可能取值；
2. 求每个取值的概率；
3. 写出分布列，检验概率之和为 1；
4. 计算期望、方差；
5. 用期望（和方差）做决策：期望大的收益高，方差小的更稳定。
