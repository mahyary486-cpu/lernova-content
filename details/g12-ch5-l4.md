# Inverse Trigonometric Functions

Trigonometric functions are not one-to-one, so we restrict their domains to build inverses. The inverse functions take a ratio and return an angle.

## Key ideas
- **y = arcsin x** (also sin^(-1) x): domain [-1, 1], range [-pi/2, pi/2]. It means sin y = x.
- **y = arccos x:** domain [-1, 1], range [0, pi].
- **y = arctan x:** domain all real numbers, range (-pi/2, pi/2). It has horizontal asymptotes y = plus or minus pi/2.
- The inverse gives exactly one angle: the one in the restricted range.
- **Cancellation:** sin(arcsin x) = x for x in [-1, 1]. But arcsin(sin x) = x only when x is in [-pi/2, pi/2].
- sin^(-1) x means the inverse function, not 1/sin x.

## Evaluating
Ask: which angle in the range has this value?

## Worked examples
**Example 1.** Evaluate arcsin(-1/2).
1. The range is [-pi/2, pi/2], and sin(-pi/6) = -1/2.
2. So arcsin(-1/2) = -pi/6.

**Example 2.** Evaluate arccos(-sqrt(2)/2).
1. The range is [0, pi]. The reference angle is pi/4, and the angle is in Quadrant II.
2. So the answer is pi - pi/4 = 3pi/4.

**Example 3.** Evaluate cos(arcsin(3/5)).
1. Let y = arcsin(3/5). Then sin y = 3/5 and y is in Quadrant I.
2. Draw a right triangle: opposite 3, hypotenuse 5, adjacent 4.
3. cos y = 4/5.

**Example 4.** Evaluate arcsin(sin(5pi/6)).
1. sin(5pi/6) = 1/2.
2. arcsin(1/2) = pi/6, not 5pi/6, because 5pi/6 is outside the range.

## Common mistakes
- Reading sin^(-1) as a reciprocal.
- Giving an answer outside the range, such as arccos(-1/2) = -2pi/3. The correct value is 2pi/3.
- Writing arcsin(sin x) = x for every x.
- Trying to evaluate arcsin 2. The domain is [-1, 1], so it is undefined.
