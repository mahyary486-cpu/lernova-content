# Algorithmique et programmation avec Scratch

## Notions
- Instruction : une action simple (avancer de 50, tourner de 90 degrés).
- Séquence : des instructions exécutées l’une après l’autre.
- Variable : une case mémoire qui porte un nom et contient une valeur.
- Boucle : on répète des instructions. « Répéter 4 fois » ou « répéter jusqu’à ce que… ».
- Test : « si condition alors … sinon … ».
- Bloc personnalisé : une suite d’instructions à laquelle on donne un nom pour la réutiliser.
- Événement : un clic, une touche pressée.

## Dessiner un carré
répéter 4 fois : avancer de 100, tourner de 90 degrés.
Le polygone régulier à n côtés se trace avec « répéter n fois : avancer de c, tourner de 360/n degrés ». Pour un triangle équilatéral : tourner de 120 degrés.

## Variables
Exemple : mettre x à 5, puis ajouter 3 à x, puis dire x. Le programme dit 8.
Pour calculer l’aire d’un carré : demander le côté c, mettre aire à c × c, dire aire.

## Test
Si note ≥ 10 alors dire « Reçu » sinon dire « Refusé ».

## Boucle conditionnelle
répéter jusqu’à ce que x > 100 : mettre x à x × 2. Si x vaut 3 au départ, il prend les valeurs 6, 12, 24, 48, 96, 192 et le programme s’arrête avec 192.

## Pour déboguer
On teste le programme avec plusieurs valeurs, on suit l’exécution pas à pas et on vérifie les valeurs des variables.
