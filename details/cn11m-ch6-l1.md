# 分类加法与分步乘法计数原理

## 分类加法计数原理

完成一件事有 n **类**办法，在第 i 类办法中有 mᵢ 种不同的方法，则完成这件事共有

**N = m₁ + m₂ + … + mₙ** 种不同的方法。

特点：每一类办法中的**任何一种方法**都能**独立完成**这件事。

## 分步乘法计数原理

完成一件事需要 n 个**步骤**，做第 i 步有 mᵢ 种不同的方法，则完成这件事共有

**N = m₁ × m₂ × … × mₙ** 种不同的方法。

特点：**每一步都完成**，才算完成这件事。

## 例题

**例 1：** 从 3 本不同的书和 2 本不同的杂志中任选 1 本，有 3 + 2 = 5 种选法（分类）。

**例 2：** 从 A 地到 B 地有 3 条路，从 B 地到 C 地有 2 条路，从 A 经 B 到 C 有 3 × 2 = 6 种走法（分步）。

## 区分

"做一件事，**或者**……**或者**……"用加法；"做一件事，**先**……**再**……"用乘法。
