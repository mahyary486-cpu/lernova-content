# If-Sätze (Conditionals)

## Typ 0
Allgemeingültig: if + Simple Present, Simple Present. *If you heat ice, it melts.*

## Typ 1
Realistische Bedingung: if + Simple Present, will + Infinitiv. *If it rains, we will stay at home.* Unless = if not.

## Typ 2
Unwahrscheinlich oder unreal: if + Simple Past, would + Infinitiv. *If I had a car, I would drive to work. If I were you, I would apologise.*

## Typ 3
Nicht mehr änderbar: if + Past Perfect, would have + Partizip. *If I had known, I would have helped.*

## Wünsche
*I wish I had more time.*
