# 错位相减与裂项求和

## 错位相减法

适用于"等差 × 等比"型数列 aₙ = bₙ · cₙ 的求和。

**例：** Sₙ = 1·2 + 2·2² + 3·2³ + … + n·2ⁿ

- 2Sₙ = 1·2² + 2·2³ + … + (n − 1)·2ⁿ + n·2ⁿ⁺¹；
- 两式相减：−Sₙ = 2 + 2² + … + 2ⁿ − n·2ⁿ⁺¹ = 2ⁿ⁺¹ − 2 − n·2ⁿ⁺¹；
- 所以 **Sₙ = (n − 1)·2ⁿ⁺¹ + 2**。

检验：n = 2 时 S₂ = 2 + 8 = 10，公式 (2 − 1) × 8 + 2 = 10。

## 裂项相消法

**1 / (n(n + 2)) = ½(1/n − 1/(n + 2))**

Σ(k = 1 到 n) 1/(k(k + 2)) = ½(1 + 1/2 − 1/(n + 1) − 1/(n + 2))。

检验：n = 2：1/3 + 1/8 = 11/24；公式 ½(3/2 − 1/3 − 1/4) = ½ × 11/12 = 11/24。

## 提示

- 错位相减后，要注意项数和符号；
- 裂项相消时，要看清消去了哪些项，剩下哪些项。
