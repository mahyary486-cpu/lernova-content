# 变量的相关关系与线性回归

## 相关关系

- **函数关系**：变量之间有确定的关系；
- **相关关系**：变量之间有关系，但不确定。

用**散点图**直观判断：点从左下到右上，**正相关**；点从左上到右下，**负相关**。

## 相关系数 r

- r 的取值范围是 [−1, 1]；
- r > 0 正相关，r < 0 负相关；
- 相关系数的绝对值越接近 1，线性相关程度越强；越接近 0，线性相关程度越弱。

## 经验回归方程

ŷ = b̂x + â，其中

- b̂ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)²；
- â = ȳ − b̂x̄。

**回归直线一定经过样本点的中心 (x̄, ȳ)**。

## 例题

x̄ = 3，ȳ = 5，b̂ = 2：â = 5 − 2 × 3 = −1，回归方程 ŷ = 2x − 1。

当 x = 6 时，预测值 ŷ = 2 × 6 − 1 = 11。
