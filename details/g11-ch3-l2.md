# Adding, Subtracting and Multiplying Polynomials

## Adding
Combine **like terms** (same power of x).
(3x^2 + 2x - 1) + (x^2 - 5x + 4) = 4x^2 - 3x + 3.

## Subtracting
Subtract every term of the second polynomial: change **all** its signs, then combine.
(2x^3 - x) - (x^3 + 4x - 2) = 2x^3 - x - x^3 - 4x + 2 = **x^3 - 5x + 2**.

## Multiplying
Multiply every term of the first polynomial by every term of the second, then combine like terms.
(x + 2)(x^2 - 3x + 1) = x^3 - 3x^2 + x + 2x^2 - 6x + 2 = **x^3 - x^2 - 5x + 2**.

The **degree of a product** is the sum of the degrees. For (3x^2 + 1)(x^3 - 4x), the degree is 2 + 3 = **5**.

## Special products
- (a + b)^2 = a^2 + 2ab + b^2
- (a - b)^2 = a^2 - 2ab + b^2
- (a + b)(a - b) = a^2 - b^2
- (a + b)^3 = a^3 + 3a^2 b + 3a b^2 + b^3
- (a - b)^3 = a^3 - 3a^2 b + 3a b^2 - b^3

Examples:
- (2x - 1)^2 = 4x^2 - 4x + 1
- (x + 3)^3 = x^3 + 9x^2 + 27x + 27
- (x - 2)(x + 2)(x^2 + 4) = (x^2 - 4)(x^2 + 4) = **x^4 - 16**

## Worked example
(x + 2)(x + 5) = x^2 + 5x + 2x + 10 = **x^2 + 7x + 10**.

## Common mistakes
- Writing (a + b)^2 = a^2 + b^2. The middle term 2ab is missing.
- Subtracting only the first term of the second polynomial and not changing the other signs.
- Adding degrees when adding polynomials. Adding does not change the degree this way; only multiplying adds the degrees.
- Combining terms with different powers, like x^2 and x^3.
