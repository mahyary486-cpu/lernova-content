# Variables, types et affectations en Python

## Affectation
x = 5 donne à la variable x la valeur 5. On peut réaffecter : x = x + 2 ajoute 2 à x (si x valait 5, il vaut maintenant 7).
Échanger deux variables : a, b = b, a. Si a = 5 et b = 3, alors après a, b = b, a on a a = 3 et b = 5.

## Types
- int : entiers (3, −7).
- float : nombres décimaux (3.5, 0.25). La virgule s’écrit avec un point.
- str : texte entre guillemets ('Bonjour').
- bool : True ou False.
type(x) renvoie le type de x.

## Opérateurs arithmétiques
- Addition +, soustraction -, multiplication *, division /.
- Puissance : 2 ** 3 vaut 8.
- Quotient entier : 7 // 2 vaut 3.
- Reste de la division : 7 % 2 vaut 1.
- Test de parité : x % 2 == 0 est vrai si x est pair.

## Affichage et saisie
print(x) affiche la valeur de x. input() lit un texte saisi par l’utilisateur ; int(...) ou float(...) le convertit en nombre.

## Texte
'3' + '4' vaut '34' (concaténation) alors que 3 + 4 vaut 7.

## Erreur fréquente
Le signe = est une affectation, pas un test. Pour tester l’égalité, on utilise ==.
