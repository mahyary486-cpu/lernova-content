# Понятие производной

**Производная** функции f в точке x показывает, как быстро меняется функция. Её обозначают f′(x).

**Определение.** f′(x) — это предел отношения приращения функции к приращению аргумента: (f(x + h) − f(x)) / h при h → 0.

**Геометрический смысл.** Значение f′(a) равно угловому коэффициенту касательной к графику функции в точке с абсциссой a.

**Физический смысл.** Если s(t) — координата точки в момент t, то s′(t) — мгновенная скорость, а производная скорости — ускорение.

**Простейшие случаи.** Производная постоянной равна нулю: (5)′ = 0. Для функции f(x) = 3x производная равна 3.
