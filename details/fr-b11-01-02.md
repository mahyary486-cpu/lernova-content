# Mutations, allèles et phénotypes

## Mutation
Une mutation est une modification de la séquence de nucléotides de l’ADN. Elle apparaît spontanément (erreurs de réplication) ou sous l’effet d’agents mutagènes (rayons UV, rayons X, certaines substances). Elle crée un nouvel allèle du gène.

## Types de mutations
- Substitution : un nucléotide est remplacé par un autre.
  - silencieuse : le codon modifié code le même acide aminé ;
  - faux-sens : le codon modifié code un acide aminé différent ;
  - non-sens : le codon modifié devient un codon stop, la protéine est tronquée.
- Insertion ou délétion : un nucléotide est ajouté ou supprimé ; tous les codons suivants sont décalés (décalage du cadre de lecture), ce qui modifie fortement la protéine.

## Du génotype au phénotype
Génotype (allèles) → ARNm → protéine → phénotype. Un allèle modifié peut produire une protéine modifiée ou non fonctionnelle, donc un phénotype différent à l’échelle moléculaire, cellulaire ou de l’organisme.

## Exemple : la drépanocytose
Une substitution dans le gène de la chaîne β de l’hémoglobine remplace un acide aminé (l’acide glutamique par la valine). L’hémoglobine modifiée s’agrège dans certaines conditions, et les globules rouges prennent une forme de faucille.

## Erreur fréquente
Toutes les mutations n’ont pas d’effet : certaines sont silencieuses, d’autres touchent des zones non codantes.
