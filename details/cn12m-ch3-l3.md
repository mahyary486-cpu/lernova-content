# 解三角形综合

## 基本公式

- 正弦定理：a / sin A = b / sin B = c / sin C = 2R；
- 余弦定理：a² = b² + c² − 2bc cos A；
- 面积：**S = ½ab sin C**。

## 边角互化

题目条件中有边的二次式（如 a² + b² − c²）常用余弦定理，有边的一次式和角的正弦时常用正弦定理。

## 例题

**例 1：** a² + b² − c² = ab：cos C = (a² + b² − c²) / (2ab) = 1/2，所以 C = 60°。

**例 2：** b = 2，c = 3，A = 60°：

- a² = 4 + 9 − 2 × 2 × 3 × 1/2 = 7，a = √7；
- 面积 S = ½ × 2 × 3 × sin 60° = 3√3/2。

## 最值问题

**例：** C = 60°，c = 2，求面积的最大值。

c² = a² + b² − ab ≥ 2ab − ab = ab，所以 ab ≤ 4，S = ½ab sin 60° ≤ ½ × 4 × √3/2 = √3，当 a = b = 2 时取等号。
