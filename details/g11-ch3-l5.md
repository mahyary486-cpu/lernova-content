# Finding the Zeros of Polynomials

## What is a zero?
A **zero** of f is a number c where **f(c) = 0**. It is also called a root or solution. Real zeros are the x-intercepts of the graph.

## Rational Root Theorem
If a polynomial has integer coefficients, every rational zero has the form **p / q**, where
- **p** is a factor of the constant term, and
- **q** is a factor of the leading coefficient.

Example: f(x) = x^3 + 2x^2 - x - 6. The constant term is -6 and the leading coefficient is 1, so the possible rational zeros are ±1, ±2, ±3, ±6. For instance, 3 is a possible zero, but 4 and 5 are not.

Example: f(x) = 2x^3 + x^2 - 13x + 6. The factors of 6 are 1, 2, 3, 6 and the factors of 2 are 1, 2. The possible zeros are ±1, ±2, ±3, ±6, ±1/2, ±3/2. The number **4** is not on the list.

## Finding all zeros (steps)
1. List the possible rational zeros.
2. Test candidates with the Remainder Theorem or synthetic division until one gives 0.
3. Divide to get a lower-degree polynomial.
4. Solve what is left (factor or use the quadratic formula).

**Worked example.** f(x) = 2x^3 + x^2 - 13x + 6.
f(2) = 16 + 4 - 26 + 6 = 0, so 2 is a zero. Synthetic division by x - 2 (coefficients 2, 1, -13, 6): 2, 5, -3, 0. The quotient is 2x^2 + 5x - 3 = (2x - 1)(x + 3).
The zeros are **x = 2, x = 1/2 and x = -3**.

## Multiplicity
If the factor (x - c) appears k times, c is a zero of **multiplicity k**.
f(x) = (x - 1)^2 (x + 2) has zero **1 with multiplicity 2** and zero **-2 with multiplicity 1**.

## Conjugate pairs
- If a + bi is a zero of a polynomial with **real** coefficients, then a - bi is also a zero. Example: if 3 + 2i is a zero, so is **3 - 2i**.
- If a + sqrt(b) is a zero of a polynomial with **rational** coefficients, then a - sqrt(b) is also a zero. Example: if 1 + sqrt(2) is a zero, so is **1 - sqrt(2)**.

## Common mistakes
- Forgetting the ± in the list of possible zeros.
- Putting the factors of the leading coefficient on top. It is (factors of the constant) / (factors of the leading coefficient).
- Stopping after finding one zero. Divide and keep going until the quotient is solved.
