# الگو و دنباله

## این درس درباره‌ی چیست؟

به این فکر کنید که هر هفته ۵۰۰۰ تومان به حسابتان اضافه می‌شود. بعد از یک هفته ۵۰۰۰، بعد از دو هفته ۱۰۰۰۰ و بعد از سه هفته ۱۵۰۰۰ دارید. این فهرست از عددها یک الگو دارد و ما می‌توانیم بدون شمردن همه‌ی هفته‌ها بگوییم بعد از ۱۰۰ هفته چقدر داریم. اسم این فهرست مرتب «دنباله» است و در این درس یاد می‌گیریم آن را چگونه بنویسیم و توصیف کنیم.

## دنباله چیست؟

دنباله فهرستی از عددهاست که ترتیب در آن مهم است. جمله‌ی اول را a_۱، جمله‌ی دوم را a_۲ و جمله‌ی n‌ام را a_n می‌نامیم. به n «شماره‌ی جمله» و به a_n «مقدار جمله» می‌گوییم. یعنی در دنباله‌ی ۳, ۶, ۹, ۱۲, ... داریم a_۱ = ۳ و a_۲ = ۶ و a_۴ = ۱۲.

## جمله‌ی عمومی

بهترین توصیف دنباله، فرمولی است که با گذاشتن n، مقدار هر جمله را به دست می‌دهد. به آن «جمله‌ی عمومی» می‌گوییم. برای دنباله‌ی ۳, ۶, ۹, ۱۲, ... فرمول a_n = ۳n درست کار می‌کند: برای n = ۱ می‌شود ۳، برای n = ۲ می‌شود ۶ و همین‌طور تا آخر.

گاهی قاعده را به صورت «بازگشتی» می‌دهند: هر جمله از جمله‌ی قبلی ساخته می‌شود. مثلاً a_۱ = ۲ و a_(n+۱) = a_n + ۳ یعنی از ۲ شروع کن و هر بار ۳ تا اضافه کن: ۲, ۵, ۸, ۱۱, ... .

## چگونه جمله‌ی عمومی را حدس بزنیم؟

۱. اختلاف جمله‌های متوالی را حساب کنید. اگر همیشه ثابت و برابر d باشد، جمله‌ی عمومی به شکل dn + c است.
۲. با گذاشتن n = ۱ ثابت c را پیدا کنید.
۳. با جمله‌های بعدی بررسی کنید که فرمول درست است.

اگر اختلاف‌ها ثابت نبودند ولی اختلاف اختلاف‌ها ثابت بود، فرمول از نوع n^۲ است. مثلاً ۱, ۴, ۹, ۱۶, ... مربع‌های کامل‌اند و a_n = n^۲.

## مثال‌های حل‌شده

**مثال ۱.** چهار جمله‌ی اول دنباله‌ی a_n = n^۲ + ۱ را بنویسید.
گام ۱: به جای n عددهای ۱ و ۲ و ۳ و ۴ را می‌گذاریم. گام ۲: برای n = ۱ می‌شود ۱ + ۱ = ۲ و برای n = ۲ می‌شود ۴ + ۱ = ۵. گام ۳: برای n = ۳ می‌شود ۹ + ۱ = ۱۰ و برای n = ۴ می‌شود ۱۶ + ۱ = ۱۷. پاسخ: ۲ و ۵ و ۱۰ و ۱۷.

**مثال ۲.** جمله‌ی عمومی دنباله‌ی ۴, ۷, ۱۰, ۱۳, ... را بیابید.
گام ۱: اختلاف جمله‌های متوالی را حساب می‌کنیم: ۷ − ۴ = ۳ و ۱۰ − ۷ = ۳ و ۱۳ − ۱۰ = ۳. اختلاف ثابت و برابر ۳ است. گام ۲: پس جمله‌ی عمومی به شکل ۳n + c است. گام ۳: برای n = ۱ باید جمله ۴ شود: ۳ + c = ۴ پس c = ۱. پاسخ: a_n = ۳n + ۱. بررسی: a_۴ = ۱۳ که با جمله‌ی چهارم می‌خواند.

**مثال ۳.** آیا ۱۰۰ جمله‌ای از دنباله‌ی a_n = ۳n + ۱ است؟
گام ۱: معادله‌ی ۳n + ۱ = ۱۰۰ را حل می‌کنیم. گام ۲: ۳n = ۹۹ پس n = ۳۳. گام ۳: چون n = ۳۳ عددی صحیح و مثبت است، ۱۰۰ یکی از جمله‌هاست و جمله‌ی سی‌وسوم است. اگر n عددی غیرصحیح مثل ۳۳٫۵ درآمده بود، آن عدد جزو دنباله نبود.

## اشتباه‌های رایج و دلیلشان

- **اشتباه گرفتن n با a_n:** n شماره‌ی جایگاه است و a_n مقداری که در آن جایگاه قرار دارد.
- **حدس زدن فرمول فقط از دو جمله:** چند فرمول مختلف می‌توانند با دو جمله بخوانند. حتماً با جمله‌ی سوم و چهارم بررسی کنید.
- **قبول‌کردن n غیرصحیح:** شماره‌ی جمله باید عددی صحیح و مثبت باشد.

## جمع‌بندی

دنباله فهرست مرتبی از عددهاست. جمله‌ی عمومی a_n مقدار جمله‌ی n‌ام را می‌دهد. برای حدس آن، اختلاف جمله‌ها را حساب کنید. عددی عضو دنباله است که معادله‌ی a_n = آن عدد، جواب صحیح و مثبت داشته باشد.
