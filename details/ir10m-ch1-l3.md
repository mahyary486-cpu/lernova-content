# الگو و دنباله

دنباله فهرستی مرتب از عددهاست که از یک قاعده پیروی می‌کند و جمله‌ی عمومی آن قاعده را برای هر شماره‌ی جمله می‌دهد.

## نکته‌های کلیدی

- دنباله را با a_۱, a_۲, a_۳, ... نشان می‌دهیم. a_n جمله‌ی عمومی یا جمله‌ی n‌ام است و n شماره‌ی جمله.
- گاهی قاعده به صورت بازگشتی داده می‌شود: هر جمله با جمله‌ی قبلی ساخته می‌شود، مثلاً a_(n+۱) = a_n + ۳ با a_۱ = ۲.
- با داشتن جمله‌ی عمومی می‌توان هر جمله را حساب کرد: a_n = ۳n − ۱ نتیجه می‌دهد a_۱ = ۲ و a_۲ = ۵ و a_۳ = ۸.
- برای حدس جمله‌ی عمومی از الگوی تفاضل جمله‌ها یا مقایسه با n و n^۲ استفاده می‌کنیم.
- جمله‌ی خاصی از دنباله است اگر بتوان n صحیح مثبتی پیدا کرد که a_n برابر آن عدد شود.

## مثال‌های حل‌شده

**مثال ۱.** چهار جمله‌ی اول دنباله‌ی a_n = n^۲ + ۱ را بنویسید.
گام ۱: n = ۱: ۱ + ۱ = ۲. گام ۲: n = ۲: ۴ + ۱ = ۵. گام ۳: n = ۳: ۱۰. گام ۴: n = ۴: ۱۷. پاسخ: ۲ و ۵ و ۱۰ و ۱۷.

**مثال ۲.** جمله‌ی عمومی دنباله‌ی ۴, ۷, ۱۰, ۱۳, ... را بیابید.
گام ۱: اختلاف جمله‌های متوالی همیشه ۳ است. گام ۲: پس جمله‌ی عمومی به شکل ۳n + c است. گام ۳: با n = ۱: ۳ + c = ۴ پس c = ۱. پاسخ: a_n = ۳n + ۱. بررسی: a_۴ = ۱۳.

**مثال ۳.** آیا ۱۰۰ جمله‌ای از دنباله‌ی a_n = ۳n + ۱ است؟
گام ۱: ۳n + ۱ = ۱۰۰. گام ۲: ۳n = ۹۹ پس n = ۳۳، یک عدد صحیح مثبت. پاسخ: بله، جمله‌ی سی‌وسوم است.

## اشتباه‌های رایج

- اشتباه گرفتن n (شماره‌ی جمله) با a_n (مقدار جمله).
- حدس جمله‌ی عمومی فقط از دو جمله. حتماً با جمله‌های بعدی بررسی کنید.
- قبول‌کردن n غیرصحیح یا منفی برای جمله‌ی خاص.

## به یاد داشته باشید

- a_n جمله‌ی عمومی است و n شماره‌ی جمله.
- برای حدس قاعده، اختلاف جمله‌ها را حساب کنید.
- برای عضو بودن عدد در دنباله باید n صحیح و مثبت شود.
