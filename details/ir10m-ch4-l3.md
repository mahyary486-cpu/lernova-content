# معادله‌های گویا و رادیکالی

## این درس درباره‌ی چیست؟

گاهی مجهول در مخرج کسر یا زیر رادیکال است. این معادله‌ها را با یک ایده‌ی ساده به معادله‌ی آشنا تبدیل می‌کنیم، اما باید حواسمان به **جواب‌های اضافی** باشد.

## معادله‌ی گویا (مجهول در مخرج)

**گام‌ها:**
۱) مخرج‌ها را فاکتور بگیرید و شرط مخالف‌صفر بودن آن‌ها را بنویسید.
۲) دو طرف را در ک.م.م مخرج‌ها ضرب کنید تا کسرها حذف شوند.
۳) معادله‌ی به‌دست‌آمده را حل کنید.
۴) جواب‌هایی را که مخرج را صفر می‌کنند کنار بگذارید.

**مثال:** ۱/x + ۱/(x − ۱) = ۳/۲
شرط: x ≠ ۰ و x ≠ ۱
دو طرف را در ۲x(x − ۱) ضرب می‌کنیم:
۲(x − ۱) + ۲x = ۳x(x − ۱)
۴x − ۲ = ۳x² − ۳x
۳x² − ۷x + ۲ = ۰
Δ = ۴۹ − ۲۴ = ۲۵ → x = (۷ ± ۵)/۶ → x = ۲ یا x = ۱/۳
هر دو جواب با شرط‌ها سازگارند.

## معادله‌ی رادیکالی

وقتی مجهول زیر رادیکال است، ابتدا رادیکال را تنها می‌کنیم، سپس دو طرف را به توان دو می‌رسانیم.

**مثال:** √(x + ۲) = x
دو طرف به توان دو: x + ۲ = x² → x² − x − ۲ = ۰ → (x − ۲)(x + ۱) = ۰
x = ۲ یا x = −۱.

**حتماً آزمون کنید:**
- x = ۲: √۴ = ۲ ✓
- x = −۱: √۱ = ۱ ولی سمت راست −۱ است ✗

پس فقط x = ۲ جواب است. به توان دو رساندن می‌تواند جواب اضافی بسازد، چون (−۱)² و (۱)² برابرند.

## چرا آزمون لازم است؟

دو عدد متفاوت ممکن است مربع یکسان داشته باشند. وقتی دو طرف را به توان دو می‌رسانیم، شرط «سمت راست نباید منفی باشد» از دست می‌رود. پس جواب‌ها را در معادله‌ی اصلی بگذارید.

## جمع‌بندی

- گویا: شرط مخرج، ضرب در ک.م.م، حل، حذف ریشه‌های ممنوع
- رادیکالی: رادیکال را تنها کنید، به توان برسانید، حل کنید، در معادله‌ی اصلی بیازمایید
