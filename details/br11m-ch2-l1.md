# Progressão aritmética (PA)

Uma PA é uma sequência em que a diferença entre termos consecutivos é constante: a **razão r**.

Exemplo: (2, 5, 8, 11, ...) tem r = 3.

## Termo geral

**aₙ = a₁ + (n − 1) · r**

O 10º termo de uma PA com a₁ = 3 e r = 4 é 3 + 9 · 4 = 39.

## Soma dos n primeiros termos

**Sₙ = (a₁ + aₙ) · n / 2**

Soma dos 10 primeiros ímpares: (1 + 19) · 10/2 = 100.

## Propriedades

- Se r > 0, a PA é crescente; se r < 0, decrescente.
- Três termos a, b, c em PA: **b = (a + c)/2**. Se (x, 10, 16) está em PA, x = 4.
- Número de termos: em (5, 8, 11, ..., 53), 53 = 5 + (n − 1) · 3 dá n = 17.
