# 直线的方程

## 斜率

直线的倾斜角 α（0° ≤ α < 180°），斜率 **k = tan α**。过两点 (x₁, y₁)、(x₂, y₂) 的直线斜率

k = (y₂ − y₁) / (x₂ − x₁)（x₁ ≠ x₂）。

## 直线方程的形式

- **点斜式**：y − y₀ = k(x − x₀)；
- **斜截式**：y = kx + b；
- **两点式**：(y − y₁) / (y₂ − y₁) = (x − x₁) / (x₂ − x₁)；
- **截距式**：x/a + y/b = 1；
- **一般式**：Ax + By + C = 0（A、B 不同时为 0）。

## 位置关系

- 平行：k₁ = k₂，且不重合；
- 垂直：**k₁k₂ = −1**。

## 例题

**例 1：** 过点 (1, 2)、斜率为 3 的直线：y − 2 = 3(x − 1)，即 3x − y − 1 = 0。

**例 2：** 直线 2x − y + 1 = 0 的斜率为 2，直线 x + 2y − 3 = 0 的斜率为 −1/2，二者乘积为 −1，所以互相垂直。
