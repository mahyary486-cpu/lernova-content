# Реаксияҳои мубодилаи ионӣ

Дар маҳлул электролитҳо ба ионҳо тақсим шудаанд ва ионҳо ба ҳам мепайванданд. Реаксия вақте то охир мегузарад, ки як маҳсул аз маҳлул дур шавад: таҳшин (↓), газ (↑) ё моддаи кам диссотсиатсияшаванда (H₂O). Агар чунин нашавад, ионҳо дар маҳлул мемонанд.

Реаксияро дар се шакл менависанд. Молекулавӣ: AgNO₃ + NaCl → AgCl↓ + NaNO₃. Ионии пурра: Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl↓ + Na⁺ + NO₃⁻. Ионии мухтасар: Ag⁺ + Cl⁻ → AgCl↓. Ионҳои ҳам дар чап ва ҳам дар рост якхела (тамошобин) хориҷ мешаванд.

Реаксияҳои сифатӣ ионҳоро ошкор мекунанд: Cl⁻ бо Ag⁺ таҳшини сафеди AgCl, SO₄²⁻ бо Ba²⁺ таҳшини сафеди BaSO₄, Cu²⁺ бо OH⁻ таҳшини кабуд. Дар безараргардонӣ H⁺ + OH⁻ → H₂O.
