# Реаксияҳои мубодилаи ионӣ

## Шартҳои то охир рафтан

Реаксия то охир меравад, агар:

1. таҳшин ҳосил шавад (↓),
2. газ ҷудо шавад (↑),
3. моддаи кам диссотсиатсияшаванда (масалан, H₂O) ҳосил шавад.

## Се шакли навиштан

**Молекулӣ:** AgNO₃ + NaCl → AgCl↓ + NaNO₃

**Ионии пурра:** Ag⁺ + NO₃⁻ + Na⁺ + Cl⁻ → AgCl↓ + Na⁺ + NO₃⁻

**Ионии мухтасар:** Ag⁺ + Cl⁻ → AgCl↓

## Реаксияи безараргардонӣ

HCl + NaOH → NaCl + H₂O. Муодилаи мухтасар: **H⁺ + OH⁻ → H₂O**.

## Ҷудошавии газ

Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
