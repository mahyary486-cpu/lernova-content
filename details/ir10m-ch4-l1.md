# حل معادله‌ی درجه‌ی دوم

## این درس درباره‌ی چیست؟

گاهی مجهول ما به توان دو می‌رسد. مثلاً می‌خواهید زمینی مستطیل‌شکل با مساحت ۴۸ متر مربع بسازید که طولش ۲ متر از عرضش بیشتر باشد. اگر عرض را x بنامیم، باید x(x + ۲) = ۴۸ را حل کنیم. این یک معادله‌ی درجه‌ی دوم است. در این درس سه روش اصلی حل آن را یاد می‌گیریم.

## معادله‌ی درجه‌ی دوم چیست؟

هر معادله‌ای که بتوان آن را به شکل زیر نوشت، درجه‌ی دوم است:

**ax² + bx + c = ۰** (به‌شرط a ≠ ۰)

عددهای a و b و c ضریب‌ها نام دارند. اگر a صفر باشد، x² حذف می‌شود و معادله دیگر درجه‌ی دوم نیست. جواب‌های معادله را **ریشه‌ها** می‌نامیم.

## روش اول: ریشه‌گیری مستقیم

وقتی معادله فقط x² و عدد دارد (بدون جمله‌ی x)، آن را برای x² حل می‌کنیم و از دو طرف ریشه می‌گیریم.

**مثال:** x² − ۱۶ = ۰
x² = ۱۶، پس x = ۴ یا x = −۴.

نکته‌ی مهم: ریشه‌ی دوم یک عدد مثبت دو مقدار دارد (مثبت و منفی). اگر x² برابر عدد منفی شود، در اعداد حقیقی جواب نداریم.

## روش دوم: فاکتورگیری

این روش بر یک قاعده‌ی ساده تکیه دارد: **اگر حاصل‌ضرب دو عدد صفر باشد، دست‌کم یکی از آن‌ها صفر است.**

**مثال ۱:** x² − ۵x = ۰
x(x − ۵) = ۰، پس x = ۰ یا x = ۵.

**مثال ۲:** x² − ۵x + ۶ = ۰
دو عدد می‌خواهیم که ضربشان ۶ و مجموعشان −۵ باشد: −۲ و −۳.
(x − ۲)(x − ۳) = ۰، پس x = ۲ یا x = ۳.

**خطای رایج:** در معادله‌ی x² = ۵x هرگز دو طرف را بر x تقسیم نکنید، چون ریشه‌ی x = ۰ را از دست می‌دهید. به‌جای آن همه‌چیز را به یک طرف ببرید و فاکتور بگیرید.

## روش سوم: مربع کامل

اگر فاکتورگیری آسان نباشد، می‌توانیم معادله را به شکل (x + p)² = q درآوریم.

**مثال:** x² + ۶x + ۲ = ۰
۱) عدد ثابت را به طرف دیگر می‌بریم: x² + ۶x = −۲
۲) نصف ضریب x یعنی ۳ را به توان دو می‌رسانیم (۹) و به دو طرف اضافه می‌کنیم: x² + ۶x + ۹ = ۷
۳) سمت چپ مربع کامل است: (x + ۳)² = ۷
۴) x + ۳ = ±√۷، پس x = −۳ ± √۷.

## مثال کاربردی: همان زمین

x(x + ۲) = ۴۸ → x² + ۲x − ۴۸ = ۰ → (x + ۸)(x − ۶) = ۰.
x = ۶ یا x = −۸. عرض نمی‌تواند منفی باشد، پس عرض ۶ متر و طول ۸ متر است. (۶ × ۸ = ۴۸ ✓)

همیشه جواب را با مسئله بسنجید؛ هر ریشه‌ای که معنی ندارد کنار گذاشته می‌شود.

## جمع‌بندی

- شکل کلی: ax² + bx + c = ۰ با a ≠ ۰
- بدون جمله‌ی x: ریشه‌گیری مستقیم
- ضرب‌شدنی به صفر: فاکتورگیری
- در حالت کلی: مربع کامل (و در درس بعد، فرمول کلی)
- جواب نهایی را با شرایط مسئله بسنجید
