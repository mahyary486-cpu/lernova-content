# 库仑定律与电场强度

## 库仑定律

真空中两个静止点电荷之间的作用力：

**F = k q₁q₂ / r²**，k = 9×10⁹ N·m²/C²。

同种电荷相互排斥，异种电荷相互吸引。

**例：** q₁ = q₂ = 1×10⁻⁶ C，相距 r = 0.3 m：

F = 9×10⁹ × 10⁻¹² / 0.09 = 0.1 N。

## 电场强度

- 定义式：**E = F / q**，方向与**正电荷**受力方向相同；
- 点电荷的场强：**E = kQ / r²**；
- 匀强电场：各点场强大小、方向都相同。

**例：** Q = 4×10⁻⁹ C，在 r = 0.6 m 处：

E = 9×10⁹ × 4×10⁻⁹ / 0.36 = 36 / 0.36 = 100 N/C。

## 电场线

- 从正电荷出发，到负电荷（或无穷远）终止；
- 疏密表示场强大小，切线方向表示场强方向；
- 电场线不相交、不闭合。

场强是矢量，多个场源的场强叠加遵循平行四边形定则。
