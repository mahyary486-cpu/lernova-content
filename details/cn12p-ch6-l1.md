# 欧姆定律、电阻定律与电功率

## 欧姆定律

**I = U / R**，适用于金属导体和电解质溶液。

## 电阻定律

导体的电阻 **R = ρ L / S**。ρ 是电阻率，与材料、温度有关。

**例：** 铜导线 ρ = 1.7×10⁻⁸ Ω·m，L = 100 m，S = 1×10⁻⁶ m²：

R = 1.7×10⁻⁸ × 100 / 10⁻⁶ = 1.7 Ω。

## 电功与电功率

- 电功 W = UIt；电功率 P = UI；
- **纯电阻**电路：P = I²R = U²/R，电能全部转化为内能；
- **非纯电阻**（如电动机）：电功率 UI = 热功率 I²R + 机械功率 P机。

**例：** 电动机 U = 220 V，I = 2 A，线圈电阻 R = 5 Ω：

- 总功率 P = 220 × 2 = 440 W；
- 热功率 P热 = I²R = 20 W；
- 机械功率 P机 = 440 − 20 = 420 W。

## 串并联

- 串联：电流相等，电压与电阻成正比；
- 并联：电压相等，电流与电阻成反比。
