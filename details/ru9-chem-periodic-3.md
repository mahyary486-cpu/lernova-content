# Типы и скорость химических реакций

**Типы реакций по числу и составу веществ.**

- **Соединения:** A + B → AB (2H₂ + O₂ → 2H₂O).
- **Разложения:** AB → A + B (CaCO₃ → CaO + CO₂).
- **Замещения:** простое вещество вытесняет элемент из сложного (Zn + 2HCl → ZnCl₂ + H₂).
- **Обмена:** вещества обмениваются составными частями (NaOH + HCl → NaCl + H₂O).

**По тепловому эффекту** реакции бывают **экзотермические** (тепло выделяется, например горение угля) и **эндотермические** (тепло поглощается, например разложение известняка).

**Скорость реакции** растёт при повышении температуры, увеличении концентрации реагентов, измельчении твёрдых веществ и добавлении **катализатора**. Катализатор ускоряет реакцию, но сам не расходуется.
