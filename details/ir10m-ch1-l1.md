# مجموعه‌های عددی و بازه‌ها

مجموعه‌های عددی را از ساده به کامل می‌شناسیم و زیرمجموعه‌های پیوسته‌ی اعداد حقیقی را با بازه نشان می‌دهیم.

## نکته‌های کلیدی

- N اعداد طبیعی، W اعداد حسابی (با صفر)، Z اعداد صحیح، Q اعداد گویا و R اعداد حقیقی‌اند. روابط: N ⊂ W ⊂ Z ⊂ Q ⊂ R.
- بازه‌ی باز (a, b) یعنی همه‌ی x با a < x < b. بازه‌ی بسته [a, b] یعنی a ≤ x ≤ b. بازه‌ی نیم‌باز [a, b) یعنی a ≤ x < b و (a, b] یعنی a < x ≤ b.
- بازه‌های نامتناهی: (a, +∞) یعنی x > a و (-∞, b] یعنی x ≤ b. ∞ عدد نیست و کنارش همیشه پرانتز می‌گذاریم.
- روی محور اعداد، دایره‌ی توخالی یعنی عدد جزو بازه نیست و دایره‌ی توپر یعنی جزو بازه است.
- اجتماع و اشتراک بازه‌ها را با کشیدن آن‌ها روی یک محور پیدا می‌کنیم.

## مثال‌های حل‌شده

**مثال ۱.** بازه‌ی [-۲, ۳) را با نماد مجموعه بنویسید.
گام ۱: ابتدای بازه بسته است، پس -۲ جزو آن است. گام ۲: انتهای بازه باز است، پس ۳ جزو آن نیست. پاسخ: {x ∈ R | -۲ ≤ x < ۳}.

**مثال ۲.** اگر A = [-۲, ۳) و B = (۱, ۵]، حاصل A ∩ B و A ∪ B و A − B را بیابید.
گام ۱: هر دو را روی محور می‌کشیم. گام ۲: قسمت مشترک از بعد از ۱ تا قبل از ۳ است و خود ۱ در B نیست و ۳ در A نیست، پس A ∩ B = (۱, ۳). گام ۳: اجتماع از -۲ تا ۵ را می‌پوشاند و -۲ و ۵ هر دو جزو یکی از بازه‌ها هستند، پس A ∪ B = [-۲, ۵]. گام ۴: A − B یعنی بخش A که در B نیست: [-۲, ۱].

**مثال ۳.** مجموعه‌ی {x ∈ R | x ≤ ۴} را با بازه بنویسید و بگویید ۴ جزو آن هست یا نه.
گام ۱: x می‌تواند هر عدد کوچک‌تر یا مساوی ۴ باشد. گام ۲: انتهای راست بسته است و سمت چپ نامتناهی. پاسخ: (-∞, ۴]. بله، ۴ جزو آن است.

## اشتباه‌های رایج

- گذاشتن کروشه کنار ∞. کنار ∞ همیشه پرانتز می‌آید.
- اشتباه گرفتن (۱, ۳) به‌عنوان زوج مرتب و بازه. از متن مسئله مشخص می‌شود کدام منظور است.
- فراموش‌کردن اینکه بین هر دو عدد حقیقی بی‌شمار عدد هست و نمی‌توان بازه را «فهرست» کرد.

## به یاد داشته باشید

- پرانتز یعنی نقطه‌ی انتهایی جزو بازه نیست و کروشه یعنی هست.
- N ⊂ W ⊂ Z ⊂ Q ⊂ R.
- برای اجتماع و اشتراک بازه‌ها آن‌ها را روی محور بکشید.
