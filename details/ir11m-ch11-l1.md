# فضای نمونه، پیشامد و قاعده‌های احتمال

## این درس درباره‌ی چیست؟

احتمال میزان امکان رخ دادن یک پیشامد را با عددی بین 0 و 1 می‌سنجد.

## مفهوم‌ها

- **فضای نمونه** S: مجموعه‌ی همه‌ی حالت‌های ممکن آزمایش
- **پیشامد**: زیرمجموعه‌ای از S
- در فضای هم‌شانس: **P(A) = تعداد حالت‌های مطلوب ÷ تعداد کل حالت‌ها**

**مثال:** در پرتاب تاس P(زوج) = 3/6 = 1/2.

## قاعده‌ها

- 0 ≤ P(A) ≤ 1، P(S) = 1 و P(∅) = 0
- **P(A′) = 1 − P(A)**
- **P(A ∪ B) = P(A) + P(B) − P(A ∩ B)**
- اگر A و B ناسازگار باشند P(A ∪ B) = P(A) + P(B)

**مثال:** P(A) = 0٫5 و P(B) = 0٫4 و P(A ∩ B) = 0٫2 ⇒ P(A ∪ B) = 0٫7.
