# 原子核与核能

## 核反应方程

核反应中，**质量数和电荷数都守恒**。

**例 1（卢瑟福发现质子）：** ¹⁴₇N + ⁴₂He → ¹⁷₈O + ¹₁H

质量数：14 + 4 = 17 + 1；电荷数：7 + 2 = 8 + 1。

**例 2（裂变）：** ²³⁵₉₂U + ¹₀n → ¹⁴⁴₅₆Ba + ⁸⁹₃₆Kr + 3¹₀n

## 衰变与半衰期

- α 衰变：质量数减 4，电荷数减 2；
- β 衰变：电荷数加 1；
- 半衰期：N = N₀ (1/2)^(t/τ)，由原子核本身决定。

## 核能

**ΔE = Δm · c²**，1 u 对应 931.5 MeV。

**例（聚变）：** ²₁H + ³₁H → ⁴₂He + ¹₀n，质量亏损 Δm = 0.0189 u：

ΔE = 0.0189 × 931.5 ≈ **17.6 MeV**。

## 重核裂变与轻核聚变

- 裂变：原子弹、核电站；
- 聚变：氢弹、太阳内部，需要极高的温度。

比结合能越大，原子核越稳定。
