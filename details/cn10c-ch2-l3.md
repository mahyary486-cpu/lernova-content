# 氯气的实验室制法与氯离子的检验

## 实验室制取氯气

MnO₂ + 4HCl（浓）=(△)= MnCl₂ + Cl₂↑ + 2H₂O

装置顺序：

1. **发生装置**：固体 + 液体，需要加热；
2. **除杂**：先通过饱和食盐水除去 HCl，再通过浓硫酸干燥；
3. **收集**：向上排空气法；
4. **尾气处理**：用 NaOH 溶液吸收。

## 氯离子的检验

取少量待测液，先加入稀硝酸酸化，再滴加 **AgNO₃ 溶液**，若产生**白色沉淀**，则含 Cl⁻：

Ag⁺ + Cl⁻ = AgCl↓

加稀硝酸的目的是排除 CO₃²⁻ 等离子的干扰。

## 例题

**例：** 4.6 g 钠（0.2 mol）与足量的水反应，生成 H₂ 0.1 mol，在标准状况下的体积为 0.1 × 22.4 = 2.24 L。
