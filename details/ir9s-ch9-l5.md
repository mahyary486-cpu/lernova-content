# Mechanical advantage and efficiency

Mechanical advantage tells how much a machine multiplies a force, and efficiency tells how much of the input work becomes useful work.

## Key ideas

- Mechanical advantage (MA) = load force / effort force. It has no unit because it is a ratio.
- If MA is greater than 1, the machine multiplies the force. If MA is less than 1, the machine gives up force to gain distance or speed.
- The ideal mechanical advantage (IMA) is found from the shape of the machine, for example length / height for a ramp. It assumes no friction.
- The actual mechanical advantage (AMA) is found from real forces: load / effort. Because of friction, AMA is smaller than IMA.
- Work input = effort × distance moved by the effort. Work output = load × distance moved by the load.
- A machine cannot give more work than it receives. Work output is always smaller than or equal to work input.
- Efficiency = (useful work output / work input) × 100%.
- Efficiency is always less than 100% for real machines, because some energy changes into heat by friction and sound.
- To improve efficiency, reduce friction with oil, wheels or bearings, and use light parts.

## Examples

Example 1: Mechanical advantage. A machine lifts a 600 N load with an effort of 150 N.
- MA = 600 / 150 = 4.
- The machine multiplies the force by 4.

Example 2: A ramp with friction. A worker pushes a 500 N load up a ramp that is 3 m long and 1.2 m high. The effort along the ramp is 300 N.
- Work output = 500 × 1.2 = 600 J.
- Work input = 300 × 3 = 900 J.
- Efficiency = 600 / 900 × 100% ≈ 66.7%.
- IMA = 3 / 1.2 = 2.5, and AMA = 500 / 300 ≈ 1.67.
- The lost energy is 900 - 600 = 300 J, changed to heat by friction.

Example 3: A pulley system. A pulley system lifts an 800 N load by 2 m. The effort is 500 N and it moves 4 m.
- Work output = 800 × 2 = 1600 J.
- Work input = 500 × 4 = 2000 J.
- Efficiency = 1600 / 2000 × 100% = 80%.

## Common mistakes

- Saying that a machine has an efficiency above 100%. This would mean that energy is created, which is not possible.
- Mixing up the ideal and the actual mechanical advantage.
- Using the wrong distance. The input distance is the one moved by the effort, and the output distance is the one moved by the load.
- Writing the efficiency as a fraction when the question asks for a percentage.

## Remember

- MA = load / effort.
- Efficiency = useful work output / work input × 100%.
- Friction makes real machines less than 100% efficient.
