# 光的折射与全反射

## 折射定律

光从真空射入介质：

**n = sin θ₁ / sin θ₂**（θ₁ 为入射角，θ₂ 为折射角）

折射率还可表示为 **n = c / v**，n > 1，所以光在介质中的速度小于真空中的光速。

**例：** 入射角 60°，折射角 30°：n = sin 60° / sin 30° = √3；光在介质中的速度 v = c / n = 3×10⁸ / √3 ≈ 1.73×10⁸ m/s。

## 全反射

光从**光密介质**射向**光疏介质**，当入射角**大于或等于临界角 C** 时，折射光线消失，只剩反射光线：

**sin C = 1 / n**

**例：** n = √2，sin C = 1/√2，C = 45°。

## 应用

- **光导纤维**：利用全反射传递光信号，用于光纤通信；
- 钻石的璀璨：折射率大、临界角小，容易发生全反射；
- 海市蜃楼、沙漠蜃景。
