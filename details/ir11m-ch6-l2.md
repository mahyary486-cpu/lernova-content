# قاعده‌های حد و روش‌های جبری

## این درس درباره‌ی چیست؟

برای محاسبه‌ی حدهای مبهم (مثل 0/0) ابتدا عبارت را ساده می‌کنیم.

## قاعده‌ها

حد جمع، تفاضل، ضرب و تقسیم (با مخرج غیرصفر) برابر جمع، تفاضل، ضرب و تقسیم حدهاست. برای چندجمله‌ای‌ها کافی است مقدار نقطه را جای‌گذاری کنیم.

## حالت 0/0

- **تجزیه و ساده کردن:** lim(x→2) (x² − 4)/(x − 2) = lim (x + 2) = 4
- **ضرب در مزدوج:** lim(x→0) (√(x + 4) − 2)/x = 1/4
- حدهای مثلثاتی: lim(x→0) sin x / x = 1 و lim(x→0) tan x / x = 1
