# Somme de variables aléatoires : espérance et variance

## Espérance
- E(X + Y) = E(X) + E(Y) (toujours vraie).
- E(aX + b) = aE(X) + b.
Exemple : si E(X) = 3, alors E(2X + 1) = 7. Si E(X) = 4, E(3X − 2) = 10.

## Variance et écart-type
- V(aX + b) = a² V(X). Si V(X) = 9, alors V(3X − 2) = 81.
- Si X et Y sont indépendantes : V(X + Y) = V(X) + V(Y), et aussi V(X − Y) = V(X) + V(Y).
- σ(X) = √V(X).
Exemple : V(X) = 2 et V(Y) = 3 avec X et Y indépendantes donnent V(X + Y) = 5.
Exemple : E(X) = 2, E(Y) = 5, V(X) = 1, V(Y) = 4, indépendantes : E(X − Y) = −3 et V(X − Y) = 5.

## Moyenne d’un échantillon
Soient X_1, …, X_n indépendantes de même loi, d’espérance μ et de variance V. La moyenne M_n = (X_1 + … + X_n)/n vérifie
E(M_n) = μ, V(M_n) = V/n et σ(M_n) = σ/√n.
Exemple : V = 16, n = 4 donne V(M_n) = 4. Avec σ = 6 et n = 9, σ(M_n) = 2.

## Interprétation
Quand n augmente, l’écart-type de la moyenne diminue : la moyenne se concentre autour de μ.

## Pour que σ(M_n) ≤ 0,1 avec σ = 1
σ/√n ≤ 0,1 équivaut à √n ≥ 10, donc n ≥ 100.

## Erreur fréquente
La relation V(X + Y) = V(X) + V(Y) n’est valable que si X et Y sont indépendantes.
