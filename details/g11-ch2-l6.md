# Quadratic Inequalities

## What is a quadratic inequality?
It looks like ax^2 + bx + c > 0 (or <, ≥, ≤). The solution is a set of x-values, usually an **interval** or two intervals.

## Method (sign analysis)
1. Move everything to one side, so the other side is 0.
2. Find the **boundary points**: solve ax^2 + bx + c = 0 (factor or use the formula).
3. These points split the number line into intervals. Test one number from each interval.
4. Keep the intervals where the inequality is true. Use open circles for < and >, closed circles for ≤ and ≥.

## Using the graph
For a parabola that opens up:
- The part **below** the x-axis (y < 0) is **between** the roots.
- The part **above** the x-axis (y > 0) is **outside** the roots.

## Examples
- **x^2 - 9 < 0.** Roots are -3 and 3. Between the roots the parabola is below the axis, so **-3 < x < 3**.
- **x^2 > 4.** Roots are -2 and 2. Outside the roots: **x < -2 or x > 2**.
- **x^2 - x - 6 > 0.** Factor: (x - 3)(x + 2) > 0. Roots are -2 and 3. Outside: **x < -2 or x > 3**.
- **x^2 - 5x + 4 ≤ 0.** Roots are 1 and 4. Between, including the roots: **1 ≤ x ≤ 4**.
- **-x^2 + 4 ≥ 0.** Move: x^2 ≤ 4, so **-2 ≤ x ≤ 2**.
- **2x^2 - 3x - 2 < 0.** Factor: (2x + 1)(x - 2) < 0. Roots are -1/2 and 2. Between: **-1/2 < x < 2**.

## No real roots
If the quadratic never touches the x-axis, the answer is either **all real numbers** or **no solution**, depending on which side of the axis the parabola is.
x^2 + x + 1 > 0: here D = 1 - 4 = -3 < 0 and the parabola opens up, so it is always above the axis. The solution is **all real numbers**.

## Common mistakes
- Forgetting to flip the inequality sign when multiplying or dividing by a negative number.
- Writing "between" when the answer is "outside", and the other way around.
- Using open circles when the sign is ≤ or ≥.
- Not moving all terms to one side first.
