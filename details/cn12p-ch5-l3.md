# 电容器与带电粒子在电场中的运动

## 电容器

- 电容 **C = Q / U**，单位法拉（F）；
- 平行板电容器：C = εS / (4πkd)（S 为正对面积，d 为板间距）。

**例：** C = 2×10⁻⁶ F，U = 100 V：Q = CU = 2×10⁻⁴ C。

**两种情况：**

- 充电后与电源**断开**：Q 不变；
- 与电源**保持连接**：U 不变。

## 带电粒子的加速

电场力做功等于动能增加：

**qU = ½mv²**，所以 **v = √(2qU / m)**。

**例：** 电子（q = 1.6×10⁻¹⁹ C，m = 9.1×10⁻³¹ kg）经 U = 100 V 加速：

v = √(2 × 1.6×10⁻¹⁹ × 100 / 9.1×10⁻³¹) ≈ 5.9×10⁶ m/s。

## 带电粒子的偏转（类平抛）

粒子以 v₀ 垂直射入匀强电场：

- 垂直电场方向：匀速运动，t = L / v₀；
- 沿电场方向：匀加速，a = qE / m = qU / (md)；
- 偏转位移 y = ½at²。

基本粒子（电子、质子）一般不计重力；带电小球、油滴等要计重力。
