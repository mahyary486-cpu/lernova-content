# Sequences and Notation

## What is a sequence?
A **sequence** is an ordered list of numbers called **terms**. We write a_1, a_2, a_3, ... and a_n is the **nth term**. The number n is the **position** of the term.

## Explicit formulas
An **explicit formula** gives a_n directly from n.
- a_n = 3n - 1 gives 2, 5, 8, 11, ... For example a_4 = 3(4) - 1 = **11**.
- a_n = n^2 gives 1, 4, 9, 16, ...
- a_n = 2^n - 1 gives 1, 3, 7, 15, 31, ... so a_5 = **31**.
- a_n = (-1)^n * n alternates in sign: -1, 2, -3, 4, ... so a_3 = **-3**.

## Recursive formulas
A **recursive formula** gives the first term and a rule that uses the previous term.
- a_1 = 2 and a_n = a_(n-1) + 3 gives 2, 5, 8, ... so a_3 = **8**.
- a_1 = 3 and a_n = 2 a_(n-1) - 1 gives 3, 5, 9, 17, ... so a_4 = **17**.
To find a_10 from a recursive formula you must find every term before it, so explicit formulas are faster.

## Writing a formula from a pattern
Look at how the terms change.
- 2, 5, 8, 11: add 3 each time, so a_n = **3n - 1**.
- 1, 4, 9, 16: squares, so a_n = **n^2**.
- 3, 6, 12, 24: multiply by 2 each time, so a_n = 3 * 2^(n-1).

## Factorials
n! (read "n factorial") is the product of the whole numbers from n down to 1.
- 4! = 4 * 3 * 2 * 1 = 24
- 5! = **120**
- 0! is defined to be 1.

## Worked examples
1. a_n = 2n + 5. Then a_1 = 7, a_2 = 9, a_3 = 11.
2. Fibonacci: a_1 = 1, a_2 = 1, a_n = a_(n-1) + a_(n-2) gives 1, 1, 2, 3, 5, 8, ...

## Common mistakes
- Mixing up the position n and the value of the term.
- Forgetting that (-1)^n changes sign with every term.
- Using n! as n times a number. 5! is not 5 times 1.
