# Regla de Ruffini y teorema del resto

## Ruffini
Para dividir P(x) = x³ − 2x² − 5x + 6 por (x − 3):
- Coeficientes: 1, −2, −5, 6.
- Se baja el 1; 1·3 = 3 → −2 + 3 = 1; 1·3 = 3 → −5 + 3 = −2; −2·3 = −6 → 6 − 6 = 0.
- Cociente: x² + x − 2. Resto: 0.

## Teorema del resto
El resto de dividir P(x) por (x − a) es P(a).

## Teorema del factor
Si P(a) = 0, entonces (x − a) divide a P.

## Aplicación
Como el resto fue 0, x³ − 2x² − 5x + 6 = (x − 3)(x² + x − 2) = (x − 3)(x − 1)(x + 2).

## Error frecuente
Usar a con el signo equivocado: para dividir por (x + 2) se usa a = −2.
