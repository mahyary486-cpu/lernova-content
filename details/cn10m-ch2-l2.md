# 一元二次不等式

## 解法

设 a > 0，方程 ax² + bx + c = 0 的判别式 Δ = b² − 4ac。

| 判别式 | ax² + bx + c > 0 | ax² + bx + c < 0 |
|---|---|---|
| Δ > 0（根为 x₁ < x₂） | x < x₁ 或 x > x₂ | x₁ < x < x₂ |
| Δ = 0（根为 x₀） | x ≠ x₀ | 无解 |
| Δ < 0 | R | 无解 |

口诀：**大于取两边，小于取中间**。

## 解题步骤

1. 化成标准形式（二次项系数为正）；
2. 求出对应方程的根；
3. 画出二次函数草图，写出解集。

## 例题

**例 1：** x² − 3x + 2 < 0，即 (x − 1)(x − 2) < 0，解集为 {x | 1 < x < 2}。

**例 2：** x² − 2x − 3 > 0，即 (x − 3)(x + 1) > 0，解集为 {x | x < −1 或 x > 3}。
