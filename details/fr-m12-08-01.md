# Vecteurs, repérage et coordonnées dans l’espace

## Repère
Un repère orthonormé de l’espace est (O ; i, j, k), formé d’une origine et de trois vecteurs unitaires deux à deux orthogonaux. Un point M a pour coordonnées (x ; y ; z).

## Coordonnées de vecteurs
Le vecteur AB a pour coordonnées (xB − xA ; yB − yA ; zB − zA).
Exemple : A(1 ; 0 ; 2) et B(4 ; 2 ; 3) donnent AB(3 ; 2 ; 1).

## Milieu
Le milieu I de [AB] a pour coordonnées ((xA + xB)/2 ; (yA + yB)/2 ; (zA + zB)/2).
Exemple : A(1 ; 2 ; 3) et B(3 ; 4 ; 5) donnent I(2 ; 3 ; 4).

## Norme et distance
‖u‖ = √(x² + y² + z²) pour u(x ; y ; z).
Exemples : ‖(1 ; 2 ; 2)‖ = 3 ; ‖(2 ; 3 ; 6)‖ = 7. La distance AB est la norme de AB : A(0 ; 0 ; 0) et B(2 ; 3 ; 6) donnent AB = 7.

## Colinéarité
Deux vecteurs sont colinéaires si l’un est un multiple de l’autre : (1 ; 2 ; 3) et (2 ; 4 ; 6) sont colinéaires. Trois points A, B, C sont alignés si AB et AC sont colinéaires.
Exemple : A(1 ; 2 ; 3), B(2 ; 4 ; 6), C(3 ; 6 ; 9) : AB(1 ; 2 ; 3) et AC(2 ; 4 ; 6) donc A, B, C sont alignés.

## Coplanarité
Trois vecteurs u, v, w sont coplanaires si l’un est une combinaison linéaire des deux autres.

## Erreur fréquente
Dans l’espace, la formule de la distance comporte trois termes sous la racine.
