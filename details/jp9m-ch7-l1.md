# 三平方の定理

## 定理

直角三角形で、直角をはさむ2辺の長さを a、b、斜辺の長さを c とすると

**a² + b² = c²**

**例：** a = 3、b = 4 のとき c² = 9 + 16 = 25 より c = 5。

**例：** 斜辺 13、1辺 5 のとき、他の辺 b は b² = 169 − 25 = 144 より b = 12。

## 逆

3辺の長さが a、b、c の三角形で a² + b² = c² が成り立てば、c を斜辺とする直角三角形です。

**例：** 5、12、13 → 25 + 144 = 169 = 13² なので直角三角形。

## 覚えておくと便利な組

(3, 4, 5)、(5, 12, 13)、(8, 15, 17)、(7, 24, 25)
