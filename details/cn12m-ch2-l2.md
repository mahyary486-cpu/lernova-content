# 导数与不等式恒成立

## 解题方法

1. **分离参数**：把参数 a 分离出来，转化为 a ≥ g(x)ₘₐₓ 或 a ≤ g(x)ₘᵢₙ；
2. **构造函数**：令 h(x) = f(x) − g(x)，求 h(x) 的最值。

## 经典不等式

**例 1：** eˣ ≥ x + 1。

令 h(x) = eˣ − x − 1，h′(x) = eˣ − 1。x < 0 时 h′ < 0，x > 0 时 h′ > 0，所以 h(x) 在 x = 0 处取最小值 h(0) = 0，于是 h(x) ≥ 0。

**例 2：** x > 0 时，ln x ≤ x − 1。

令 h(x) = x − 1 − ln x，h′(x) = 1 − 1/x，x = 1 时取最小值 h(1) = 0。

## 分离参数

**例：** x² + ax + 1 ≥ 0 对一切 x > 0 恒成立，求 a 的范围。

分离参数：a ≥ −(x + 1/x)。因为 x + 1/x ≥ 2，所以 −(x + 1/x) 的最大值为 −2，于是 a ≥ −2。

## 提示

注意"恒成立"与"存在"的区别：恒成立用最值，存在性问题取另一端的最值。
