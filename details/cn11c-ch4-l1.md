# 原电池原理与化学电源

## 原电池

把**化学能转化为电能**的装置。

- **负极**：较活泼的金属，发生**氧化反应**，失去电子；
- **正极**：发生**还原反应**，得到电子；
- 电子由负极经导线流向正极；电流方向相反；
- **盐桥**：连接两个半电池，形成闭合回路并平衡电荷。

## Zn − Cu 原电池（CuSO₄ 溶液）

- 负极：Zn − 2e⁻ = Zn²⁺；
- 正极：Cu²⁺ + 2e⁻ = Cu；
- 总反应：Zn + Cu²⁺ = Zn²⁺ + Cu。

## 化学电源

- **一次电池**：如锌锰干电池，不能充电；
- **二次电池**（可充电）：如铅酸蓄电池，放电时：
  - 负极：Pb + SO₄²⁻ − 2e⁻ = PbSO₄；
  - 正极：PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ = PbSO₄ + 2H₂O；
- **燃料电池**：氢氧燃料电池（酸性）：
  - 负极：H₂ − 2e⁻ = 2H⁺；
  - 正极：O₂ + 4H⁺ + 4e⁻ = 2H₂O。

燃料电池的反应物不是储存在电池内部，而是连续从外部通入。
