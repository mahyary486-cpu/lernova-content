# 因数分解と式の利用

## 因数分解とは

多項式を、いくつかの式の**積**の形に表すことを**因数分解**といいます。展開の逆の計算です。

## 1. 共通因数をくくり出す

各項に共通な因数を見つけて、かっこの外に出します。

**例：** 6x² + 9x = 3x(2x + 3)

## 2. 公式を使う

1. x² + (a + b)x + ab = (x + a)(x + b)
2. x² + 2ax + a² = (x + a)²
3. x² − 2ax + a² = (x − a)²
4. x² − a² = (x + a)(x − a)

**例：** x² + 5x + 6 = (x + 2)(x + 3)（積が 6、和が 5 になる2数は 2 と 3）

**例：** 2x² − 8 = 2(x² − 4) = 2(x + 2)(x − 2)（まず共通因数、次に公式）

## 式の利用

- 置きかえ：x + 1 = A とおくと、(x + 1)² − 5(x + 1) + 6 = A² − 5A + 6 = (A − 2)(A − 3) = (x − 1)(x − 2)
- 式の値：x + y = 5、xy = 6 のとき x² + y² = (x + y)² − 2xy = 25 − 12 = 13
