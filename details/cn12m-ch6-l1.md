# 直线与圆锥曲线的位置关系

## 基本方法

1. 联立直线方程与圆锥曲线方程；
2. 消去一个未知数，得到一元二次方程；
3. 用判别式 Δ 判断交点个数；
4. 用韦达定理表示 x₁ + x₂ 和 x₁x₂。

## 弦长公式

直线斜率为 k，与曲线交于 A(x₁, y₁)、B(x₂, y₂)：

**|AB| = √(1 + k²) · |x₁ − x₂|**，其中 |x₁ − x₂| = √((x₁ + x₂)² − 4x₁x₂)。

## 例题

直线 y = x − 1 与抛物线 y² = 4x 交于 A、B 两点，求 |AB|。

- 联立：(x − 1)² = 4x，即 x² − 6x + 1 = 0；
- x₁ + x₂ = 6，x₁x₂ = 1，|x₁ − x₂| = √(36 − 4) = 4√2；
- |AB| = √2 × 4√2 = 8。

检验：过焦点的弦长 = x₁ + x₂ + p = 6 + 2 = 8。

## 注意

消元后二次项系数含参数时，要讨论它是否为 0。
