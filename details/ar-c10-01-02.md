# Hidróxidos y ácidos

## Hidróxidos
Óxido básico + H₂O → hidróxido.
CaO + H₂O → Ca(OH)₂.

## Oxoácidos
Óxido ácido + H₂O → oxoácido.
SO₃ + H₂O → H₂SO₄; N₂O₅ + H₂O → 2 HNO₃.

## Hidrácidos
HCl, HBr, H₂S (en solución acuosa).

## Uso cotidiano
NaOH (soda cáustica), ácido clorhídrico (agua fuerte), ácido sulfúrico (baterías).

## Error frecuente
Escribir Ca(OH)₂ como CaOH₂.
