# Grupos funcionales y reacciones

## Funciones
Alcohol, aldehído, cetona, ácido, éster, amina, amida.

## Reacciones
- Sustitución: alcano + Cl₂ → cloroalcano + HCl.
- Adición: eteno + H₂ → etano.
- Oxidación: etanol → etanal → ácido acético.
- Esterificación: ácido + alcohol → éster + agua.

## Aromas
Los ésteres dan olor a frutas.

## Error frecuente
Confundir aldehído (–CHO) con cetona (–CO–).
