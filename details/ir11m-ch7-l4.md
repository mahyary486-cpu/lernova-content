# قاعده‌ی ضرب، تقسیم و زنجیره‌ای

## این درس درباره‌ی چیست؟

برای مشتق ضرب و تقسیم توابع و توابع ترکیبی قاعده‌های ویژه داریم.

## ضرب و تقسیم

- **(f·g)′ = f′g + fg′**
- **(f/g)′ = (f′g − fg′)/g²**

**مثال:** (x/(x + 1))′ = ((x + 1) − x)/(x + 1)² = 1/(x + 1)².

## قاعده‌ی زنجیره‌ای

**(f(g(x)))′ = f′(g(x)) · g′(x)**.

**مثال:** ((2x + 1)²)′ = 2(2x + 1) × 2 = 4(2x + 1) و ((x² + 1)³)′ = 6x(x² + 1)².
