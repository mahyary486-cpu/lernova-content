# Aritmetik diziler

## Dizi nedir?

Dizi, ℕ⁺ kümesinden ℝ ye tanımlı bir fonksiyondur. Terimleri a₁, a₂, a₃, … biçiminde yazılır; aₙ genel terimdir.

- aₙ = 3n − 2 için a₁ = 1, a₁₀ = 28.
- aₙ = n² − 5n + 4 için terimler: 0, −2, −2, 0, 4, … (negatif terimler n = 2 ve 3 te).

## Aritmetik dizi

Ardışık iki terim farkı sabittir: **d = aₙ₊₁ − aₙ**.

- **Genel terim:** aₙ = a₁ + (n − 1)d
- **Ardışık üç terim:** 2b = a + c (b orta terim)
- d > 0 artan, d < 0 azalan, d = 0 sabit dizi.

**Örnek:** 3, 7, 11, … için d = 4. a₈ = 3 + 7·4 = 31.

## Terimler arası ilişki

aₘ ile aₙ biliniyorsa **d = (aₙ − aₘ)/(n − m)**. a₃ = 11 ve a₇ = 23 ise d = 12/4 = 3 ve a₁ = 11 − 2·3 = 5.

Eşit uzaklıktaki terimlerin toplamı sabittir: a₄ + a₆ = 2a₅.

## İlk n terimin toplamı

**Sₙ = n(a₁ + aₙ)/2 = n[2a₁ + (n − 1)d]/2**

- a₁ = 4, d = 2: a₁₀ = 22 ve S₁₀ = 10·26/2 = 130.
- 1 + 2 + … + n = n(n + 1)/2. 1 den 20 ye toplam 210.
- İlk n tek sayının toplamı n², ilk n çift sayının toplamı n(n + 1) dir.

## Sₙ ile aₙ arasında ilişki

**aₙ = Sₙ − Sₙ₋₁** (n ≥ 2), a₁ = S₁. Sₙ = n² + 2n ise a₁₀ = 120 − 99 = 21.

## Aritmetik ortanca yerleştirme

İki sayı arasına k terim yerleştirmek için toplam k + 2 terim vardır. 5 ile 29 arasına 5 terim: 29 = 5 + 6d → d = 4; ortadaki terim 17.

## Uygulama

Her ay sabit miktar artan birikim aritmetik dizidir: ilk ay 500 TL, her ay 100 TL fazla → 12. ay 500 + 11·100 = 1 600 TL.
