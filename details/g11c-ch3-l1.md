# Solution Concentration Units

Different jobs need different concentration units: molarity for reactions, molality for temperature effects, ppm for traces.

## Key ideas
- **Molarity** M = mol solute / L solution.
- **Molality** m = mol solute / kg solvent.
- **Mass percent** = mass solute / mass solution x 100%.
- **Mole fraction** X = n component / n total.
- **ppm** = mass solute / mass solution x 10^6.
- **Dilution**: M1 V1 = M2 V2.

## Worked examples
**Example 1: Molarity.** Dissolve 11.7 g of NaCl (58.5 g/mol) to make 500 mL of solution.
1. n = 11.7 / 58.5 = 0.2 mol.
2. M = 0.2 / 0.5 = 0.4 M.

**Example 2: Molality.** 0.2 mol of solute is dissolved in 400 g of water.
1. Mass of solvent = 0.4 kg.
2. m = 0.2 / 0.4 = 0.5 mol/kg.

**Example 3: Mole fraction.** 1 mol of ethanol is mixed with 3 mol of water.
1. Total moles = 4.
2. X(ethanol) = 1 / 4 = 0.25.

## Common mistakes
- Using the volume of solvent for molarity.
- Using grams in place of kilograms for molality.
- Adding the solute to the full final volume of water.
