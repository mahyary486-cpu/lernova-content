# Простейшие тригонометрические уравнения

Здесь k — любое целое число.

- **sin x = a** (только при |a| ≤ 1): x = (−1)ᵏ · arcsin a + πk. При a = 1/2: x = π/6 + 2πk или x = 5π/6 + 2πk.
- **cos x = a** (только при |a| ≤ 1): x = ±arccos a + 2πk. При a = −1/2: x = ±2π/3 + 2πk.
- **tg x = a**: x = arctg a + πk. При a = 1: x = π/4 + πk.

**Особые случаи.** Уравнение cos x = 0 даёт x = π/2 + πk. Уравнение sin x = 2 не имеет решений, так как синус не превосходит 1.

На отрезке [0; 2π] уравнение sin x = 1/2 имеет ровно 2 решения.
