# Propiedades de la potenciación

## Propiedades
- Producto de igual base: aᵐ · aⁿ = aᵐ⁺ⁿ.
- Cociente de igual base: aᵐ : aⁿ = aᵐ⁻ⁿ.
- Potencia de potencia: (aᵐ)ⁿ = aᵐ·ⁿ.
- Distributiva respecto del producto y del cociente: (a·b)ⁿ = aⁿ·bⁿ.

## Ejemplos
- 2³ · 2⁴ = 2⁷ = 128.
- 5⁶ : 5² = 5⁴ = 625.
- (3²)³ = 3⁶ = 729.

## No vale para la suma
(a + b)² no es a² + b². Por ejemplo (2 + 3)² = 25, pero 2² + 3² = 13.

## Error frecuente
Multiplicar las bases al multiplicar potencias de igual base: 2³ · 2⁴ no es 4⁷.
