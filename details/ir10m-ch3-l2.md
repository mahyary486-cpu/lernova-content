# توان‌های گویا و قاعده‌های آن‌ها

## این درس درباره‌ی چیست؟

تا اینجا نمای عدد را فقط عددی صحیح می‌دیدیم. ولی می‌توان نما را کسر هم گرفت، مثلاً ۹^(۱/۲). این نوشته‌ها ریشه‌ها را به توان‌ها تبدیل می‌کنند و باعث می‌شود همه‌ی قاعده‌های توان برای ریشه‌ها هم به کار بروند. این یکی از مفیدترین ابزارهای جبر است.

## چرا a^(۱/n) یعنی ریشه‌ی n‌ام؟

اگر بخواهیم قاعده‌ی «توان یک توان» یعنی (a^m)^n = a^(m×n) برای نماهای کسری هم برقرار بماند، باید (a^(۱/۲))^۲ = a^(۱/۲ × ۲) = a^۱ = a باشد. عددی که مربعش a شود، همان √a است. پس باید a^(۱/۲) = √a باشد. همین استدلال برای هر n نتیجه می‌دهد:

**a^(۱/n) = ریشه‌ی n‌ام a**

## توان کسری عمومی

برای نمای m/n داریم:

**a^(m/n) = (ریشه‌ی n‌ام a) به توان m = ریشه‌ی n‌ام (a^m)**

برای محاسبه معمولاً بهتر است اول ریشه بگیریم و بعد به توان m برسانیم، چون عددها کوچک‌تر می‌مانند. مثلاً ۸^(۲/۳) = (∛۸)^۲ = ۲^۲ = ۴.

نمای منفی مثل قبل معکوس می‌گیرد: a^(-m/n) = ۱ / a^(m/n).

## چرا پایه مثبت می‌گیریم؟

برای توان‌های گویا معمولاً پایه را مثبت در نظر می‌گیریم، چون برای پایه‌ی منفی نتیجه‌ها گیج‌کننده می‌شوند. مثلاً (-۸)^(۱/۳) برابر -۲ است، ولی اگر ۱/۳ را به شکل ۲/۶ بنویسیم نتیجه نباید فرق کند و (-۸)^(۲/۶) با ریشه‌ی زوج دچار مشکل می‌شود. با پایه‌ی مثبت چنین مشکلی پیش نمی‌آید.

## قاعده‌های توان‌ها (برای a > ۰ و b > ۰)

- a^p × a^q = a^(p+q)
- a^p / a^q = a^(p−q)
- (a^p)^q = a^(p×q)
- (a × b)^p = a^p × b^p
- (a / b)^p = a^p / b^p

نماها p و q می‌توانند هر عدد گویا باشند.

## مثال‌های حل‌شده

**مثال ۱.** حاصل ۱۶^(۳/۴) و ۲۷^(-۲/۳) را بیابید.
گام ۱: ۱۶^(۳/۴) = (۱۶^(۱/۴))^۳. ریشه‌ی چهارم ۱۶ برابر ۲ است، پس ۲^۳ = ۸. گام ۲: ۲۷^(-۲/۳) = ۱ / ۲۷^(۲/۳). گام ۳: ۲۷^(۲/۳) = (∛۲۷)^۲ = ۳^۲ = ۹. پاسخ: ۲۷^(-۲/۳) = ۱/۹.

**مثال ۲.** عبارت ۸^(۲/۳) × ۴^(-۱/۲) را ساده کنید.
گام ۱: ۸^(۲/۳) = (∛۸)^۲ = ۴. گام ۲: ۴^(-۱/۲) = ۱ / √۴ = ۱/۲. گام ۳: ۴ × ۱/۲ = ۲. پاسخ: ۲.

**مثال ۳.** عبارت x^(۱/۲) × x^(۳/۲) را برای x > ۰ ساده کنید و ∛(x^۲) را با توان کسری بنویسید.
گام ۱: پایه‌ها برابرند، پس نماها را جمع می‌کنیم: ۱/۲ + ۳/۲ = ۴/۲ = ۲. گام ۲: حاصل x^۲ می‌شود. گام ۳: ∛(x^۲) = x^(۲/۳). پاسخ: x^۲ و x^(۲/۳).

## اشتباه‌های رایج و دلیلشان

- **ضرب‌کردن نماها هنگام ضرب توان‌ها:** وقتی پایه‌ها یکی است، نماها را جمع می‌کنیم.
- **جابه‌جاکردن مخرج و صورت نما:** در a^(m/n)، مخرج n شماره‌ی ریشه و صورت m توان است.
- **فراموش‌کردن معکوس‌گرفتن برای نمای منفی:** a^(-m/n) را باید به ۱ / a^(m/n) تبدیل کنید.

## جمع‌بندی

a^(۱/n) همان ریشه‌ی n‌ام a است و a^(m/n) = (ریشه‌ی n‌ام a)^m. همه‌ی قاعده‌های توان برای نماهای گویا هم برقرارند. برای محاسبه اول ریشه بگیرید و بعد توان را اعمال کنید.
