# 二次方程式・二次不等式

## 判別式

ax² + bx + c = 0 の判別式 D = b² − 4ac

- D > 0：異なる2つの実数解（グラフは x 軸と2点で交わる）
- D = 0：重解（x 軸と1点で接する）
- D < 0：実数解なし（共有点なし）

**例：** x² + kx + 9 = 0 が重解 → k² − 36 = 0 より k = ±6。

## x 軸との交点

y = 0 とおいて x を求めます。2つの交点の距離は |α − β|。

## 二次不等式

(x − α)(x − β) < 0（α < β）の解は α < x < β、> 0 の解は x < α、β < x。グラフが x 軸の下（上）にある範囲です。

**例：** x² − x − 6 ≧ 0 → (x + 2)(x − 3) ≧ 0 → x ≦ −2、3 ≦ x。
