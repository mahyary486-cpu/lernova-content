# Растворы и pH

**Массовая доля** ω = m(вещества) / m(раствора). Если 20 г соли растворили в 180 г воды, ω = 20 / 200 = 10 %. Для приготовления 200 г 5 %-ного раствора нужно 10 г соли.

**Молярная концентрация** c = n / V. При n = 0,5 моль и V = 2 л получаем c = 0,25 моль/л. Для приготовления 500 мл 0,2 М раствора NaOH (M = 40 г/моль) нужно n = 0,1 моль, то есть 4 г.

**Водородный показатель:** pH = −lg [H⁺]. При [H⁺] = 10⁻³ моль/л получаем pH = 3. Раствор HCl с c = 0,01 моль/л имеет pH = 2.

pH < 7 — кислая среда, pH = 7 — нейтральная, pH > 7 — щелочная.
