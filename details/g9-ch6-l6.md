# Comparing Linear, Quadratic and Exponential Models

Three families of functions describe different kinds of change. Telling them apart from a table, graph or equation is a core skill.

## Identifying from a table
Use equally spaced x-values.
- **Linear:** the first differences (change in y) are constant. Equation y = mx + b.
- **Quadratic:** the first differences change, but the **second differences** (differences of the differences) are constant. Equation y = ax^2 + bx + c.
- **Exponential:** the **ratios** of consecutive y-values are constant. Equation y = a * b^x.

## Growth behavior
- Linear: adds the same amount each step.
- Quadratic: the rate of change itself changes steadily; the graph curves.
- Exponential: multiplies by the same factor each step. With b > 1 it eventually grows faster than any linear or quadratic function.

## Worked examples
**Example 1.** x = 0, 1, 2, 3 and y = 2, 5, 8, 11.
1. First differences: 3, 3, 3. Constant, so it is linear: y = 3x + 2.

**Example 2.** x = 0, 1, 2, 3 and y = 1, 2, 5, 10.
1. First differences: 1, 3, 5. Not constant.
2. Second differences: 2, 2. Constant, so it is quadratic: y = x^2 + 1.

**Example 3.** x = 0, 1, 2, 3 and y = 3, 6, 12, 24.
1. Ratios: 2, 2, 2. It is exponential: y = 3 * 2^x.

**Example 4.** Compare y = 2^x and y = x^2.
At x = 2 and x = 4 they are equal (4 and 16). For x = 3, 2^3 = 8 is less than 9. After x = 4, 2^x is always larger; at x = 5, 32 against 25, and at x = 10, 1024 against 100.

## Modeling choices
Constant weekly savings is linear. Area of a square as the side grows is quadratic. A population doubling each year or a loan with compound interest is exponential.

## Common mistakes
- Using first differences alone, which cannot separate quadratic from exponential.
- Comparing differences when the x-values are not equally spaced.
- Thinking an exponential always starts above a quadratic. It may start below but passes it eventually.
