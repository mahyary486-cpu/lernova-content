# 空间中直线与平面的向量表示

## 方向向量与法向量

- 直线的**方向向量** u：与直线平行的非零向量；
- 平面的**法向量** n：垂直于平面的非零向量。

## 用向量研究位置关系

- 线面平行：u · n = 0（且直线不在平面内）；
- 线面垂直：u ∥ n；
- 面面平行：n₁ ∥ n₂；面面垂直：n₁ · n₂ = 0。

## 用向量求角

- **异面直线所成的角** θ：cos θ = |u₁ · u₂| / (|u₁||u₂|)；
- **直线与平面所成的角** θ：sin θ = |u · n| / (|u||n|)；
- **二面角**：|cos θ| = |n₁ · n₂| / (|n₁||n₂|)，具体是锐角还是钝角，要结合图形判断。

## 点到平面的距离

d = |AP · n| / |n|（A 是平面内一点，P 是平面外一点）。

**例 1：** u = (1, 1, 1)，n = (0, 0, 1)：sin θ = 1/√3 = √3/3。

**例 2：** n = (1, 2, 2)，AP = (2, 1, 1)：d = |2 + 2 + 2| / 3 = 2。
