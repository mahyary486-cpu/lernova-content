# دامنه، برد و نمودار

## این درس درباره‌ی چیست؟

هر تابع فقط برای بعضی ورودی‌ها معنی دارد و فقط بعضی خروجی‌ها را می‌سازد. مجموعه‌ی ورودی‌های مجاز را **دامنه** و مجموعه‌ی خروجی‌های ممکن را **برد** می‌نامیم.

## دامنه

دامنه، همه‌ی مقدارهای x است که ضابطه برای آن‌ها تعریف می‌شود. دو محدودیت رایج:

- مخرج نباید صفر شود.
- زیر رادیکال با فرجه‌ی زوج نباید منفی باشد.

**مثال ۱:** f(x) = ۱/(x − ۲). مخرج نباید صفر شود، پس x ≠ ۲. دامنه: ℝ − {۲}.

**مثال ۲:** f(x) = √(x − ۳). باید x − ۳ ≥ ۰ باشد، پس دامنه [۳, +∞) است.

**مثال ۳:** f(x) = x² + ۱ هیچ محدودیتی ندارد. دامنه: ℝ.

## برد

برد را از روی نمودار یا ضابطه پیدا می‌کنیم.

- f(x) = x² + ۱ همیشه ≥ ۱ است، پس برد [۱, +∞) است.
- f(x) = ۲x + ۱ هر مقدار حقیقی می‌گیرد، پس برد ℝ است.

## خواندن دامنه و برد از نمودار

دامنه همان «گستره‌ی افقی» نمودار (از چپ‌ترین تا راست‌ترین نقطه) و برد همان «گستره‌ی عمودی» آن (از پایین‌ترین تا بالاترین نقطه) است.

## تابع خطی

تابع خطی شکل **f(x) = ax + b** دارد و نمودارش خط راست است.
- a شیب خط است: به ازای هر یک واحد افزایش x، مقدار y به اندازه‌ی a تغییر می‌کند.
- b عرض از مبدأ است (نقطه‌ی (۰, b)).

**مثال:** برای f(x) = ۳x − ۲ شیب ۳ و عرض از مبدأ −۲ است. اگر a = ۰ شود، تابع ثابت می‌شود و نمودارش خط افقی است.

## جمع‌بندی

دامنه = ورودی‌های مجاز (مخرج ≠ ۰، زیر رادیکال زوج ≥ ۰). برد = خروجی‌های ممکن. تابع خطی ax + b با شیب a و عرض از مبدأ b.
