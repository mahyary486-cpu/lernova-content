# Buffers and the Henderson-Hasselbalch Equation

A buffer is like a shock absorber for pH: the acid and base pair soaks up added H+ or OH-.

## Key ideas
- A buffer = **weak acid + conjugate base** (comparable amounts).
- **pH = pKa + log([A-] / [HA])**.
- When **[A-] = [HA]**, **pH = pKa**.
- Effective range: **pKa +/- 1**.
- Added acid: **A- + H+ -> HA**; added base: **HA + OH- -> A- + H2O**.
- Blood pH **7.4** is held by the **H2CO3 / HCO3-** buffer.

## Worked examples
**Example 1: Buffer pH.** 0.20 M acetic acid and 0.40 M acetate (pKa = 4.74).
1. pH = 4.74 + log(0.40 / 0.20) = 4.74 + log 2.
2. pH = 4.74 + 0.30 = 5.04.

**Example 2: Adding acid.** To 1.0 L of a buffer with 0.20 mol HA and 0.20 mol A- (pKa 4.74) is added 0.02 mol of HCl.
1. A- falls to 0.18 mol and HA rises to 0.22 mol.
2. pH = 4.74 + log(0.18 / 0.22) = 4.74 - 0.09 = 4.65.

**Example 3: Choosing a buffer.** Which acid is best for a buffer at pH 5: acetic (pKa 4.74) or formic (pKa 3.75)?
1. Choose a pKa close to the desired pH.
2. Acetic acid.

## Common mistakes
- Using the wrong acid/base ratio.
- Forgetting that moles (not concentrations) can be used in the ratio.
- Thinking a buffer stops pH change completely.
