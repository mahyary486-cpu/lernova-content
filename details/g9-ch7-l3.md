# Data Displays

Data displays turn a list of numbers into a picture so that patterns are easier to see. The best display depends on the type of data.

## Types of data
- **Categorical data** places items in groups, such as favorite color.
- **Numerical data** are numbers, such as heights or test scores.

## Common displays
- **Dot plot:** one dot above a number line for each data value. Good for small sets of data.
- **Bar graph:** bars show counts for categories. The bars do not touch.
- **Histogram:** bars show how many values fall in equal-width intervals (bins). The bars touch because the intervals are continuous.
- **Stem-and-leaf plot:** each value is split into a stem (leading digits) and a leaf (last digit). It keeps every actual value.
- **Box-and-whisker plot:** shows the minimum, first quartile Q1, median, third quartile Q3 and maximum.

## Building a stem-and-leaf plot
Data: 12, 15, 21, 23, 23, 27, 31, 38.
1. Stems are the tens digits: 1, 2, 3.
2. Leaves for stem 1: 2, 5. Stem 2: 1, 3, 3, 7. Stem 3: 1, 8.
3. Include a key such as 2 : 3 means 23.

## Reading a histogram
Suppose intervals 0-9, 10-19, 20-29 have frequencies 4, 7, 5. There are 4 + 7 + 5 = 16 values in total. The tallest bar, 10-19, holds the most data. A histogram does not show individual values, only how many are in each interval.

## Shape of a distribution
- **Symmetric:** the left and right sides look alike.
- **Skewed right:** a long tail toward larger values.
- **Skewed left:** a long tail toward smaller values.
- An **outlier** is a value far from the rest.

## Five-number summary example
Data: 2, 4, 5, 7, 8, 10, 12.
1. Minimum = 2, maximum = 12.
2. Median = 7, the middle value.
3. Lower half is 2, 4, 5, so Q1 = 4. Upper half is 8, 10, 12, so Q3 = 10.
4. The box runs from 4 to 10 and the whiskers reach 2 and 12.

Each section of a box plot (whisker, half the box) holds about 25 percent of the data.

## Common mistakes
- Leaving gaps between histogram bars or using unequal bin widths.
- Forgetting to order the leaves from smallest to largest.
- Reading a long box as meaning more data. Box length shows spread, not count.
- Forgetting the key in a stem-and-leaf plot.
