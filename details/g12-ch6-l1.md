# Law of Sines

## The idea
In any triangle with sides a, b, c opposite angles A, B, C:

**a / sin A = b / sin B = c / sin C**

Use it when you know an angle and its opposite side (a "matched pair") plus one more piece: AAS, ASA or SSA.

## Key ideas
- The three angles add to 180 degrees, so two angles give the third.
- Area of a triangle: **Area = (1/2) a b sin C** (two sides and the angle between them).
- SSA (two sides and a non-included angle) is the ambiguous case. It can give 0, 1 or 2 triangles.

## Worked example 1: AAS
A = 40 degrees, B = 60 degrees, a = 10. Find b and c.
1. C = 180 - 40 - 60 = 80 degrees.
2. b = 10 sin 60 / sin 40 = 10(0.8660)/0.6428 = 13.47.
3. c = 10 sin 80 / sin 40 = 10(0.9848)/0.6428 = 15.32.

## Worked example 2: the ambiguous case
A = 30 degrees, a = 8, b = 10. Find B.
1. sin B = b sin A / a = 10(0.5)/8 = 0.625.
2. B = 38.68 degrees, or the supplement B = 180 - 38.68 = 141.32 degrees.
3. Check the second angle: 30 + 141.32 = 171.32, which is less than 180, so both work.
4. Two triangles exist: C = 111.32 degrees or C = 8.68 degrees.

If sin B comes out greater than 1, there is no triangle. If sin B = 1, there is exactly one right triangle.

## Worked example 3: area
Two sides are 7 and 9 with an included angle of 50 degrees.
1. Area = (1/2)(7)(9) sin 50.
2. = 31.5(0.7660) = 24.13 square units.

## Common mistakes
- Using the Law of Sines when you have SAS or SSS. Those need the Law of Cosines.
- Forgetting the second (obtuse) solution in the SSA case.
- Calculator in radian mode when the angles are in degrees.
- Mixing up which side is opposite which angle.
