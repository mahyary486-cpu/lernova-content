# Zero da função afim e aplicações

## Zero da função

É o x tal que f(x) = 0. Em ax + b = 0 temos **x = −b/a**. Para f(x) = 2x − 6, o zero é x = 3.

## Estudo do sinal

Para f(x) = x − 2: f(x) > 0 se x > 2, f(x) = 0 se x = 2 e f(x) < 0 se x < 2. Para a > 0, f é positiva à direita do zero.

## Ponto de encontro de duas retas

Iguala-se f(x) = g(x). Para y = x + 1 e y = −x + 5: x + 1 = −x + 5 → x = 2 e y = 3, ou seja, o ponto (2, 3).

## Aplicações

- **Táxi:** bandeirada de R$ 5 e R$ 2 por km: C(x) = 2x + 5.
- **Plano de celular:** R$ 30 fixos + R$ 0,50 por minuto excedente: uma conta de R$ 55 corresponde a 50 minutos excedentes.

## Taxa de variação

Em f(x) = −3x + 7, a cada aumento de 1 unidade em x, f(x) diminui 3 unidades.
