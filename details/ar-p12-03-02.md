# Espectro electromagnético y aplicaciones

| Región | Aplicación |
|---|---|
| Radio | Comunicaciones, TV |
| Microondas | Hornos, radar, celulares |
| Infrarrojo | Controles remotos, termografía |
| Visible | Visión |
| Ultravioleta | Esterilización, bronceado |
| Rayos X | Radiografías |
| Gamma | Radioterapia |

## Riesgos
Las radiaciones ionizantes (UV intenso, X, gamma) dañan el ADN.

## Error frecuente
Confundir radiación con radiactividad.
