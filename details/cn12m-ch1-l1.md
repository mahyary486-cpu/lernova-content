# 复数的概念

## 虚数单位与复数

规定 **i² = −1**。形如 **z = a + bi**（a、b ∈ R）的数叫复数，a 叫**实部**，b 叫**虚部**。

## 分类

- b = 0：实数；
- b ≠ 0：虚数；其中 a = 0 且 b ≠ 0 的叫**纯虚数**。

## 复数相等

a + bi = c + di ⇔ a = c 且 b = d。

## 共轭复数与模

- 共轭复数：z = a + bi 的共轭为 **z̄ = a − bi**；
- 模：**|z| = √(a² + b²)**。

## 例题

**例 1：** z = 3 + 4i：|z| = 5，z̄ = 3 − 4i。

**例 2：** (m − 1) + (m + 1)i 是纯虚数，则 m − 1 = 0 且 m + 1 ≠ 0，所以 m = 1。

注意：纯虚数要求实部为 0 **且**虚部不为 0。
