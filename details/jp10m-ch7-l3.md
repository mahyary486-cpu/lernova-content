# 方べきの定理と内接円・外接円

## 方べきの定理

- 円の弦 AB、CD の交点 P（円の内部）：PA × PB = PC × PD
- 円の外の点 P から接線 PT と割線 PAB：PT² = PA × PB

**例：** PA = 4、AB = 5（PB = 9）のとき PT² = 36、PT = 6。

## 内接円・外接円の半径

△ABC の面積 S、3辺 a、b、c のとき

- 外接円の半径 R = abc / (4S)
- 内接円の半径 r = 2S / (a + b + c)

**例：** 13、14、15 の三角形は S = 84 で、R = 65/8、r = 4。
