# Галогенҳо ва хлориди гидроген

## Галогенҳо

Фтор (F), хлор (Cl), бром (Br), йод (I) — элементҳои гурӯҳи VII. Молекулаҳояшон дуатомаанд: F₂, Cl₂, Br₂, I₂.

## Хлор

Cl₂ — газ зарди сабз, бӯйи тез ва захрнок. Бо металлҳо ва гидроген реаксия мекунад:

H₂ + Cl₂ → 2HCl

## Хлориди гидроген ва кислотаи хлорид

HCl — газ беранг. Маҳлули он дар об — кислотаи хлорид (намаки), электролити қавӣ.

M(HCl) = 1 + 35,5 = 36,5 г/моль.

## Реаксияи сифатӣ ба Cl⁻

Ag⁺ + Cl⁻ → AgCl↓ (таҳшини сафеди тарбоза).
