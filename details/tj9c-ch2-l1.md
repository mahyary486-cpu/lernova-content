# Галогенҳо ва хлориди гидроген

Фтор (F), хлор (Cl), бром (Br) ва йод (I) галогенҳо мебошанд. Молекулаҳояшон дуатомаанд: F₂, Cl₂, Br₂, I₂. Аз боло ба поён дар гурӯҳ фаъолии галогенҳо кам мешавад, бинобар ин галогени фаъолтар галогени камфаъолро аз намаки он мебарорад: Cl₂ + 2NaBr → 2NaCl + Br₂.

Хлор Cl₂ гази зарди сабзи захрнок аст. Бо гидроген реаксия мекунад: H₂ + Cl₂ → 2HCl. Хлориди гидроген HCl гази беранг аст, дар об хеле хуб ҳал мешавад ва маҳлули он кислотаи хлорид (намак) аст. Массаи молекулавии нисбии HCl = 36,5.

Кислотаи хлорид бо металлҳои пеш аз гидроген дар қатори фаъолӣ реаксия карда H₂ ҷудо мекунад: Zn + 2HCl → ZnCl₂ + H₂↑. Реаксияи сифатӣ ба Cl⁻: Ag⁺ + Cl⁻ → AgCl↓.
