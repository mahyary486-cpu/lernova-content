# 抛物线

## 定义

平面内到一个定点 F 和一条定直线 l（F 不在 l 上）的距离**相等**的点的轨迹。

## 标准方程

**y² = 2px**（p > 0）：

- 焦点 **(p/2, 0)**；
- 准线 **x = −p/2**；
- 开口向右。

另外三种：y² = −2px（向左）、x² = 2py（向上）、x² = −2py（向下）。

## 焦半径

抛物线 y² = 2px 上的点 P(x₀, y₀)：**|PF| = x₀ + p/2**。

## 例题

**例 1：** y² = 8x，2p = 8，p = 4：焦点 (2, 0)，准线 x = −2。

**例 2：** 点 P(2, 4) 在 y² = 8x 上（16 = 8 × 2），|PF| = 2 + 2 = 4。

## 直线与圆锥曲线

联立直线方程与曲线方程，消元后得到一元二次方程，用判别式 Δ 判断交点个数；用韦达定理求弦长、中点等。
