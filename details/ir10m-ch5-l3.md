# تابع چندضابطه‌ای و قدرمطلق

## این درس درباره‌ی چیست؟

بعضی قانون‌ها برای ورودی‌های مختلف فرق می‌کنند. مثلاً تعرفه‌ی پست: تا ۱ کیلوگرم یک قیمت و بعد از آن قیمت دیگر. چنین رابطه‌هایی را با تابع چندضابطه‌ای می‌نویسیم.

## تابع چندضابطه‌ای

در این تابع، ضابطه بسته به بازه‌ی x عوض می‌شود.

**مثال:**
f(x) = x + ۱ اگر x < ۲
f(x) = ۵ اگر x ≥ ۲

- f(۰): چون ۰ < ۲، از ضابطه‌ی اول: ۰ + ۱ = ۱
- f(۲): چون ۲ ≥ ۲، از ضابطه‌ی دوم: ۵
- f(۴): ۵

برای رسم، هر ضابطه را فقط روی بازه‌ی خودش می‌کشیم. در نقطه‌ی مرز با دایره‌ی توپر یا توخالی نشان می‌دهیم که آن نقطه جزو کدام تکه است.

## قدرمطلق

قدرمطلق |x| فاصله‌ی x از صفر است:
|x| = x اگر x ≥ ۰
|x| = −x اگر x < ۰

پس |x| یک تابع چندضابطه‌ای است. |۵| = ۵ و |−۵| = ۵. نمودار y = |x| شکل V است و رأس آن در مبدأ قرار دارد. برد آن [۰, +∞) است.

## قدرمطلق عبارت

**مثال:** f(x) = |x − ۳|
- اگر x ≥ ۳: f(x) = x − ۳
- اگر x < ۳: f(x) = ۳ − x
نمودار همان V است که رأسش به نقطه‌ی (۳, ۰) رفته است. f(۱) = |−۲| = ۲.

## حل معادله‌ی ساده‌ی قدرمطلقی

**مثال:** |x − ۱| = ۴ یعنی x − ۱ = ۴ یا x − ۱ = −۴، پس x = ۵ یا x = −۳.

## جمع‌بندی

تابع چندضابطه‌ای در هر بازه ضابطه‌ی خودش را دارد. قدرمطلق دو ضابطه دارد و نمودارش V شکل است. معادله‌ی |A| = k (با k > ۰) دو جواب A = k یا A = −k دارد.
