# Mode of grouped data

The modal class is the class with the highest frequency. Mode = l + (f₁ − f₀)/(2f₁ − f₀ − f₂) × h, where l is the lower limit of the modal class, f₁ its frequency, f₀ and f₂ the frequencies of the classes before and after, and h the class width.

Example: l = 20, f₁ = 12, f₀ = 8, f₂ = 6, h = 10 gives mode 24.
