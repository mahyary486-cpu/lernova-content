# 酸雨与无机非金属材料

## 酸雨

pH **小于 5.6** 的降水叫酸雨。

形成：

- SO₂ + H₂O ⇌ H₂SO₃，2H₂SO₃ + O₂ = 2H₂SO₄；
- 氮氧化物最终转化为 HNO₃。

## 防治

- 减少化石燃料的使用，开发清洁能源；
- 燃煤脱硫：2CaO + 2SO₂ + O₂ =(高温)= 2CaSO₄；
- 汽车尾气催化转化：2NO + 2CO =(催化剂)= N₂ + 2CO₂。

## 无机非金属材料

- **硅**：半导体材料，用于计算机芯片、太阳能电池；
- **二氧化硅**（SiO₂）：石英、光导纤维的主要成分；
- **硅酸盐**：陶瓷、玻璃、水泥是三大传统硅酸盐材料。

SiO₂ 是酸性氧化物，但不与水反应，能与氢氟酸反应（用氢氟酸刻蚀玻璃）。
