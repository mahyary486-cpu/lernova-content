# Нобаробарии квадратӣ

Нобаробарии квадратӣ ифодаест монанди ax² + bx + c < 0 (ё >, ≤, ≥). Графики функсияи y = ax² + bx + c парабола аст. Агар a > 0, шохаҳои парабола ба боло нигаронида шудаанд, агар a < 0, ба поён.

Қадами аввал: муодилаи ax² + bx + c = 0-ро ҳал карда, решаҳои x₁ < x₂-ро меёбем. Онҳо меҳвари ададиро ба се қисм ҷудо мекунанд. Барои a > 0 байни решаҳо ифода манфӣ, берун аз онҳо мусбат аст. Барои нобаробарии қатъӣ (<, >) худи решаҳо дохил намешаванд (қавсҳои гирд), барои ғайриқатъӣ (≤, ≥) дохил мешаванд (қавсҳои мураббаъ).

Агар D < 0 бошад, парабола меҳвари Ox-ро намебурад: барои a > 0 ифода ҳамеша мусбат аст, пас нобаробарии > 0 барои ҳамаи x дуруст ва < 0 ҳеҷ гоҳ дуруст нест.
