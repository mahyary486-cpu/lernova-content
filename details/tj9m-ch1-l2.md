# Нобаробарӣҳои квадратӣ

## Усули фосилаҳо

1. Нобаробарӣро ба намуди ax² + bx + c ∨ 0 меоранд.
2. Решаҳои ax² + bx + c = 0-ро меёбанд.
3. Решаҳоро ба меҳвари ададӣ мегузоранд ва аломати ифодаро дар ҳар фосила месанҷанд.

## Қоида барои a > 0

- Байни решаҳо ифода **манфӣ** аст, берун аз решаҳо — **мусбат**.
- Барои нобаробарии қатъӣ (<, >) нуқтаҳои охир дохил намешаванд, барои ғайриқатъӣ (≤, ≥) — дохил мешаванд.

**Мисол:** x² − 5x + 6 ≤ 0. Решаҳо 2 ва 3, ҷавоб: [2; 3].

**Мисол:** x² + 2x + 5 > 0. D = 4 − 20 < 0, парабола ба боло, пас нобаробарӣ барои ҳамаи x дуруст аст.
