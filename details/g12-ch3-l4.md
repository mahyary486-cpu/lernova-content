# Logarithmic Equations and Inequalities

## Equations
Combine logs into one, rewrite in exponential form, solve, then **check the domain**.

**log(x) + log(x - 3) = 1.** Combine: log(x(x - 3)) = 1, so x(x - 3) = 10 and x^2 - 3x - 10 = 0. Then (x - 5)(x + 2) = 0. The value x = -2 makes log(-2) undefined, so the only solution is **x = 5**.

**ln(x^2) = 4.** Then x^2 = e^4, so **x = e^2 or x = -e^2**. (Both work, because x^2 is positive for either sign.)

## Inequalities with exponentials
- If the base is **greater than 1**, the inequality keeps its direction when you compare exponents.
  - 2^x > 16 means 2^x > 2^4, so **x > 4**.
  - e^x < 5 means **x < ln 5**.
- If the base is **between 0 and 1**, the direction **reverses**.
  - (1/2)^x < 1/8 means (1/2)^x < (1/2)^3, so **x > 3**.

## Inequalities with logarithms
Remember two things: the argument must be positive, and a base greater than 1 keeps the direction.
- **log_3(x - 1) < 2.** First, x - 1 > 0. Then x - 1 < 3^2 = 9. So **1 < x < 10**.
- **ln x ≥ 1.** x ≥ e^1, so **x ≥ e**.
- **log_2(x) > 3.** x > 2^3, so **x > 8**.
- **log_2(x + 1) ≤ 3.** We need 0 < x + 1 ≤ 8, so **-1 < x ≤ 7**.

## Strategy
1. Find the domain (arguments positive).
2. Rewrite to a single log on one side and a number on the other.
3. Convert to exponential form.
4. Solve and keep only answers in the domain.

## Common mistakes
- Forgetting the domain condition in an inequality (the lower bound like x > 1).
- Reversing the inequality when the base is greater than 1.
- Not reversing it when the base is between 0 and 1.
- Dropping the negative solution of ln(x^2) = 4.
