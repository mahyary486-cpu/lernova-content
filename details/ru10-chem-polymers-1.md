# Полимеры: получение и свойства

**Полимеры** — вещества, молекулы которых состоят из многократно повторяющихся звеньев. Исходные низкомолекулярные вещества называют **мономерами**.

**Полимеризация** — соединение молекул мономера в длинную цепь без выделения побочных продуктов: n CH₂=CH₂ → (–CH₂–CH₂–)ₙ. Число n — **степень полимеризации**. Если M(C₂H₄) = 28 г/моль и n = 1000, то M(полимера) = 28 000 г/моль. Полимер с M = 56 000 г/моль имеет n = 56 000 / 28 = 2000.

**Примеры.** Полиэтилен (из этилена), полипропилен (из пропилена), поливинилхлорид (ПВХ) из винилхлорида CH₂=CHCl, полистирол, тефлон.

**Поликонденсация** — образование полимера с выделением низкомолекулярного вещества (например, воды). Так получают капрон и белки.
