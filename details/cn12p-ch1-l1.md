# 受力分析与物体的平衡综合

## 受力分析的顺序

1. 先画**重力**；
2. 再找**弹力**（接触面、绳、弹簧）；
3. 再找**摩擦力**（有弹力才可能有摩擦力）；
4. 最后分析电场力、磁场力等。

## 整体法与隔离法

- **整体法**：研究系统外力对整体的作用，不考虑内力；
- **隔离法**：求系统内物体间的相互作用力。

## 平衡问题的解法

合成法、分解法、正交分解法：F合 = 0，即 Fₓ = 0，F_y = 0。

## 例题（取 sin 37° = 0.6，cos 37° = 0.8）

**例 1：** 重 G = 20 N 的物体静止在倾角 30° 的斜面上：

- 静摩擦力 f = G sin 30° = 10 N；
- 支持力 N = G cos 30° = 10√3 N。

**例 2：** 重 40 N 的物体用水平绳 OA 和与竖直方向成 37° 的绳 OB 悬挂：

- 竖直方向：T_B cos 37° = G，T_B = 40 / 0.8 = 50 N；
- 水平方向：T_A = T_B sin 37° = 30 N。

## 动态平衡

缓慢变化的过程，物体始终处于平衡状态，可用**图解法**（力的三角形）分析各力的变化。
