# 三角比

## 定義

直角三角形で、角 θ の対辺 a、隣辺 b、斜辺 c のとき

sinθ = a/c、cosθ = b/c、tanθ = a/b

## 30°・45°・60° の値

- 30°：sin = 1/2、cos = √3/2、tan = √3/3
- 45°：sin = √2/2、cos = √2/2、tan = 1
- 60°：sin = √3/2、cos = 1/2、tan = √3

## 相互関係

- tanθ = sinθ / cosθ
- sin²θ + cos²θ = 1、1 + tan²θ = 1/cos²θ

**例：** sinθ = 3/5（0° < θ < 90°）のとき cosθ = 4/5、tanθ = 3/4。
