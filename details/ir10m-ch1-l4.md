# دنباله‌ی حسابی

دنباله‌ی حسابی دنباله‌ای است که هر جمله از جمله‌ی قبل با افزودن یک عدد ثابت به نام قدر نسبت به دست می‌آید.

## نکته‌های کلیدی

- در دنباله‌ی حسابی a_(n+۱) − a_n = d همیشه ثابت است. d را قدر نسبت می‌نامیم.
- جمله‌ی عمومی: a_n = a_۱ + (n − ۱)d.
- مجموع n جمله‌ی اول: S_n = n(a_۱ + a_n)/۲ یا S_n = n(۲a_۱ + (n − ۱)d)/۲.
- میانگین حسابی: اگر a و b و c سه جمله‌ی متوالی یک دنباله‌ی حسابی باشند، b = (a + c)/۲.
- برای درج چند واسطه‌ی حسابی بین دو عدد، اول قدر نسبت را از رابطه‌ی جمله‌ی عمومی به دست می‌آوریم.

## مثال‌های حل‌شده

**مثال ۱.** در دنباله‌ی حسابی با a_۱ = ۵ و d = ۳، جمله‌ی دهم و شماره‌ی جمله‌ای که برابر ۶۲ است را بیابید.
گام ۱: a_۱۰ = ۵ + ۹ × ۳ = ۳۲. گام ۲: ۵ + ۳(n − ۱) = ۶۲ پس ۳(n − ۱) = ۵۷. گام ۳: n − ۱ = ۱۹ و n = ۲۰. پاسخ: a_۱۰ = ۳۲ و جمله‌ی بیستم برابر ۶۲ است.

**مثال ۲.** مجموع ۲۰ جمله‌ی اول همین دنباله را بیابید.
گام ۱: a_۲۰ = ۶۲. گام ۲: S_۲۰ = ۲۰(۵ + ۶۲)/۲ = ۱۰ × ۶۷. پاسخ: ۶۷۰.

**مثال ۳.** بین ۳ و ۱۹ سه واسطه‌ی حسابی درج کنید.
گام ۱: دنباله ۵ جمله دارد: a_۱ = ۳ و a_۵ = ۱۹. گام ۲: ۱۹ = ۳ + ۴d پس d = ۴. گام ۳: جمله‌ها: ۳, ۷, ۱۱, ۱۵, ۱۹. پاسخ: ۷ و ۱۱ و ۱۵.

## اشتباه‌های رایج

- نوشتن a_n = a_۱ + nd. ضریب d برابر (n − ۱) است.
- فراموش‌کردن اینکه بین دو عدد با k واسطه، دنباله k + ۲ جمله دارد.
- استفاده از فرمول مجموع بدون دانستن a_n.

## به یاد داشته باشید

- a_n = a_۱ + (n − ۱)d و S_n = n(a_۱ + a_n)/۲.
- تفاضل جمله‌های متوالی ثابت است.
- b = (a + c)/۲ برای سه جمله‌ی متوالی.
