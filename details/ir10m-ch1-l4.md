# دنباله‌ی حسابی

## این درس درباره‌ی چیست؟

اگر هر روز دقیقاً یک اندازه به مبلغ پس‌اندازتان اضافه کنید، یا هر طبقه از ساختمان به اندازه‌ی ثابتی از طبقه‌ی قبل بالاتر باشد، با یک دنباله‌ی حسابی سروکار دارید. این دنباله‌ها آن‌قدر مرتب‌اند که می‌توان هر جمله و حتی مجموع جمله‌ها را بدون نوشتن همه‌ی آن‌ها حساب کرد.

## تعریف

دنباله‌ی حسابی دنباله‌ای است که تفاضل هر جمله از جمله‌ی قبلی همیشه یک عدد ثابت باشد. به این عدد «قدر نسبت» می‌گوییم و آن را d می‌نامیم:

a_(n+۱) − a_n = d

اگر d مثبت باشد جمله‌ها بزرگ می‌شوند (۵, ۸, ۱۱, ...) و اگر منفی باشد کوچک می‌شوند (۲۰, ۱۷, ۱۴, ...).

## جمله‌ی عمومی

برای رسیدن از جمله‌ی اول به جمله‌ی n‌ام باید (n − ۱) بار d اضافه کنیم، چون از جمله‌ی اول تا جمله‌ی n‌ام (n − ۱) قدم فاصله است. پس:

a_n = a_۱ + (n − ۱) × d

مثلاً برای رسیدن به جمله‌ی پنجم ۴ بار d اضافه می‌کنیم، نه ۵ بار.

## مجموع n جمله‌ی اول

گاوس کوچک متوجه شد که برای جمع ۱ + ۲ + ... + ۱۰۰ کافی است جمله‌ها را دو به دو از دو سر جفت کنیم: ۱ + ۱۰۰ و ۲ + ۹۹ و ... . هر جفت ۱۰۱ می‌شود و ۵۰ جفت داریم. همین فکر برای هر دنباله‌ی حسابی کار می‌کند:

S_n = n × (a_۱ + a_n) / ۲

اگر a_n را ندانیم می‌توانیم آن را از جمله‌ی عمومی جایگزین کنیم: S_n = n × (۲a_۱ + (n − ۱)d) / ۲.

## واسطه‌ی حسابی

اگر a و b و c سه جمله‌ی متوالی یک دنباله‌ی حسابی باشند، b دقیقاً وسط a و c است: b = (a + c)/۲. به b میانگین حسابی یا واسطه‌ی حسابی a و c می‌گوییم. برای درج چند واسطه بین دو عدد، اول d را پیدا می‌کنیم.

## مثال‌های حل‌شده

**مثال ۱.** در دنباله‌ی حسابی با a_۱ = ۵ و d = ۳، جمله‌ی دهم را بیابید و بگویید چندمین جمله برابر ۶۲ است.
گام ۱: a_۱۰ = ۵ + (۱۰ − ۱) × ۳ = ۵ + ۲۷ = ۳۲. گام ۲: برای پیداکردن شماره‌ی جمله‌ی ۶۲ معادله می‌نویسیم: ۵ + ۳(n − ۱) = ۶۲. گام ۳: ۳(n − ۱) = ۵۷ پس n − ۱ = ۱۹ و n = ۲۰. پاسخ: a_۱۰ = ۳۲ و جمله‌ی بیستم برابر ۶۲ است.

**مثال ۲.** مجموع ۲۰ جمله‌ی اول همین دنباله را بیابید.
گام ۱: جمله‌ی بیستم را داریم: a_۲۰ = ۶۲. گام ۲: S_۲۰ = ۲۰ × (۵ + ۶۲) / ۲. گام ۳: ۲۰ × ۶۷ / ۲ = ۱۰ × ۶۷ = ۶۷۰. پاسخ: ۶۷۰.

**مثال ۳.** بین ۳ و ۱۹ سه واسطه‌ی حسابی درج کنید.
گام ۱: اگر سه عدد بین آن دو بگذاریم، روی هم ۵ جمله داریم: a_۱ = ۳ و a_۵ = ۱۹. گام ۲: از جمله‌ی عمومی: ۱۹ = ۳ + ۴d پس ۴d = ۱۶ و d = ۴. گام ۳: جمله‌ها: ۳ و ۷ و ۱۱ و ۱۵ و ۱۹. پاسخ: ۷ و ۱۱ و ۱۵.

## اشتباه‌های رایج و دلیلشان

- **نوشتن a_n = a_۱ + n × d:** از جمله‌ی اول تا n‌ام فقط (n − ۱) قدم فاصله است.
- **فراموش‌کردن تعداد جمله‌ها در درج واسطه:** اگر k واسطه بگذاریم، دنباله k + ۲ جمله دارد، چون دو عدد اولیه هم جزو جمله‌هاست.
- **استفاده از فرمول مجموع بدون دانستن جمله‌ی آخر:** ابتدا a_n را حساب کنید یا از فرمول دوم استفاده کنید.

## جمع‌بندی

در دنباله‌ی حسابی تفاضل متوالی‌ها ثابت است. a_n = a_۱ + (n − ۱)d و S_n = n(a_۱ + a_n)/۲. برای سه جمله‌ی متوالی، جمله‌ی وسط میانگین دو جمله‌ی کناری است.
