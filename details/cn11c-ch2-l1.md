# 化学反应速率

## 定义

**v = Δc / Δt**，单位 mol/(L·s) 或 mol/(L·min)。

同一反应中，用不同物质表示的速率之比等于**化学计量数之比**。

**例 1：** 2A + B → 3C，v(A) = 0.4 mol/(L·s)，则 v(B) = 0.2，v(C) = 0.6 mol/(L·s)。

**例 2：** N₂ + 3H₂ ⇌ 2NH₃，3 s 内 NH₃ 浓度增加 0.6 mol/L：v(NH₃) = 0.2 mol/(L·s)，v(H₂) = 0.2 × 3/2 = 0.3 mol/(L·s)。

## 影响因素

- **浓度**：增大反应物浓度，速率加快；
- **温度**：升高温度，速率加快；
- **催化剂**：改变反应速率，反应前后本身不变；
- **压强**：对有气体参加的反应，增大压强相当于增大浓度；
- 固体表面积：表面积越大，速率越快。

## 碰撞理论

能发生反应的碰撞叫**有效碰撞**，发生有效碰撞的分子叫活化分子。升高温度、使用催化剂都能增大活化分子的百分数。
