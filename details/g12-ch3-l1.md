# Transformed Exponential and Logarithmic Graphs

## Exponential functions f(x) = a * b^(x - h) + k
- The **horizontal asymptote** is **y = k**.
- The **domain** is all real numbers.
- The **range** is y > k if a > 0, and y < k if a < 0.
- The **y-intercept** is f(0).

Example: f(x) = 2^(x - 3) + 1.
- Horizontal asymptote **y = 1**, range **y > 1**.
- y-intercept: f(0) = 2^(-3) + 1 = 1/8 + 1 = **9/8**.

Example: g(x) = -3^x. The negative reflects the graph over the x-axis, so the range is **y < 0** and the asymptote is y = 0.

Example: f(x) = 3 * 2^(-x) = 3 * (1/2)^x is **decay** with y-intercept 3.

## Logarithmic functions f(x) = a * log_b(x - h) + k
- The **vertical asymptote** is **x = h**.
- The **domain** is x > h (when the argument is x - h).
- The range is all real numbers.

Example: h(x) = ln(x + 2) - 1.
- Vertical asymptote **x = -2**, domain **x > -2**.
- x-intercept: ln(x + 2) = 1, so x + 2 = e and x = e - 2, about 0.72.

Example: g(x) = log_2(4 - x). We need 4 - x > 0, so the domain is **x < 4** and the vertical asymptote is x = 4. This is a reflection over the y-axis, then a shift.

Example: y = log(-x) has domain **x < 0**.

## Inverse functions
The exponential and the logarithm are inverses, so their graphs are reflections over **y = x**. The domain and range swap, and the horizontal asymptote becomes a vertical one.
To invert f(x) = 2^x + 1: write y = 2^x + 1, swap x and y, and solve: x - 1 = 2^y, so **f^-1(x) = log_2(x - 1)** with domain x > 1.

## Common mistakes
- Forgetting to find the domain from the **argument** of the log (it must be positive).
- Giving the asymptote of a log as a horizontal line. It is a vertical line x = h.
- Using the wrong sign for the shift. In f(x - h) the shift is to the right.
