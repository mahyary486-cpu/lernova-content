# Solving One-Step and Two-Step Equations

## The balance idea
An equation is like a balanced scale. Whatever you do to one side, you must do to the other.

## Inverse operations
| Operation in the equation | Undo it with |
|---|---|
| + number | - the same number |
| - number | + the same number |
| x number | / the same number |
| / number | x the same number |

## One-step examples
- x + 7 = 12. Subtract 7 from both sides: x = 5.
- 3x = 21. Divide both sides by 3: x = 7.
- x / 4 = 5. Multiply both sides by 4: x = 20.

## Two-step equations
Undo addition or subtraction first, then undo multiplication or division.

**Example.** 2x + 3 = 11
1. Subtract 3: 2x = 8.
2. Divide by 2: x = 4.
3. Check: 2(4) + 3 = 11. Correct.

**Example.** x / 3 - 2 = 4
1. Add 2: x / 3 = 6.
2. Multiply by 3: x = 18.

## Word problems
A taxi charges $3 plus $2 per mile. The total is $17. How many miles?
Write 2m + 3 = 17. Subtract 3: 2m = 14. Divide by 2: m = 7 miles.

## Common mistakes
- Changing only one side of the equation.
- Dividing before subtracting in a two-step equation.
- Dropping a negative sign, such as -4x = 12 giving x = 3 instead of x = -3.
