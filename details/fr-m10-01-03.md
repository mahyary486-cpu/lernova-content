# Valeur absolue et distance entre deux réels

## Définition
La valeur absolue d’un réel x, notée ∣x∣, est :
- x si x ≥ 0 ;
- −x si x ≤ 0.
Exemples : ∣5∣ = 5 ; ∣−7∣ = 7 ; ∣0∣ = 0.

## Distance
La distance entre deux réels a et b est ∣a − b∣. Par exemple, la distance entre 2 et 9 vaut ∣2 − 9∣ = 7.

## Propriétés
- ∣x∣ ≥ 0 pour tout réel x.
- ∣−x∣ = ∣x∣.
- ∣a × b∣ = ∣a∣ × ∣b∣.
- √(x²) = ∣x∣ : par exemple √((−5)²) = 5.

## Équations et inéquations (r > 0)
- ∣x − a∣ = r équivaut à x = a − r ou x = a + r.
- ∣x − a∣ ≤ r équivaut à a − r ≤ x ≤ a + r, c’est-à-dire x ∈ [a − r ; a + r].
- ∣x − a∣ ≥ r équivaut à x ≤ a − r ou x ≥ a + r.
Exemple : ∣x − 2∣ ≤ 3 donne x ∈ [−1 ; 5]. Et ∣x + 1∣ > 2 donne x < −3 ou x > 1.

## Cas sans solution
∣x − 1∣ = −2 n’a aucune solution, car une valeur absolue n’est jamais négative.

## Erreur fréquente
∣a + b∣ n’est pas égal à ∣a∣ + ∣b∣ en général : ∣2 + (−5)∣ = 3 mais ∣2∣ + ∣−5∣ = 7.
