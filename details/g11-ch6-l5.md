# Finite Geometric Series

## The formula
The sum of the first n terms of a geometric series (r not equal to 1) is

**S_n = a_1 (1 - r^n) / (1 - r)**

If r = 1, every term is the same and S_n = n * a_1.

## Why it works
Write S_n = a_1 + a_1 r + ... + a_1 r^(n-1). Multiply by r and subtract: S_n - r S_n = a_1 - a_1 r^n. Then S_n (1 - r) = a_1 (1 - r^n).

## Examples
**2 + 4 + 8 + 16 + 32.** a_1 = 2, r = 2, n = 5. S_5 = 2(1 - 32)/(1 - 2) = 2(-31)/(-1) = **62**.

**1 + 3 + 9 + 27 + 81.** r = 3. S_5 = (1 - 243)/(1 - 3) = **121**.

**With sigma notation.** The sum from k = 1 to 6 of 2^k = 2 + 4 + ... + 64. a_1 = 2, r = 2, n = 6. S = 2(1 - 64)/(1 - 2) = **126**.

**3, 6, 12, ... first 8 terms.** S_8 = 3(1 - 256)/(1 - 2) = 3 * 255 = **765**.

**A fraction ratio.** a_1 = 6, r = 1/2, n = 5. S_5 = 6(1 - 1/32)/(1 - 1/2) = 6 * (31/32) / (1/2) = **93/8**, which is 11.625.

**Alternating signs.** 81 - 27 + 9 - 3 + 1. Here r = -1/3 and n = 5. Adding directly: 81 - 27 = 54, 54 + 9 = 63, 63 - 3 = 60, 60 + 1 = **61**. The formula gives the same value.

**Sigma with a shifted exponent.** The sum from k = 1 to 4 of 5 * 3^(k-1) = 5(1 + 3 + 9 + 27) = **200**.

## Finding the number of terms
Use a_n = a_1 r^(n-1) first to find n, then use the formula for S_n.

## Common mistakes
- Using the arithmetic series formula for a geometric series.
- Forgetting parentheses: (1 - r^n), not 1 - r * n.
- Using r^(n-1) in the sum formula. The sum formula uses r^n.
- Dividing by 1 + r instead of 1 - r.
