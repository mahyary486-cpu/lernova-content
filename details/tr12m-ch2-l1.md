# Limit

## Limit kavramı

lim(x→a) f(x) = L, x ler a ya yaklaşırken (a olmaksızın) f(x) in L ye yaklaşması demektir.

- **Soldan limit:** x → a⁻
- **Sağdan limit:** x → a⁺
- Limitin var olması için **sol limit = sağ limit**.

## Cebirsel hesaplama

- Polinom: değer yerine konur. lim(x→3)(x² − 2x) = 3.
- Sabit fonksiyon: lim(x→5) 7 = 7.

## 0/0 belirsizliği

Pay ve paydanın ikisi de sıfır oluyorsa çarpanlara ayırıp sadeleştirin.

- lim(x→1)(x² − 1)/(x − 1) = lim (x + 1) = 2
- lim(x→3)(x² − 9)/(x² − 5x + 6) = lim (x + 3)/(x − 2) = 6
- lim(x→1)(x³ − 1)/(x − 1) = 1 + 1 + 1 = 3
- lim(x→2)(x³ − 8)/(x² − 4) = 12/4 = 3

**Köklü ifade:** Eşlenikle çarpın veya x − 4 = (√x − 2)(√x + 2) kullanın: lim(x→4)(x − 4)/(√x − 2) = 4. lim(x→0)(√(x + 9) − 3)/x = 1/6.

## Parçalı fonksiyonlar

Parçalı tanımlı fonksiyonda kritik noktada sol ve sağ limit ayrı hesaplanır.

f(x) = 2x + 1 (x < 1), x² + k (x ≥ 1): sol limit 3, sağ limit 1 + k; limit için k = 2.

∣x∣/x için x = 0 da sol limit −1, sağ limit 1 → limit yok.

## Sonsuzda limit

Rasyonel fonksiyonlarda pay ve payda derecesine bakın:

- Pay derecesi < payda derecesi → limit 0 (lim 1/x = 0).
- Dereceler eşit → baş katsayıların oranı: lim(3x + 1)/(x − 2) = 3.
- Pay derecesi > payda derecesi → ±∞.

## İpuçları

- Önce değer yerine koyun; belirsizlik çıkarsa çarpanlara ayırın.
- Limit, fonksiyonun o noktadaki değerinden bağımsızdır.
