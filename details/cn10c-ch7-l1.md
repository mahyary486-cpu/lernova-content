# 硫及其化合物

## 硫

黄色晶体，不溶于水，微溶于酒精，易溶于 CS₂。硫在氧气中燃烧：S + O₂ =(点燃)= SO₂。

## 二氧化硫

无色、有刺激性气味的有毒气体，易溶于水。

- **酸性氧化物**：SO₂ + H₂O ⇌ H₂SO₃；
- **漂白性**：能使品红溶液褪色，加热后又恢复红色（暂时性漂白）；
- **还原性**：2SO₂ + O₂ ⇌ 2SO₃（催化剂、加热）。

## 浓硫酸的特性

- **吸水性**：可作干燥剂；
- **脱水性**：使蔗糖等炭化变黑；
- **强氧化性**：Cu + 2H₂SO₄（浓）=(△)= CuSO₄ + SO₂↑ + 2H₂O。

常温下，浓硫酸使铁、铝**钝化**，所以可以用铁或铝制容器盛装浓硫酸。

浓硫酸稀释时，要把浓硫酸沿器壁缓缓注入水中。
