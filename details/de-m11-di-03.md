# Grundlegende Ableitungsregeln

## Regeln

- **Konstante:** (c)′ = 0
- **Potenzregel:** (xⁿ)′ = n · xⁿ⁻¹
- **Faktorregel:** (c · f)′ = c · f′
- **Summenregel:** (f + g)′ = f′ + g′

## Standardableitungen

- (sin x)′ = cos x
- (cos x)′ = −sin x
- (eˣ)′ = eˣ
- (ln x)′ = 1/x
- (√x)′ = 1/(2√x)
- (1/x)′ = −1/x²

## Beispiele

**Beispiel 1:** f(x) = 3x² − 4x + 1.
f′(x) = 6x − 4.

**Beispiel 2:** f(x) = x⁵ − 2x³.
f′(x) = 5x⁴ − 6x².

**Beispiel 3:** f(x) = 3 · sin x + eˣ.
f′(x) = 3 · cos x + eˣ.

**Beispiel 4:** Tangentensteigung von f(x) = x² an der Stelle x = 3.
f′(3) = 6.

## Tipp

Wurzeln und Brüche zuerst als Potenzen schreiben: √x = x^(1/2) und 1/x = x⁻¹.
