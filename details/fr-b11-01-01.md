# Transcription et traduction

## Du gène à la protéine
Un gène est une portion d’ADN qui code une protéine (ou un ARN). Son expression se fait en deux étapes : transcription puis traduction.

## Transcription
- Lieu : le noyau (chez les eucaryotes).
- Une enzyme, l’ARN polymérase, copie un brin du gène (le brin transcrit) en une molécule d’ARN messager (ARNm).
- L’ARN est monocaténaire et contient l’uracile (U) à la place de la thymine (T).
Exemple : brin transcrit TAC GGA CTT → ARNm AUG CCU GAA.

## Traduction
- Lieu : le cytoplasme, au niveau des ribosomes.
- L’ARNm est lu par groupes de trois nucléotides : les codons.
- Chaque codon correspond à un acide aminé ; des ARN de transfert apportent les acides aminés.
- Les acides aminés sont liés les uns aux autres pour former la protéine.
Exemple : AUG CCU GAA code Méthionine – Proline – Acide glutamique.

## Le code génétique
- 4 bases forment 4³ = 64 codons possibles pour seulement 20 acides aminés : le code est redondant (plusieurs codons peuvent coder le même acide aminé).
- AUG est le codon d’initiation (méthionine) ; UAA, UAG et UGA sont des codons stop.
- Le code est universel : il est le même chez presque tous les êtres vivants.

## Erreur fréquente
La transcription fabrique de l’ARN, pas de la protéine : la protéine est produite par la traduction.
