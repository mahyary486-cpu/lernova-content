# قاعده‌های مشتق چندجمله‌ای‌ها

## این درس درباره‌ی چیست؟

برای مشتق‌گیری سریع از قاعده‌ها استفاده می‌کنیم.

## قاعده‌ها

- مشتق ثابت: **0**
- **(xⁿ)′ = n·xⁿ⁻¹**
- (c·f)′ = c·f′
- (f ± g)′ = f′ ± g′

**مثال:** (x³ − 3x + 1)′ = 3x² − 3 و (1/x)′ = (x⁻¹)′ = −1/x².

## اکسترمم

نقطه‌هایی که f′(x) = 0 است نقطه‌های بحرانی‌اند. اگر f′ از مثبت به منفی برود **بیشینه** و اگر از منفی به مثبت برود **کمینه** داریم. مثلاً f(x) = x² − 4x + 1 در x = 2 کمینه دارد.
