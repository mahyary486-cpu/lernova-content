# 一元二次方程的概念与解法

## 概念

只含有一个未知数，并且未知数的最高次数是 2 的整式方程，叫作**一元二次方程**。

一般形式：**ax² + bx + c = 0**（a ≠ 0）。ax² 叫二次项，bx 叫一次项，c 叫常数项；a、b 分别叫二次项系数、一次项系数。

## 四种解法

1. **直接开平方法**：形如 x² = p（p ≥ 0）或 (x + m)² = p。例：(x − 1)² = 4，x − 1 = ±2，所以 x₁ = 3，x₂ = −1。
2. **配方法**：把方程化成 (x + m)² = n 的形式。例：x² + 6x − 7 = 0，两边加 9 得 (x + 3)² = 16，所以 x₁ = 1，x₂ = −7。
3. **公式法**：当 b² − 4ac ≥ 0 时，x = (−b ± √(b² − 4ac)) / (2a)。例：2x² − 3x − 2 = 0 中 a = 2，b = −3，c = −2，b² − 4ac = 25，x = (3 ± 5) / 4，所以 x₁ = 2，x₂ = −1/2。
4. **因式分解法**：例：x² − 5x + 6 = 0，(x − 2)(x − 3) = 0，所以 x₁ = 2，x₂ = 3。

## 怎样选择方法

先看能否直接开平方或因式分解，都不行再用公式法。

**易错点**：不能把方程两边同时除以含未知数的式子，否则会丢根。例：x² = 3x 应写成 x(x − 3) = 0，得 x = 0 或 x = 3。
