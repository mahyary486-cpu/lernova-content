# 充分条件、必要条件与量词

## 充分条件与必要条件

- 如果 p ⇒ q，那么 p 是 q 的**充分条件**，q 是 p 的**必要条件**；
- 如果 p ⇒ q 且 q ⇒ p，那么 p 是 q 的**充要条件**，记作 p ⇔ q。

**例：** "x > 2" 是 "x > 1" 的**充分不必要条件**：x > 2 可推出 x > 1，但 x > 1 推不出 x > 2。

## 全称量词与存在量词

- 全称量词：∀（"任意""所有"）；全称量词命题：∀x ∈ M，p(x)；
- 存在量词：∃（"存在""有一个"）；存在量词命题：∃x ∈ M，p(x)。

## 命题的否定

- ∀x ∈ M，p(x) 的否定是 **∃x ∈ M，¬p(x)**；
- ∃x ∈ M，p(x) 的否定是 **∀x ∈ M，¬p(x)**。

**例：** "∀x ∈ R，x² ≥ 0" 的否定是 "∃x ∈ R，x² < 0"。

注意：否定时要同时**改变量词**并**否定结论**。
