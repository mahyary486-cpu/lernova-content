# 光电效应与波粒二象性

## 光电效应规律

- 存在**截止频率** ν_c：入射光频率低于 ν_c 不能发生光电效应；
- 光电子的最大初动能随入射光频率增大而增大，与光强**无关**；
- 光强增大，**饱和光电流**增大；
- 发生瞬时。

## 爱因斯坦光电效应方程

**Eₖ = hν − W₀**，h = 6.63×10⁻³⁴ J·s。

## 遏止电压

**eU_c = Eₖ = hν − W₀**

**例：** 逸出功 W₀ = 2.0 eV，光子能量 3.0 eV：

- Eₖ = 1.0 eV；
- 遏止电压 U_c = 1.0 V。

## 截止频率

**ν_c = W₀ / h**

**例：** W₀ = 2 eV = 3.2×10⁻¹⁹ J：ν_c = 3.2×10⁻¹⁹ / 6.63×10⁻³⁴ ≈ 4.8×10¹⁴ Hz。

## 波粒二象性

光既有波动性又有粒子性。实物粒子也具有波动性，德布罗意波长 **λ = h / p**。
