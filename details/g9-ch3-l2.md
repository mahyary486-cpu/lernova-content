# Solving Systems by Substitution

## The idea
In **substitution**, you solve one equation for a variable, then replace that variable in the other equation. This leaves one equation with one variable, which you can solve.

## Method
1. Pick an equation and solve it for one variable. Choose a variable with a coefficient of 1 if possible.
2. Substitute that expression into the other equation.
3. Solve for the remaining variable.
4. Substitute back to find the other variable.
5. Check in both original equations.

## Worked examples
**Example 1.** Solve y = 2x + 1 and 3x + y = 11.
1. The first equation already gives y. Substitute into the second: 3x + (2x + 1) = 11.
2. Combine: 5x + 1 = 11, so 5x = 10 and x = 2.
3. Then y = 2(2) + 1 = 5.
4. Check: 3(2) + 5 = 11. True.
Solution: (2, 5).

**Example 2.** Solve x + 2y = 8 and 3x - y = 3.
1. Solve the first for x: x = 8 - 2y.
2. Substitute: 3(8 - 2y) - y = 3.
3. Distribute: 24 - 6y - y = 3, so 24 - 7y = 3, and -7y = -21, so y = 3.
4. Then x = 8 - 2(3) = 2.
5. Check: 2 + 6 = 8 and 6 - 3 = 3. Both are true.
Solution: (2, 3).

**Example 3.** Solve y = 3x - 2 and 6x - 2y = 4.
1. Substitute: 6x - 2(3x - 2) = 4.
2. Distribute: 6x - 6x + 4 = 4, so 4 = 4.
3. This is always true, so the lines are the same. There are infinitely many solutions.

## Special cases
- If you get a false statement like 0 = 5, there is **no solution** (parallel lines).
- If you get a true statement like 4 = 4, there are **infinitely many solutions** (same line).

## Common mistakes
- Substituting into the same equation you solved. You must use the other equation.
- Forgetting to distribute a negative or a coefficient across parentheses, such as 3(8 - 2y).
- Stopping after finding one variable. Always find both.
- Making sign errors when moving terms.
