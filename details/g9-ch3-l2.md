# Solving Systems by Substitution

## The idea
Replace one variable in an equation with an expression from the other equation. This leaves one equation with one variable.

## Steps
1. Solve one equation for a variable (choose one with coefficient 1 or -1 if you can).
2. Substitute that expression into the other equation.
3. Solve for the remaining variable.
4. Substitute back to find the other variable.
5. Check in both original equations.

## Example 1
Solve y = 2x - 1 and 3x + y = 14.
- Substitute: 3x + (2x - 1) = 14.
- Combine: 5x - 1 = 14, so 5x = 15 and x = 3.
- Back-substitute: y = 2(3) - 1 = 5.
- Check: 3(3) + 5 = 14 is true. The solution is (3, 5).

## Example 2
Solve x + 2y = 7 and 3x - y = 7.
- Solve the first for x: x = 7 - 2y.
- Substitute: 3(7 - 2y) - y = 7.
- Distribute: 21 - 6y - y = 7, so -7y = -14 and y = 2.
- Then x = 7 - 2(2) = 3.
- Check: 3 + 4 = 7 and 9 - 2 = 7. The solution is (3, 2).

## Special cases
- **No solution:** y = 2x + 3 and y = 2x - 1 give 2x + 3 = 2x - 1, which simplifies to 3 = -1. This is false, so the lines are parallel.
- **Infinitely many solutions:** y = 2x + 3 and 2y - 4x = 6 give 2(2x + 3) - 4x = 6, which simplifies to 6 = 6. This is always true, so the equations describe the same line.

## Common mistakes
- Substituting into the same equation you solved.
- Forgetting parentheses: 3(7 - 2y) must be distributed to both terms.
- Finding x but forgetting to find y.
