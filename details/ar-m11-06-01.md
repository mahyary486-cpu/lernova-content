# Sucesiones aritméticas

## Definición
Cada término se obtiene sumando una constante d al anterior.
Ejemplo: 3, 7, 11, 15, … tiene d = 4.

## Término general
aₙ = a₁ + (n − 1)·d.
Para 3, 7, 11, …: a₁₀ = 3 + 9·4 = 39.

## Suma de los n primeros términos
Sₙ = n(a₁ + aₙ)/2.
S₁₀ = 10(3 + 39)/2 = 210.

## Propiedad
Cada término es el promedio de sus vecinos: aₙ = (aₙ₋₁ + aₙ₊₁)/2.

## Error frecuente
Usar n·d en lugar de (n − 1)·d en el término general.
