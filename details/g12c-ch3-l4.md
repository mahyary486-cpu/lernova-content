# Isomerism and Organic Reactions

Two molecules can have the same formula, such as C4H10, but be completely different substances.

## Key ideas
- **Isomers**: same **molecular formula**, different **structure**.
- **Structural**: chain, position, functional-group isomers.
- **Stereoisomers**: **cis-trans** and **optical** (chiral carbon).
- **Substitution**, **addition**, **elimination**, **oxidation**, **hydrolysis**.
- **Elimination**: alcohol -> alkene + water (conc. H2SO4).
- **Saponification**: fat + NaOH -> **soap** + glycerol.

## Worked examples
**Example 1: Count isomers.** How many structural isomers does C4H10 have?
1. Butane (straight chain).
2. 2-methylpropane (branched). So 2.

**Example 2: Chiral.** Is CH3-CHBr-CH2CH3 chiral?
1. The second carbon has H, Br, CH3 and C2H5.
2. Four different groups, so it is chiral.

**Example 3: Elimination.** Ethanol is heated with concentrated H2SO4.
1. Water is removed from adjacent carbons.
2. Ethene is formed: C2H5OH -> C2H4 + H2O.

## Common mistakes
- Thinking isomers have different molecular formulas.
- Missing a chiral center.
- Mixing up hydrolysis and condensation.
