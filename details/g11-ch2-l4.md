# The Quadratic Formula and the Discriminant

## The quadratic formula
For ax^2 + bx + c = 0 (a is not 0):

**x = (-b ± sqrt(b^2 - 4ac)) / (2a)**

It works for **every** quadratic equation. First write the equation as ax^2 + bx + c = 0 and read off a, b and c.

## The discriminant
The part under the square root, **D = b^2 - 4ac**, tells you what kind of solutions there are:
| Discriminant | Solutions |
|---|---|
| D > 0 | two different real solutions |
| D = 0 | exactly one real solution (a double root) |
| D < 0 | no real solutions; two complex solutions |

## Examples
**Two real solutions.** 2x^2 + 3x - 2 = 0. Here a = 2, b = 3, c = -2. D = 9 + 16 = 25. Then x = (-3 ± 5) / 4, so **x = 1/2 or x = -2**.

**Irrational solutions.** x^2 - 6x + 7 = 0. D = 36 - 28 = 8, and sqrt(8) = 2 sqrt(2). So x = (6 ± 2 sqrt(2)) / 2 = **3 ± sqrt(2)**.

**Complex solutions.** x^2 + 2x + 5 = 0. D = 4 - 20 = -16. Then x = (-2 ± sqrt(-16)) / 2 = (-2 ± 4i) / 2 = **-1 ± 2i**.

**Using D = 0.** For what k does x^2 + 6x + k = 0 have exactly one solution? D = 36 - 4k = 0, so **k = 9**.

**No real solutions.** 3x^2 - 4x + 2 = 0 has D = 16 - 24 = -8, which is negative, so there are no real solutions.

## Which method to use?
- Easy factoring: factor.
- Squared expression and no middle term: square roots.
- Anything else: the quadratic formula (it always works).

## Common mistakes
- Writing b^2 + 4ac instead of b^2 - 4ac.
- Forgetting that -b is the opposite of b. If b = -6, then -b = 6.
- Dividing only part of the numerator by 2a. The whole top is divided by 2a.
- Dividing by a instead of 2a.
