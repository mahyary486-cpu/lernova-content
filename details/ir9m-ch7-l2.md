# Operations on rational expressions

This lesson shows how to multiply, divide, add and subtract rational expressions, using the same rules as for numerical fractions.

## Key ideas

Rational expressions follow the same rules as ordinary fractions. Always factor first, and remember that no denominator may be zero.

Multiplication: (A/B) · (C/D) = (A · C)/(B · D). Factor everything first and cancel common factors before multiplying out.

Division: (A/B) ÷ (C/D) = (A/B) · (D/C). Flip the second fraction and multiply. For this, C must not be zero either.

Addition and subtraction: the denominators must be the same.
1. Factor each denominator.
2. Find the least common denominator (LCD). It contains every different factor, each taken the most times it appears in any one denominator.
3. Rewrite each fraction with the LCD by multiplying its numerator and denominator by the missing factors.
4. Add or subtract the numerators and keep the LCD.
5. Simplify the result if possible.

When subtracting, put brackets around the whole numerator that is subtracted, so that the minus sign changes every term in it.

A division example: (x^2 - 4)/(x + 3) ÷ (x + 2)/(x^2 - 9) = (x - 2)(x + 2)/(x + 3) · (x - 3)(x + 3)/(x + 2) = (x - 2)(x - 3).

## Worked examples

Example 1. Multiply (x/(x + 1)) · ((x^2 - 1)/x^2).

Step 1: Factor: x^2 - 1 = (x - 1)(x + 1).
Step 2: Write the product: x(x - 1)(x + 1) / ((x + 1) · x^2).
Step 3: Cancel x and (x + 1): the result is (x - 1)/x.
Check with x = 2: (2/3) · (3/4) = 1/2, and (2 - 1)/2 = 1/2.
Answer: (x - 1)/x, with x ≠ 0 and x ≠ -1.

Example 2. Add 2/(x - 1) + 3/(x + 2).

Step 1: The denominators have no common factor, so the LCD is (x - 1)(x + 2).
Step 2: Rewrite: 2(x + 2)/((x - 1)(x + 2)) + 3(x - 1)/((x - 1)(x + 2)).
Step 3: Add the numerators: 2x + 4 + 3x - 3 = 5x + 1.
Step 4: The result is (5x + 1)/((x - 1)(x + 2)). It cannot be simplified.
Check with x = 2: 2/1 + 3/4 = 2.75, and (10 + 1)/(1 · 4) = 11/4 = 2.75.
Answer: (5x + 1)/((x - 1)(x + 2)), with x ≠ 1 and x ≠ -2.

Example 3. Subtract x/(x^2 - 4) - 1/(x - 2).

Step 1: Factor: x^2 - 4 = (x - 2)(x + 2). The LCD is (x - 2)(x + 2).
Step 2: Rewrite the second fraction: 1/(x - 2) = (x + 2)/((x - 2)(x + 2)).
Step 3: Subtract with brackets: (x - (x + 2))/((x - 2)(x + 2)).
Step 4: Simplify the numerator: x - x - 2 = -2.
Step 5: The result is -2/((x - 2)(x + 2)), which equals -2/(x^2 - 4).
Check with x = 3: 3/5 - 1 = -2/5, and -2/(9 - 4) = -2/5.
Answer: -2/(x^2 - 4), with x ≠ 2 and x ≠ -2.

## Common mistakes

- Adding denominators. We do not use a/b + c/d = (a + c)/(b + d). We must find a common denominator first.
- Forgetting brackets in subtraction. In x - (x + 2), the minus sign changes both terms in the bracket.
- Using a common denominator that is too large. Factor the denominators first so the LCD is as small as possible.
- Forgetting to flip the second fraction in division.

## Remember

- Multiplication and division: factor, flip if dividing, then cancel.
- Addition and subtraction: find the LCD, combine the numerators, then simplify.
- Check an answer by putting in an allowed number for x.
