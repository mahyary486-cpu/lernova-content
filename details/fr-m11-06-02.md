# Produit scalaire dans un repère orthonormé et orthogonalité

## Expression analytique
Dans un repère orthonormé, pour u(x ; y) et v(x’ ; y’) :
u·v = xx’ + yy’ et ‖u‖² = x² + y².
Exemples :
- u(2 ; 3) et v(1 ; 4) : u·v = 2 + 12 = 14.
- u(−1 ; 2) et v(3 ; 1) : u·v = −3 + 2 = −1.
- u(3 ; 4) : u·u = 25.

## Orthogonalité
u(1 ; 2) et v(2 ; −1) : u·v = 2 − 2 = 0, donc u et v sont orthogonaux.
Pour que u(2 ; k) soit orthogonal à v(3 ; −6) : 6 − 6k = 0, donc k = 1.

## Angle entre deux vecteurs
cos θ = u·v/(‖u‖ × ‖v‖).
Exemple : u(1 ; 0) et v(1 ; 1) : u·v = 1, ‖u‖ = 1, ‖v‖ = √2 donc cos θ = 1/√2 = √2/2 et θ = 45°.

## Application aux triangles
Pour A(1 ; 1), B(4 ; 2), C(2 ; 5) : AB→(3 ; 1) et AC→(1 ; 4) donnent AB→·AC→ = 3 + 4 = 7 > 0 : l’angle en A est aigu.
Pour A(0 ; 0), B(2 ; 0), C(0 ; 3) : AB→·AC→ = 0 : le triangle est rectangle en A.

## Perpendicularité de droites
Deux droites sont perpendiculaires si leurs vecteurs directeurs sont orthogonaux, ou si leurs vecteurs normaux le sont.

## Erreur fréquente
La formule xx’ + yy’ n’est valable que dans un repère orthonormé.
