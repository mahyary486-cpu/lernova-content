# Electrolysis and Faraday's Laws

Aluminium, chlorine and sodium hydroxide are all made industrially by electrolysis.

## Key ideas
- **Electrolytic cell**: non-spontaneous reaction driven by a source.
- **Anode** (+): oxidation; **cathode** (-): reduction.
- **Q = I t**; **n_e = Q / F**.
- **m = M I t / (n F)**.
- Water electrolysis: **H2 : O2 = 2 : 1**.
- **Electroplating**: the object is the **cathode**.

## Worked examples
**Example 1: Mass deposited.** A current of 2.0 A flows for 3860 s through Cu^2+ solution (M = 63.5, n = 2).
1. Q = 2.0 x 3860 = 7720 C and n_e = 7720 / 96,500 = 0.08 mol.
2. Moles Cu = 0.04, mass = 0.04 x 63.5 = 2.54 g.

**Example 2: Time.** How long to deposit 1.08 g of Ag (M = 108, n = 1) at 0.50 A?
1. n = 1.08 / 108 = 0.0100 mol, so Q = 0.0100 x 96,500 = 965 C.
2. t = Q / I = 965 / 0.50 = 1930 s.

**Example 3: Products.** Which products form on electrolysis of molten NaCl?
1. Na+ is reduced at the cathode.
2. Na at the cathode and Cl2 at the anode.

## Common mistakes
- Confusing galvanic and electrolytic cells.
- Forgetting n in Faraday's law.
- Using minutes instead of seconds.
