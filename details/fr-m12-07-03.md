# Inégalités de concentration et loi des grands nombres

## Inégalité de Bienaymé-Tchebychev
Pour une variable aléatoire X d’espérance E(X) et de variance V(X), et pour tout réel δ > 0 :
P(∣X − E(X)∣ ≥ δ) ≤ V(X)/δ².
Elle majore la probabilité que X s’écarte de son espérance d’au moins δ.
Exemple : V(X) = 4 et δ = 4 : P(∣X − E(X)∣ ≥ 4) ≤ 4/16 = 0,25.
Exemple : X suit B(100 ; 0,5), E(X) = 50, V(X) = 25, δ = 15 : P(∣X − 50∣ ≥ 15) ≤ 25/225 = 1/9.

## Inégalité de concentration pour la moyenne
Pour la moyenne M_n de n variables indépendantes de même loi (espérance μ, variance V) :
P(∣M_n − μ∣ ≥ δ) ≤ V/(nδ²).
Exemple : V = 1, n = 100, δ = 0,5 : probabilité ≤ 1/(100 × 0,25) = 0,04.

## Loi des grands nombres
Plus n est grand, plus la probabilité que M_n s’écarte de μ d’au moins δ est petite : elle tend vers 0. La moyenne observée se rapproche de l’espérance.

## Utilisation
On peut déterminer une taille d’échantillon : pour que la probabilité d’un écart de δ soit au plus égale à 0,05, il suffit que V/(nδ²) ≤ 0,05, soit n ≥ V/(0,05δ²).

## Interprétation
Ces résultats justifient l’estimation d’une probabilité par une fréquence observée sur un grand nombre d’épreuves.

## Erreur fréquente
L’inégalité de Bienaymé-Tchebychev donne une majoration, pas la valeur exacte de la probabilité.
