# Муодилаи квадратӣ

## Таъриф

Муодилаи намуди **ax² + bx + c = 0**, ки дар он a ≠ 0, муодилаи квадратӣ ном дорад.

## Дискриминант

D = b² − 4ac

- D > 0 — муодила ду решаи гуногун дорад: x₁ = (−b + √D) / (2a), x₂ = (−b − √D) / (2a).
- D = 0 — як реша: x = −b / (2a).
- D < 0 — решаи ҳақиқӣ нест.

## Теоремаи Виета

Барои x² + px + q = 0: x₁ + x₂ = −p ва x₁ · x₂ = q.

**Мисол:** x² − 5x + 6 = 0. Ҷамъ = 5, ҳосили зарб = 6, пас x₁ = 2, x₂ = 3.

**Мисол:** 3x² − 7x + 2 = 0. D = 49 − 24 = 25, x = (7 ± 5) / 6, яъне x₁ = 2, x₂ = 1/3.
