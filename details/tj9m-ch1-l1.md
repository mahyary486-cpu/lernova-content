# Муодилаи квадратӣ

Муодилаи намуди ax² + bx + c = 0, ки дар он a ≠ 0, муодилаи квадратӣ ном дорад. Барои ҳал кардани он аввал коэффитсиентҳои a, b ва c-ро бо ишораҳояшон ҷудо мекунем ва дискриминант D = b² − 4ac-ро меёбем. Дискриминант нишон медиҳад, ки муодила чанд реша дорад.

Агар D > 0, ду решаи гуногун ҳаст: x₁ = (−b + √D) / (2a) ва x₂ = (−b − √D) / (2a). Агар D = 0, фақат як реша мемонад: x = −b / (2a). Агар D < 0, решаи ҳақиқӣ нест, зеро аз адади манфӣ реша гирифта намешавад.

Теоремаи Виета роҳи тезтарро медиҳад: барои x² + px + q = 0 ҷамъи решаҳо −p ва ҳосили зарби онҳо q аст. Масалан, барои x² − 5x + 6 = 0 ададҳои 2 ва 3 ҷамъашон 5 ва зарбашон 6 аст. Пас аз ҳал кардан ҳамеша решаҳоро ба муодила гузошта санҷед.
