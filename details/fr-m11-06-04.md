# Équation d’un cercle et droites définies par un vecteur normal

## Équation d’un cercle
Le cercle de centre Ω(a ; b) et de rayon r est l’ensemble des points M(x ; y) tels que ΩM = r, soit
(x − a)² + (y − b)² = r².
Exemples :
- centre O et rayon 3 : x² + y² = 9 ;
- centre (1 ; −2) et rayon 3 : (x − 1)² + (y + 2)² = 9.

## Reconnaître un cercle
x² + y² − 4x + 6y − 12 = 0 s’écrit (x − 2)² + (y + 3)² = 12 + 4 + 9 = 25 : cercle de centre (2 ; −3) et de rayon 5.

## Cercle de diamètre [AB]
M appartient au cercle de diamètre [AB] si et seulement si MA→·MB→ = 0.
Exemple : A(0 ; 0) et B(2 ; 0) : MA→·MB→ = x(x − 2) + y² = 0. Le centre est le milieu (1 ; 0) et le rayon 1.
Pour A(0 ; 0) et B(4 ; 2) : centre (2 ; 1), rayon √5 et équation (x − 2)² + (y − 1)² = 5.

## Vecteur normal à une droite
Un vecteur normal n d’une droite d est un vecteur non nul orthogonal à un vecteur directeur de d. Si n(a ; b), la droite a une équation ax + by + c = 0.
- Pour 2x + 3y − 5 = 0, un vecteur normal est (2 ; 3).
- Droite passant par A(1 ; 2) de vecteur normal n(3 ; −1) : 3(x − 1) − (y − 2) = 0, soit 3x − y − 1 = 0.

## Perpendicularité
d : x + 2y − 4 = 0 et d’ : 2x − y + 1 = 0 ont pour vecteurs normaux (1 ; 2) et (2 ; −1). Leur produit scalaire vaut 2 − 2 = 0 : les droites sont perpendiculaires.

## Erreur fréquente
Dans l’équation d’un cercle, les signes dans les parenthèses sont opposés aux coordonnées du centre.
