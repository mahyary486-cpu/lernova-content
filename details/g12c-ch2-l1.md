# Oxidation Numbers and Redox Reactions

Rusting, burning, batteries, bleaching and photosynthesis look very different, but all of them are redox processes, which means that electrons are transferred from one substance to another. In some of these reactions the transfer is easy to see, as when a metal becomes an ion. In others, such as the burning of methane, no ions are formed, and we need a bookkeeping system to follow the electrons. That system is the oxidation number.

## Key ideas

Oxidation is the loss of electrons, and reduction is the gain of electrons. A helpful memory aid is OIL RIG: oxidation is loss, reduction is gain. The two always occur together, because electrons that one substance loses must be gained by another. The substance that is oxidized is called the reducing agent, since it supplies electrons, and the substance that is reduced is the oxidizing agent, since it takes electrons. This naming is a frequent source of confusion, and the best way to remember it is that the agent is named for what it does to the other substance.

The oxidation number is the charge that an atom would have if all the bonding electrons were given to the more electronegative atom. A few rules are enough for most cases. An atom in a free element has an oxidation number of 0. Oxygen is usually -2, and hydrogen is usually +1, with the exceptions of peroxides, where oxygen is -1, and metal hydrides, where hydrogen is -1. Fluorine is always -1. The sum of the oxidation numbers equals the charge of the particle, which is zero for a neutral compound. When an element is oxidized, its oxidation number increases, and when it is reduced, the number decreases. A reaction is a redox reaction only if some oxidation number changes, which makes the numbers a test for the type of reaction.

In a disproportionation reaction, the same element is both oxidized and reduced, because it starts in an intermediate oxidation state. Chlorine in a basic solution is an example. Common strong oxidizing agents are F2, O2 and MnO4-, which readily accept electrons. Common reducing agents are the active metals and hydrogen, which readily lose them.

## Worked examples

**Example 1: Oxidation number of Cr in Cr2O7 2-.**
1. The sum of the oxidation numbers must equal the charge of the ion, which is -2.
2. Oxygen is -2, so seven oxygen atoms contribute 7 x (-2) = -14, and the equation is 2 x Cr + (-14) = -2.
3. Then 2 x Cr = +12, so Cr = +6.

**Example 2: Identify the agents in Zn + Cu 2+ -> Zn 2+ + Cu.**
1. Zinc changes from 0 to +2, so it loses electrons. It is oxidized, and it is the reducing agent.
2. Copper changes from +2 to 0, so it gains electrons. It is reduced, and Cu 2+ is the oxidizing agent.
3. The two electrons lost by each zinc atom are gained by one copper ion.

**Example 3: Disproportionation in Cl2 + 2 OH- -> Cl- + OCl- + H2O.**
1. In Cl2 the oxidation number of chlorine is 0.
2. In Cl- it is -1, so some chlorine is reduced. In OCl- it is +1 (since O is -2 and the charge is -1), so some chlorine is oxidized.
3. One element goes both up and down, so this is a disproportionation.

## Common mistakes

Students often mix up oxidation and reduction, and OIL RIG helps to fix this. Another error is to say that the oxidizing agent is the substance that is oxidized, when it is the substance that is reduced. The third mistake is to use +1 for hydrogen in metal hydrides such as NaH, where hydrogen is -1, because it is bonded to a less electronegative atom.
