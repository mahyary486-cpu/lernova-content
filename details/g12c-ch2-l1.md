# Oxidation Numbers and Redox Reactions

Rusting, burning, batteries and photosynthesis are all redox processes.

## Key ideas
- **Oxidation** = loss of electrons; **reduction** = gain (**OIL RIG**).
- **Oxidizing agent** is reduced; **reducing agent** is oxidized.
- Free element: **0**; O: **-2**; H: **+1**; sum = **charge**.
- Oxidation number **increases** on oxidation.
- In **disproportionation** the same element is oxidized and reduced.
- Strong oxidizers: **F2, O2, MnO4-**; reducers: **metals, H2**.

## Worked examples
**Example 1: Oxidation number.** Find the oxidation number of Cr in Cr2O7^2-.
1. 2 Cr + 7 x (-2) = -2.
2. Cr = +6.

**Example 2: Identify the agents.** In Zn + Cu^2+ -> Zn^2+ + Cu, which is oxidized?
1. Zn goes 0 to +2: oxidized (reducing agent).
2. Cu^2+ goes +2 to 0: reduced (oxidizing agent).

**Example 3: Disproportionation.** In Cl2 + 2 OH- -> Cl- + OCl- + H2O, what happens to Cl?
1. Cl goes from 0 to -1 (reduced) and 0 to +1 (oxidized).
2. It is a disproportionation.

## Common mistakes
- Mixing up oxidation and reduction.
- Forgetting that the agent is the species that is reduced (oxidizing agent).
- Using +1 for hydrogen in metal hydrides.
