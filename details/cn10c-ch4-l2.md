# 铁盐和亚铁盐

## Fe³⁺ 的检验

向溶液中滴加 **KSCN 溶液**，溶液变为**红色**，则含 Fe³⁺。

## 颜色

- Fe²⁺ 溶液：浅绿色；
- Fe³⁺ 溶液：棕黄色。

## Fe²⁺ 和 Fe³⁺ 的转化

- Fe²⁺ → Fe³⁺（**还原性**）：加氧化剂，如 2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻；
- Fe³⁺ → Fe²⁺（**氧化性**）：加还原剂，如 2Fe³⁺ + Fe = 3Fe²⁺。

## 应用

- 配制 FeSO₄ 溶液时要加入少量**铁粉**，防止 Fe²⁺ 被氧化；
- 除去 FeCl₂ 溶液中的少量 FeCl₃：加入**过量铁粉**，再过滤；
- 除去 FeCl₃ 溶液中的少量 FeCl₂：通入适量 Cl₂。
