# Dérivée et variations de l’exponentielle

## Dérivée
(e^x)’ = e^x. Comme e^x > 0 pour tout x, la dérivée est strictement positive.

## Variations
La fonction exponentielle est strictement croissante sur ℝ. Conséquences :
- e^a < e^b équivaut à a < b ;
- e^a = e^b équivaut à a = b.
Exemples : e^x > e² équivaut à x > 2 ; e^x < e^(−1) équivaut à x < −1.

## Valeurs de référence
e^0 = 1, e^1 ≈ 2,718. Pour x < 0, 0 < e^x < 1 ; pour x > 0, e^x > 1.

## Tangente en 0
f(0) = 1 et f’(0) = 1. La tangente en 0 a pour équation y = 1 × (x − 0) + 1 = x + 1.
On en déduit que e^x ≥ x + 1 pour tout x (la courbe est au-dessus de sa tangente en 0).

## Dérivées d’expressions
- (3e^x − x²)’ = 3e^x − 2x.
- (x e^x)’ = e^x + x e^x = (x + 1)e^x.
- (e^x/x)’ = (e^x × x − e^x)/x² = e^x(x − 1)/x².

## Comparaison
e^x − e^(2x) = e^x(1 − e^x) est positif si e^x < 1, c’est-à-dire pour x < 0.

## Erreur fréquente
La dérivée de e^(2x) n’est pas e^(2x) : il y a un facteur 2.
