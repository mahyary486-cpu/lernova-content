# 乗法公式と式の展開

## 多項式 × 多項式

(a + b)(c + d) = ac + ad + bc + bd のように、すべての項どうしをかけて展開します。

## 乗法公式

1. (x + a)(x + b) = x² + (a + b)x + ab
2. (x + a)² = x² + 2ax + a²
3. (x − a)² = x² − 2ax + a²
4. (x + a)(x − a) = x² − a²

**例1：** (x + 3)(x + 5) = x² + 8x + 15

**例2：** (x − 4)² = x² − 8x + 16

**例3：** (x + 6)(x − 6) = x² − 36

## 計算の工夫

数を 100 や 50 に近い形に直して公式を使うと、暗算が楽になります。

**例：** 98² = (100 − 2)² = 10000 − 400 + 4 = 9604

**例：** 52 × 48 = (50 + 2)(50 − 2) = 2500 − 4 = 2496
