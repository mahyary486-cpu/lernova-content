# Arithmetic Sequences

## Definition
In an **arithmetic sequence** each term is found by **adding the same number** to the previous one. That number is the **common difference d**.
- 5, 9, 13, 17, ... has d = **4**.
- 20, 15, 10, 5, ... has d = -5.
To find d, subtract any term from the next term: d = a_(n+1) - a_n.

## Formulas
- **Recursive:** a_n = a_(n-1) + d
- **Explicit:** **a_n = a_1 + (n - 1)d**

## Examples
**Find a term.** 5, 9, 13, ... Here a_1 = 5 and d = 4, so a_10 = 5 + 9(4) = **41**.

**Another term.** a_1 = -3 and d = 2. Then a_20 = -3 + 19(2) = **35**.

**From two terms.** a_4 = 14 and a_9 = 34. From a_4 to a_9 there are 5 steps, so 5d = 20 and d = 4. Then a_1 = 14 - 3(4) = **2**.

**Is a number in the sequence?** For 3, 8, 13, ... the terms are 3 + 5(n - 1). Is 98 a term? 5(n - 1) = 95 gives n = 20, so **yes**, it is the 20th term. Is 100 a term? 5(n - 1) = 97 gives n = 20.4, which is not a whole number, so **no**.

**How many terms?** For 7, 10, 13, ..., 100: 7 + 3(n - 1) = 100 gives n - 1 = 31, so n = **32** terms.

## Arithmetic means
The **arithmetic mean** of two numbers is their average. The arithmetic mean of 8 and 20 is (8 + 20)/2 = **14**, and 8, 14, 20 is an arithmetic sequence.

## Linear connection
An arithmetic sequence is a **linear function** of n: the common difference is the slope.

## Common mistakes
- Using a_n = a_1 + nd. The correct formula has **(n - 1)**d, because a_1 has no steps yet.
- Finding d by dividing. For arithmetic sequences, subtract.
- Forgetting the sign of d for a decreasing sequence.
