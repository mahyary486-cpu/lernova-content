# Graphing Quadratic Functions

## Two forms of a quadratic
- **Standard form:** y = ax^2 + bx + c (a is not 0)
- **Vertex form:** y = a(x - h)^2 + k, with vertex **(h, k)**

The graph is a **parabola**. If a > 0 it opens **up** and the vertex is the lowest point (a **minimum**). If a < 0 it opens **down** and the vertex is the highest point (a **maximum**). A larger abs(a) makes the parabola narrower.

## Key features from standard form
- **Axis of symmetry:** x = -b / (2a)
- **Vertex:** put x = -b / (2a) into the function to get y
- **y-intercept:** c (the point (0, c))

## Finding the vertex
y = x^2 - 6x + 5. Here a = 1 and b = -6, so x = 6/2 = 3. Then y = 9 - 18 + 5 = -4. The vertex is **(3, -4)** and the axis of symmetry is x = 3.

## Maximum and minimum values
y = -2x^2 + 8x. Here a = -2 and b = 8, so x = -8 / (-4) = 2. Then y = -8 + 16 = 8. Since a is negative, the **maximum value is 8**, reached at x = 2.

## Writing the equation from the vertex and a point
A parabola has vertex (2, -1) and passes through (3, 1).
Start with y = a(x - 2)^2 - 1. Put in the point: 1 = a(1)^2 - 1, so a = 2. The equation is **y = 2(x - 2)^2 - 1**.

## Worked examples
1. y = (x - 2)^2 + 5 has vertex **(2, 5)**.
2. y = 2(x - 1)^2 + 3 opens up, so it has a **minimum value of 3**.
3. y = -3x^2 + 1 opens **down**, because a = -3 is negative.

## Common mistakes
- Using the wrong sign for h: in y = (x - 2)^2 + 5 the vertex is (2, 5), not (-2, 5).
- Forgetting to put x = -b / (2a) back into the function to get the y-coordinate.
- Saying a parabola opening down has a minimum.
