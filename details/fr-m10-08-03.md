# Boucles for et while

## Boucle for
for i in range(5):
    print(i)
affiche 0, 1, 2, 3, 4 : 5 passages, de 0 à 4.
- range(1, 6) donne 1, 2, 3, 4, 5.
- range(2, 10, 3) donne 2, 5, 8.
La borne supérieure est toujours exclue.

## Accumulation
s = 0
for i in range(1, 4):
    s = s + i
À la fin, s vaut 1 + 2 + 3 = 6.
Somme des carrés de 1 à 5 : 1 + 4 + 9 + 16 + 25 = 55.

## Compter
c = 0
for i in range(1, 21):
    if i % 3 == 0:
        c = c + 1
À la fin, c vaut 6 : 3, 6, 9, 12, 15 et 18.

## Boucle while
n = 1
while n < 10:
    n = n * 2
n prend les valeurs 1, 2, 4, 8, 16 et la boucle s’arrête quand n ≥ 10 : n vaut 16.

## Boucle infinie
while True: sans instruction qui arrête la boucle ne s’arrête jamais. Il faut que la condition devienne fausse.

## Quand choisir ?
for quand on connaît le nombre de répétitions, while quand on répète jusqu’à ce qu’une condition change.

## Erreur fréquente
Penser que range(5) contient 5 : il s’arrête à 4.
