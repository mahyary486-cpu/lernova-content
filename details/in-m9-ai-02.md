# Squares of sums and differences

(a + b)² = a² + 2ab + b² and (a − b)² = a² − 2ab + b². 

Examples: (x + 1)² = x² + 2x + 1, (2x + 3)² = 4x² + 12x + 9, (3x − 2)² = 9x² − 12x + 4.

They also give quick arithmetic: 101² = (100 + 1)² = 10201 and 99² = (100 − 1)² = 9801. Useful consequences: (x + y)² + (x − y)² = 2x² + 2y² and (x + y)² − (x − y)² = 4xy.
