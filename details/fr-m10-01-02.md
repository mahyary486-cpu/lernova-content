# Intervalles de ℝ, réunion et intersection

## Notations
- [a ; b] : a ≤ x ≤ b (bornes incluses).
- ]a ; b[ : a < x < b (bornes exclues).
- [a ; b[ : a ≤ x < b.
- [a ; +∞[ : x ≥ a.
- ]−∞ ; b[ : x < b.
Le symbole ∞ n’est pas un nombre : le crochet est toujours ouvert du côté de l’infini.

## Représentation
Sur une droite graduée, on colore la partie correspondant à l’intervalle. Un crochet « tourné vers l’intérieur » signifie que la borne est comprise.

## Réunion et intersection
- A ∪ B : les x qui sont dans A ou dans B.
- A ∩ B : les x qui sont dans A et dans B.
Exemples :
- [1 ; 6] ∩ [4 ; 9] = [4 ; 6].
- [1 ; 3] ∪ [2 ; 5] = [1 ; 5].
- ]1 ; 5[ ∩ [5 ; 8] = ∅ : l’ensemble vide, car 5 n’est pas dans ]1 ; 5[.

## Traduire une inégalité
−1 ≤ x < 4 s’écrit x ∈ [−1 ; 4[. La condition « x < 2 ou x ≥ 7 » s’écrit x ∈ ]−∞ ; 2[ ∪ [7 ; +∞[.

## Erreur fréquente
Écrire [2 ; +∞] est faux : +∞ n’est jamais atteint, on écrit [2 ; +∞[.
