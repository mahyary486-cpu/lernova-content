# Équations et inéquations avec ln et exp

## Méthode
1. Déterminer l’ensemble de définition (arguments des ln strictement positifs).
2. Transformer l’équation (somme de ln en ln d’un produit).
3. Résoudre puis vérifier que les solutions appartiennent au domaine.

## Équations
- ln x = 2 donne x = e².
- e^x = 5 donne x = ln 5.
- e^(2x) = 3 donne 2x = ln 3, donc x = (ln 3)/2.
- ln x = ln(3x − 4) : domaine x > 4/3 ; x = 3x − 4 donne x = 2.
- ln(x − 1) + ln(x + 1) = ln 8 : domaine x > 1 ; (x − 1)(x + 1) = 8 donne x² = 9, donc x = 3.
- (ln x)² − ln x − 2 = 0 : en posant X = ln x, X² − X − 2 = 0 donne X = 2 ou X = −1, donc x = e² ou x = e^(−1).

## Inéquations
- ln x > 0 équivaut à x > 1.
- ln x ≤ 1 équivaut à 0 < x ≤ e.
- e^x ≥ 4 équivaut à x ≥ ln 4.
- ln(x − 3) définie pour x > 3.

## Problème de seuil
Trouver le plus petit entier n tel que 1,05^n ≥ 2 : n ln 1,05 ≥ ln 2, donc n ≥ ln 2/ln 1,05 ≈ 14,2, soit n = 15.

## Erreur fréquente
Diviser par ln(1,05) est possible car ln(1,05) > 0. Diviser par un ln négatif inverserait l’inégalité.
