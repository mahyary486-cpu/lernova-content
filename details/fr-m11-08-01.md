# Listes et compréhension de listes en Python

## Listes
L = [5, 3, 8]
- L[0] vaut 5 ; L[-1] vaut 8 (dernier élément).
- len(L) vaut 3.
- L.append(10) ajoute 10 à la fin.
- sorted(L) renvoie la liste triée [3, 5, 8].
- max(L), min(L) et sum(L) donnent le maximum, le minimum et la somme.

## Tranches
Pour L = [1, 2, 3, 4], L[1:3] vaut [2, 3] : l’indice de fin est exclu.

## Parcours
for x in L:
    print(x)

## Compréhension de liste
Syntaxe : [expression for x in range(n) if condition].
- [x * x for x in range(4)] donne [0, 1, 4, 9].
- [2 * k for k in range(1, 5)] donne [2, 4, 6, 8].
- [x for x in range(10) if x % 2 == 0] donne [0, 2, 4, 6, 8].
- [x ** 2 for x in range(0, 7, 2)] donne [0, 4, 16, 36].

## Moyenne d’une liste
sum(L) / len(L). Pour [2, 4, 9] : 15 / 3 = 5.

## Types
type([1, 2]) renvoie list.

## Erreur fréquente
Les indices commencent à 0 : une liste de 3 éléments a pour indices 0, 1 et 2, et L[3] provoque une erreur.
