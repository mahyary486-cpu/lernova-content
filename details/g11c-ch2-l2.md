# Boyle's, Charles's and Gay-Lussac's Laws

Pumping a bicycle tire squeezes the air into a smaller volume, so the pressure goes up.

## Key ideas
- **Boyle**: **P1 V1 = P2 V2** (T constant).
- **Charles**: **V1 / T1 = V2 / T2** (P constant).
- **Gay-Lussac**: **P1 / T1 = P2 / T2** (V constant).
- **Combined**: **P1 V1 / T1 = P2 V2 / T2**.
- Use **kelvins** for T.
- Units of P and V only need to match on both sides.

## Worked examples
**Example 1: Boyle's law.** A gas at 2.0 atm and 3.0 L expands to 6.0 L at constant T.
1. P2 = P1 V1 / V2 = 2.0 x 3.0 / 6.0.
2. P2 = 1.0 atm.

**Example 2: Charles's law.** A gas of 4.0 L at 250 K is heated to 500 K at constant P.
1. V2 = V1 T2 / T1 = 4.0 x 500 / 250.
2. V2 = 8.0 L.

**Example 3: Gay-Lussac's law.** A gas at 1.0 atm and 300 K is heated to 450 K in a rigid vessel.
1. P2 = P1 T2 / T1 = 1.0 x 450 / 300.
2. P2 = 1.5 atm.

## Common mistakes
- Using Celsius temperatures.
- Mixing up which variable is held constant.
- Applying the laws when the amount of gas changes.
