# Modeling with Functions

## Choosing a model from data
Look at the patterns in a table with evenly spaced x-values:
- **Constant first differences:** linear model.
- **Constant second differences:** quadratic model.
- **Constant ratios:** exponential model.

Example: y-values 2, 5, 10, 17, 26 at x = 1, 2, 3, 4, 5. The first differences are 3, 5, 7, 9 (not constant). The second differences are 2, 2, 2. So the model is **quadratic** (y = x^2 + 1).

Example: 3, 6, 12, 24. The ratio is always 2, so the model is **exponential**, y = 3 * 2^(x - 1).

## Building a model from information
**Linear.** Through (0, 5) and (4, 13): the slope is (13 - 5)/4 = 2, so **y = 2x + 5**.

**Exponential.** Through (0, 200) and (3, 1600): a = 200 and b^3 = 1600/200 = 8, so b = 2. The model is **y = 200 * 2^x**.

**Quadratic.** Vertex (2, -1) and the point (0, 3): y = a(x - 2)^2 - 1. At x = 0: 4a - 1 = 3, so a = 1. The model is **y = (x - 2)^2 - 1**.

## Applications
- A tank holds 100 gallons and drains at 5 gallons per minute: **V = 100 - 5t**. It is empty when 100 - 5t = 0, so after **20 minutes**.
- A population of 500 that triples every year: P = 500 * 3^t.
- The height of a thrown ball is quadratic in time. Its maximum is at the vertex.

## Using a model
- **Interpolation:** predicting inside the range of the data. Usually reliable.
- **Extrapolation:** predicting outside the range of the data. Less reliable.
- The model's **domain** must make sense. Time cannot be negative, and the tank cannot hold less than 0 gallons.

## Residuals
A **residual** is the difference between the actual value and the value the model predicts: (actual) - (predicted). Small residuals with no pattern mean the model fits well.

## Common mistakes
- Using a linear model for data that grows by a constant ratio.
- Extrapolating far beyond the data.
- Forgetting the units of the answer.
