# Algebraic expressions

A **variable** is a letter that represents a number. **Like terms** have the same variable part and can be combined: 3x + 2x = 5x.

**Evaluating.** To evaluate 2x + 1 when x = 4, substitute: 2(4) + 1 = 9.

**Distributive property.** a(b + c) = ab + ac. For example 2(x + 3) = 2x + 6.

**Simplifying.** (3x + 4) + (2x − 7) = 5x − 3. Another example: 4(2x − 1) − 3(x + 2) = 8x − 4 − 3x − 6 = 5x − 10.
