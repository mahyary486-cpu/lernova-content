# 非金属及其化合物的转化

## 氯

Cl₂ → HClO（漂白性）→ 漂白粉；实验室制法：MnO₂ + 4HCl（浓）=(△)= MnCl₂ + Cl₂↑ + 2H₂O。

## 硫

S → SO₂ → SO₃ → H₂SO₄。

接触法制硫酸：4FeS₂ + 11O₂ =(高温)= 2Fe₂O₃ + 8SO₂；2SO₂ + O₂ ⇌ 2SO₃。

## 氮

N₂ → NO → NO₂ → HNO₃。

**氨的催化氧化：** 4NH₃ + 5O₂ =(催化剂，△)= 4NO + 6H₂O

工业制硝酸：2NO + O₂ = 2NO₂；3NO₂ + H₂O = 2HNO₃ + NO。

## 硅

- 制粗硅：SiO₂ + 2C =(高温)= Si + 2CO↑；
- SiO₂ + 2NaOH = Na₂SiO₃ + H₂O，所以盛放 NaOH 溶液的试剂瓶要用**橡胶塞**，不能用玻璃塞（Na₂SiO₃ 会把瓶口和塞子粘在一起）；
- 光导纤维的成分是 SiO₂，半导体材料是 Si。

## 记忆方法

把每种元素的"价态—物质类别"画成转化图（价类二维图），按图写化学方程式。
