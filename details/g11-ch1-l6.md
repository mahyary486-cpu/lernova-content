# Inverse Functions

## What is an inverse?
The **inverse** of f, written f^-1, undoes f. If f takes 2 to 9, then f^-1 takes 9 back to 2: f(2) = 9 means f^-1(9) = 2.
Warning: f^-1 means the inverse function. It does **not** mean 1/f.

## When does an inverse function exist?
f has an inverse that is a function only if f is **one-to-one**: each output comes from exactly one input. On a graph this is the **horizontal line test**: no horizontal line crosses the graph more than once.
f(x) = x^2 fails, because f(2) = f(-2) = 4.

## Finding the inverse (4 steps)
1. Write y = f(x).
2. **Swap** x and y.
3. Solve for y.
4. Write y = f^-1(x).

Example: f(x) = 3x - 6.
y = 3x - 6, so swap: x = 3y - 6. Then 3y = x + 6, so **f^-1(x) = (x + 6)/3**.

Example: f(x) = x^3 + 1.
x = y^3 + 1, so y^3 = x - 1 and **f^-1(x) = cube root of (x - 1)**.

## Checking an inverse
f and g are inverses if f(g(x)) = x **and** g(f(x)) = x.
Example: f(x) = 2x + 3 and g(x) = (x - 3)/2. Then f(g(x)) = 2 * (x - 3)/2 + 3 = x.

## Graph and domain
- The graph of f^-1 is the reflection of the graph of f over the line **y = x**.
- The domain of f becomes the range of f^-1, and the range of f becomes the domain of f^-1.

## Restricting the domain
f(x) = x^2 has no inverse function, but if we restrict it to x ≥ 0 it becomes one-to-one. Then **f^-1(x) = sqrt(x)**, with domain x ≥ 0.

## Common mistakes
- Treating f^-1(x) as 1/f(x).
- Forgetting to swap x and y before solving.
- Giving an inverse for a function that fails the horizontal line test without restricting its domain.
