# Прогрессияи геометрӣ

Пайдарпаии ададҳои ғайринулӣ, ки дар он ҳар ҳад аз ҳади қаблӣ бо зарб ба як адади доимӣ q ҳосил мешавад, прогрессияи геометрӣ ном дорад. q — махраҷ. Масалан, 3, 6, 12, 24, … махраҷаш 2 аст.

Ҳади n-ум: bₙ = b₁·qⁿ⁻¹. Суми n ҳади аввал (q ≠ 1): Sₙ = b₁(qⁿ − 1) / (q − 1). Ҳар ҳад миёнаи геометрии ҳамсояҳояш аст: bₙ² = bₙ₋₁·bₙ₊₁.

Агар модули q аз 1 хурд бошад (масалан, q = 1/3), ҳадҳо ба нул наздик мешаванд ва суми беохир вуҷуд дорад: S = b₁ / (1 − q). Бо ин формула касри даврӣ ба касри оддӣ табдил дода мешавад, масалан 0,333… = 0,3 / (1 − 0,1) = 1/3.
