# Прогрессияи геометрӣ

## Таъриф

Пайдарпаии b₁, b₂, b₃, … ки дар он bₙ₊₁ = bₙ · q, прогрессияи геометрӣ аст. q — **махраҷ**.

## Формулаҳо

- Ҳади n-ум: **bₙ = b₁ · qⁿ⁻¹**
- Суми n ҳади аввал (q ≠ 1): **Sₙ = b₁(qⁿ − 1) / (q − 1)**
- Хосият: bₙ² = bₙ₋₁ · bₙ₊₁.
- Прогрессияи беохири кохишёбанда (модули q аз 1 хурд): **S = b₁ / (1 − q)**.

**Мисол:** b₁ = 2, q = 3. Пас b₄ = 2 · 3³ = 54.

**Мисол:** b₁ = 6, q = 1/3. S = 6 / (1 − 1/3) = 9.
