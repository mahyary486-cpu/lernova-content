# Конус

**Конус** получается вращением прямоугольного треугольника вокруг одного из катетов. R — радиус основания, h — высота, l — образующая.

**Связь:** l = √(R² + h²). Для R = 3 и h = 4 получаем l = 5.

**Осевое сечение** — равнобедренный треугольник.

**Площади.**

- боковая поверхность S_бок = πRl;
- полная поверхность S = πR(R + l).

**Примеры.** При R = 3 и l = 5: S_бок = 15π, а S = π · 3 · 8 = 24π.
