# Factoriser une expression

## Facteur commun
On repère un facteur présent dans tous les termes.
- 6x + 9 = 3(2x + 3)
- x² − 5x = x(x − 5)
- (x + 1)(x − 2) + (x + 1)(3x) = (x + 1)(x − 2 + 3x) = (x + 1)(4x − 2)

## Avec les identités remarquables
- x² − 49 = x² − 7² = (x + 7)(x − 7)
- x² + 6x + 9 = (x + 3)²
- 4x² − 20x + 25 = (2x − 5)²
- 9x² − 16 = (3x + 4)(3x − 4)

## Méthode
1. Y a-t-il un facteur commun évident ? Si oui, on le met en facteur.
2. Y a-t-il une différence de deux carrés ? On utilise a² − b².
3. Y a-t-il trois termes dont deux sont des carrés ? On regarde si le terme du milieu est le double produit.

## Vérification
On redéveloppe le résultat : on doit retrouver l’expression de départ.

## Intérêt
Factoriser sert à résoudre des équations : si un produit est nul, l’un de ses facteurs est nul.
