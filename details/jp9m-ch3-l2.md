# 解の公式

## 解の公式

2次方程式 ax² + bx + c = 0 の解は

x = (−b ± √(b² − 4ac)) / 2a

## 使い方

1. 式を ax² + bx + c = 0 の形に整理する。
2. a、b、c の値を読みとる（符号に注意）。
3. 公式に代入して計算する。
4. √ の中の数に平方数の因数があれば、簡単にする。

**例：** x² + 3x − 1 = 0（a = 1、b = 3、c = −1）

b² − 4ac = 9 − 4 × 1 × (−1) = 13 なので x = (−3 ± √13) / 2

**例：** 2x² + 5x + 1 = 0（a = 2、b = 5、c = 1）

b² − 4ac = 25 − 8 = 17 なので x = (−5 ± √17) / 4

## 注意

- −b の符号、分母が 2a であること（a だけではない）に注意します。
- 約分できるときは、分子と分母を共通の数でわります。
