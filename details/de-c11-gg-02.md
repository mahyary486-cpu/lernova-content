# Massenwirkungsgesetz

## Gleichgewichtskonstante
Für die Reaktion **a A + b B ⇌ c C + d D** gilt im Gleichgewicht das **Massenwirkungsgesetz (MWG)**:

**K_c = [C]^c · [D]^d / ([A]^a · [B]^b)**

- Die eckigen Klammern bedeuten Konzentrationen in mol/L.
- Die Koeffizienten der Reaktionsgleichung werden zu **Exponenten**.
- Produkte stehen im Zähler, Edukte im Nenner.
- Reine Feststoffe und reine Flüssigkeiten werden nicht aufgeführt.

## Bedeutung von K
- **K >> 1:** Das Gleichgewicht liegt auf der **Produktseite**.
- **K << 1:** Das Gleichgewicht liegt auf der **Eduktseite**.
- K hängt nur von der **Temperatur** ab, nicht von den Anfangskonzentrationen und nicht vom Katalysator.

## Beispiele
Ammoniak: N₂ + 3 H₂ ⇌ 2 NH₃ ⇒ K_c = [NH₃]² / ([N₂] · [H₂]³)

Rechenbeispiel: H₂ + I₂ ⇌ 2 HI mit [H₂] = 0,2 mol/L, [I₂] = 0,2 mol/L, [HI] = 0,8 mol/L:
K_c = 0,8² / (0,2 · 0,2) = 0,64 / 0,04 = **16**

## Reaktionsquotient
Setzt man beliebige Konzentrationen ein, erhält man den Quotienten Q.
- Q < K: Die Hinreaktion überwiegt, bis Q = K.
- Q > K: Die Rückreaktion überwiegt, bis Q = K.
