# 分词作宾语补足语

## 感官动词 + 宾语 + 分词

see, hear, watch, notice, feel, find + sb / sth + **doing** / **done**

- **doing**：强调动作**正在进行**：I saw him **crossing** the road.
- **done**：宾语是动作的承受者（被动）：I heard the song **sung** in English.

## have / get + 宾语 + done

1. 让别人做某事：I **had** my bike **repaired**.（请人修自行车）
2. 遭遇不幸：He **had** his wallet **stolen**.（钱包被偷）

## 其他

- **keep / leave** + sb + **doing**：Don't keep him **waiting**.
- **have** sb **doing**：He had us **laughing** all the time.
- **get** sth **done**：We must get the work **finished** today.

## 对比：do / doing / done

| 结构 | 意思 |
|---|---|
| see sb **do** | 看见某人做（完整过程） |
| see sb **doing** | 看见某人正在做 |
| see sth **done** | 看见某事被做 |

## 提示

宾语和分词之间的关系：**主动用 doing，被动用 done**。
