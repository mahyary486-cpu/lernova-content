# 名词性从句的连接词

## 连接词的三种类型

1. **从属连词**：that, whether, if（**不作成分**）；
2. **连接代词**：what, who, whom, whose, which（**作成分**）；
3. **连接副词**：when, where, why, how（**作状语**）。

## that 与 what

- **that**：不作成分，没有意义；在主语、表语、同位语从句中**不能省略**；
  - **That** he is late is true.
- **what**：在从句中**作成分**（主语、宾语、表语）；
  - **What** he said is right.（what 作 said 的宾语）

## that 与 whether

- **whether** = 是否，有"是不是"的意思；
- 在**主语从句、表语从句、同位语从句**中，只能用 **whether**，不用 if：
  - **Whether** it is true is still unknown.
  - The question is **whether** we should go.

## 判断方法

1. 先看从句**是否缺少成分**：缺少 → 用 what、who 等；
2. 不缺成分，没有"是否"的意思 → 用 **that**；
3. 不缺成分，有"是否"的意思 → 用 **whether**。

## 例句

- I have no idea **where** he has gone.
- **Who** will win is still unknown.
