# Векторы и координаты в пространстве

В пространстве вектор задают тремя координатами (x; y; z).

**Координаты вектора AB:** из координат конца вычитают координаты начала. Для A(1; 2; 3) и B(4; 6; 8): AB = (3; 4; 5).

**Длина:** |a| = √(x² + y² + z²). Для (1; 2; 2) длина равна 3.

**Расстояние между точками** A и B равно длине вектора AB. Для (0; 0; 0) и (2; 3; 6) оно равно 7.

**Середина отрезка:** среднее арифметическое координат. Для A(2; 4; 6) и B(4; 0; 2) получаем (3; 2; 4).

**Скалярное произведение:** a · b = x₁x₂ + y₁y₂ + z₁z₂, а cos φ = (a · b) / (|a| · |b|). Для (1; 2; 3) и (2; −1; 0) получаем 2 − 2 + 0 = 0, значит, векторы перпендикулярны. Угол между (1; 0; 0) и (1; 1; 0) равен 45°. Векторы (2; k; 1) и (1; 3; −2) перпендикулярны, если 2 + 3k − 2 = 0, то есть k = 0.
