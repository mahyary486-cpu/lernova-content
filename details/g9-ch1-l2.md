# Order of Operations and Evaluating Expressions

## PEMDAS
1. **P**arentheses (and other grouping symbols, like fraction bars)
2. **E**xponents
3. **M**ultiplication and **D**ivision, from left to right
4. **A**ddition and **S**ubtraction, from left to right

Multiplication and division have equal rank, so work from left to right. The same is true for addition and subtraction.

## Worked examples
**Example 1.** 3 + 4 x 2
Multiply first: 4 x 2 = 8. Then add: 3 + 8 = 11.

**Example 2.** 18 / 3 x 2
Left to right: 18 / 3 = 6, then 6 x 2 = 12.

**Example 3.** 12 - 3(4 - 1)
Parentheses: 4 - 1 = 3. Multiply: 3 x 3 = 9. Subtract: 12 - 9 = 3.

**Example 4.** Evaluate x^2 - 3x when x = -2.
Substitute with parentheses: (-2)^2 - 3(-2) = 4 + 6 = 10.

## Evaluating expressions
To evaluate an algebraic expression, replace every variable with its given value and then simplify with PEMDAS. Writing negative values in parentheses protects you from sign errors.

## Common mistakes
- Adding before multiplying (3 + 4 x 2 is 11, not 14).
- Doing multiplication before division just because M comes before D. They have equal rank.
- Writing -2^2 as 4. The exponent applies only to 2, so -2^2 = -4. With parentheses, (-2)^2 = 4.
