# Parábola, vértice y eje de simetría

## Elementos
- Concavidad: a > 0 hacia arriba (mínimo), a < 0 hacia abajo (máximo).
- Vértice: xᵥ = −b/(2a) e yᵥ = f(xᵥ).
- Eje de simetría: x = xᵥ.
- Ordenada al origen: (0; c).

## Ejemplo
f(x) = x² − 4x + 3.
- a = 1 > 0: abre hacia arriba.
- xᵥ = 4/2 = 2; yᵥ = 4 − 8 + 3 = −1. Vértice (2; −1).
- Eje: x = 2. Ordenada: (0; 3).

## Cómo graficar
Se marcan el vértice, la ordenada, su punto simétrico y las raíces si existen.

## Error frecuente
Calcular xᵥ = b/(2a) sin el signo menos.
