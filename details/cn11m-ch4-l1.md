# 等差数列

## 定义

从第 2 项起，每一项与它的前一项的差都等于同一个常数 d：**aₙ₊₁ − aₙ = d**，d 叫公差。

## 公式

- 通项公式：**aₙ = a₁ + (n − 1)d**；
- 前 n 项和：**Sₙ = n(a₁ + aₙ) / 2 = na₁ + n(n − 1)d / 2**；
- 等差中项：a、b、c 成等差数列 ⇔ 2b = a + c。

## 性质

若 m + n = p + q，则 aₘ + aₙ = aₚ + a_q。

## 例题

**例：** a₁ = 2，d = 3：

- a₁₀ = 2 + 9 × 3 = 29；
- S₁₀ = 10 × (2 + 29) / 2 = 155。
