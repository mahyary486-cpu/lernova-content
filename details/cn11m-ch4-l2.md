# 等比数列

## 定义

从第 2 项起，每一项与它的前一项的比都等于同一个非零常数 q：**aₙ₊₁ / aₙ = q**，q 叫公比。

## 公式

- 通项公式：**aₙ = a₁qⁿ⁻¹**；
- 前 n 项和：q ≠ 1 时 **Sₙ = a₁(1 − qⁿ) / (1 − q)**；q = 1 时 Sₙ = na₁；
- 等比中项：a、b、c 成等比数列 ⇔ **b² = ac**。

## 性质

若 m + n = p + q，则 aₘ · aₙ = aₚ · a_q。

## 例题

**例 1：** a₁ = 2，q = 3：a₄ = 2 × 3³ = 54。

**例 2：** S₄ = 2(1 − 3⁴) / (1 − 3) = 2 × (−80) / (−2) = 80。

**例 3：** a₂ = 4，a₅ = 32，则 q³ = a₅ / a₂ = 8，q = 2。

**注意**：等比数列的各项和公比都不能为 0。
