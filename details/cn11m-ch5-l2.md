# 导数与函数的单调性、极值

## 单调性

- f′(x) > 0：f(x) 在该区间上单调**递增**；
- f′(x) < 0：f(x) 在该区间上单调**递减**。

## 极值

设 f′(x₀) = 0：

- 左侧 f′(x) > 0，右侧 f′(x) < 0：x₀ 是**极大值点**；
- 左侧 f′(x) < 0，右侧 f′(x) > 0：x₀ 是**极小值点**。

**注意**：f′(x₀) = 0 只是极值的**必要条件**，要检验两侧导数是否异号。

## 例题

f(x) = x³ − 3x：

- f′(x) = 3x² − 3 = 3(x − 1)(x + 1)；
- f′(x) > 0 ⇒ x < −1 或 x > 1，所以递增区间 (−∞, −1)、(1, +∞)；
- f′(x) < 0 ⇒ −1 < x < 1，递减区间 (−1, 1)；
- 极大值 f(−1) = 2，极小值 f(1) = −2。
