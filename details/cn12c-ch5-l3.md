# 电化学综合

## 判断原电池与电解池

有**外加电源**的是电解池；没有外加电源、自发发生氧化还原反应的是原电池。

## 燃料电池（碱性氢氧燃料电池）

- 负极：H₂ + 2OH⁻ − 2e⁻ = 2H₂O；
- 正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻；
- 总反应：2H₂ + O₂ = 2H₂O。

## 电解的计算

串联电路中，各电极转移的电子数**相等**。

**例：** 用惰性电极电解 CuSO₄ 溶液，阴极增重 6.4 g（0.1 mol Cu）：

- 阴极：Cu²⁺ + 2e⁻ = Cu，转移电子 0.2 mol；
- 阳极：4OH⁻ − 4e⁻ = 2H₂O + O₂↑，生成 O₂ 0.05 mol；
- 标准状况下 V(O₂) = 0.05 × 22.4 = **1.12 L**。

## 电解后溶液的恢复

"出什么，补什么"：电解 CuSO₄ 溶液，析出 Cu 和 O₂，相当于脱去了 CuO，所以要加入 **CuO**（0.1 mol）才能恢复原来的浓度。

## 注意

加入 Cu(OH)₂ 会多加水，不能恢复原浓度（除非电解还产生了 H₂）。
