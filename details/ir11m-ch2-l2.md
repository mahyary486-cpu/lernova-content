# معادله‌ی درجه‌ی دوم، دلتا و روابط ریشه‌ها

## این درس درباره‌ی چیست؟

معادله‌ی ax² + bx + c = 0 (a ≠ 0) را به چند روش حل می‌کنیم و درباره‌ی ریشه‌هایش پیش از حل نتیجه می‌گیریم.

## دلتا و فرمول ریشه‌ها

مقدار **Δ = b² − 4ac** را دلتا می‌نامیم.

- Δ > 0: دو ریشه‌ی حقیقی متمایز
- Δ = 0: یک ریشه‌ی مضاعف
- Δ < 0: ریشه‌ی حقیقی ندارد

ریشه‌ها: **x = (−b ± √Δ) / 2a**

## مجموع و حاصل‌ضرب ریشه‌ها

اگر x₁ و x₂ ریشه‌ها باشند:

- **x₁ + x₂ = −b/a**
- **x₁ · x₂ = c/a**

**مثال:** در x² − 7x + 10 = 0 مجموع ریشه‌ها 7 و حاصل‌ضرب آن‌ها 10 است، پس ریشه‌ها 2 و 5 هستند.

## کاربرد

عبارت‌هایی مثل x₁² + x₂² را بدون حل معادله می‌توان محاسبه کرد: x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂. همچنین 1/x₁ + 1/x₂ = (x₁ + x₂)/(x₁x₂).
