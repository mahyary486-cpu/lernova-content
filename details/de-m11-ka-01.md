# Extrema und Monotonie

## Monotonie

- f′(x) > 0 auf einem Intervall: f ist dort **streng monoton steigend**.
- f′(x) < 0 auf einem Intervall: f ist dort **streng monoton fallend**.

## Extremstellen

- **Notwendig:** f′(x₀) = 0
- **Hinreichend (Hochpunkt):** f′(x₀) = 0 und f″(x₀) < 0
- **Hinreichend (Tiefpunkt):** f′(x₀) = 0 und f″(x₀) > 0
- Alternativ: **Vorzeichenwechsel von f′** (von + nach − bei einem Hochpunkt, von − nach + bei einem Tiefpunkt)

Ist auch f″(x₀) = 0, entscheidet das Vorzeichen von f′. So hat f(x) = x⁴ bei x = 0 einen Tiefpunkt.

## Globale Extrema

Man vergleicht die lokalen Extrema mit den **Funktionswerten an den Rändern** des Definitionsbereichs.

## Beispiele

**Beispiel 1:** f(x) = x² − 4x + 3.
f′(x) = 2x − 4 = 0 ergibt x = 2. f″ = 2 > 0, Tiefpunkt (2, −1).

**Beispiel 2:** f(x) = x³ − 3x.
f′(x) = 3x² − 3 = 0 ergibt x = ±1.
Hochpunkt (−1, 2), Tiefpunkt (1, −2).

**Beispiel 3:** f(x) = x³ − 6x² + 9x.
Hochpunkt (1, 4), Tiefpunkt (3, 0).
