# Lagebeziehungen von Punkt, Gerade und Ebene

## Punktprobe

Ein Punkt liegt in der Ebene, wenn seine Koordinaten die Koordinatengleichung erfüllen.

**Beispiel:** P(2; 1; 1) und x + 2y − z = 3.
2 + 2 − 1 = 3, der Punkt liegt in der Ebene.

## Gerade und Ebene

Drei Fälle:

- **Schneidend:** genau ein Schnittpunkt
- **Echt parallel:** kein gemeinsamer Punkt
- **Gerade liegt in der Ebene**

## Vorgehen

Man setzt die Geradengleichung in die Ebenengleichung ein und löst nach t.

- **Genau eine Lösung:** Schnittpunkt
- **Keine Lösung:** echt parallel
- **Beliebiges t:** Gerade liegt in der Ebene

Gilt **u · n = 0**, ist die Gerade parallel zur Ebene oder liegt in ihr.

## Beispiele

**Beispiel 1:** g: x = t · (1; 1; 1), E: x + y + z = 3.
3t = 3 ergibt t = 1, Schnittpunkt (1; 1; 1).

**Beispiel 2:** g: x = (0; 0; 1) + t · (1; 0; 0), E: z = 0.
Echt parallel.

**Beispiel 3:** g: x = (1; 0; 0) + t · (0; 1; 0), E: x = 1.
Die Gerade liegt in der Ebene.
