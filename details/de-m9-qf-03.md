# Quadratische Gleichungen lösen

Eine quadratische Gleichung hat die **Normalform x² + px + q = 0**. Sie hat höchstens **zwei** Lösungen.

## Einfache Sonderfälle

**Wurzelziehen** (kein x-Glied): x² = c. Für c > 0 gibt es zwei Lösungen x = ±√c.

Beispiel: x² = 16 ergibt x = 4 oder x = −4.

**Ausklammern** (kein konstantes Glied): x² + px = 0 wird zu x(x + p) = 0.

Nach dem **Satz vom Nullprodukt** ist ein Produkt genau dann null, wenn mindestens ein Faktor null ist. Beispiel: x(x − 5) = 0 ergibt x = 0 oder x = 5.

## Die pq-Formel

**x₁,₂ = −p/2 ± √((p/2)² − q)**

Beispiel: x² − 6x + 5 = 0 mit p = −6 und q = 5.

x = 3 ± √(9 − 5) = 3 ± 2, also x₁ = 5 und x₂ = 1.

## Die Diskriminante

**D = (p/2)² − q** (der Term unter der Wurzel)

- D > 0: zwei Lösungen
- D = 0: genau eine Lösung (Doppellösung)
- D < 0: keine reelle Lösung

## Die abc-Formel

Für ax² + bx + c = 0 gilt: **x₁,₂ = (−b ± √(b² − 4ac)) / (2a)**

Beispiel: 2x² − 5x + 2 = 0. Es ist D = 25 − 16 = 9, also x = (5 ± 3) / 4. Das ergibt x₁ = 2 und x₂ = 0,5.

## Satz von Vieta

Sind x₁ und x₂ die Lösungen von x² + px + q = 0, dann gilt:

- x₁ + x₂ = −p
- x₁ · x₂ = q

Damit kann man Lösungen prüfen oder die zweite Lösung finden.
