# Systems of linear equations

A system of linear equations is a set of two or more linear equations that must all be true at the same time for the same values of the variables.

## Key ideas

- A solution of a system with two variables is an ordered pair (x, y) that makes both equations true.
- Graphically, each equation is a line. The solution is the point where the lines cross.
- There are three possible cases:
  - The lines cross at one point: exactly one solution (different slopes).
  - The lines are parallel and different: no solution (same slope, different intercepts).
  - The lines are the same line: infinitely many solutions.
- Substitution method: solve one equation for one variable, then put that expression into the other equation.
- Elimination method: multiply the equations by suitable numbers so that one variable has opposite coefficients, then add the equations to remove that variable.
- Always check the answer in both original equations.

## Worked examples

Example 1. Solve y = 2x - 1 and 3x + y = 9 by substitution.

Step 1: Put y = 2x - 1 into the second equation: 3x + (2x - 1) = 9.
Step 2: Combine: 5x - 1 = 9, so 5x = 10, so x = 2.
Step 3: Then y = 2 × 2 - 1 = 3.
Step 4: Check: 3 × 2 + 3 = 9 and 3 = 2 × 2 - 1. Both are true. The solution is (2, 3).

Example 2. Solve 2x + 3y = 12 and 4x - 3y = 6 by elimination.

Step 1: The y terms are +3y and -3y, so they cancel when we add.
Step 2: Add the equations: 6x = 18, so x = 3.
Step 3: Put x = 3 into the first equation: 6 + 3y = 12, so 3y = 6, so y = 2.
Step 4: Check in the second equation: 4 × 3 - 3 × 2 = 12 - 6 = 6. It works. The solution is (3, 2).

Example 3. Solve 3x + 2y = 7 and 2x - 5y = -8.

Step 1: Make the y coefficients opposite. Multiply the first equation by 5: 15x + 10y = 35.
Step 2: Multiply the second equation by 2: 4x - 10y = -16.
Step 3: Add: 19x = 19, so x = 1.
Step 4: Put x = 1 into 3x + 2y = 7: 3 + 2y = 7, so y = 2.
Step 5: Check in the second equation: 2 × 1 - 5 × 2 = 2 - 10 = -8. It works. The solution is (1, 2).

Example 4 (special case). Solve x + y = 4 and 2x + 2y = 10.

Step 1: Multiply the first equation by 2: 2x + 2y = 8.
Step 2: This says 2x + 2y = 8 and also 2x + 2y = 10, which cannot both be true.
Step 3: The lines are parallel, so there is no solution.

## Common mistakes

- Multiplying only one side of an equation when scaling it. Multiply every term on both sides.
- Finding x and then stopping. A solution needs both x and y.
- Making sign errors when subtracting equations. Adding after making coefficients opposite is safer.
- Not checking. A quick check in both equations catches most errors.

## Remember

- The solution of a system is the crossing point of the lines.
- Use substitution when a variable is already alone, and elimination when coefficients can be matched.
- A system can have one, none or infinitely many solutions.
