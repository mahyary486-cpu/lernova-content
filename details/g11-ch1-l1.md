# Functions, Domain and Range

## What is a function?
A **function** gives each input (x) exactly one output (y). The set of all allowed inputs is the **domain**. The set of all outputs is the **range**.
- {(1, 2), (2, 3), (3, 4)} is a function: every x appears once.
- {(1, 2), (1, 3), (2, 4)} is **not** a function: the input 1 has two outputs.

## Vertical line test
A graph is a function if **no vertical line** crosses it more than once. A circle fails the test, so a circle is not a function.

## Function notation
f(x) is read "f of x". To evaluate, replace x with the given input.
If f(x) = 3x - 2, then f(4) = 3(4) - 2 = **10**.
If the input is an expression, replace x with the whole expression, in parentheses: f(a + 1) = 3(a + 1) - 2 = 3a + 1.

## Finding the domain
Start with all real numbers, then remove the inputs that break a rule:
- You cannot divide by zero. For f(x) = 1/(x + 5), x cannot be -5.
- A square root needs a number that is not negative. For f(x) = sqrt(x - 3), we need x - 3 ≥ 0, so x ≥ 3.

## Finding the range
Think about the outputs. For f(x) = x^2 + 2, the term x^2 is never negative, so the smallest output is 2. The range is y ≥ 2.

## Worked examples
1. f(x) = x^2 - 4x. Find f(-1). f(-1) = (-1)^2 - 4(-1) = 1 + 4 = **5**.
2. Domain of f(x) = 7/(x - 1). Only x = 1 is forbidden, so the domain is **all real numbers except 1**.
3. Is x^2 + y^2 = 25 a function? **No.** The vertical line x = 3 crosses the circle at (3, 4) and (3, -4).

## Common mistakes
- Reading f(x) as "f times x". It means "the output of f when the input is x".
- Forgetting parentheses with negative inputs. For x^2, f(-1) is (-1)^2 = 1, not -1.
- Mixing up the two rules: a square root of 0 is allowed (x - 3 = 0 is fine), but a denominator of 0 is never allowed.
