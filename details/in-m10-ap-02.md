# Finding terms and number of terms

To find which term equals a value, solve a + (n − 1)d = value for n; n must be a positive integer. For 3, 8, 13, … the value 78 is the 16th term.

To count terms in an AP with last term l use n = (l − a)/d + 1. For 7, 13, 19, …, 205 there are (205 − 7)/6 + 1 = 34 terms.
