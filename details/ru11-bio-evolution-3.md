# Формы отбора и видообразование

**Формы естественного отбора.**

- **Стабилизирующий** сохраняет среднее значение признака в постоянных условиях (например, масса новорождённых).
- **Движущий** сдвигает среднее значение признака при изменении условий (например, индустриальный меланизм у берёзовой пяденицы).
- **Разрывающий (дизруптивный)** поддерживает крайние варианты признака.

**Видообразование.**

- **Аллопатрическое** связано с географической изоляцией.
- **Симпатрическое** идёт без географической изоляции, например путём полиплоидии у растений.

Новый вид возникает, когда между популяциями появляется **репродуктивная изоляция**.
