# Properties of Logarithms

## The three main properties
For positive numbers M and N and a base b (b > 0, b is not 1):
| Property | Rule |
|---|---|
| Product | log_b(MN) = log_b(M) + log_b(N) |
| Quotient | log_b(M/N) = log_b(M) - log_b(N) |
| Power | log_b(M^p) = p * log_b(M) |

Logs turn **multiplication into addition**, **division into subtraction** and **powers into multiplication**.

## Using the properties
**Expanding.**
- log_2(8x) = log_2(8) + log_2(x) = **3 + log_2(x)**
- log(x^3 y) = **3 log(x) + log(y)**
- ln(sqrt(x)) = ln(x^(1/2)) = **(1/2) ln(x)**
- log_3(x^2 / 9) = 2 log_3(x) - 2

**Condensing** (the reverse).
- log(5) + log(4) = log(20)
- log_2(12) - log_2(3) = log_2(4) = **2**
- 2 log(x) + log(y) = **log(x^2 y)**
- 3 ln(2) - ln(4) = ln(8) - ln(4) = ln(2)

## Change of base formula
**log_b(x) = log(x) / log(b) = ln(x) / ln(b)**
This lets you compute any log with a calculator.
Example: log_2(10) = ln(10) / ln(2), about **3.32**.

## Useful facts
- log_b(1) = 0 and log_b(b) = 1.
- log_b(b^x) = x.
- log_5(25) + log_5(5) = 2 + 1 = **3**.

## Worked example
Simplify log_6(4) + log_6(9). By the product property, log_6(36) = **2**.

## Common mistakes (these are false!)
- log(M + N) is **not** log(M) + log(N).
- log(M) / log(N) is **not** log(M/N).
- (log M)^2 is **not** 2 log(M).
- log_b(M) * log_b(N) is **not** log_b(M + N).
Only the three properties above are valid.
