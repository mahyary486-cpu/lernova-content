# Systems of Equations and Matrices

A system of equations asks for values that satisfy every equation at once. Matrices give a compact way to store and solve systems.

## Solving systems
- **Substitution:** solve one equation for a variable and substitute into the other.
- **Elimination:** add or subtract multiples of equations to cancel a variable.
- A linear system has one solution (lines cross), no solution (parallel lines) or infinitely many (same line).
- A linear-conic system, such as a line and a circle, can have 0, 1 or 2 solutions.

## Matrix basics
- A matrix with m rows and n columns has size m x n.
- Add or subtract matrices of the same size entry by entry.
- To multiply A (m x n) by B (n x p), the inner sizes must match. Each entry is a row of A times a column of B, summed. Order matters: AB is usually not BA.
- For [a b; c d] the determinant is ad - bc. If it is not zero, the inverse is (1/(ad - bc)) [d -b; -c a].
- A system AX = B has solution X = (A inverse) B when A is invertible.

## Worked examples

**Example 1. Multiply [1 2; 3 4] by [2 0; 1 3].**
1. Row 1: 1*2 + 2*1 = 4 and 1*0 + 2*3 = 6.
2. Row 2: 3*2 + 4*1 = 10 and 3*0 + 4*3 = 12.
3. Result: [4 6; 10 12].

**Example 2. Solve 2x + y = 4 and 5x + 3y = 9 with matrices.**
1. A = [2 1; 5 3], determinant 6 - 5 = 1, so the inverse is [3 -1; -5 2].
2. X = [3 -1; -5 2] times [4; 9] = [12 - 9; -20 + 18] = [3; -2].
3. Solution (3, -2). Check: 6 - 2 = 4 and 15 - 6 = 9.

**Example 3. Intersect y = x + 1 with x^2 + y^2 = 25.**
1. Substitute: x^2 + (x + 1)^2 = 25, so 2x^2 + 2x - 24 = 0.
2. Divide by 2: x^2 + x - 12 = 0, so (x + 4)(x - 3) = 0.
3. x = 3 gives y = 4 and x = -4 gives y = -3.
4. Solutions (3, 4) and (-4, -3).

## Common mistakes
- Multiplying matrices entry by entry. Use rows times columns.
- Assuming AB = BA.
- Using the wrong signs in the inverse: swap a and d, negate b and c.
- Finding only the x values of a nonlinear system and forgetting to find y.
