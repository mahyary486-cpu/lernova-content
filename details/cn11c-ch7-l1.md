# 晶体的常识

## 晶体与非晶体

- **晶体**：内部粒子在三维空间里呈周期性有序排列，如食盐、金刚石、冰；
- **非晶体**：内部粒子排列相对无序，如玻璃、橡胶。

## 晶体的特征

1. **自范性**：能自发地呈现多面体外形；
2. **各向异性**：不同方向上物理性质不同；
3. 有**固定的熔点**；
4. 对 X 射线有衍射效应。

**区分晶体和非晶体最可靠的科学方法**：对固体进行 **X 射线衍射实验**。

## 晶胞

晶胞是晶体中**最小的重复单元**，晶体可以看成是无数晶胞"无隙并置"堆积而成。

## 获得晶体的途径

熔融态物质凝固；气态物质凝华；溶质从溶液中析出。
