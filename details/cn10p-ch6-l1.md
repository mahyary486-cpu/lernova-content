# 描述圆周运动的物理量

## 线速度

做圆周运动的物体通过的弧长与所用时间的比值：**v = Δs / Δt = 2πr / T**，方向沿圆周的**切线**。

## 角速度

半径转过的角度与所用时间的比值：**ω = Δθ / Δt = 2π / T**，单位 rad/s。

## 周期、频率、转速

- 周期 T：转一圈所用的时间；
- 频率 f = 1/T；
- 转速 n：单位时间转过的圈数，**ω = 2πf = 2πn**。

## 关系

**v = ωr**

**例：** T = 2 s，r = 0.5 m：ω = 2π/2 = π rad/s，v = ωr = 0.5π ≈ 1.57 m/s。

## 常见模型

- **同轴转动**：各点角速度 ω 相同；
- **皮带传动**（不打滑）：轮缘各点线速度 v 相同。

匀速圆周运动的速度大小不变，但**方向时刻改变**，所以是变速运动。
