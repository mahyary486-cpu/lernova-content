# Solving Trigonometric Equations

A trigonometric equation is true only for certain angles. Unlike an identity, it has specific solutions, and because the functions are periodic there are often infinitely many.

## Key ideas
1. Isolate the trig function, for example sin x = 1/2.
2. Find the solutions in one period using the unit circle or an inverse function.
3. For general solutions, add the period: 2pi*k for sine and cosine, pi*k for tangent (k is any integer).
4. For equations with several terms, factor, use the quadratic formula, or rewrite with an identity so only one function remains.
5. For arguments like 2x, solve for 2x first, then divide by 2. Be sure to include enough solutions: on [0, 2pi) there are twice as many.
6. Check for extraneous solutions, especially if you squared both sides or divided by an expression.

## Worked examples
**Example 1.** Solve 2 sin x - 1 = 0 on [0, 2pi).
1. sin x = 1/2.
2. Sine is positive in Quadrants I and II, so x = pi/6 or x = 5pi/6.
3. General solution: x = pi/6 + 2pi*k or x = 5pi/6 + 2pi*k.

**Example 2.** Solve 2 cos^2 x - cos x - 1 = 0 on [0, 2pi).
1. Factor: (2 cos x + 1)(cos x - 1) = 0.
2. cos x = -1/2 gives x = 2pi/3 or 4pi/3. cos x = 1 gives x = 0.
3. Solutions: 0, 2pi/3, 4pi/3.

**Example 3.** Solve tan(2x) = 1 on [0, 2pi).
1. 2x = pi/4 + pi*k.
2. x = pi/8 + pi*k/2.
3. For k = 0, 1, 2, 3: x = pi/8, 5pi/8, 9pi/8, 13pi/8.

**Example 4.** Solve sin 2x = sin x on [0, 2pi).
1. 2 sin x cos x - sin x = 0, so sin x (2 cos x - 1) = 0.
2. sin x = 0 gives x = 0, pi. cos x = 1/2 gives x = pi/3, 5pi/3.

## Common mistakes
- Dividing both sides by sin x and losing the solutions where sin x = 0.
- Giving only the calculator answer and missing the second solution in another quadrant.
- Solving tan(2x) = 1 and forgetting to divide the general solution by 2.
- Not checking that the answers lie in the requested interval.
