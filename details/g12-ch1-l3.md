# Even and Odd Functions

## Definitions
- A function is **even** if **f(-x) = f(x)** for every x in its domain. Its graph is **symmetric about the y-axis**.
- A function is **odd** if **f(-x) = -f(x)** for every x in its domain. Its graph is **symmetric about the origin** (it looks the same after a 180-degree turn).
- If neither is true, the function is **neither**.

## Examples
**Even:** x^2, x^4, |x|, cos x, and constants such as 5.
**Odd:** x, x^3, 1/x, sin x.
**Neither:** x^2 + x, 2^x, sqrt(x).

## Testing algebraically
Replace x with -x and simplify.
- f(x) = x^4 - 3x^2: f(-x) = x^4 - 3x^2 = f(x). **Even.**
- f(x) = x^3 + x: f(-x) = -x^3 - x = -(x^3 + x). **Odd.**
- f(x) = x^2 + x: f(-x) = x^2 - x. This is not f(x) and not -f(x). **Neither.**

## Using symmetry
- If (2, 5) is on the graph of an **even** function, so is **(-2, 5)**.
- If (2, 5) is on the graph of an **odd** function, so is **(-2, -5)**.
- If an odd function is defined at 0, then f(0) = 0.

## Combining functions
| Operation | Result |
|---|---|
| even + even | even |
| odd + odd | odd |
| even * even | even |
| odd * odd | **even** |
| even * odd | odd |

Example: x * x = x^2. The product of two odd functions (x and x) is the even function x^2.

## Polynomials
A polynomial with only even powers of x (like x^4 - 3x^2 + 7) is even. A polynomial with only odd powers (like x^5 + 2x) is odd. Mixed powers usually mean neither.

## Common mistakes
- Thinking every function is either even or odd. Many are neither.
- Thinking "even" means an even exponent only. A constant term counts as even (x^0).
- Forgetting to change the sign of every term when finding -f(x).
