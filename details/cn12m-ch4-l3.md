# 数列的综合应用

## 数列的最值

等差数列 aₙ = 11 − 2n：首项 9，公差 −2。

Sₙ 最大 ⇔ 所有非负项之和：aₙ ≥ 0 ⇔ n ≤ 5，所以 n = 5 时 Sₙ 最大，S₅ = 5 × (9 + 1) / 2 = 25。

## 数列与不等式

**例：** 证明 1 + 1/2² + 1/3² + … + 1/n² < 2。

当 k ≥ 2 时，1/k² < 1/(k(k − 1)) = 1/(k − 1) − 1/k，所以

左边 < 1 + (1 − 1/2) + (1/2 − 1/3) + … + (1/(n − 1) − 1/n) = 2 − 1/n < 2。

这是"**放缩后裂项**"的典型方法。

## 数列的单调性

判断 aₙ₊₁ − aₙ 的符号：

- 大于 0：递增数列；
- 小于 0：递减数列。

## 应用问题

增长率、分期付款等问题，抽象成等差或等比数列，用通项和求和公式解决。注意 n 是**正整数**。
