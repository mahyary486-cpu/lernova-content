# Fonction carré et fonction racine carrée

## Fonction carré
f(x) = x², définie sur ℝ.
- Elle est paire : (−x)² = x².
- Décroissante sur ]−∞ ; 0], croissante sur [0 ; +∞[.
- Son minimum est 0, atteint en x = 0.
- Sa courbe est une parabole de sommet O.

## Conséquences pour comparer
- Si 0 ≤ a < b, alors a² < b².
- Si a < b ≤ 0, alors a² > b².
- Résoudre x² ≤ 9 revient à x ∈ [−3 ; 3] ; x² ≥ 9 revient à x ≤ −3 ou x ≥ 3.

## Fonction racine carrée
g(x) = √x, définie sur [0 ; +∞[.
- Elle est croissante : si 0 ≤ a < b, alors √a < √b.
- √x = k (avec k ≥ 0) donne x = k². Exemple : √x = 4 donne x = 16.
- Sa courbe est une demi-parabole couchée.

## Équation √(x − 1) = 3
On élève au carré : x − 1 = 9, donc x = 10. On vérifie : √(10 − 1) = 3.

## Erreur fréquente
√(a + b) n’est pas √a + √b. Et √(x²) = ∣x∣, qui vaut x seulement si x ≥ 0.
