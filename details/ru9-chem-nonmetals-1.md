# Галогены

**Галогены** — элементы VII группы: фтор, хлор, бром, йод. Хлор Cl₂ при обычных условиях — жёлто-зелёный ядовитый газ.

Химическая активность галогенов уменьшается сверху вниз.

**Хлороводород HCl** — газ, его раствор — соляная кислота. Соли соляной кислоты — хлориды (например, NaCl).

**Качественная реакция на хлорид-ион.** При добавлении раствора нитрата серебра AgNO₃ выпадает белый творожистый осадок AgCl: Ag⁺ + Cl⁻ = AgCl↓.
