# Спирты и фенол

**Спирты** содержат гидроксильную группу –OH. Метанол CH₃OH очень ядовит, этанол C₂H₅OH используют в медицине и промышленности. Глицерин C₃H₅(OH)₃ — трёхатомный спирт (3 группы –OH).

**Свойства этанола.**

- с натрием: 2C₂H₅OH + 2Na → 2C₂H₅ONa + H₂↑. Из 46 г (1 моль) этанола выделяется 0,5 моль H₂, то есть 11,2 л (н. у.);
- внутримолекулярная дегидратация при нагревании с концентрированной H₂SO₄ даёт этилен: C₂H₅OH → C₂H₄ + H₂O;
- горение до CO₂ и H₂O.

**Фенол** C₆H₅OH — слабая кислота. Качественная реакция на фенол: белый осадок трибромфенола с бромной водой.
