# Conditional Statements

## If-then statements
A **conditional statement** has the form **if p, then q**.
- **p** is the **hypothesis** (the if part).
- **q** is the **conclusion** (the then part).

Example: "If a figure is a square, then it is a rectangle." The hypothesis is "a figure is a square" and the conclusion is "it is a rectangle".

## Related statements
| Name | Form | Example (from: If an angle is a right angle, then it measures 90 degrees) |
|---|---|---|
| Conditional | if p, then q | If an angle is right, then it measures 90 degrees. |
| Converse | if q, then p | If an angle measures 90 degrees, then it is right. |
| Inverse | if not p, then not q | If an angle is not right, then it does not measure 90 degrees. |
| Contrapositive | if not q, then not p | If an angle does not measure 90 degrees, then it is not right. |

**Key fact:** a conditional and its **contrapositive** are logically equivalent: both are true or both are false. The converse and the inverse are equivalent to each other, but not to the original.

## Truth values and counterexamples
- A conditional is **false only** when the hypothesis is true and the conclusion is false.
- To show a conditional is false, give a **counterexample**: a case where the hypothesis is true and the conclusion is false.
- Example: "If a number is prime, then it is odd." The number 2 is prime but not odd, so the statement is false.

## Biconditionals
If a conditional **and** its converse are both true, you can join them as a **biconditional** with **if and only if**.
- "A number is even if and only if it is divisible by 2." This is true in both directions.

## Worked examples
1. "If a figure is a square, then it is a rectangle" is true. Its converse, "If a figure is a rectangle, then it is a square", is false, because a 2 by 3 rectangle is not a square.
2. Statement: "If x is greater than 5, then x squared is greater than 25." True. Converse: "If x squared is greater than 25, then x is greater than 5." False, because x = -6 gives 36, which is greater than 25, but -6 is not greater than 5.
3. Contrapositive of "If you live in Dallas, then you live in Texas": "If you do not live in Texas, then you do not live in Dallas."

## Common mistakes
- Thinking the converse always has the same truth value as the original. It does not.
- Forgetting to negate **both** parts when writing the inverse and the contrapositive.
- Using several true examples to "prove" a statement. Examples never prove it, but one counterexample disproves it.
