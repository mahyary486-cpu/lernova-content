# Positions relatives et intersections de droites et de plans

## Droite et plan
Soit d de vecteur directeur u et P de vecteur normal n.
- Si u·n ≠ 0 : d et P sont sécants en un point.
- Si u·n = 0 : d est parallèle au plan P (strictement ou incluse dans P).

## Point d’intersection
On remplace x, y, z de la représentation paramétrique de d dans l’équation de P et on résout en t.
Exemple : d : x = t, y = 1 + t, z = 2t et P : x + y + z = 4. t + (1 + t) + 2t = 4 donne 4t = 3 et t = 3/4. Le point est (3/4 ; 7/4 ; 3/2).
Autre exemple : d : x = 1 + t, y = 2t, z = −t et P : x + y + z = 3. 1 + t + 2t − t = 3 donne t = 1 et le point (2 ; 2 ; −1).

## Droite parallèle à un plan
d de vecteur directeur (1 ; 1 ; 1) et P : x − y = 0 de vecteur normal (1 ; −1 ; 0) : u·n = 1 − 1 + 0 = 0. La droite est parallèle au plan (ou incluse).

## Deux plans
Deux plans dont les vecteurs normaux ne sont pas colinéaires se coupent suivant une droite.

## Appartenance d’un point à un plan
Le point (1 ; 2 ; 3) appartient au plan x + y + z = 6, car 1 + 2 + 3 = 6. L’origine appartient au plan x + y − z = 0.

## Vecteur du plan
Pour le plan x − 2y + z = 0 (normal (1 ; −2 ; 1)), le vecteur (2 ; 1 ; 0) est parallèle au plan car 2 − 2 + 0 = 0.

## Triangle rectangle
A(0 ; 0 ; 0), B(1 ; 2 ; 2), C(2 ; 1 ; −2) : AB·AC = 2 + 2 − 4 = 0, donc ABC est rectangle en A.

## Erreur fréquente
Deux droites de l’espace qui ne sont pas sécantes ne sont pas forcément parallèles : elles peuvent être non coplanaires.
