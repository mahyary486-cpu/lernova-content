# لگاریتم: تعریف و خاصیت‌ها

## این درس درباره‌ی چیست؟

لگاریتم عکس عمل توان‌رسانی است: «به چه توانی باید a را رساند تا x شود؟»

## تعریف

**log_a x = y ⇔ aʸ = x** (a > 0 , a ≠ 1 , x > 0).

**مثال:** log₂ 8 = 3 چون 2³ = 8 و log 100 = 2 چون 10² = 100.

نتیجه‌ها: log_a 1 = 0 و log_a a = 1.

## خاصیت‌ها

- log(ab) = log a + log b
- log(a/b) = log a − log b
- log(aⁿ) = n·log a
- تغییر مبنا: log_a b = log b / log a
- a^(log_a x) = x

## مثال

اگر log 2 = 0٫3 باشد، log 8 = 3 × 0٫3 = 0٫9. همچنین log₂ 3 × log₃ 8 = log₂ 8 = 3.
