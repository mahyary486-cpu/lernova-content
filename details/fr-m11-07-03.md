# Variable aléatoire : loi, espérance, variance et écart-type

## Définition
Une variable aléatoire X associe un nombre réel à chaque issue d’une expérience aléatoire. La loi de probabilité de X est le tableau des valeurs x_1, …, x_n et des probabilités p_i = P(X = x_i), dont la somme vaut 1.

## Espérance
E(X) = p_1 x_1 + p_2 x_2 + … + p_n x_n.
Exemple : X prend les valeurs 1, 2, 3 avec les probabilités 0,2 ; 0,5 ; 0,3. E(X) = 0,2 + 1 + 0,9 = 2,1.
Exemple : X vaut −1 (0,5), 2 (0,3), 5 (0,2) : E(X) = −0,5 + 0,6 + 1 = 1,1.

## Variance et écart-type
V(X) = Σ p_i (x_i − E(X))², σ(X) = √V(X).
Exemple : X vaut 0 ou 10, chacune avec la probabilité 0,5. E(X) = 5 et V(X) = 0,5 × 25 + 0,5 × 25 = 25, donc σ(X) = 5.

## Jeu de hasard
On mise 2 € ; on gagne 5 € avec la probabilité 0,3 et rien sinon. Le gain algébrique G vaut 3 (probabilité 0,3) ou −2 (probabilité 0,7). E(G) = 0,9 − 1,4 = −0,5 : le jeu est défavorable au joueur (perte moyenne de 0,50 € par partie).

## Interprétation
L’espérance est la valeur moyenne de X sur un grand nombre de répétitions. L’écart-type mesure la dispersion des valeurs autour de cette moyenne.

## Propriétés
E(aX + b) = aE(X) + b et V(aX + b) = a²V(X).

## Erreur fréquente
L’espérance n’est pas forcément une valeur prise par X.
