# 正弦定理与余弦定理

在 △ABC 中，角 A、B、C 的对边分别为 a、b、c，外接圆半径为 R。

## 正弦定理

a / sin A = b / sin B = c / sin C = **2R**

用途：已知两角和一边，或已知两边和其中一边的对角。

**例：** A = 30°，B = 45°，a = 2，则 b = a · sin B / sin A = 2 × (√2/2) / (1/2) = 2√2。

## 余弦定理

- a² = b² + c² − 2bc cos A
- cos A = (b² + c² − a²) / (2bc)

用途：已知两边及夹角，或已知三边。

**例 1：** a = 3，b = 4，C = 60°，则 c² = 9 + 16 − 2 × 3 × 4 × ½ = 13，c = √13。

**例 2：** 三边 a = 3，b = 5，c = 7，最大角是 C：cos C = (9 + 25 − 49) / (2 × 3 × 5) = −1/2，所以 C = 120°。

## 面积

S = ½bc sin A = ½ab sin C。

cos C < 0 时，C 是钝角，三角形为钝角三角形。
