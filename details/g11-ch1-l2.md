# Parent Functions

## What is a parent function?
A **parent function** is the simplest function of its family. Every other function in the family is a transformation of it (shifted, stretched or reflected).

## The main parent functions
| Name | Rule | Shape | Domain | Range |
|---|---|---|---|---|
| Constant | f(x) = c | horizontal line | all reals | y = c |
| Linear | f(x) = x | diagonal line | all reals | all reals |
| Quadratic | f(x) = x^2 | parabola, opens up | all reals | y ≥ 0 |
| Cubic | f(x) = x^3 | S-shaped curve | all reals | all reals |
| Absolute value | f(x) = abs(x) | V shape | all reals | y ≥ 0 |
| Square root | f(x) = sqrt(x) | half a parabola on its side | x ≥ 0 | y ≥ 0 |
| Reciprocal | f(x) = 1/x | two curves (hyperbola) | x ≠ 0 | y ≠ 0 |

Here abs(x) means the absolute value of x, written |x|.

## Symmetry
- **Even function:** f(-x) = f(x). The graph is symmetric about the y-axis. Examples: x^2 and abs(x).
- **Odd function:** f(-x) = -f(x). The graph is symmetric about the origin. Examples: x, x^3 and 1/x.

## End behavior
End behavior tells what happens to f(x) as x gets very large (to the right) or very negative (to the left).
- x^2 and abs(x): both ends go **up**.
- x^3: left end goes **down**, right end goes **up**.

## Asymptotes
The graph of f(x) = 1/x never touches the line x = 0 (a **vertical asymptote**) or the line y = 0 (a **horizontal asymptote**). It gets closer and closer to them.

## Worked examples
1. Which parent function has a V-shaped graph? **abs(x).**
2. Is x^3 odd or even? f(-x) = (-x)^3 = -x^3 = -f(x), so it is **odd**.
3. Range of abs(x)? An absolute value is never negative, so **y ≥ 0**.

## Common mistakes
- Saying the range of x^2 is all real numbers. Squares are never negative.
- Saying 1/x has domain "all real numbers". The input 0 is not allowed.
- Thinking "even function" means the exponent is even. Even and odd describe symmetry, so always test f(-x).
