# 带电粒子在匀强磁场中的运动

## 匀速圆周运动

带电粒子垂直进入匀强磁场，洛伦兹力提供向心力：

qvB = mv² / r

- **轨道半径 r = mv / (qB)**；
- **周期 T = 2πm / (qB)**，与速度大小、半径无关。

**例：** 质子 m = 1.67×10⁻²⁷ kg，q = 1.6×10⁻¹⁹ C，v = 10⁶ m/s，B = 0.1 T：

r = 1.67×10⁻²⁷ × 10⁶ / (1.6×10⁻¹⁹ × 0.1) ≈ 0.10 m。

## 应用

- **质谱仪**：根据 r = mv/(qB) 分离不同质量的粒子；
- **回旋加速器**：粒子每转半周被电场加速，周期不变。最大动能

**Eₖ = q²B²R² / (2m)**，与加速电压无关（R 为 D 形盒半径）。

## 解题步骤

1. 找圆心（洛伦兹力的方向交点）；
2. 求半径（几何关系或公式）；
3. 求时间 t = (θ / 2π) T（θ 为圆心角）。
