# 正弦、余弦和正切

在 Rt△ABC 中，∠C = 90°，三边为 a、b、c（c 是斜边），对于锐角 ∠A：

- **正弦** sin A = 对边 / 斜边 = a/c
- **余弦** cos A = 邻边 / 斜边 = b/c
- **正切** tan A = 对边 / 邻边 = a/b

这些比值只与角 A 的大小有关，与三角形的大小无关。

**例：** 三边为 3、4、5 的直角三角形，设 ∠A 的对边为 3：sin A = 3/5，cos A = 4/5，tan A = 3/4。

## 重要关系

- sin²A + cos²A = 1
- tan A = sin A / cos A
- sin A = cos(90° − A)
