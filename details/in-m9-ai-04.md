# Factorising with identities

Perfect squares: x² + 2x + 1 = (x + 1)² and 9x² − 6x + 1 = (3x − 1)². Differences of squares: 4x² − 25 = (2x + 5)(2x − 5). Trinomials: x² − 7x + 12 = (x − 3)(x − 4).

Cubes: (a + b)³ = a³ + 3a²b + 3ab² + b³, a³ − b³ = (a − b)(a² + ab + b²), a³ + b³ = (a + b)(a² − ab + b²). Example: x³ − 8 = (x − 2)(x² + 2x + 4).

Useful tricks: if a + b = 5 and ab = 6 then a² + b² = 25 − 12 = 13; if x + 1/x = 3 then x² + 1/x² = 7.
