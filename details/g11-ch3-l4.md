# The Remainder and Factor Theorems

## Remainder Theorem
When a polynomial f(x) is divided by **x - c**, the remainder is **f(c)**.
This means you can find a remainder just by evaluating the function, with no division.

Example: f(x) = 2x^3 - 3x + 1 divided by x - 2. The remainder is f(2) = 2(8) - 6 + 1 = **11**.

Example: f(x) = x^2 - 5x + 6 divided by x - 1. The remainder is f(1) = 1 - 5 + 6 = **2**.

## Factor Theorem
**x - c is a factor of f(x) if and only if f(c) = 0.** In other words, c is a **zero** of f exactly when x - c is a factor.
- If f(4) = 0, then x - 4 is a factor.
- If f(-1) = 0, then **x + 1** is a factor.
If f(c) is not 0, then x - c is not a factor.

## Using the theorems
**Example 1.** Is x + 1 a factor of f(x) = x^3 - 4x^2 + x + 6? Test c = -1: f(-1) = -1 - 4 - 1 + 6 = 0. **Yes.**

**Example 2.** Find all zeros of f(x) = x^3 - 4x^2 + x + 6. Check f(2) = 8 - 16 + 2 + 6 = 0 and f(3) = 27 - 36 + 3 + 6 = 0. With f(-1) = 0 too, the zeros are **2, -1 and 3**, and f(x) = (x - 2)(x + 1)(x - 3).

**Example 3.** Find k so that x - 1 is a factor of x^3 + kx - 6. We need f(1) = 1 + k - 6 = 0, so **k = 5**.

**Example 4.** If f(2) = 0 and f(-3) = 0, then (x - 2) and (x + 3) are both factors, so **(x - 2)(x + 3)** is a factor.

**Example 5.** The remainder when x^3 + ax^2 - 4x + 3 is divided by x + 1 is 8. Then f(-1) = -1 + a + 4 + 3 = a + 6 = 8, so **a = 2**.

## Common mistakes
- Using f(c) for the divisor x + c. For x + 1, evaluate f(-1).
- Thinking a nonzero remainder means the polynomial has no factors at all. It only means that x - c is not a factor.
- Mixing up "zero" and "factor": the zero is c, the factor is x - c.
