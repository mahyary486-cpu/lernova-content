# Properties of the parabola

For y = ax² + bx + c the **vertex** has x-coordinate x₀ = −b / (2a). Put x₀ into the formula to get y₀. The vertical line x = x₀ is the **axis of symmetry**.

If a > 0 the vertex is the lowest point, so y₀ is the **minimum** value; the function decreases for x < x₀ and increases for x > x₀. If a < 0 the vertex is the highest point, so y₀ is the **maximum**, and the function increases then decreases.

**Example.** y = x² − 4x + 7. x₀ = 4 / 2 = 2 and y₀ = 4 − 8 + 7 = 3. The vertex is (2, 3), the axis is x = 2, and the minimum value is 3.

To sketch a parabola: find the vertex, the zeros (if any), the point (0, c) and its mirror image across the axis.
