# Свойства параболы

Для y = ax² + bx + c абсцисса **вершины** равна x₀ = −b / (2a). Подставив x₀ в формулу, находим y₀. Вертикальная прямая x = x₀ — **ось симметрии** параболы.

Если a > 0, вершина — самая низкая точка, y₀ — **наименьшее** значение; функция убывает при x < x₀ и возрастает при x > x₀. Если a < 0, вершина — самая высокая точка, y₀ — **наибольшее** значение; функция сначала возрастает, потом убывает.

**Пример.** y = x² − 4x + 7. x₀ = 4 / 2 = 2, y₀ = 4 − 8 + 7 = 3. Вершина — (2; 3), ось симметрии — x = 2, наименьшее значение равно 3.

Чтобы построить параболу, найдите вершину, нули (если они есть), точку (0; c) и симметричную ей относительно оси точку.
