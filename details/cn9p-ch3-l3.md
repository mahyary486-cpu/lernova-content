# 电流的测量与规律

## 电流的单位

电流用符号 I 表示，单位是**安培**（A）。

1 A = 10³ mA = 10⁶ μA。

## 电流表的使用

1. **串联**在被测电路中；
2. 电流从"+"接线柱流入，"−"接线柱流出；
3. 被测电流不能超过电流表的量程，不知道大小时先用大量程**试触**；
4. **绝对不允许**把电流表直接接在电源两极上（电流表内阻很小，会烧坏）。

## 串、并联电路中电流的规律

- 串联电路：电流**处处相等**，I = I₁ = I₂；
- 并联电路：干路电流等于各支路电流**之和**，I = I₁ + I₂。

**例：** 并联电路中，干路电流为 0.9 A，一条支路的电流为 0.4 A，则另一条支路的电流为 0.9 − 0.4 = 0.5 A。
