# Abstände und Winkel

## Abstand Punkt–Ebene

Für E: ax + by + cz = d und P(x₀; y₀; z₀):

**Abstand = Betrag(ax₀ + by₀ + cz₀ − d) : Betrag(n)**

- Ursprung und 3x + 4y = 10: 10 : 5 = 2
- P(1; 0; 0) und x + y + z = 4: 3 : √3 = √3 ≈ 1,73
- P(2; 2; 1) und 2x + 2y + z = 0: 9 : 3 = 3

## Abstand paralleler Ebenen

x + y + z = 1 und x + y + z = 4: Betrag(4 − 1) : √3 = √3.

## Lotfußpunkt und Spiegelung

- **Lotfußpunkt:** Lotgerade durch P mit Richtung n mit der Ebene schneiden. Für P(1; 1; 1) und x + y + z = 0 ergibt sich (0; 0; 0).
- **Spiegelpunkt:** P′ = P + 2 · (Lotfußpunkt − P). Spiegelung von (1; 2; 3) an z = 0 ergibt (1; 2; −3).

## Winkel

- **Zwei Ebenen:** Winkel zwischen den Normalenvektoren (spitzer Winkel). x + y + z = 3 und z = 0: cos φ = 1/√3, also φ ≈ 54,7°.
- **Gerade und Ebene:** **sin φ = Betrag(u · n) : (Betrag(u) · Betrag(n))**. Gerade mit Richtung (1; 1; 1) und z = 0: φ ≈ 35,3°.

## Volumen

- **Spat:** Betrag des Spatprodukts (a × b) · c
- **Tetraeder:** ein Sechstel davon. O, (1; 0; 0), (0; 1; 0), (0; 0; 1) ergeben 1/6.
