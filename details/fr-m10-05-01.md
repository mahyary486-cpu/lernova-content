# Repère du plan : coordonnées, milieu et distance

## Repère
Un repère du plan est formé d’une origine O et de deux axes. Il est orthonormé si les axes sont perpendiculaires et ont la même unité de longueur. Un point M a pour coordonnées (x ; y).

## Milieu d’un segment
Si A(xA ; yA) et B(xB ; yB), le milieu I de [AB] a pour coordonnées
((xA + xB)/2 ; (yA + yB)/2).
Exemple : A(2 ; 4) et B(6 ; 0) donnent I(4 ; 2).
Pour trouver B quand on connaît A et le milieu I : xB = 2xI − xA et yB = 2yI − yA. Avec A(−1 ; 2) et I(1 ; 3), on obtient B(3 ; 4).

## Distance (repère orthonormé)
AB = √((xB − xA)² + (yB − yA)²).
Exemple : A(1 ; 2) et B(4 ; 6) donnent AB = √(9 + 16) = 5.
Exemple : A(2 ; 1) et B(6 ; 3) donnent AB = √(16 + 4) = √20 = 2√5.

## Nature d’un triangle
On calcule les trois longueurs. Si AB² + AC² = BC², le triangle est rectangle en A (réciproque de Pythagore). Si deux longueurs sont égales, il est isocèle.
Exemple : A(0 ; 0), B(3 ; 0), C(0 ; 4) : AB² + AC² = 9 + 16 = 25 = BC², donc rectangle en A.

## Erreur fréquente
La formule de distance suppose un repère orthonormé. Ne pas oublier la racine carrée à la fin.
