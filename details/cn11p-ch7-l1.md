# 交变电流的产生与描述

## 产生

线圈在匀强磁场中绕垂直于磁场的轴**匀速转动**，产生正弦交变电流。从**中性面**开始计时：

**e = Eₘ sin ωt**，其中 **Eₘ = nBSω**

- 中性面：线圈平面与磁场垂直，磁通量最大，电动势为 0。

## 描述的物理量

- 周期 T、频率 f，ω = 2π / T = 2πf；
- 我国民用交流电：**f = 50 Hz**，T = 0.02 s，ω = 100π rad/s。

## 有效值

让交流电和直流电通过同一电阻，在相同时间内产生的热量相等，这个直流电的值叫交流电的有效值。

正弦交流电：**E = Eₘ / √2**，U = Uₘ / √2，I = Iₘ / √2。

**例：** 电压峰值 311 V，有效值 U = 311 / 1.414 ≈ 220 V。

家庭电路的 220 V 是**有效值**，峰值 220√2 ≈ 311 V。

电表的读数、电器铭牌上的数值、计算热量和电功率，都用有效值。
