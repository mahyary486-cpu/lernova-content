# Arithmetic progression and the nth term

An arithmetic progression (AP) is a list of numbers where each term is obtained by adding a fixed number d, the common difference, to the previous term: a, a + d, a + 2d, …

The nth term is aₙ = a + (n − 1)d. For d > 0 the AP increases, for d < 0 it decreases and for d = 0 it is constant.
