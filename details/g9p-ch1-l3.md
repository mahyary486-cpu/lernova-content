# Scientific Notation and Significant Figures

Physics deals with numbers that are far too large or too small to write comfortably: the distance to the Sun is about 150,000,000,000 m and the mass of a dust particle can be 0.000000001 kg. Writing so many zeros is slow and easy to get wrong. Scientific notation solves this problem. A second problem is how much a measured number can be trusted, and significant figures solve that.

## Key ideas

In scientific notation a number is written as a x 10^n, where a is a number from 1 up to (but not including) 10 and n is a whole number. To write 45,000,000 you move the decimal point seven places to the left, which gives 4.5 x 10^7. To write 0.00032 you move the decimal point four places to the right, which gives 3.2 x 10^-4. A simple rule helps: a large number has a positive exponent and a number smaller than one has a negative exponent. A number like 12 x 10^3 is not in proper scientific notation because 12 is not between 1 and 10; it should be written 1.2 x 10^4.

When you multiply numbers written this way, you multiply the front numbers and add the exponents. When you divide, you divide the front numbers and subtract the exponents. This makes calculations with very large or small values much easier.

Significant figures show how precise a measurement is. The digits that are known for certain, plus the one estimated digit, are the significant figures. There are simple rules for counting them. Every nonzero digit is significant. Zeros between nonzero digits are significant, so 2.003 has four. Leading zeros, which only show the position of the decimal point, are never significant, so 0.00450 has three significant figures (4, 5 and the final 0). Trailing zeros count only when the number has a decimal point, so 1200 with no decimal point is counted as having two significant figures, while 1200. has four. Exact numbers, such as 12 eggs in a dozen or the defined fact that 100 cm equal 1 m, have unlimited significant figures.

When you calculate with measurements, the answer cannot be more precise than the data. For multiplication and division, the answer keeps as many significant figures as the measurement with the fewest. For addition and subtraction, the answer keeps as many decimal places as the number with the fewest decimal places. You should round only at the end, because rounding in the middle of a long calculation adds errors.

## Worked examples

**Example 1: Writing in scientific notation.** Write 45,000,000 and 0.00032 in scientific notation.
1. For 45,000,000, move the decimal point 7 places to the left to get a number between 1 and 10: 4.5.
2. Because the number is large, the exponent is positive: 4.5 x 10^7.
3. For 0.00032, move the decimal point 4 places to the right to get 3.2. The number is small, so the exponent is negative: 3.2 x 10^-4.

**Example 2: Counting significant figures.** How many significant figures are in 0.00450, 1200 and 2.003?
1. In 0.00450 the zeros at the front do not count. The digits 4, 5 and the last 0 do count because the number has a decimal point, so there are 3 significant figures.
2. In 1200, with no decimal point, the trailing zeros do not count. Only 1 and 2 are significant, so there are 2.
3. In 2.003 the zeros lie between nonzero digits, so all four digits count.

**Example 3: Multiplying measurements.** A rectangle is 3.2 m long and 1.25 m wide. Find its area with the correct number of significant figures.
1. Multiplying gives 3.2 x 1.25 = 4.00.
2. The length 3.2 has 2 significant figures and the width 1.25 has 3. The answer may have only as many as the less precise number, which is 2.
3. The area is 4.0 m^2.

## Common mistakes

Students often count leading zeros as significant, which makes a measurement look more precise than it is. Another mistake is to write 12 x 10^3 and call it scientific notation; the first number must be between 1 and 10. Many people copy every digit from the calculator display, but the display shows more digits than the measurements justify. Rounding too early, for example after each step of a long calculation, can also change the final answer, so keep extra digits until the end.
