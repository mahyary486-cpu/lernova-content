# Scientific Notation and Significant Figures

Very large and very small numbers are easier to read in scientific notation. Significant figures tell the reader how much of a number can be trusted.

## Key ideas
- **Scientific notation**: a x 10^n where 1 <= a < 10 and n is a whole number. 45,000,000 = 4.5 x 10^7 and 0.00032 = 3.2 x 10^-4.
- **Significant figures** rules: nonzero digits count; zeros between nonzero digits count; leading zeros never count; trailing zeros count only if the number has a decimal point.
- **Multiply or divide**: the answer has the same number of significant figures as the factor with the fewest.
- **Add or subtract**: the answer has the same number of decimal places as the number with the fewest decimal places.
- **Exact numbers** (like 12 eggs) and defined conversions (like 100 cm = 1 m) have unlimited significant figures.
- With powers of ten: multiply the numbers and add the exponents; divide the numbers and subtract the exponents.

## Worked examples
**Example 1: Writing in scientific notation.** Write 45,000,000 and 0.00032 in scientific notation.
1. Move the decimal in 45,000,000 seven places left: 4.5 x 10^7.
2. Move the decimal in 0.00032 four places right: 3.2 x 10^-4.

**Example 2: Counting significant figures.** How many significant figures are in 0.00450, 1200 and 2.003?
1. 0.00450: the leading zeros do not count, 4 5 0 count, so 3 figures.
2. 1200 with no decimal point: only 1 and 2 count, so 2 figures.
3. 2.003: the zeros are between nonzero digits, so 4 figures.

**Example 3: Multiplying measurements.** A rectangle is 3.2 m by 1.25 m. Find its area with the correct significant figures.
1. 3.2 x 1.25 = 4.00.
2. 3.2 has 2 significant figures and 1.25 has 3, so the answer has 2.
3. Area = 4.0 m^2.

## Common mistakes
- Counting leading zeros as significant.
- Writing 12 x 10^3 as scientific notation. The first number must be between 1 and 10.
- Keeping every digit shown on the calculator display.
- Rounding too early in a long calculation.
