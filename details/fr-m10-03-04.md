# Fonctions paires et fonctions impaires

## Définitions
Soit f définie sur un ensemble D tel que, si x est dans D, alors −x est aussi dans D.
- f est paire si f(−x) = f(x) pour tout x de D. Sa courbe est symétrique par rapport à l’axe des ordonnées.
- f est impaire si f(−x) = −f(x) pour tout x de D. Sa courbe est symétrique par rapport à l’origine du repère.

## Exemples
- f(x) = x² est paire : (−x)² = x².
- f(x) = ∣x∣ est paire.
- f(x) = x³ est impaire : (−x)³ = −x³.
- f(x) = 1/x est impaire.
- f(x) = x³ − x est impaire : f(−x) = −x³ + x = −f(x).
- f(x) = x² + 1 est paire. f(x) = x³ + 1 n’est ni paire ni impaire.

## Conséquences
- Si f est paire et f(−3) = 7, alors f(3) = 7.
- Si f est impaire et f(2) = 5, alors f(−2) = −5.
- Si f est impaire et définie en 0, alors f(0) = 0.

## Méthode
On calcule f(−x), on le simplifie et on le compare à f(x) et à −f(x).

## Erreur fréquente
Une fonction peut n’être ni paire ni impaire. Pour le montrer, un seul contre-exemple suffit.
