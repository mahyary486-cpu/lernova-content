# 函数性质的综合应用

## 单调性与奇偶性

- 偶函数 f(x) 在 [0, +∞) 单调递增：f(a) < f(b) ⇔ **|a| < |b|**；
- 奇函数在对称区间上的单调性相同。

**例：** 偶函数 f(x) 在 [0, +∞) 单调递增，解 f(2x − 1) < f(3)：

|2x − 1| < 3，−3 < 2x − 1 < 3，所以 −1 < x < 2。

## 周期性

- f(x + T) = f(x)：T 是周期；
- f(x + a) = −f(x)：周期 T = 2a。

**例：** f(x + 2) = −f(x)，f(1) = 3，则 f(x + 4) = f(x)，f(5) = f(1) = 3。

## 对称性

- f(a + x) = f(a − x)：图象关于直线 x = a 对称；
- f(a + x) + f(a − x) = 2b：图象关于点 (a, b) 对称。

## 综合思路

先判断奇偶性、周期性，把自变量化到已知区间上，再用单调性比较大小或解不等式。
