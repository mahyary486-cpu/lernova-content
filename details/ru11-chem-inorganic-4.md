# Генетическая связь классов веществ

**Генетический ряд металла:** металл → основный оксид → основание → соль. Например: Ca → CaO → Ca(OH)₂ → CaCO₃. При реакции CaO + H₂O образуется Ca(OH)₂.

**Генетический ряд неметалла:** неметалл → кислотный оксид → кислота → соль. Например, S → SO₂ → H₂SO₃ → Na₂SO₃.

**Амфотерные** оксиды и гидроксиды (Al, Zn, Cr) реагируют и с кислотами, и со щелочами.

**Примеры.** SO₃ — кислотный оксид, Na₂O — основный, Al₂O₃ — амфотерный. Для вычисления по уравнению: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl. Из 0,1 моль Na₂SO₄ получается 0,1 моль BaSO₄ массой 23,3 г (M = 233 г/моль).

**Различение ионов.** Хлорид-ион даёт с AgNO₃ белый осадок AgCl, а бромид-ион — светло-жёлтый осадок AgBr.
