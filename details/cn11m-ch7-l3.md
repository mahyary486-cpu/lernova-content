# 二项分布与正态分布

## 二项分布

做 n 次独立重复试验，每次成功的概率为 p，成功的次数 X 服从**二项分布**，记作 X ~ B(n, p)：

**P(X = k) = Cₙᵏ pᵏ (1 − p)ⁿ⁻ᵏ**（k = 0, 1, …, n）

- 期望 **E(X) = np**；
- 方差 **D(X) = np(1 − p)**。

**例 1：** 投篮命中率 0.6，投 3 次恰好命中 2 次：C₃² × 0.6² × 0.4 = 3 × 0.36 × 0.4 = 0.432。

**例 2：** X ~ B(10, 0.3)：E(X) = 3，D(X) = 10 × 0.3 × 0.7 = 2.1。

## 正态分布

X ~ N(μ, σ²)：曲线呈"钟形"，关于直线 x = μ 对称，μ 是期望，σ² 是方差。

**3σ 原则**：

- P(μ − σ ≤ X ≤ μ + σ) ≈ 0.6827；
- P(μ − 2σ ≤ X ≤ μ + 2σ) ≈ 0.9545；
- P(μ − 3σ ≤ X ≤ μ + 3σ) ≈ 0.9973。

**例：** μ = 100，σ = 10，P(90 ≤ X ≤ 110) ≈ 0.6827。
