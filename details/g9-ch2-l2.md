# Slope and Rate of Change

## What slope means
Slope tells you how much y changes when x increases by 1.

**slope = rise / run = (y2 - y1) / (x2 - x1)**

## Reading the sign
- Positive slope: the line goes **up** from left to right.
- Negative slope: the line goes **down** from left to right.
- Zero slope: a **horizontal** line (y = a number).
- Undefined slope: a **vertical** line (x = a number), because the run is 0.

## Worked examples
**Example 1.** Through (0, 0) and (2, 4): slope = (4 - 0) / (2 - 0) = 2.

**Example 2.** Through (1, 3) and (3, 11): slope = (11 - 3) / (3 - 1) = 8 / 2 = 4.

**Example 3.** Through (2, 5) and (6, 1): slope = (1 - 5) / (6 - 2) = -4 / 4 = -1.

**Example 4.** Through (-2, 3) and (4, -9): slope = (-9 - 3) / (4 - (-2)) = -12 / 6 = -2.

**Example 5.** A line rises 3 units for every 6 units to the right: slope = 3 / 6 = 1/2.

## Steepness
Compare the **absolute values** of slopes. A line with slope -5 is steeper than a line with slope 4, because 5 is greater than 4. The sign only tells you the direction.

## Finding a missing coordinate
The line through (2, k) and (5, 12) has slope 3. Then (12 - k) / (5 - 2) = 3, so 12 - k = 9 and k = 3.

## Common mistakes
- Subtracting in a different order on top and bottom. Use the same order for both.
- Mixing up rise and run (writing run / rise).
- Saying a vertical line has slope 0. It is undefined; a horizontal line has slope 0.
