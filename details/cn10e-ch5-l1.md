# 条件句中的虚拟语气

条件句分为**真实条件句**和**虚拟条件句**。虚拟条件句表示与事实**相反**或**不太可能**发生的假设。

## 与现在事实相反

**If + 过去式（be 用 were），主句：would / could / might + 动词原形**

- If I **were** you, I **would study** harder.
- If he **worked** harder, he **would pass** the exam.（事实：他不努力）

## 与过去事实相反

**If + had done，主句：would / could / might + have done**

- If I **had studied** harder, I **would have passed** the exam.（事实：没努力，没通过）

## 与将来事实可能相反

**If + 过去式 / should do / were to do，主句：would / should / could + 动词原形**

- If it **should rain** tomorrow, we **would stay** at home.
- If I **were to** win the lottery, I **would travel** around the world.

## 与真实条件句的对比

| 类型 | 例句 |
|---|---|
| 真实条件 | If it rains tomorrow, we **will stay** at home. |
| 虚拟条件 | If it rained tomorrow, we **would stay** at home. |

## 错综时间

前后时间不一致：If I **had taken** his advice, I **would be** better now.
