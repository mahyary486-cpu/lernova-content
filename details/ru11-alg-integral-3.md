# Площадь криволинейной трапеции

Площадь фигуры, ограниченной графиком непрерывной функции y = f(x) ≥ 0, осью x и прямыми x = a, x = b, равна **S = ∫ₐᵇ f(x) dx**.

**Пример.** Площадь под параболой y = x² на [0; 2]: S = 2³ / 3 = 8/3.

**Площадь между кривыми.** Если f(x) ≥ g(x) на [a; b], то S = ∫ₐᵇ (f(x) − g(x)) dx.

**Пример.** Фигура между y = x и y = x² на [0; 1]: S = ∫₀¹ (x − x²) dx = 1/2 − 1/3 = 1/6.
