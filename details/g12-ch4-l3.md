# Right Triangle and Reciprocal Trigonometry

For an acute angle in a right triangle, the trigonometric ratios compare side lengths. They agree with the unit circle values for angles between 0 and 90 degrees.

## Key ideas
Label the sides relative to the angle theta: opposite, adjacent and hypotenuse.
- sin theta = opposite / hypotenuse
- cos theta = adjacent / hypotenuse
- tan theta = opposite / adjacent
- **Reciprocal functions:** csc theta = 1/sin theta, sec theta = 1/cos theta, cot theta = 1/tan theta = cos theta / sin theta.
- **Cofunctions:** sin theta = cos(90 degrees - theta), tan theta = cot(90 degrees - theta), sec theta = csc(90 degrees - theta).
- The Pythagorean theorem a^2 + b^2 = c^2 finds a missing side.
- **Angle of elevation** is measured up from the horizontal; **angle of depression** is measured down from the horizontal.

## Worked examples
**Example 1: All six ratios.** In a right triangle with legs 5 and 12, find the six ratios for the angle A opposite the side 5.
1. Hypotenuse = sqrt(25 + 144) = 13.
2. sin A = 5/13, cos A = 12/13, tan A = 5/12.
3. csc A = 13/5, sec A = 13/12, cot A = 12/5.

**Example 2: From one ratio.** If sin theta = 3/5 and theta is acute, find the rest.
1. Opposite = 3, hypotenuse = 5, so adjacent = sqrt(25 - 9) = 4.
2. cos theta = 4/5, tan theta = 3/4.
3. csc theta = 5/3, sec theta = 5/4, cot theta = 4/3.

**Example 3: Height.** From 50 m away from the base of a tower, the angle of elevation to the top is 35 degrees.
1. tan 35 degrees = height / 50.
2. height = 50 x tan 35 degrees = 50 x 0.7002, about 35.0 m.

## Special values
sin 30 degrees = 1/2, so csc 30 degrees = 2. cos 45 degrees = sqrt(2)/2, so sec 45 degrees = sqrt(2). tan 60 degrees = sqrt(3), so cot 60 degrees = sqrt(3)/3.

## Common mistakes
- Mixing up which side is opposite and which is adjacent.
- Thinking csc is the inverse of cos. Csc is the reciprocal of sin, sec of cos.
- Using a calculator in the wrong mode (degrees versus radians).
- Using sin^(-1) on a calculator when the reciprocal 1/sin is wanted.
