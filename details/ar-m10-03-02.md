# Fórmula resolvente

## Fórmula
x = (−b ± √(b² − 4ac)) / (2a)

## Ejemplo
2x² − 3x − 5 = 0: a = 2, b = −3, c = −5.
Δ = 9 + 40 = 49, √Δ = 7.
x = (3 ± 7)/4 → x₁ = 5/2 y x₂ = −1.

## Relaciones de Cardano–Vieta
- x₁ + x₂ = −b/a.
- x₁ · x₂ = c/a.
En el ejemplo: 5/2 + (−1) = 3/2 = −(−3)/2 ✓.

## Error frecuente
Olvidar el signo de b: si b = −3, entonces −b = +3.
