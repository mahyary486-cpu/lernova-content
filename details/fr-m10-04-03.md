# Fonctions inverse et cube

## Fonction inverse
f(x) = 1/x, définie sur ℝ privé de 0.
- Elle est impaire : 1/(−x) = −1/x.
- Elle est décroissante sur ]−∞ ; 0[ et sur ]0 ; +∞[.
- Sa courbe est une hyperbole qui ne coupe aucun axe.
- Si 0 < a < b, alors 1/a > 1/b.

## Attention
La fonction inverse n’est pas décroissante sur ℝ privé de 0 tout entier : 1/(−1) = −1 est plus petit que 1/1 = 1 alors que −1 < 1.

## Exemples
- 1/x ≥ 1 avec x > 0 : x ∈ ]0 ; 1].
- Si x ∈ [2 ; 5], alors 1/x ∈ [1/5 ; 1/2].

## Fonction cube
g(x) = x³, définie sur ℝ.
- Elle est impaire.
- Elle est croissante sur ℝ.
- x³ a le même signe que x.
Sa courbe passe par l’origine avec un point d’inflexion en O.

## Comparaison
Pour a < b, on a a³ < b³ (contrairement au carré, la fonction cube ne change pas de sens de variation).

## Erreur fréquente
Penser que x³ est toujours positif : (−2)³ = −8.
