# Sequences and Series Review

A **sequence** is an ordered list of numbers a1, a2, a3, ... A **series** is the sum of the terms of a sequence. This lesson reviews the two main types and the sigma notation used to write sums.

## Arithmetic sequences
Each term is the previous term plus a constant **common difference d**.
- nth term: **an = a1 + (n - 1)d**
- Sum of the first n terms: **Sn = n(a1 + an) / 2**

## Geometric sequences
Each term is the previous term times a constant **common ratio r**.
- nth term: **an = a1 x r^(n-1)**
- Sum of the first n terms (r not 1): **Sn = a1(1 - r^n) / (1 - r)**
- Infinite sum, only when |r| is less than 1: **S = a1 / (1 - r)**. If |r| is 1 or more, the infinite series has no finite sum (it diverges).

## Sigma notation
The sum of f(k) for k from 1 to n means f(1) + f(2) + ... + f(n). The index k starts at the lower number and stops at the upper number. For example, the sum of (2k + 1) for k = 1 to 4 is 3 + 5 + 7 + 9 = 24.

## Worked examples
1. Find the 20th term of 5, 8, 11, ...
   1. d = 8 - 5 = 3 and a1 = 5.
   2. a20 = 5 + 19 x 3 = 62.
2. Find the sum of the first 8 terms of 3, 6, 12, ...
   1. r = 2 and a1 = 3.
   2. S8 = 3(1 - 2^8) / (1 - 2) = 3 x 255 = 765.
3. Find the sum of 8 + 4 + 2 + 1 + ... forever.
   1. r = 1/2, so |r| < 1 and the sum exists.
   2. S = 8 / (1 - 1/2) = 16.
4. Find the sum of the first 30 positive integers.
   1. This is arithmetic with a1 = 1, a30 = 30.
   2. S30 = 30(1 + 30) / 2 = 465.

## Recursive and explicit rules
An **explicit** rule gives an directly from n, such as an = 4n - 1. A **recursive** rule gives each term from earlier terms, such as a1 = 3 and an = a(n-1) + 4.

## Common mistakes
- Using n instead of n - 1 in the nth term formulas.
- Using the infinite sum formula when |r| is 1 or more.
- Miscounting terms in sigma notation: k = 3 to 7 has 5 terms, not 4.
- Forgetting that the common ratio can be negative or a fraction.
