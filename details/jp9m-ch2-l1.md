# 平方根の意味と大小

## 平方根

2乗して a になる数を、a の**平方根**といいます。

- 正の数 a の平方根は、正と負の2つあり、絶対値が等しくなります。正の方を √a、負の方を −√a と書き、まとめて ±√a と表します。
- 0 の平方根は 0 だけです。
- 負の数の平方根は、実数の範囲にはありません。

**例：** 9 の平方根は ±3、2 の平方根は ±√2

## 根号の性質

a > 0 のとき

1. (√a)² = a、(−√a)² = a
2. √(a²) = a

**例：** √49 = 7、(√5)² = 5、√((−3)²) = 3

## 大小の比べ方

a、b が正の数で a < b ならば、√a < √b。2乗して比べると大小がわかります。

**例：** 3 と √10 → 3² = 9、(√10)² = 10 なので 3 < √10

## 整数部分

k² ≦ n < (k + 1)² のとき、√n の整数部分は k です。**例：** 25 ≦ 30 < 36 より √30 の整数部分は 5。
