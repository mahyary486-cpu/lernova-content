# Правила дифференцирования

**Таблица производных.**

- (xⁿ)′ = n · xⁿ⁻¹, поэтому (x²)′ = 2x, (x³)′ = 3x² и (1/x)′ = −1/x²
- (sin x)′ = cos x
- (cos x)′ = −sin x
- (c)′ = 0 и (cx)′ = c

**Правила.**

- (u + v)′ = u′ + v′
- (c · u)′ = c · u′
- (u · v)′ = u′v + uv′
- (u / v)′ = (u′v − uv′) / v²

**Примеры.** (x² + 3x)′ = 2x + 3. (x · sin x)′ = sin x + x cos x. Для f(x) = x³ − 3x получаем f′(x) = 3x² − 3 и f′(2) = 9. Для (x² + 1) / x производная равна (2x · x − (x² + 1)) / x² = (x² − 1) / x².
