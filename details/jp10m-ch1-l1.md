# 式の展開と因数分解

## 3次の公式

- (a + b)³ = a³ + 3a²b + 3ab² + b³、(a − b)³ = a³ − 3a²b + 3ab² − b³
- (a + b)(a² − ab + b²) = a³ + b³、(a − b)(a² + ab + b²) = a³ − b³

**例：** (x + 2)³ = x³ + 6x² + 12x + 8、x³ + 27 = (x + 3)(x² − 3x + 9)

## たすきがけ

ax² + bx + c の因数分解で、a = pq、c = rs と分けて、ps + qr = b となる組をさがす。

**例：** 3x² + 7x + 2 = (3x + 1)(x + 2)（3×2 + 1×1 = 7）

## 置きかえ・次数の低い文字で整理

- x + 1 = A とおくと、(x + 1)² − 5(x + 1) + 6 = (A − 2)(A − 3) = (x − 1)(x − 2)。
- x⁴ − 16 = (x² + 4)(x² − 4) = (x² + 4)(x + 2)(x − 2)。
