# Корни n-й степени

**Корнем n-й степени** из числа a, записываемым ⁿ√a, называют число, n-я степень которого равна a.

- При **нечётном** n корень существует для любого действительного a: ³√27 = 3 и ³√(−8) = −2.
- При **чётном** n корень существует только при a ≥ 0, причём ⁿ√a ≥ 0: ⁴√16 = 2.

**Свойства** (при a, b ≥ 0): ⁿ√(ab) = ⁿ√a · ⁿ√b и ⁿ√(a / b) = ⁿ√a / ⁿ√b.

**Пример.** √50 − √18 = 5√2 − 3√2 = 2√2.
