# Определение и свойства логарифма

**Логарифмом** числа b по основанию a (a > 0, a ≠ 1, b > 0) называют показатель степени, в которую нужно возвести a, чтобы получить b: log_a b = c, если a^c = b.

**Примеры.** log₂ 8 = 3, log₃ 81 = 4, log₅ 1 = 0, log_a a = 1, lg 1000 = 3 (десятичный логарифм).

**Основное логарифмическое тождество:** a^(log_a b) = b. Например, 2^(log₂ 5) = 5.

**Свойства.**

- log_a (xy) = log_a x + log_a y
- log_a (x / y) = log_a x − log_a y
- log_a xᵖ = p · log_a x
- формула перехода: log_a b = log_c b / log_c a

**Примеры.** log₂ 12 − log₂ 3 = log₂ 4 = 2. log₆ 4 + log₆ 9 = log₆ 36 = 2. log₉ 27 = log₃ 27 / log₃ 9 = 3 / 2. Если lg 2 = a, то lg 8 = 3a.
