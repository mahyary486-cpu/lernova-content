# Органическая химия

**Классы.** Алканы CₙH₂ₙ₊₂ (метан CH₄), алкены CₙH₂ₙ (этилен C₂H₄), спирты (–OH), альдегиды (–CHO), карбоновые кислоты (–COOH). Глюкоза C₆H₁₂O₆.

**Реакции.** Гидратация этилена даёт этанол: C₂H₄ + H₂O → C₂H₅OH. Альдегиды дают реакцию «серебряного зеркала». Кислота и спирт образуют сложный эфир.

**Горение метана:** CH₄ + 2O₂ → CO₂ + 2H₂O.
