# Fonction logarithme népérien : définition et propriétés algébriques

## Définition
La fonction exponentielle est continue, strictement croissante sur ℝ, à valeurs dans ]0 ; +∞[. Pour tout réel a > 0, l’équation e^x = a a une unique solution, notée ln a. La fonction ln est définie sur ]0 ; +∞[.
- e^(ln x) = x pour x > 0 ;
- ln(e^y) = y pour tout réel y.
Valeurs : ln 1 = 0 et ln e = 1.

## Propriétés algébriques (a > 0, b > 0, n entier)
- ln(ab) = ln a + ln b ;
- ln(1/a) = −ln a ;
- ln(a/b) = ln a − ln b ;
- ln(a^n) = n ln a ;
- ln(√a) = (1/2) ln a.

## Exemples
- ln 8 = ln(2³) = 3 ln 2.
- ln 6 − ln 2 = ln 3.
- ln(2) + ln(3) = ln 6.
- ln(1/e) = −1 et ln(e²) = 2.

## Domaine
Pour que ln(u(x)) existe, il faut u(x) > 0. Par exemple, ln(x − 3) est défini sur ]3 ; +∞[.

## Lien avec l’exponentielle
Les courbes de exp et de ln sont symétriques par rapport à la droite y = x.

## Équations de base
- ln x = a équivaut à x = e^a.
- e^x = b (b > 0) équivaut à x = ln b.

## Erreur fréquente
ln(a + b) n’est pas égal à ln a + ln b ; seul le produit se transforme en somme.
