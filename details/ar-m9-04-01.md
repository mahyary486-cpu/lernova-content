# Proporcionalidad directa y función lineal

## Función de proporcionalidad directa
f(x) = kx. El cociente f(x)/x es constante e igual a k. Su gráfico es una recta que pasa por el origen (0; 0).

## Función lineal
f(x) = mx + b, donde
- m es la pendiente,
- b es la ordenada al origen.

## Ejemplo
Un kilo de pan cuesta $3000. El costo de x kilos es C(x) = 3000x. Para 2,5 kg, C = $7500.

## Tabla de valores
Para f(x) = 2x + 1: f(0) = 1, f(1) = 3, f(2) = 5. Cada vez que x aumenta 1, f(x) aumenta 2.

## Error frecuente
Creer que toda función lineal es de proporcionalidad directa: solo lo es cuando b = 0.
