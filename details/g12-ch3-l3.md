# Harder Exponential Equations

## Same base after rewriting
Rewrite both sides with the same base, then set the exponents equal.
3^(2x + 1) = 81^(x - 1). Since 81 = 3^4: 3^(2x + 1) = 3^(4x - 4), so 2x + 1 = 4x - 4 and **x = 5/2**.

## Isolate, then take a logarithm
- 7 * 2^x = 56. Divide by 7: 2^x = 8, so **x = 3**.
- e^x = 7. Take ln: **x = ln 7**.
- e^x = 1/e = e^(-1), so **x = -1**.
- 2e^(3x) = 10. Divide by 2: e^(3x) = 5. Take ln: 3x = ln 5, so **x = (ln 5)/3**, about 0.54.

## Different bases
5^x = 2^(x + 1). Take ln of both sides: x ln 5 = (x + 1) ln 2. Collect the x terms: x ln 5 - x ln 2 = ln 2, so x(ln 5 - ln 2) = ln 2 and
**x = ln 2 / (ln 5 - ln 2)**, about 0.756.

## Quadratic form
Let u = e^x (or 2^x, 3^x ...) and solve for u first. Remember that u is always positive.

**e^(2x) - 5e^x + 6 = 0.** Let u = e^x: u^2 - 5u + 6 = 0, so (u - 2)(u - 3) = 0. Then e^x = 2 or e^x = 3, so **x = ln 2 or x = ln 3**.

**2^x + 2^(-x) = 5/2.** Let u = 2^x, so u + 1/u = 5/2. Multiply by 2u: 2u^2 - 5u + 2 = 0, so (2u - 1)(u - 2) = 0 and u = 1/2 or u = 2. Then **x = -1 or x = 1**.

## An application
How long for 100 dollars to grow to 200 dollars at 5% per year? 100(1.05)^t = 200, so 1.05^t = 2 and t = ln 2 / ln 1.05, about **14.2 years**.

## Common mistakes
- Taking the log of a sum term by term. First isolate the exponential.
- Solving u but forgetting to go back to x.
- Accepting u = negative or 0. Since e^x > 0, such a u gives no solution.
