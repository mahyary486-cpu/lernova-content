# Infinite Geometric Series

## When does an infinite series have a sum?
An infinite geometric series a_1 + a_1 r + a_1 r^2 + ... **converges** (has a finite sum) only when **|r| < 1**, that is, when -1 < r < 1. Then the terms get smaller and smaller.

**S = a_1 / (1 - r)**

If |r| ≥ 1 the series **diverges**: it has no finite sum.

## Examples
**8 + 4 + 2 + 1 + ...** a_1 = 8, r = 1/2. S = 8/(1 - 1/2) = **16**.

**1/3 + 1/9 + 1/27 + ...** a_1 = 1/3, r = 1/3. S = (1/3)/(2/3) = **1/2**.

**With a negative ratio.** 3 - 1 + 1/3 - ... has a_1 = 3 and r = -1/3. S = 3/(1 + 1/3) = 3/(4/3) = **9/4**.

**Sigma notation.** The sum from k = 1 to infinity of 5 (1/2)^(k-1) has a_1 = 5 and r = 1/2, so S = 5/(1/2) = **10**.

**Diverges.** 2 + 4 + 8 + ... has r = 2. Since |r| > 1 it has **no sum**. (The formula would give -2, which is meaningless here.)

## Repeating decimals as fractions
A repeating decimal is an infinite geometric series.
- 0.777... = 0.7 + 0.07 + 0.007 + ... with a_1 = 0.7 and r = 0.1. S = 0.7/0.9 = **7/9**.
- 0.2727... = 0.27 + 0.0027 + ... with a_1 = 0.27 and r = 0.01. S = 0.27/0.99 = 27/99 = **3/11**.

## Bouncing ball
A ball is dropped from 10 feet and bounces back to 60% of its previous height each time. The rebound heights are 6, 3.6, 2.16, ... with sum 6/(1 - 0.6) = 15 feet going up. The ball also falls the same distances, so the total distance is 10 + 2(15) = **40 feet**.

## When x is a variable
The series 1 + x + x^2 + ... converges to 1/(1 - x) only when |x| < 1.

## Common mistakes
- Using the formula when |r| ≥ 1.
- Forgetting that a negative r gives 1 - r = 1 + |r| in the denominator.
- Writing 0.777... as 7/10 or 7/99.
- Forgetting to count the fall and the rise separately in a bouncing problem.
