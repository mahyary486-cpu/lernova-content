# Inéquations produit et quotient

## Méthode
1. On met tout dans un membre pour comparer à 0.
2. On factorise et on repère les valeurs qui annulent chaque facteur.
3. On dresse le tableau de signes.
4. On lit les intervalles qui répondent à la question et on vérifie les bornes.

## Exemples
- (x − 3)(x + 2) > 0 : solution x ∈ ]−∞ ; −2[ ∪ ]3 ; +∞[.
- (x + 1)(x − 4) ≤ 0 : solution x ∈ [−1 ; 4], bornes incluses car l’inégalité est large.
- (x − 2)/(x + 1) ≥ 0 : x ∈ ]−∞ ; −1[ ∪ [2 ; +∞[. La borne −1 est exclue car elle annule le dénominateur.

## Avec un carré
x² ≥ 25 équivaut à (x − 5)(x + 5) ≥ 0, donc x ∈ ]−∞ ; −5] ∪ [5 ; +∞[.
x² ≤ 9 équivaut à x ∈ [−3 ; 3].

## Problème type
Un rectangle a un périmètre de 20 cm et une aire de 21 cm². Si x est la longueur, la largeur vaut 10 − x et x(10 − x) = 21, soit x² − 10x + 21 = 0, donc (x − 3)(x − 7) = 0. La longueur est 7 cm.

## Erreur fréquente
Pour une inéquation, on ne multiplie jamais les deux membres par une expression dont on ne connaît pas le signe : on passe par le tableau de signes.
