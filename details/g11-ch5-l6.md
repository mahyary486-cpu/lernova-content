# Solving Logarithmic Equations

## Method 1: rewrite in exponential form
If the equation has **one** logarithm, isolate it and convert.
- log_2(x) = 5 gives x = 2^5 = **32**.
- log_3(x + 1) = 2 gives x + 1 = 9, so **x = 8**.
- 2 log(x) = 6. Divide by 2: log(x) = 3, so x = 10^3 = **1000**.
- ln(x) = 2 gives **x = e^2**.

## Method 2: set the arguments equal
If both sides have a single log with the **same base**: log_b(M) = log_b(N) means M = N.
- log(3x - 2) = log(x + 6). So 3x - 2 = x + 6, and **x = 4**.

## Method 3: combine first
Use the properties to make a single logarithm, then use method 1.
**log_2(x) + log_2(x - 2) = 3.**
1. Product property: log_2(x(x - 2)) = 3.
2. Exponential form: x(x - 2) = 8, so x^2 - 2x - 8 = 0.
3. (x - 4)(x + 2) = 0, so x = 4 or x = -2.
4. **Check the domain.** For x = -2, log_2(-2) is not defined, so reject it. The solution is **x = 4**.

**log(x + 3) - log(x) = 1.** Quotient property: log((x + 3)/x) = 1, so (x + 3)/x = 10, giving x + 3 = 10x and **x = 1/3**.

## Always check for extraneous solutions
The argument of a logarithm must be **positive**. Put each answer into the original equation.
Example: log_3(x) + log_3(x - 8) = 2. Then x(x - 8) = 9, so x^2 - 8x - 9 = 0 and x = 9 or x = -1. Only **x = 9** works, because -1 makes log_3(-1) undefined.

## Applications
- **Decibels, pH and earthquakes** use logarithms. Every step of +1 on a base-10 scale means 10 times more.
- pH = -log[H+]. A solution with [H+] = 0.001 has pH = -log(10^-3) = **3**.

## Common mistakes
- Forgetting the domain check after combining logs.
- Writing log(x) + log(y) = log(x + y). It equals log(xy).
- Dropping the log from only one side when the other side is a plain number.
- Mixing up the base and the argument when writing the exponential form.
