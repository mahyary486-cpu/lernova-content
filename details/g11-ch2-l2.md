# Solving Quadratics by Factoring and Square Roots

## Zero Product Property
If A * B = 0, then A = 0 **or** B = 0. This is why factoring helps: write the equation as **(something) * (something) = 0** and set each factor equal to 0.

## Steps for factoring
1. Move every term to one side so the other side is 0.
2. Factor (greatest common factor first, then trinomial).
3. Set each factor equal to 0 and solve.

## Examples
- (x - 2)(x - 3) = 0 gives **x = 2 or x = 3**.
- x^2 - 4x = 0: factor out x, so x(x - 4) = 0. Then **x = 0 or x = 4**.
- x^2 + x - 12 = 0: find two numbers with product -12 and sum 1, which are 4 and -3. So (x + 4)(x - 3) = 0 and **x = -4 or x = 3**.
- 2x^2 + 7x + 3 = 0 factors as (2x + 1)(x + 3) = 0, so **x = -1/2 or x = -3**.
- x^2 - 2x = 8: move the 8 first. x^2 - 2x - 8 = 0, so (x - 4)(x + 2) = 0 and **x = 4 or x = -2**.

## The square root method
Use it when the equation has a squared expression and no middle term.
- x^2 = 49 gives **x = 7 or x = -7** (always both signs).
- (x - 2)^2 = 9 gives x - 2 = 3 or x - 2 = -3, so **x = 5 or x = -1**.
- 4x^2 - 25 = 0 gives 4x^2 = 25, then x^2 = 25/4, so **x = 5/2 or x = -5/2**.

## Checking
Put each answer back into the original equation. The solutions are also the **x-intercepts** of the graph.

## Common mistakes
- Setting the product equal to a number other than 0 and then factoring, for example x(x - 2) = 8 does **not** give x = 8.
- Forgetting the negative root when taking a square root.
- Dividing both sides by x, which loses the solution x = 0.
- Sign errors: the factor (x + 4) gives x = -4, not 4.
