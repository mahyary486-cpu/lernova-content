# 铁的单质、氧化物和氢氧化物

## 铁的性质

铁能与氧气、氯气、酸等反应。铁与水蒸气在高温下反应：

3Fe + 4H₂O（g）=(高温)= Fe₃O₄ + 4H₂

## 铁的氧化物

| 化学式 | 颜色 | 俗称或用途 |
|---|---|---|
| FeO | 黑色 | — |
| Fe₂O₃ | 红棕色 | 铁红，颜料 |
| Fe₃O₄ | 黑色 | 磁性氧化铁 |

## 铁的氢氧化物

- **Fe(OH)₂**：白色，Fe²⁺ + 2OH⁻ = Fe(OH)₂↓；
- **Fe(OH)₃**：红褐色，Fe³⁺ + 3OH⁻ = Fe(OH)₃↓。

Fe(OH)₂ 在空气中很快被氧化：

4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃

现象：白色沉淀 → 灰绿色 → **红褐色**。
