# 化学反应与热能

## 放热反应与吸热反应

**放热反应**（反应物总能量 > 生成物总能量）：

- 燃烧反应；
- 酸碱中和反应；
- 活泼金属与酸的反应；
- 大多数化合反应。

**吸热反应**（反应物总能量 < 生成物总能量）：

- Ba(OH)₂·8H₂O 与 NH₄Cl 的反应；
- 大多数分解反应；
- C 与 CO₂ 高温反应、C 与水蒸气高温反应。

## 反应热的计算

能量变化 = **断键吸收的总能量 − 成键放出的总能量**。

**例：** H₂ + Cl₂ = 2HCl：

- 断 1 mol H—H（436 kJ）和 1 mol Cl—Cl（243 kJ），吸收 679 kJ；
- 形成 2 mol H—Cl（2 × 431 = 862 kJ），放出 862 kJ；
- 放出的能量比吸收的多，净放出 862 − 679 = **183 kJ**。

## 能源

化石燃料（煤、石油、天然气）是不可再生能源；太阳能、风能、氢能是清洁能源。
