# Étude de la fonction ln : dérivée, variations et limites

## Dérivée
ln est dérivable sur ]0 ; +∞[ et (ln x)’ = 1/x. Comme 1/x > 0, ln est strictement croissante sur ]0 ; +∞[.

## Limites
- lim(x→+∞) ln x = +∞ ;
- lim(x→0+) ln x = −∞.
La courbe de ln admet l’axe des ordonnées (x = 0) comme asymptote verticale.

## Signe
- ln x < 0 pour 0 < x < 1 ;
- ln x = 0 pour x = 1 ;
- ln x > 0 pour x > 1.
Ainsi ln x > 0 équivaut à x > 1 ; ln x ≤ 1 équivaut à 0 < x ≤ e.

## Tangente en 1
f(1) = 0 et f’(1) = 1 : la tangente en 1 a pour équation y = x − 1. Comme ln est concave, ln x ≤ x − 1 pour tout x > 0.

## Exemples de dérivées
- (x ln x − x)’ = ln x + 1 − 1 = ln x.
- (ln x − x)’ = 1/x − 1 : positive pour x < 1, négative pour x > 1. Le maximum est ln 1 − 1 = −1 en x = 1.

## Comparaison
Pour a et b strictement positifs : ln a < ln b équivaut à a < b.

## Applications
Un capital de 1 000 € à 5 % par an double quand 1,05^n ≥ 2, c’est-à-dire n ≥ ln 2/ln 1,05 ≈ 14,2 : au bout de 15 ans.

## Erreur fréquente
Oublier que ln n’est définie que pour x > 0.
