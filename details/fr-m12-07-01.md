# Épreuves indépendantes, schéma de Bernoulli et loi binomiale

## Épreuves indépendantes
Deux épreuves sont indépendantes si le résultat de l’une n’influence pas la probabilité de l’autre. La probabilité d’une succession de résultats est le produit des probabilités de chaque résultat.
Exemple : P(deux Piles) = 0,3 × 0,3 = 0,09 pour une pièce truquée avec P(Pile) = 0,3.

## Schéma de Bernoulli
Une épreuve de Bernoulli a deux issues : succès (probabilité p) et échec (probabilité 1 − p). La répétition de n telles épreuves identiques et indépendantes forme un schéma de Bernoulli.

## Loi binomiale
Le nombre X de succès suit la loi binomiale B(n ; p) :
P(X = k) = C(n,k) × p^k × (1 − p)^(n − k), pour k de 0 à n.
Exemples :
- B(5 ; 0,5) : P(X = 5) = 0,5⁵ = 1/32.
- B(3 ; 0,2) : P(X = 0) = 0,8³ = 0,512.
- B(4 ; 0,5) : P(X = 2) = 6/16 = 0,375.
- B(4 ; 0,1) : P(X ≥ 1) = 1 − 0,9⁴ = 1 − 0,6561 = 0,3439.

## Espérance et variance
E(X) = np et V(X) = np(1 − p).
Exemple : B(20 ; 0,25) donne E(X) = 5 et V(X) = 20 × 0,25 × 0,75 = 3,75.
Si E(X) = 18 et V(X) = 7,2, alors 1 − p = 7,2/18 = 0,4, donc p = 0,6 et n = 30.

## Somme de variables de Bernoulli
Si X_1, …, X_n sont des variables de Bernoulli indépendantes de paramètre p, alors X = X_1 + … + X_n suit B(n ; p).
La somme de deux variables de Bernoulli indépendantes de paramètre 0,5 suit B(2 ; 0,5).

## Erreur fréquente
Les tirages sans remise ne sont pas indépendants : la loi n’est pas binomiale.
