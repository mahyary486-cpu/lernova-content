# فرمول کلی ریشه‌ها و دلتا

## این درس درباره‌ی چیست؟

مربع کامل همیشه جواب می‌دهد، اما کمی طولانی است. اگر همان روش را یک بار روی معادله‌ی کلی ax² + bx + c = ۰ انجام دهیم، فرمولی به دست می‌آید که هر معادله‌ی درجه‌ی دوم را حل می‌کند.

## فرمول

مقدار **Δ = b² − ۴ac** را «دلتا» یا مبین معادله می‌نامیم. ریشه‌ها از این رابطه می‌آیند:

**x = (−b ± √Δ) / ۲a**

## دلتا به ما چه می‌گوید؟

قبل از حل کامل می‌توانیم از روی دلتا بفهمیم چند ریشه داریم:

- **Δ > ۰:** دو ریشه‌ی حقیقی متمایز
- **Δ = ۰:** یک ریشه‌ی مضاعف: x = −b/۲a
- **Δ < ۰:** هیچ ریشه‌ی حقیقی ندارد (چون ریشه‌ی دوم عدد منفی در اعداد حقیقی تعریف نمی‌شود)

## مثال ۱: دو ریشه

۲x² − ۵x − ۳ = ۰ → a = ۲، b = −۵، c = −۳
Δ = (−۵)² − ۴(۲)(−۳) = ۲۵ + ۲۴ = ۴۹، √Δ = ۷
x = (۵ ± ۷) / ۴ → x = ۳ یا x = −۰٫۵

## مثال ۲: یک ریشه

x² − ۶x + ۹ = ۰ → Δ = ۳۶ − ۳۶ = ۰
x = ۶/۲ = ۳ (ریشه‌ی مضاعف). توجه کنید که این معادله همان (x − ۳)² = ۰ است.

## مثال ۳: بدون ریشه‌ی حقیقی

x² + x + ۱ = ۰ → Δ = ۱ − ۴ = −۳ < ۰
در اعداد حقیقی جواب ندارد.

## کاربرد: پارامتر مجهول

**مسئله:** m چه مقداری باشد تا x² − ۴x + m = ۰ دقیقاً یک ریشه داشته باشد؟
شرط: Δ = ۰ → ۱۶ − ۴m = ۰ → m = ۴.

## مجموع و حاصل‌ضرب ریشه‌ها

اگر ریشه‌ها x₁ و x₂ باشند:

- **S = x₁ + x₂ = −b/a**
- **P = x₁ · x₂ = c/a**

**مثال:** در x² − ۷x + ۱۲ = ۰ داریم S = ۷ و P = ۱۲؛ ریشه‌ها ۳ و ۴ هستند (۳ + ۴ = ۷ و ۳ × ۴ = ۱۲).

این رابطه‌ها کمک می‌کنند بدون حل کامل، پاسخ را بررسی کنید.

## خطاهای رایج

- فراموش‌کردن علامت منفی b در −b
- محاسبه‌ی اشتباه b² وقتی b منفی است: (−۵)² برابر ۲۵ است، نه −۲۵
- برنداشتن معادله به شکل استاندارد پیش از شناسایی a و b و c

## جمع‌بندی

Δ = b² − ۴ac را حساب کنید؛ اگر منفی بود تمام. اگر نه، x = (−b ± √Δ)/۲a ریشه‌ها را می‌دهد. مجموع ریشه‌ها −b/a و حاصل‌ضربشان c/a است.
