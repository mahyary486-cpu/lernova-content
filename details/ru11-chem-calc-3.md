# Качественные реакции на ионы

- **Cl⁻:** AgNO₃ даёт белый творожистый осадок AgCl. **Br⁻** даёт светло-жёлтый осадок AgBr.
- **SO₄²⁻:** BaCl₂ даёт белый осадок BaSO₄.
- **CO₃²⁻:** при действии кислоты выделяется CO₂.
- **NH₄⁺:** со щёлочью при нагревании выделяется аммиак с резким запахом.
- **Fe³⁺:** со щёлочью даёт красно-бурый осадок Fe(OH)₃.
- **Cu²⁺:** со щёлочью даёт голубой осадок Cu(OH)₂.

**Индикаторы.** В щелочной среде фенолфталеин становится малиновым, лакмус — синим, а метиловый оранжевый — жёлтым.
