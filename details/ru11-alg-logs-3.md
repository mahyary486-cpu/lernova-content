# Логарифмические уравнения

Простейшее уравнение: log_a f(x) = log_a g(x) равносильно f(x) = g(x) при условии f(x) > 0 и g(x) > 0.

**Алгоритм.**

1. Найдите область допустимых значений (выражения под логарифмами положительны).
2. Преобразуйте уравнение (свойства логарифмов).
3. Решите полученное уравнение.
4. Проверьте корни по области допустимых значений.

**Примеры.**

- log₂ (x + 1) = 3 даёт x + 1 = 8, поэтому x = 7.
- log₃ x = −2 даёт x = 3⁻² = 1/9.
- log₃ x + log₃ (x − 2) = 1. Область: x > 2. Тогда x(x − 2) = 3, x² − 2x − 3 = 0, x = 3 или x = −1. Корень −1 не входит в область, поэтому x = 3.
- log₂ (x² − 3x) = 2 даёт x² − 3x = 4, откуда x = 4 или x = −1. Оба корня подходят, так как x² − 3x = 4 > 0.
