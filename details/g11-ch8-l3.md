# Trigonometric Functions of Any Angle

## Angles beyond 90°
An angle is in **standard position** when its vertex is at the origin and its initial side is on the positive x-axis. Positive angles turn counterclockwise, negative angles turn clockwise.

If the terminal side passes through the point (x, y) and r = sqrt(x² + y²), then
**sin θ = y/r, cos θ = x/r, tan θ = y/x.**

Example: the terminal side passes through (-3, 4). Then r = 5, so sin θ = **4/5**, cos θ = **-3/5**, tan θ = **-4/3**.

## Signs in the four quadrants
| Quadrant | Positive functions |
|---|---|
| I | all |
| II | sine (cos and tan are negative) |
| III | tangent (sin and cos are negative) |
| IV | cosine (sin and tan are negative) |

Memory aid: **All Students Take Calculus**.

## Reference angles
The **reference angle** is the acute angle between the terminal side and the x-axis. To find sin, cos or tan of any angle: use the reference angle's value, then apply the sign of the quadrant.
- 150°: reference angle **30°**, quadrant II. sin 150° = **1/2** (positive in QII), cos 150° = -sqrt(3)/2.
- 225°: reference angle 45°, quadrant III. cos 225° = **-sqrt(2)/2**.
- 300°: reference angle 60°, quadrant IV. tan 300° = **-sqrt(3)**.
- 210°: reference angle 30°, quadrant III. sin 210° = **-1/2**.
- 120°: reference angle 60°, quadrant II. cos 120° = **-1/2**.
- 5π/6: reference angle π/6.

## Coterminal angles
Angles that share the same terminal side differ by a multiple of 360° (or 2π). They have the same sine, cosine and tangent.
- 400° is coterminal with 400° - 360° = **40°**.
- -60° is coterminal with -60° + 360° = **300°**.

## Negative angles
- sin(-θ) = -sin θ, so sin(-30°) = **-1/2**.
- cos(-θ) = cos θ.

## Finding other values
If sin θ = 3/5 and θ is in quadrant II: the adjacent side is 4, and cosine is negative in QII, so cos θ = **-4/5**.

## Common mistakes
- Forgetting the sign of the quadrant.
- Using the angle instead of the reference angle for the value.
- Mixing up the reference angle with the coterminal angle.
