# Exponentialgleichungen und Anwendungen

## Exponentialgleichungen lösen

Eine Gleichung, in der die Unbekannte im Exponenten steht, löst man auf zwei Arten:

**1. Gleiche Basis (Exponentenvergleich):**

2ˣ = 32 → 2ˣ = 2⁵ → x = 5.
3ˣ = 1/9 → 3ˣ = 3⁻² → x = −2.
4ˣ = 2ˣ⁺³ → 2²ˣ = 2ˣ⁺³ → 2x = x + 3 → x = 3.

**2. Mit dem Logarithmus:**

aˣ = b ergibt **x = log_a(b) = lg(b) / lg(a)**.

Beispiel: 2ˣ = 10 ergibt x = lg(10)/lg(2) ≈ 3,32.

Hat die Gleichung einen Vorfaktor, isoliert man zuerst die Potenz: 3 · 2ˣ = 48 → 2ˣ = 16 → x = 4.

## Zinseszins

**K(n) = K₀ · (1 + p/100)ⁿ**

**Beispiel:** 1 000 € mit 3 % Zinsen, 2 Jahre: K = 1 000 · 1,03² = 1 060,90 €.

## Verdopplungszeit

Wann hat sich ein Kapital bei 4 % Zinsen verdoppelt? 1,04ⁿ = 2 ergibt n = ln(2)/ln(1,04) ≈ 17,7 Jahre.

Bei 5 %: 1,05ˣ = 2 ergibt x ≈ 14,2 Jahre.

## Halbwertszeit

Nach n Halbwertszeiten ist nur noch (1/2)ⁿ übrig.

- Halbwertszeit 8 Tage, Zeitraum 24 Tage: 3 Halbwertszeiten, also 1/8 = 12,5 %.
- Ein Wirkstoff halbiert sich alle 4 Stunden. 6,25 % = 1/16 = (1/2)⁴ sind nach 4 Halbwertszeiten, also nach 16 Stunden erreicht.

## Vorgehen bei Textaufgaben

1. Anfangswert und Wachstumsfaktor bestimmen.
2. Funktionsgleichung N(t) = N₀ · qᵗ aufstellen.
3. Gleichung lösen (gleiche Basis oder Logarithmus).
4. Antwortsatz mit Einheit schreiben.
