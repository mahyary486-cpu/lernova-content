# 標本調査の利用

## 池の魚の数を推定する

1. 池で a 匹をつかまえて印をつけ、池にもどす。
2. 十分にまざった後、b 匹をつかまえたら、印のついたものが c 匹いた。
3. 池の魚の数を N 匹とすると、印の割合が等しいと考えて a：N = c：b。
4. よって N = a × b ÷ c。

**例：** a = 60、b = 80、c = 6 → N = 60 × 80 ÷ 6 = 800 匹。

## 不良品の数の推定

製品 5000 個から 500 個を調べて不良品が 5 個だったとき、全体の不良品は約 5000 × 5/500 = 50 個。

## 無作為性のたいせつさ

標本が母集団をかたよりなく代表していなければ、推定の結果は信頼できません。標本の選び方に気をつけます。
