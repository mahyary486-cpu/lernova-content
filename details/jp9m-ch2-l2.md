# 根号を含む式の計算

## 乗法・除法

a > 0、b > 0 のとき

- √a × √b = √(ab)
- √a ÷ √b = √(a/b)

## 根号の外に出す

√(a²b) = a√b

**例：** √12 = √(2² × 3) = 2√3、√50 = 5√2

## 加法・減法

根号の中が同じ数どうしは、係数をまとめます。根号の中が違うときは、先に簡単にしてから考えます。

**例：** 3√2 + 5√2 = 8√2

**例：** √8 + √18 = 2√2 + 3√2 = 5√2

注意：√2 + √3 は √5 にはなりません。

## 展開

乗法公式が使えます。

- (√a + √b)(√a − √b) = a − b
- (√a + k)² = a + 2k√a + k²

**例：** (√3 + 1)² = 3 + 2√3 + 1 = 4 + 2√3
