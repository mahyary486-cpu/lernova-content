# Cortège électronique et tableau périodique

## Couches électroniques
Les électrons d’un atome (le cortège électronique) se répartissent sur des couches désignées par K, L, M… On remplit d’abord la couche K, puis L, puis M. Pour Z ≤ 18, les capacités sont :
- couche K : 2 électrons au maximum ;
- couche L : 8 électrons au maximum ;
- couche M : 8 électrons au maximum.
Exemples : H (Z = 1) : (K)¹ ; C (Z = 6) : (K)²(L)⁴ ; O (Z = 8) : (K)²(L)⁶ ; Na (Z = 11) : (K)²(L)⁸(M)¹ ; Cl (Z = 17) : (K)²(L)⁸(M)⁷.

## Électrons de valence
Les électrons de valence sont ceux de la dernière couche occupée (couche externe). Ils déterminent les propriétés chimiques. Exemple : le chlore a 7 électrons de valence.

## Le tableau périodique
- Les éléments sont rangés par numéro atomique Z croissant.
- Une ligne (période) correspond au remplissage d’une couche ; une colonne regroupe des éléments ayant le même nombre d’électrons de valence.
- Familles : alcalins (1 électron de valence : Li, Na, K), halogènes (7 : F, Cl, Br), gaz nobles (couche externe complète : He, Ne, Ar).
Les éléments d’une même famille ont des propriétés chimiques voisines.

## Stabilité des gaz nobles
Les gaz nobles (He : 2 électrons ; Ne, Ar : 8 électrons de valence) sont très stables et peu réactifs. Les autres atomes tendent à acquérir cette configuration : règle du duet (2 électrons) pour H, Li, Be, règle de l’octet (8 électrons) pour les autres.
