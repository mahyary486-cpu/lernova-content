# Balayage, dichotomie et recherche de racine

## Balayage
On calcule f(x) pour des valeurs régulièrement espacées et on repère l’intervalle où le signe change.
x = 0
while f(x) < 0:
    x = x + 0.1
On trouve ainsi un encadrement de la solution d’amplitude 0,1.

## Dichotomie
Pour f continue sur [a ; b] avec f(a) et f(b) de signes contraires :
1. On calcule le milieu m = (a + b)/2.
2. Si f(a) × f(m) ≤ 0, la solution est dans [a ; m] : b prend la valeur m.
3. Sinon, elle est dans [m ; b] : a prend la valeur m.
4. On recommence jusqu’à ce que b − a soit assez petit.

## Exemple : f(x) = x² − 2 sur [0 ; 4]
- m = 2, f(2) = 2 > 0 : la solution est dans [0 ; 2].
- m = 1, f(1) = −1 < 0 : la solution est dans [1 ; 2].
- m = 1,5, f(1,5) = 0,25 > 0 : la solution est dans [1 ; 1,5].
Après trois itérations, l’encadrement est [1 ; 1,5] ; la racine cherchée est √2 ≈ 1,414.

## Efficacité
Après n étapes, l’amplitude est (b − a)/2^n. Avec 10 étapes, on divise l’amplitude par 1 024.

## Compter dans un intervalle
c = 0
for i in range(1, 51):
    if i % 7 == 0:
        c = c + 1
c vaut 7 (les multiples de 7 jusqu’à 49).

## Erreur fréquente
La dichotomie ne fonctionne que si f est continue et change de signe sur [a ; b].
