# Dispersion, Color and the Electromagnetic Spectrum

A rainbow shows that white light is a mixture of colors, each bent by a slightly different amount.

## Key ideas
- **Dispersion**: n depends on wavelength; **violet** bends most, **red** least.
- **c = f lambda**; c = **3.00 x 10^8 m/s**.
- Spectrum order: **radio, microwave, infrared, visible, ultraviolet, X-ray, gamma**.
- Higher frequency = shorter wavelength = **higher photon energy**.
- Light primaries: **red, green, blue**.
- A colored object **reflects** its own color and absorbs the others.

## Worked examples
**Example 1: Wavelength.** A microwave has a frequency of 2.45 x 10^9 Hz.
1. lambda = c / f = 3.00 x 10^8 / 2.45 x 10^9.
2. lambda = 0.12 m.

**Example 2: Frequency.** Green light has lambda = 550 nm.
1. f = c / lambda = 3.00 x 10^8 / 5.5 x 10^-7.
2. f = 5.45 x 10^14 Hz.

**Example 3: Photon energy.** Compare ultraviolet and infrared photons.
1. Ultraviolet has a higher frequency.
2. So ultraviolet photons carry more energy (E = h f).

## Common mistakes
- Thinking red light bends most in a prism.
- Mixing up light and pigment primaries.
- Thinking radio waves are sound waves.
