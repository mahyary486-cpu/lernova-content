# Sommes de termes consécutifs et algorithmes de seuil

## Somme des entiers
1 + 2 + 3 + … + n = n(n + 1)/2.
Exemples : 1 + 2 + … + 10 = 55 et 1 + 2 + … + 100 = 5 050.

## Somme de termes d’une suite arithmétique
S = (nombre de termes) × (premier terme + dernier terme)/2.
Exemple : les 20 premiers termes (de u_0 à u_19) de u_0 = 1, r = 2 sont 1, 3, …, 39 : S = 20 × (1 + 39)/2 = 400.

## Somme de termes d’une suite géométrique
Pour q ≠ 1 : 1 + q + q² + … + q^n = (1 − q^(n+1))/(1 − q).
Exemples :
- 1 + 2 + 4 + 8 + 16 + 32 = (1 − 2^6)/(1 − 2) = 63.
- 1 + 3 + 9 + 27 + 81 = (1 − 3^5)/(1 − 3) = 121.

## Algorithme de seuil en Python
u = 1
n = 0
while u < 100:
    u = 2 * u
    n = n + 1
Avec u_0 = 1 et u_(n+1) = 2u_n, la boucle s’arrête quand u ≥ 100. Les valeurs sont 2, 4, 8, 16, 32, 64, 128 : n vaut 7 à la fin.

## Interprétation
n est le plus petit rang pour lequel u_n ≥ 100.

## Erreur fréquente
Compter le nombre de termes : de u_0 à u_n il y a n + 1 termes, pas n.
