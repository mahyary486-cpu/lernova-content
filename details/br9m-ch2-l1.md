# Resolução e fórmula de Bhaskara

## Forma geral

ax² + bx + c = 0, com **a ≠ 0**. Em x² − 5x + 6 = 0 temos a = 1, b = −5 e c = 6.

## Equações incompletas

- **b = 0:** x² − 9 = 0 → x² = 9 → x = ±3.
- **c = 0:** x² − 3x = 0 → x(x − 3) = 0 → x = 0 ou x = 3.

## Fórmula de Bhaskara

1. Calcule o discriminante: **Δ = b² − 4ac**.
2. Aplique: **x = (−b ± √Δ) / (2a)**.

## Exemplo

x² − 6x + 8 = 0 → Δ = 36 − 32 = 4 → x = (6 ± 2)/2, ou seja, x = 4 ou x = 2.

## Problema

Um retângulo tem lados x e x + 2 e área 24 m². Então x(x + 2) = 24 → x² + 2x − 24 = 0 → x = 4 (a raiz −6 não serve, pois x é medida de comprimento).
