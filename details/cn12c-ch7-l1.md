# 官能团转化与有机推断

## 基本转化链

乙烯 → 乙醇 → 乙醛 → 乙酸 → 乙酸乙酯

- 乙烯 + H₂O →(催化剂，加热加压) 乙醇；
- 乙醇 + O₂ →(Cu，△) 乙醛；
- 乙醛 + O₂ →(催化剂) 乙酸；
- 乙酸 + 乙醇 ⇌(浓硫酸，△) 乙酸乙酯 + 水。

## 卤代烃

- NaOH **水溶液**，加热：水解，生成醇；
- NaOH **醇溶液**，加热：消去，生成烯。

## 推断的突破口

- 能发生银镜反应：含**醛基**；
- 遇 FeCl₃ 显紫色：含**酚羟基**；
- 与 NaHCO₃ 反应放出 CO₂：含**羧基**；
- 与 Na 反应放出 H₂：含**羟基**或**羧基**；
- 使溴水褪色：含碳碳双键、三键或醛基（还原性）。

## 例题

A（C₂H₄）→ B（C₂H₅OH）→ C（CH₃CHO）→ D（CH₃COOH）；B + D → E（CH₃COOC₂H₅）。

推断时，也可以利用相对分子质量的变化（如 −2：醇变醛；+16：醛变酸）。
