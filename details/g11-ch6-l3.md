# Arithmetic Series and Sigma Notation

## Series
A **series** is the **sum** of the terms of a sequence. S_n is the sum of the first n terms.

## Sum of an arithmetic series
**S_n = n (a_1 + a_n) / 2**, or equivalently **S_n = (n/2)(2a_1 + (n - 1)d)**.
In words: the number of terms times the **average** of the first and last terms.

## Examples
**1 + 2 + ... + 100.** n = 100, a_1 = 1, a_100 = 100. S = 100(101)/2 = **5050**.

**3 + 7 + 11 + ... + 43.** d = 4, so 3 + 4(n - 1) = 43 gives n = 11. S_11 = 11(3 + 43)/2 = 11 * 23 = **253**.

**Using a_1 and d.** a_1 = 5, d = 3, n = 12. S_12 = (12/2)(2 * 5 + 11 * 3) = 6(43) = **258**.

**First 20 even positive integers.** 2 + 4 + ... + 40 = 20(2 + 40)/2 = **420**.

## Sigma notation
The symbol Σ means "add up". The sum from k = 1 to 5 of (2k + 1) is written with k = 1 below the sigma and 5 above it:
(2*1 + 1) + (2*2 + 1) + (2*3 + 1) + (2*4 + 1) + (2*5 + 1) = 3 + 5 + 7 + 9 + 11 = **35**.

- The sum from k = 3 to 6 of k^2 = 9 + 16 + 25 + 36 = **86**.
- The sum from k = 1 to 4 of 3 = 3 + 3 + 3 + 3 = **12** (a constant is added n times).

## Useful sum
The sum from k = 1 to n of k is **n(n + 1)/2**. For n = 30, this is 30(31)/2 = **465**.

## Properties
- Constants come out: the sum of c * a_k equals c times the sum of a_k.
- The sum splits: the sum of (a_k + b_k) equals the sum of a_k plus the sum of b_k.

## Common mistakes
- Counting the number of terms incorrectly. From k = 3 to 6 there are 6 - 3 + 1 = 4 terms.
- Using S_n = n(a_1 + a_n) without dividing by 2.
- Using the arithmetic sum formula for a geometric series.
