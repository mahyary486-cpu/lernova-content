# 部分倒装

**部分倒装**：把**助动词、情态动词或 be 动词**提到主语之前。

## 1. 否定词或半否定词位于句首

never, hardly, seldom, little, rarely, not only, no sooner ... than, hardly ... when, not until

- **Never have I** seen such a film.
- **Not only did he** come, but he also helped us.
- **Seldom does he** go out.
- **No sooner had I** arrived **than** it began to rain.

## 2. not until 位于句首

- **Not until midnight did he** go to bed.

注意：倒装的是**主句**，not until 引导的从句不倒装。

## 3. so / neither / nor 引起的倒装

表示"……也是这样"：

- — I like it. — **So do I**.
- — I don't like it. — **Neither / Nor do I**.

## 4. only + 状语位于句首

- **Only then did I** realize my mistake.
- **Only in this way can we** solve the problem.

## 倒装的方法

- 谓语有助动词 / 情态动词 / be：把它提到主语前；
- 谓语是实义动词：加 do / does / did，放在主语前，动词用原形。
