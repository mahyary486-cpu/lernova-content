# Fracciones y expresiones decimales

## Idea clave
Un número racional es el cociente de dos enteros, a/b con b ≠ 0. Su expresión decimal es exacta (por ejemplo 3/4 = 0,75) o periódica (por ejemplo 1/3 = 0,3333…).

## Método: de fracción a decimal
Se divide el numerador por el denominador. Si el denominador, una vez simplificada la fracción, solo tiene los factores 2 y 5, el decimal es exacto.

## Método: de decimal a fracción
- Decimal exacto: 0,35 = 35/100 = 7/20.
- Periódico puro: 0,7̂ = 7/9 y 0,36̂ = 36/99 = 4/11.
- Periódico mixto: 0,2̂5 → (25 − 2)/90 = 23/90 (en 0,25̂ el período es solo el 5).

## Ejemplos
- 5/8 = 0,625.
- 2,5 = 25/10 = 5/2.
- 0,1̂ + 0,2̂ = 1/9 + 2/9 = 3/9 = 1/3.

## Error frecuente
Creer que 0,9̂ es menor que 1. En realidad 0,9̂ = 9/9 = 1.
