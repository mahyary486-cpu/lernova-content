# Les trois identités remarquables

## Les égalités
Pour tous nombres a et b :
- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- (a + b)(a − b) = a² − b²

## Exemples de développement
- (x + 5)² = x² + 2 × x × 5 + 5² = x² + 10x + 25
- (2x − 3)² = (2x)² − 2 × 2x × 3 + 3² = 4x² − 12x + 9
- (x + 4)(x − 4) = x² − 16

## Calcul mental
- 101² = (100 + 1)² = 10 000 + 200 + 1 = 10 201
- 99² = (100 − 1)² = 10 000 − 200 + 1 = 9 801
- 51 × 49 = (50 + 1)(50 − 1) = 2 500 − 1 = 2 499

## Justification
(a + b)² = (a + b)(a + b) = a² + ab + ba + b² = a² + 2ab + b². On peut aussi le voir avec l’aire d’un carré de côté a + b découpé en quatre morceaux.

## Erreurs fréquentes
- (a + b)² n’est pas a² + b².
- Dans (a − b)², le terme b² est positif.
- Dans (a + b)(a − b), il n’y a pas de terme en x.
