# Produit scalaire : définitions et propriétés

## Définition
Pour deux vecteurs non nuls u et v formant un angle θ :
u·v = ‖u‖ × ‖v‖ × cos θ.
Si l’un des vecteurs est nul, u·v = 0.
Exemples : ‖u‖ = 4, ‖v‖ = 3, θ = 60° donnent u·v = 4 × 3 × 1/2 = 6 ; ‖u‖ = 5, ‖v‖ = 2, θ = 0 donnent 10 ; θ = 120° avec 5 et 2 donne 5 × 2 × (−1/2) = −5.

## Propriétés
- Symétrie : u·v = v·u.
- Bilinéarité : u·(v + w) = u·v + u·w et (k u)·v = k(u·v).
- u·u = ‖u‖².
- ‖u + v‖² = ‖u‖² + 2u·v + ‖v‖².

## Orthogonalité
Deux vecteurs non nuls sont orthogonaux si et seulement si u·v = 0. Exemple : ‖u‖ = 3, ‖v‖ = 4 et u·v = 0 donnent ‖u + v‖² = 9 + 16 = 25, donc ‖u + v‖ = 5.

## Signe
- u·v > 0 : l’angle est aigu.
- u·v < 0 : l’angle est obtus.
- u·v = 0 : l’angle est droit.

## Colinéarité
Si v = −3u avec ‖u‖ = 2 : u·v = −3‖u‖² = −12.

## Projeté orthogonal
Si H est le projeté orthogonal de C sur la droite (AB), alors AB→·AC→ = AB→·AH→.

## Erreur fréquente
Le produit scalaire de deux vecteurs est un nombre, pas un vecteur.
