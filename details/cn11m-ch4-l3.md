# 数列求和与递推

## Sₙ 与 aₙ 的关系

- a₁ = S₁；
- n ≥ 2 时，**aₙ = Sₙ − Sₙ₋₁**；
- 最后检验 n = 1 时是否满足。

**例：** Sₙ = n² + n：a₁ = 2；n ≥ 2 时 aₙ = n² + n − (n − 1)² − (n − 1) = 2n，a₁ = 2 也满足，所以 aₙ = 2n。

## 常用求和方法

- **裂项相消法**：1 / (n(n + 1)) = 1/n − 1/(n + 1)；
- **错位相减法**：用于 aₙ · bₙ（等差乘等比）型；
- **分组求和法**：把数列拆成几个容易求和的数列。

**例：** 1/(1×2) + 1/(2×3) + … + 1/(9×10) = (1 − 1/2) + (1/2 − 1/3) + … + (1/9 − 1/10) = 1 − 1/10 = 9/10。

## 累加法

aₙ₊₁ − aₙ = f(n) 型的递推，可写出 a₂ − a₁、a₃ − a₂、……，累加得 aₙ。
